문제 해설 — 밴드 이름·비밀번호 규칙·시저 암호 풀고 되돌리기 (2)

2026. 10. 26.

※ 이 글은 위키독스 『왕초보를 위한 Python』 5.3.2 연습 문제와 5.3.3·5.3.4 본문 예제를 제 나름의 언어로 풀어 설명한 것입니다. 문제 원문은 각 절의 링크에서 먼저 읽어 보세요. 코드는 이 글에서 새로 작성한 풀이이고, 실행 결과는 파이썬 3.14.7로 실제로 돌려서 넣었어요.

랜덤이 들어간 프로그램은 값이 아니라 규칙을 지키는지를 확인하고, 암호는 표를 뒤집으면 풀려요.

5.3 여러 가지 모듈 연습 문제

5.3.2 밴드 이름 짓기 (1)

문제: 색 이름과 음식 이름을 무작위로 하나씩 뽑아 밴드 이름을 지어주는 프로그램을 만들어요. 원문 보기

.py 파일에서 실행 (python bandname1.py)

import random  # random 모듈을 가져와 주세요

colors = ['검은', '화이트', '파란', '청색', '빨간', '노란']         # colors 에 색 이름들의 리스트를 담아 주세요
foods = ['콰삭칩', '소보로', '쭈꾸미', '커피', '옹심이', '떡볶이']  # foods 에 음식 이름들의 리스트를 담아 주세요

print(random.choice(colors), random.choice(foods))  # colors 와 foods 에서 하나씩 아무거나 뽑아 이어서 화면에 보여 주세요
$ python bandname1.py
화이트 옹심이
$ python bandname1.py
검은 콰삭칩
$ python bandname1.py
화이트 옹심이
$ python bandname1.py
화이트 쭈꾸미
$ python bandname1.py
빨간 쭈꾸미

실행할 때마다 결과가 달라요. 같은 결과를 글에 싣기 위해 파일 맨 위에 random.seed(1)부터 random.seed(5)까지 하나씩 몰래 넣어 돌린 결과이고, 여러분 화면의 이름은 이것과 다를 거예요. random.choice(리스트)는 리스트에서 원소 하나를 아무거나 뽑아 주고, print에 값을 쉼표로 두 개 주면 사이에 빈칸 하나를 두고 이어 찍어요. 색 6개와 음식 6개라서 가능한 이름은 6 × 6 = 36가지예요. 목록에 단어를 더하면 가짓수는 두 목록 길이의 곱으로 늘어요.

5.3.3 비밀번호 만들기 — 본문 끝의 도전

문제: 교재 본문은 글자를 무작위로 16번 뽑는 것까지만 보여 주고, 영문자·숫자·특수문자를 모두 넣어야 한다는 규칙이 있다면 머리를 써야 한다며 도전 과제로 남겨 둬요. 연습 문제 번호는 따로 없고, 교재 쪽 풀이는 ch05/gen_password.py에 있다고 해요. 아래는 이 글에서 새로 작성한 풀이예요. 원문 보기

먼저 왜 "머리를 써야 하는지"부터 볼게요. 후보 59글자에서 16번 뽑을 때 밑줄이 한 번도 안 나올 확률은 (58/59)의 16제곱이에요.

p_none = (58 / 59) ** 16     # p_none 에 밑줄이 한 번도 안 나올 확률을 담아 주세요
print(round(p_none, 3))      # p_none 을 소수 셋째 자리까지 반올림해 화면에 보여 주세요
print(round(1 - p_none, 3))  # 밑줄이 한 번이라도 나올 확률을 소수 셋째 자리까지 반올림해 화면에 보여 주세요
0.761
0.239

밑줄이 들어갈 확률이 24% 남짓이라 네 번에 세 번은 특수문자 없는 비밀번호가 나와요. 그래서 각 종류에서 하나씩 먼저 뽑아 놓고, 남은 자리를 전체 후보에서 채운 다음 섞는 방법을 써요.

.py 파일에서 실행

import random, string  # random 과 string 을 가져와 주세요

LETTERS = [x for x in string.ascii_letters if x not in 'lIO']  # LETTERS 에 헷갈리는 l, I, O 를 뺀 영문자를 담아 주세요
DIGITS = [x for x in string.digits if x != '0']                # DIGITS 에 0 을 뺀 숫자를 담아 주세요
SPECIAL = ['_']                                                # SPECIAL 에 특수문자로 쓸 밑줄을 담아 주세요

def make_password(length=16):                                                     # length 를 받는 make_password 라는 동작을 만들어 주세요 (기본값은 16)
    chars = LETTERS + DIGITS + SPECIAL                                            # chars 에 쓸 수 있는 글자 전체를 담아 주세요
    pw = [random.choice(LETTERS), random.choice(DIGITS), random.choice(SPECIAL)]  # pw 에 종류별로 하나씩 뽑은 글자 셋을 담아 주세요
    while len(pw) < length:                                                       # pw 의 길이가 length 보다 짧은 동안 아래를 반복해 주세요
        pw.append(random.choice(chars))                                           # pw 뒤에 chars 에서 뽑은 글자 하나를 붙여 주세요
    random.shuffle(pw)                                                            # pw 를 섞어 주세요
    return ''.join(pw)                                                            # pw 의 글자들을 이어 붙인 문자열을 결과로 돌려주세요

random.seed(7)        # 같은 결과가 나오게 출발값을 7 로 정해 주세요
pw = make_password()  # pw 에 만든 비밀번호를 담아 주세요
print(pw)             # pw 를 화면에 보여 주세요
print(len(pw))        # pw 의 글자 수를 화면에 보여 주세요

ok = True                                                                  # ok 에 True 를 담아 주세요
for _ in range(1000):                                                      # 아래를 1000번 반복해 주세요
    t = make_password()                                                    # t 에 비밀번호를 하나 만들어 담아 주세요
    if not (set(t) & set(LETTERS) and set(t) & set(DIGITS) and '_' in t):  # 만약 t 에 영문자, 숫자, 밑줄 중 하나라도 없으면
        ok = False                                                         # ok 에 False 를 담아 주세요
print(ok)                                                                  # ok 를 화면에 보여 주세요
decNKdyvHg_S3o4_
16
True

첫 줄의 비밀번호는 random.seed(7)로 출발값을 정해서 나온 것이고, 파이썬 버전이 다르면 이 글자들은 달라질 수 있어요. 달라지지 않는 건 아래 두 줄이에요. 길이는 16이고, 1000개를 만들어도 영문자·숫자·밑줄이 빠진 비밀번호가 하나도 없어요. 처음에 3글자를 종류별로 확보하고 나머지를 채운 뒤 shuffle로 섞는 순서가 핵심이에요. 섞지 않으면 모든 비밀번호가 "영문자, 숫자, 밑줄"로 시작해서 규칙이 눈에 보여요. ''.join(pw)는 리스트의 글자들을 사이에 아무것도 넣지 않고 이어 붙여요.

보충 1진짜 비밀번호는 random이 아니라 secrets

파이썬 공식 문서의 random 모듈 첫머리에는 이 모듈의 난수 생성기를 보안 용도로 쓰면 안 되고, 보안·암호 용도는 secrets 모듈을 보라는 안내가 있어요. 이 글의 풀이는 "난수와 문자열을 같이 쓰는 법"을 익히는 연습용이에요. 실제로 쓸 비밀번호는 secrets.choice()로 같은 방식의 코드를 짜면 돼요.

보충 2튜플은 섞을 수 없어요 — random.sample

random.shuffle()은 리스트를 그 자리에서 바꾸기 때문에 튜플이나 문자열에는 쓸 수 없어요. 공식 문서는 섞인 새 리스트가 필요하면 sample(x, k=len(x))를 쓰라고 해요.

import random                             # random 모듈을 가져와 주세요
menu = '쫄면', '육계장', '비빔밥'         # menu 에 세 메뉴를 묶어 담아 주세요
mixed = random.sample(menu, k=len(menu))  # mixed 에 menu 를 전부 섞은 새 리스트를 담아 주세요
print(sorted(mixed))                      # mixed 를 정렬해 화면에 보여 주세요
print(menu)                               # 원래 menu 를 화면에 보여 주세요
['비빔밥', '육계장', '쫄면']
('쫄면', '육계장', '비빔밥')

5.3.4 시저 암호 — 풀어 보고 되돌려 보기

문제: 교재 5.3.4는 연습 문제 없이 "소문자를 3칸 민 대문자로 바꾸는" 암호화 예제만 보여 줘요. 같은 도구로 칸 수를 바꿔 가며 암호화하고 원래 문장으로 되돌리는 함수를 이 글에서 이어 풀어 봤어요(교재의 연습 문제가 아니에요). 원문 보기

.py 파일에서 실행

import string  # string 모듈을 가져와 주세요

def encrypt(text, shift):                                                    # text 와 shift 를 받는 encrypt 라는 동작을 만들어 주세요
    upper = string.ascii_uppercase[shift:] + string.ascii_uppercase[:shift]  # upper 에 대문자 알파벳을 shift 칸 돌린 줄을 담아 주세요
    return text.translate(str.maketrans(string.ascii_lowercase, upper))      # 소문자를 upper 로 바꾼 글자를 결과로 돌려주세요

def decrypt(text, shift):                                                    # text 와 shift 를 받는 decrypt 라는 동작을 만들어 주세요
    upper = string.ascii_uppercase[shift:] + string.ascii_uppercase[:shift]  # upper 에 대문자 알파벳을 shift 칸 돌린 줄을 담아 주세요
    return text.translate(str.maketrans(upper, string.ascii_lowercase))      # upper 를 소문자로 되바꾼 글자를 결과로 돌려주세요

secret = encrypt('traue nie dem brutus', 3)  # secret 에 3칸 민 암호문을 담아 주세요
print(secret)                                # secret 을 화면에 보여 주세요
print(decrypt(secret, 3))                    # secret 을 3칸 되돌린 글자를 화면에 보여 주세요
print(encrypt('hello', 13))                  # 'hello' 를 13칸 민 암호문을 화면에 보여 주세요
print(decrypt(encrypt('hello', 13), 13))     # 13칸 밀었다 되돌린 글자를 화면에 보여 주세요
print(decrypt(secret, 4))                    # secret 을 칸 수를 잘못 알고 4칸 되돌린 글자를 화면에 보여 주세요
WUDXH QLH GHP EUXWXV
traue nie dem brutus
URYYB
hello
sqztd mhd cdl aqtstr

암호화는 "소문자 → 돌린 대문자" 표를, 복호화는 그 표를 거꾸로 "돌린 대문자 → 소문자"로 만들면 돼요. str.maketrans(원래, 바꿀)의 두 인자 자리만 바꾸면 반대 방향 표가 나와요. 13칸으로 밀어 만든 URYYB는 같은 13칸으로 되돌리면 hello가 돌아와요. 마지막 줄처럼 칸 수를 한 칸 틀리면 뜻 없는 글자가 나와서, 규칙(칸 수)을 아는 사람만 읽을 수 있어요.
