파일 읽고 쓰기 정리 — 왕초보 Python 6장 파일 (6.1 ~ 6.3)

2026. 11. 2.

※ 이 글은 위키독스 『왕초보를 위한 Python』 6.1 ~ 6.3절(6장 파일)을 제 나름의 언어로 짧게 정리한 것입니다. 앞 내용은 5.3.5 ~ 5.3.9 정리에 있어요. 코드 실행 결과는 파이썬 3.12.10(윈도우)로 실제로 돌려서 넣었어요. 예제 파일은 이 글에서 직접 만든 작은 파일이에요.

open 으로 파일을 열어 read·readline·write 로 읽고 쓰고, 파이썬 값은 pickle 로, 파일 찾기는 glob 으로 해요.

1. 텍스트 파일 읽고 쓰기 (6.1)

하고 싶은 일쓰는 것
파일 열기open('파일이름') — 읽기용. 두 번째 자리에 모드를 적으면 달라진다
전부 읽기f.read() — 파일 전체를 글자 하나로 돌려준다. 줄 바꿈은 \n으로 들어 있다
쓰기f.write('글자') — 줄을 바꾸려면 \n을 직접 쓴다
닫기f.close() — 쓰기 뒤에는 꼭 닫는다
열고 닫기를 한 번에with open('파일이름') as f: — 블록이 끝나면 저절로 닫힌다

열기 모드

모드뜻기존 내용
'r' (생략하면 이것)읽기그대로. 없는 파일이면 오류
'w'쓰기전부 지워진다. 없으면 새로 만든다
'a+'덧붙이기그대로 두고 맨 끝에 이어 쓴다
'wb' · 'rb'바이트로 쓰기 · 읽기pickle 에서 쓴다 (아래 3절)

※ 이 절의 예제 파일 Python_for_Fun.txt에는 영어 세 줄(가운데 한 줄은 빈 줄)이 들어 있어요: Programming is fun. · Very fun! · (빈 줄) · You have to do it yourself...

읽기

f = open('Python_for_Fun.txt')  # f 에 Python_for_Fun.txt 를 읽기용으로 열어 담아 주세요
buffer = f.read()               # buffer 에 f 의 내용 전부를 글자 하나로 담아 주세요
print(repr(buffer))             # buffer 를 \n 이 보이는 모양 그대로 화면에 보여 주세요
print(buffer)                   # buffer 를 줄 바꿈을 적용해 화면에 보여 주세요
'Programming is fun.\nVery fun!\n\nYou have to do it yourself...\n'
Programming is fun.
Very fun!

You have to do it yourself...

※ repr()은 글자를 따옴표와 \n까지 보이는 모양으로 바꿔 줘요. 그냥 print()하면 \n이 실제 줄 바꿈으로 나타나요.

쓰기 · 덧붙이기 · 지우고 다시 쓰기

letter = open('letter.txt', 'w')  # letter 에 letter.txt 를 쓰기용으로 열어 담아 주세요
letter.write('Dear Father,')      # letter 에 'Dear Father,' 를 써 주세요
letter.close()                    # letter 를 닫아 주세요
print(open('letter.txt').read())  # letter.txt 의 내용을 읽어 화면에 보여 주세요
Dear Father,
letter = open('letter.txt', 'a+')  # letter 에 letter.txt 를 덧붙이기용으로 열어 담아 주세요
letter.write('\n\nHow are you?')   # letter 에 줄 바꿈 두 번과 'How are you?' 를 써 주세요
letter.close()                     # letter 를 닫아 주세요
print(open('letter.txt').read())   # letter.txt 의 내용을 읽어 화면에 보여 주세요
Dear Father,

How are you?
letter = open('letter.txt', 'w')  # letter 에 letter.txt 를 쓰기용으로 다시 열어 담아 주세요
letter.write('Hello')             # letter 에 'Hello' 를 써 주세요
letter.close()                    # letter 를 닫아 주세요
print(open('letter.txt').read())  # letter.txt 의 내용을 읽어 화면에 보여 주세요
Hello

※ 'w'로 다시 열자마자 파일이 비워져서 앞에 있던 Dear Father,와 How are you?가 모두 사라졌어요. 이어 쓰려면 'a+'를 써요.

닫지 않으면

f = open('unclosed.txt', 'w')             # f 에 unclosed.txt 를 쓰기용으로 열어 담아 주세요
f.write('hello')                          # f 에 'hello' 를 써 주세요
print(repr(open('unclosed.txt').read()))  # unclosed.txt 를 따로 열어 읽은 내용을 보이는 모양 그대로 화면에 보여 주세요
f.close()                                 # f 를 닫아 주세요
print(repr(open('unclosed.txt').read()))  # unclosed.txt 를 다시 열어 읽은 내용을 보이는 모양 그대로 화면에 보여 주세요
''
'hello'

※ 쓴 글자는 닫거나 비우기 전까지 파이썬 안의 임시 칸에 머물러서, 닫기 전에 파일을 따로 열어 보면 비어 있을 수 있어요. 이 문제를 피하려고 보통 with를 써요.

with 로 열면 저절로 닫힌다

with open('letter.txt', 'a+') as f:     # letter.txt 를 덧붙이기용으로 열어 f 라 부르고, 블록이 끝나면 저절로 닫아 주세요
    f.write('\nBye')                    # f 에 줄 바꿈과 'Bye' 를 써 주세요
print(repr(open('letter.txt').read()))  # letter.txt 의 내용을 보이는 모양 그대로 화면에 보여 주세요
'Hello\nBye'

한글이 든 파일은 인코딩을 적는다

이 글을 돌린 한국어 윈도우에서는 파이썬이 파일을 여는 기본 글자 규칙이 UTF-8이 아니라 cp949예요. 그래서 UTF-8로 저장된 한글 파일은 encoding='utf-8'을 적어야 읽혀요. 아래는 그 컴퓨터에서 돌린 결과예요.

with open('hello.txt', 'w', encoding='utf-8') as f:  # hello.txt 를 UTF-8 쓰기용으로 열어 f 라 불러 주세요
    f.write('안녕하세요')                                 # f 에 '안녕하세요' 를 써 주세요
with open('hello.txt', encoding='utf-8') as f:       # hello.txt 를 UTF-8 읽기용으로 열어 f 라 불러 주세요
    print(f.read())                                  # f 의 내용을 읽어 화면에 보여 주세요
with open('hello.txt') as f:                         # hello.txt 를 인코딩 없이 읽기용으로 열어 f 라 불러 주세요
    print(f.read())                                  # f 의 내용을 읽어 화면에 보여 주세요
안녕하세요
UnicodeDecodeError: 'cp949' codec can't decode byte 0xec in position 0: illegal multibyte sequence

※ 첫 번째 읽기는 되고, 인코딩을 안 적은 두 번째 읽기는 오류가 나요(맨 아래 줄이 오류 문장이에요). 글자가 영어뿐인 파일은 이 차이가 드러나지 않아요. 한글 파일을 열 때는 encoding='utf-8'을 습관으로 적어 두면 안전해요.

2. 한 줄씩 다루기 (6.2)

하고 싶은 일쓰는 것
한 줄 읽기f.readline() — 줄 끝의 \n까지 읽고 멈춘다. 다시 부르면 다음 줄
모든 줄을 리스트로f.readlines() — 줄 하나가 리스트 원소 하나
줄마다 반복for line in f: — 파일에서 한 줄씩 꺼낸다
줄 끝 떼기line.strip() — 앞뒤 공백과 \n을 지운다
낱말·칸으로 자르기line.split() — 공백 기준. line.split('\t')는 탭 기준
일부 줄만lines[2:5] 처럼 리스트 슬라이싱. 끝에서부터는 lines[-3:]

※ 이 절의 예제 파일 lines.txt에는 1번째 줄부터 15번째 줄까지 15줄이 한 줄에 하나씩 들어 있어요.

readline — 부를 때마다 다음 줄

f = open('lines.txt', encoding='utf-8')  # f 에 lines.txt 를 UTF-8 읽기용으로 열어 담아 주세요
print(repr(f.readline()))                # f 에서 한 줄을 읽어 보이는 모양 그대로 화면에 보여 주세요
print(repr(f.readline()))                # f 에서 다음 한 줄을 읽어 보이는 모양 그대로 화면에 보여 주세요
for x in range(3):                       # x 에 0, 1, 2 를 차례로 담으며 아래를 반복해 주세요
    print(f.readline(), end='')          # f 에서 다음 한 줄을 읽어 줄 바꿈을 더하지 않고 화면에 보여 주세요
'1번째 줄\n'
'2번째 줄\n'
3번째 줄
4번째 줄
5번째 줄

※ print(..., end='')는 print가 끝에 붙이는 줄 바꿈을 없애요. 읽어 온 줄 끝에 이미 \n이 있어서, 안 없애면 줄 사이에 빈 줄이 하나씩 더 생겨요.

readlines — 줄 전체를 리스트로

f = open('lines.txt', encoding='utf-8')  # f 에 lines.txt 를 UTF-8 읽기용으로 열어 담아 주세요
lines = f.readlines()                    # lines 에 f 의 모든 줄을 리스트로 담아 주세요
print(len(lines))                        # lines 의 원소 개수를 화면에 보여 주세요
print(lines[:2])                         # lines 의 앞 두 개를 화면에 보여 주세요
for l in lines[3:6]:                     # lines 의 3번부터 5번까지를 하나씩 l 이라 부르며 아래를 반복해 주세요
    print(l, end='')                     # l 을 줄 바꿈을 더하지 않고 화면에 보여 주세요
print(lines[-3:])                        # lines 의 뒤에서 세 개를 화면에 보여 주세요

4번째 줄
5번째 줄
6번째 줄
['13번째 줄\n', '14번째 줄\n', '15번째 줄\n']

※ lines[3:6]은 3번 자리부터 5번 자리까지예요. 슬라이싱은 끝 번호를 포함하지 않고, 자리 번호는 0부터 세서 "4번째 줄 ~ 6번째 줄"이 나와요. 끝에서 열 줄은 lines[-10:]이에요.

for 로 한 줄씩 · strip 으로 줄 끝 떼기

count = 0                                       # count 에 0 을 담아 주세요
with open('lines.txt', encoding='utf-8') as f:  # lines.txt 를 UTF-8 읽기용으로 열어 f 라 불러 주세요
    for line in f:                              # f 에서 한 줄씩 꺼내 line 이라 부르며 아래를 반복해 주세요
        if '1' in line:                         # 만약 line 에 '1' 이 들어 있으면
            count += 1                          # count 에 1 을 더해 주세요
            print(line.strip())                 # line 의 앞뒤 공백과 줄 바꿈을 지워 화면에 보여 주세요
print(count)                                    # count 를 화면에 보여 주세요

다 읽은 파일은 비어 있다

f = open('Python_for_Fun.txt')  # f 에 Python_for_Fun.txt 를 읽기용으로 열어 담아 주세요
print(len(f.read()))            # f 를 전부 읽은 글자 수를 화면에 보여 주세요
print(repr(f.read()))           # f 를 한 번 더 읽은 것을 보이는 모양 그대로 화면에 보여 주세요
f.seek(0)                       # f 의 읽는 자리를 맨 앞으로 돌려 주세요
print(len(f.read()))            # f 를 다시 전부 읽은 글자 수를 화면에 보여 주세요
61
''
61

※ 파일에는 "어디까지 읽었는지"를 기억하는 자리가 하나 있어요. read()가 끝까지 읽으면 그 자리가 맨 끝에 가서, 다시 읽으면 빈 글자가 나와요. seek(0)이 그 자리를 맨 앞으로 되돌려요.

3. 파일을 입맛대로 — pickle · glob · os.path (6.3)

하고 싶은 일쓰는 것
파이썬 값을 통째로 저장pickle.dump(값, f) — open('파일', 'wb')로 연 파일에
저장한 값을 되살리기pickle.load(f) — open('파일', 'rb')로 연 파일에서
패턴에 맞는 파일 찾기glob('*.txt') — *는 아무 글자 여러 개. 리스트로 돌려준다
파일이 있나os.path.exists('이름') — True 또는 False
폴더인가os.path.isdir('이름')

pickle — 딕셔너리를 파일에 넣고 꺼내기

import pickle                                                  # pickle 모듈을 가져와 주세요
import os                                                      # os 모듈을 가져와 주세요
users = {'kim': '3kid9', 'sun80': '393948', 'ljm': 'py90390'}  # users 에 아이디와 비밀번호가 든 딕셔너리를 담아 주세요
f = open('users', 'wb')                                        # f 에 users 파일을 바이트 쓰기용으로 열어 담아 주세요
pickle.dump(users, f)                                          # users 를 f 에 저장해 주세요
f.close()                                                      # f 를 닫아 주세요
print(os.path.exists('users'))                                 # users 파일이 있는지 화면에 보여 주세요
f = open('users', 'rb')                                        # f 에 users 파일을 바이트 읽기용으로 열어 담아 주세요
a = pickle.load(f)                                             # a 에 f 에서 되살린 값을 담아 주세요
f.close()                                                      # f 를 닫아 주세요
print(a)                                                       # a 를 화면에 보여 주세요
print(type(a), a == users)                                     # a 의 자료형과, a 가 users 와 같은지 화면에 보여 주세요
True
{'kim': '3kid9', 'sun80': '393948', 'ljm': 'py90390'}
<class 'dict'> True

※ 비밀번호를 이렇게 평문으로 저장하는 것은 연습용이에요. 그리고 출처를 모르는 pickle 파일은 열지 마세요. 불러올 때 파일 안의 코드가 실행될 수 있어서, 내가 만든 파일만 불러와야 해요.

glob — 파일 목록 뽑기

from glob import glob          # glob 모듈에서 glob 을 가져와 주세요
print(sorted(glob('*.txt')))   # 현재 폴더의 .txt 파일 이름들을 정렬해 화면에 보여 주세요
print(sorted(glob('*r.txt')))  # 이름이 r.txt 로 끝나는 파일들을 정렬해 화면에 보여 주세요
print(sorted(glob('l*')))      # 이름이 l 로 시작하는 파일들을 정렬해 화면에 보여 주세요
['Python_for_Fun.txt', 'color.txt', 'lines.txt', 'postcard.txt']
['color.txt']
['lines.txt']

※ 이 예제는 Python_for_Fun.txt, lines.txt, postcard.txt, color.txt 네 파일만 있는 폴더에서 돌렸어요. glob이 돌려주는 순서는 정해져 있지 않아서 sorted()로 정렬하면 결과가 늘 같아요. 다른 폴더의 파일은 glob(r'C:\Users\*')처럼 경로를 적어요. 앞의 r은 역슬래시(\)를 글자 그대로 쓰라는 표시예요.

glob 과 os.path.isdir — 폴더는 표시하기

import os                    # os 모듈을 가져와 주세요
from glob import glob        # glob 모듈에서 glob 을 가져와 주세요
from os.path import isdir    # os.path 모듈에서 isdir 을 가져와 주세요
os.mkdir('docs')             # docs 라는 폴더를 만들어 주세요
for x in sorted(glob('*')):  # 폴더 안 모든 이름을 정렬해 하나씩 x 라 부르며 아래를 반복해 주세요
    if isdir(x):             # 만약 x 가 폴더이면
        print(x, '<DIR>')    # x 와 '<DIR>' 을 화면에 보여 주세요
    else:                    # 아니면
        print(x)             # x 를 화면에 보여 주세요
