문제 해설 — 문자열·리스트 연습 문제를 자세히 뜯어본다 (2)

2026. 10. 11.

※ 이 글은 위키독스 『왕초보를 위한 Python』 4장 4.1~4.2의 연습 문제를 제가 직접 풀어 본 해설이에요. 문제는 줄여서 요약했고, 코드는 제가 새로 짰어요. 뒤쪽에는 다음 글의 실습 문제 5개 해설도 있어요.

교재 연습 문제 7개와 실습 문제 5개, 퀴즈를 한 줄씩 쪼개 풀고, 값이 바뀌는 표와 에러 없이 틀리는 실수까지 실행 결과로 보여 주는 해설이에요.

핵심 정리

개념한 줄 정리
슬라이싱x[2:4]는 2번 이상 4번 미만, x[::-1]은 뒤집기, x[-3:]은 끝 세 개다.
문자열은 불변x[0] = 'n'은 TypeError이고, 새 문자열을 만들어 다시 붙인다('n' + x[1:]).
split · strip · replace쪼개기, 양끝 공백 지우기, 바꾸기. 모두 새 문자열을 돌려주고 원본은 그대로다.
리스트 메서드append 끝에 추가, insert(0, v) 앞에 추가, pop() 끝을 빼서 돌려줌, del l[i] 삭제.
in리스트에서는 완전히 같은 원소만 찾고, 문자열에서는 부분 문자열도 찾는다.
a[:]리스트의 복사본이라 고쳐도 원본 a는 그대로다(b = a는 복사가 아니다).
순회 중 remove돌고 있는 리스트를 고치면 원소를 건너뛰니, L[:] 복사본을 돈다.

모든 코드는 Python 3에서 직접 실행해 출력과 에러 메시지를 옮겼어요.

문제 1 — 아이돌 팬 찾기 — 교재 쪽

정답과 해설

문제: 세 그룹의 팬 명단이 있어요. 첫째 그룹과 둘째 그룹의 팬이면서 셋째 그룹의 팬은 아닌 사람을 쉼표로 이어 출력해요.

실행: 로컬 파이썬 — 아무 환경 OK

newjeans = ['철수', '영희', '민수', '지현', '서연']  # newjeans 에 이름 다섯 개의 리스트를 담아 주세요
ive = ['영희', '민수', '지수', '서연', '하나']       # ive 에 이름 다섯 개의 리스트를 담아 주세요
aespa = ['철수', '지현', '지수', '서연', '나영']     # aespa 에 이름 다섯 개의 리스트를 담아 주세요

result = []                                # result 에 빈 리스트를 담아 주세요
for name in newjeans:                      # newjeans 의 원소를 하나씩 name 이라고 부르며 아래를 반복해 주세요
    if name in ive and name not in aespa:  # 만약 name 이 ive 에 있고 aespa 에는 없으면
        result.append(name)                # result 의 맨 뒤에 name 을 붙여 주세요
print(", ".join(result))                   # result 의 원소를 ', ' 로 이어 붙여 화면에 보여 주세요
영희, 민수

한 줄씩 짚어보기

  • for name in newjeans — 첫째 그룹 팬을 한 명씩 꺼내요.
  • name in ive and name not in aespa — 둘째 명단에는 있고 셋째 명단에는 없을 때만 참이에요.
  • result.append(name) — 통과한 사람만 빈 리스트에 모아요.
  • ", ".join(result) — 리스트를 쉼표와 공백으로 이어 한 문자열로 만들어요.

문제 2 — 회문 판별 — 교재 쪽

정답과 해설

문제: 앞에서 읽으나 뒤에서 읽으나 같은 말(회문)이면 True를 돌려주는 함수 palindrome()을 만들어요. 문제 1은 소문자·공백 없음, 문제 2는 대소문자가 섞임, 문제 3은 공백이 들어 있어요.

문제 1 — 소문자만

실행: 로컬 파이썬 — 아무 환경 OK

print(palindrome('anna'))      # palindrome 에 'anna' 를 넣은 결과를 화면에 보여 주세요

문제 3 — 각 자리 숫자의 합(리스트) — 교재 쪽

정답과 해설

문제: 나눗셈을 쓰지 않고 정수 num의 각 자리 숫자를 더하는 함수 sumOfDigits(num)을 만들어요.

실행: 로컬 파이썬 — 아무 환경 OK

def sumOfDigits(num):           # num 을 받는 sumOfDigits 라는 동작을 만들어 주세요
    total = 0                   # total 에 0 을 담아 주세요

    return total                # total 을 결과로 돌려주세요

print(list(str(643)))           # 643 을 글자 리스트로 만들어 화면에 보여 주세요
print(sumOfDigits(643))         # sumOfDigits 에 643 을 넣은 결과를 화면에 보여 주세요
print(sumOfDigits(47253))       # sumOfDigits 에 47253 을 넣은 결과를 화면에 보여 주세요

문제 4 — 줄기와 잎 그림 — 교재 쪽

정답과 해설

문제: 점수 리스트를 10 미만, 10대, 20대로 나눠 세 칸 stem_leaf에 채워요(문제 1). 그다음 0: [...] 모양으로 한 줄씩 출력해요(문제 2). 칸에는 일의 자리 숫자만 넣어요.

문제 1 — 칸에 채우기

실행: 로컬 파이썬 — 아무 환경 OK

score = [0, 0, 2, 4, 7, 7, 9, 11, 11, 13, 18, 20]  # score 에 점수 열두 개의 리스트를 담아 주세요
stem_leaf = [[], [], []]                           # stem_leaf 에 빈 리스트 세 개의 리스트를 담아 주세요

for s in score:                                    # score 의 원소를 하나씩 s 라고 부르며 아래를 반복해 주세요
    stem_leaf[s // 10].append(s % 10)              # stem_leaf 의 (s 를 10 으로 나눈 몫)번 리스트 맨 뒤에 s 를 10 으로 나눈 나머지를 붙여 주세요
print(stem_leaf)                                   # stem_leaf 를 화면에 보여 주세요
[[0, 0, 2, 4, 7, 7, 9], [1, 1, 3, 8], [0]]

문제 5 — 놀이 공원(1) read() — 교재 쪽

정답과 해설

문제: read(text)가 놀이기구 이름과 키 제한을 (이름, 최소, 최대)로 돌려줘요. 제한이 없는 칸은 None이에요.

실행: 로컬 파이썬 — 아무 환경 OK

def read(text):                                                               # text 를 받는 read 라는 동작을 만들어 주세요
    name, rule = text.split(':')                                              # text 를 ':' 로 잘라 name 과 rule 에 담아 주세요
    name = name.strip()                                                       # name 의 앞뒤 공백을 지워 name 에 담아 주세요
    rule = rule.strip()                                                       # rule 의 앞뒤 공백을 지워 rule 에 담아 주세요
    if rule == '-':                                                           # 만약 rule 이 '-' 이면
        return name, None, None                                               # name 과 None 두 개를 결과로 돌려주세요
    if '~' in rule:                                                           # 만약 rule 안에 '~' 가 있으면
        low, high = rule.split('~')                                           # rule 을 '~' 로 잘라 low 와 high 에 담아 주세요
        return name, int(low.replace('cm', '')), int(high.replace('cm', ''))  # name 과 low, high 에서 'cm' 를 뺀 정수를 돌려주세요
    return name, int(rule.replace('cm 이상', '')), None                         # name 과 rule 에서 'cm 이상' 을 뺀 정수와 None 을 돌려주세요

print(read('와일드 윙: 110cm 이상'))                                                # read 에 '와일드 윙: 110cm 이상' 을 넣은 결과를 화면에 보여 주세요
print(read('툼 오브 호러: -'))                                                     # read 에 '툼 오브 호러: -' 를 넣은 결과를 화면에 보여 주세요
print(read('플라이벤처: 140cm~195cm'))                                             # read 에 '플라이벤처: 140cm~195cm' 를 넣은 결과를 화면에 보여 주세요
('와일드 윙', 110, None)
('툼 오브 호러', None, None)
('플라이벤처', 140, 195)

한 줄씩 짚어보기

  • text.split(':')로 이름 쪽과 규칙 쪽으로 쪼개요. 규칙 쪽에는 앞에 공백이 붙어서 strip()이 필요해요.
  • 규칙이 '-'이면 제한이 없으니 None 두 개를 돌려줘요.
  • '~'가 있으면 한 번 더 쪼개 'cm'를 지우고 정수로 바꿔요.
  • 나머지('110cm 이상')는 'cm 이상'을 지워 최소값만 구해요.

문제 6 — 각 자리 숫자의 합(map) — 교재 쪽

def primes(n):                         # n 을 받는 primes 라는 동작을 만들어 주세요
    L = list(range(2, n + 1))          # 2 부터 n 까지의 수를 리스트로 만들어 L 에 담아 주세요
    for p in L:                        # L 의 원소를 하나씩 p 라고 부르며 아래를 반복해 주세요
        for x in L:                    # L 의 원소를 하나씩 x 라고 부르며 아래를 반복해 주세요
            if x != p and x % p == 0:  # 만약 x 가 p 와 다르고 x 를 p 로 나눈 나머지가 0 이면
                L.remove(x)            # L 에서 값 x 를 찾아 지워 주세요
    return L                           # L 을 결과로 돌려주세요

numbers = ['', '일', '이', '삼', '사', '오']  # numbers 에 빈 문자열과 한자어 숫자 다섯 개의 리스트를 담아 주세요

삼

이럴 때 의심하세요 — 이 문제들을 짜다가 결과가 이상할 때

에러가 나는 경우도 있고, 에러 없이 조용히 틀리는 경우도 있어요. 결과가 예상과 다르면 이 표부터 확인해요. 아래 증상은 모두 실제로 실행해 확인했어요.

이런 증상이 보이면먼저 열어 볼 자리확인 방법
지운 줄 알았는데 원소가 남아 있어요(에러 없음) 리스트를 돌면서 remove 하는 for 문 for x in L:을 for x in L[:]:로 바꿔 봐요 (문제 7, 실습 5)
TypeError: 'str' object does not support item assignment가 나요 x[0] = ...처럼 글자 칸에 대입하는 줄 문자열은 불변이라 'n' + x[1:]처럼 새 문자열을 만들어요 (실습 2)
in 결과가 기대와 달라요(에러 없음) in 앞뒤가 리스트인지 문자열인지 리스트는 완전히 같은 원소만, 문자열은 부분 문자열도 찾아요 (실습 4)
b = a.sort() 뒤 b를 찍으니 None이에요 sort()를 부른 줄 sort()는 제자리 정렬이고 값을 돌려주지 않아요. 새 리스트가 필요하면 sorted(a)를 써요
복사본만 고쳤는데 원본이 바뀌었어요(에러 없음) b = a 같은 대입 줄 복사는 b = a[:]로 해요 (실습 4, 퀴즈 4.2.10 Q1)
