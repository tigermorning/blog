모듈은 남이 만들어 둔 함수와 변수의 꾸러미이고, import 로 가져와서 쓰는 거예요.

1. 모듈이란 (5.1)

항목내용
모듈함수와 변수를 모아 둔 파이썬 꾸러미. 남이 만들어 둔 부품을 가져다 쓴다
가져오기import 모듈
안의 것 쓰기모듈.이름 — 점으로 잇는다
대표 예math(수학 계산), calendar(달력), tkinter(창 만들기)
 
import math          # math 모듈을 가져와 주세요
print(math.sqrt(2))  # math 의 sqrt 로 2 의 제곱근을 화면에 보여 주세요
print(math.sqrt(4))  # math 의 sqrt 로 4 의 제곱근을 화면에 보여 주세요
print(math.pi)       # math 의 pi 를 화면에 보여 주세요
print(type(math))    # math 의 자료형을 화면에 보여 주세요

calendar — 달력

항목내용
calendar.prmonth(연, 월)그 달 달력을 화면에 바로 출력한다 (돌려주는 값은 없음)
calendar.TextCalendar().formatmonth(연, 월)같은 달력을 문자열로 돌려준다
 
import calendar                     # calendar 모듈을 가져와 주세요
calendar.prmonth(2013, 7)           # 2013년 7월 달력을 화면에 보여 주세요
c = calendar.TextCalendar()         # c 에 글자 달력 도구를 담아 주세요
m = c.formatmonth(2013, 7)          # m 에 2013년 7월 달력 문자열을 담아 주세요
print(type(m), len(m.split('\n')))  # m 의 자료형과 줄 수를 화면에 보여 주세요

tkinter — 창 띄우기

from tkinter import *                        # tkinter 의 이름을 전부 가져와 주세요
widget = Label(None, text='I love Python!')  # widget 에 'I love Python!' 글자가 든 라벨을 담아 주세요
widget.pack()                                # widget 을 창에 놓아 주세요
widget.mainloop()                            # 창을 띄워 두고 기다려 주세요

※ 실행하면 I love Python!이 적힌 작은 창이 떠요. 창이 뜨는 코드라 결과는 글로 적었어요. 대화형 셸에서는 앞의 세 줄만으로도 창이 뜨고, 파일로 실행할 때는 마지막 mainloop()가 있어야 창이 떠 있어요.

2. 모듈 가져오기 (5.2)

항목내용
import 모듈모듈 전체를 가져온다. 쓸 때는 모듈.이름
from 모듈 import 이름필요한 이름만 가져온다. 쓸 때는 이름 만 쓴다. 쉼표로 여러 개 가능
from 모듈 import *모듈의 이름을 전부 가져온다. 같은 이름의 내 변수를 덮어쓸 수 있다
 
import math           # math 모듈을 가져와 주세요
print(math.sqrt(16))  # math 의 sqrt 로 16 의 제곱근을 화면에 보여 주세요
4.0
from math import sqrt       # math 에서 sqrt 만 가져와 주세요
print(sqrt(16))             # sqrt 로 16 의 제곱근을 화면에 보여 주세요
try:                        # 다음 줄을 시도해 보고
    print(math.pi)          # math 의 pi 를 화면에 보여 주세요
except NameError as e:      # 이름이 없다는 오류가 나면
    print('NameError:', e)  # 오류 내용을 화면에 보여 주세요
4.0
NameError: name 'math' is not defined

별표(*)는 내 이름을 덮어쓴다

항목내용
덮어쓰기from 모듈 import * 가 실행되면 같은 이름의 내 변수는 모듈의 것으로 바뀐다
순서나중에 대입한 쪽이 이긴다
 
pi = '내가 만든 pi'  # pi 에 '내가 만든 pi' 를 담아 주세요
print(pi)            # pi 를 화면에 보여 주세요
from math import *   # math 의 이름을 전부 가져와 주세요
print(pi)            # pi 를 화면에 보여 주세요
내가 만든 pi
3.141592653589793

지우기와 다시 읽기

항목내용
del 모듈불러온 모듈의 이름을 지운다 (파일이 지워지는 게 아니다)
reload(모듈)from importlib import reload 뒤에 쓴다. 한 번 가져온 모듈 코드를 다시 실행한다
 
import math                 # math 모듈을 가져와 주세요
del math                    # math 라는 이름을 지워 주세요
try:                        # 다음 줄을 시도해 보고
    print(math.pi)          # math 의 pi 를 화면에 보여 주세요
except NameError as e:      # 이름이 없다는 오류가 나면
    print('NameError:', e)  # 오류 내용을 화면에 보여 주세요
import math                 # math 모듈을 다시 가져와 주세요
print(math.pi)              # math 의 pi 를 화면에 보여 주세요

별칭 as

항목내용
import 모듈 as 별칭긴 모듈 이름을 짧게 부른다 (5.2.3의 import tkinter as tk)
from 모듈 import 이름 as 별칭가져오는 이름에 다른 이름을 붙인다
별칭을 붙이면원래 모듈 이름은 생기지 않는다
 
import math as m               # math 를 m 이라는 이름으로 가져와 주세요
from math import sqrt as root  # sqrt 를 root 라는 이름으로 가져와 주세요
print(m.sqrt(9), root(9))      # m.sqrt(9) 와 root(9) 를 화면에 보여 주세요
print(m.pi)                    # m 의 pi 를 화면에 보여 주세요
try:                           # 다음 줄을 시도해 보고
    print(math.pi)             # math 의 pi 를 화면에 보여 주세요
except NameError as e:         # 이름이 없다는 오류가 나면
    print('NameError:', e)     # 오류 내용을 화면에 보여 주세요

dir()와 help()로 모듈 들여다보기 (5.2.1)

항목내용
dir(모듈)모듈 안에 있는 이름을 리스트로 돌려준다
help(대상)함수·모듈의 사용법을 보여 준다
[x for x in dir(모듈) if '글자' in x]이름에 글자가 든 것만 거른다 (리스트 컴프리헨션)
 
import calendar                                      # calendar 모듈을 가져와 주세요
names = [x for x in dir(calendar) if 'leap' in x]    # names 에 calendar 이름 중 leap 이 든 것을 모아 담아 주세요
print(names)                                         # names 를 화면에 보여 주세요
help(calendar.isleap)                                # calendar.isleap 의 사용법을 보여 주세요
print(calendar.isleap(2024), calendar.isleap(2077))  # 2024 와 2077 이 윤년인지 화면에 보여 주세요

내가 만든 파일도 모듈 (5.2.4)

항목내용
모듈 파일.py 파일 이름이 모듈 이름이다 (tools.py → import tools)
찾는 곳sys.path 목록의 폴더. 다른 폴더는 sys.path.append("폴더") 로 더한다
__name__직접 실행하면 '__main__', import 되면 모듈 이름
if __name__ == "__main__":직접 실행할 때만 도는 구역. import 할 때는 건너뛴다

※ tools.py

def double(x):                        # x 를 받는 double 이라는 동작을 만들어 주세요
    return x * 2                      # x 의 두 배를 돌려주세요

print('tools의 __name__:', __name__)  # '__name__' 을 화면에 보여 주세요
if __name__ == '__main__':            # 만약 직접 실행한 것이면
    print('직접 실행:', double(4))    # double(4) 를 화면에 보여 주세요

※ user.py

import tools            # tools 를 가져와 주세요
print(tools.double(5))  # tools 의 double 로 5 의 두 배를 화면에 보여 주세요

※ python tools.py 로 직접 실행하면

tools의 __name__: __main__
직접 실행: 8

※ python user.py 로 tools 를 import 하면

3. 한눈에 정리

전체 가져오기import 모듈 → 모듈.이름
골라 가져오기from 모듈 import 이름 → 이름
전부 가져오기from 모듈 import * → 내 이름을 덮어쓸 수 있다
별칭import 모듈 as 별칭, from 모듈 import 이름 as 별칭
지우기·다시 읽기del 모듈, reload(모듈)
