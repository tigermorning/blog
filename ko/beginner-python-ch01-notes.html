1. / 와 //

8 / 2   → 4.0
8 // 2  → 4
7 / 2   → 3.5
7 // 2  → 3

핵심 한 줄: /는 소수점 유지, //는 버림.

2. import와 math

math.sqrt(2)  → NameError: name 'math' is not defined. Did you forget to import 'math'?
from math import sqrt
sqrt(2)       → 1.4142135623730951
import math as m
m.sqrt(2)     → 1.4142135623730951

3. ** 거듭제곱

3 ** 3   → 27
2 ** 10  → 1024
550 ^ 2  → 548    # ^ 는 거듭제곱이 아님
math.hypot(3, 4)  → 5.0

4. 리스트 인덱싱·슬라이싱

s = ['시청', '을지로입구', '을지로3가', '을지로4가', '동대문역사문화공원', '신당', '상왕십리', '왕십리']
s[0]     → '시청'
s[-1]    → '왕십리'
s[1:4]   → ['을지로입구', '을지로3가', '을지로4가']    # 1 이상 4 미만
s[::2]   → ['시청', '을지로3가', '동대문역사문화공원', '상왕십리']
s[::-1]  → ['왕십리', '상왕십리', '신당', '동대문역사문화공원', '을지로4가', '을지로3가', '을지로입구', '시청']

5. 추가·삭제

f = ['mother', 'father']
f.append('me')              → ['mother', 'father', 'me']                                  # 1개
f.extend(['sister', 'dog']) → ['mother', 'father', 'me', 'sister', 'dog']                 # 여러 개
f.insert(1, 'grandma')      → ['mother', 'grandma', 'father', 'me', 'sister', 'dog']      # 1번 자리
f.remove('dog')             → ['mother', 'grandma', 'father', 'me', 'sister']             # 값으로
f.pop()                     → 'sister'                                                    # 꺼내서 반환
f.pop(1)                    → 'grandma'
del f[0]                    → ['father', 'me']                                            # 반환 없음

6. 메서드와 키워드

f.pop(0)         # 메서드: 점 + 괄호
del f[0]         # 키워드: 괄호 없음
'hello'.upper()  → 'HELLO'
'hello'.append('!')  → AttributeError: 'str' object has no attribute 'append'
