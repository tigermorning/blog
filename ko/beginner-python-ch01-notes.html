1. / 와 // — 소수점을 남기나 버리나

/는 결과가 항상 소수점 있는 수(float)로 나오고, //는 나눈 뒤 소수점 아래를 버려요. 나누어떨어지는 수끼리는 값이 같아 보이지만 나누어떨어지지 않으면 결과가 달라져요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> 7 / 2 * 4
14.0      # 수학적으로 맞는 값
>>> 7 // 2 * 4
12        # 3.5에서 소수점을 버려 3, 3 × 4 = 12

핵심 한 줄: 일반 수학식은 /로 옮기고, //는 몫만 필요할 때 써요.

2. import와 math — 필요한 도구 상자만 꺼내 쓰기

import는 다른 파일(모듈)에 든 기능을 가져와 쓰게 하는 명령이에요. 가져온 뒤에는 모듈이름.기능이름으로 써요. 가져오지 않고 쓰면 에러가 나요.

실행: 파이썬 대화형 셸 — 새로 연 셸에서 import 없이 실행해야 보여요

>>> math.sqrt(2)
NameError: name 'math' is not defined. Did you forget to import 'math'?

필요한 기능 하나만 가져오거나 별명을 붙여 가져올 수도 있어요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> from math import sqrt    # sqrt 하나만 가져오기
>>> sqrt(2)                  # math. 없이 바로 사용
1.4142135623730951
>>> import math as m         # 별명 붙여 가져오기
>>> m.sqrt(2)
1.4142135623730951

핵심 한 줄: 모듈은 import로 가져온 뒤에야 쓸 수 있다.

3. ** 거듭제곱 — 앞의 수를 뒤의 수만큼 곱하기

** 앞의 수는 곱할 수, 뒤의 수는 곱하는 횟수예요. 파이썬에서 ^는 거듭제곱이 아니라 비트 연산(XOR)이라 에러 없이 엉뚱한 값이 나와요.

코드수학으로 쓰면뜻결과
3 ** 23²3을 2번 곱하기(제곱)9
3 ** 33³3을 3번 곱하기(세제곱)27
2 ** 102¹⁰2를 10번 곱하기1024

직각삼각형의 빗변은 math.sqrt(a ** 2 + b ** 2)로 구하고, math.hypot은 같은 계산을 한 번에 해 줘요.

실행: 파이썬 대화형 셸 — import math를 먼저 한 셸에서

>>> math.hypot(3, 4)
5.0
>>> math.sqrt(3 ** 2 + 4 ** 2)   # 같은 계산
5.0

핵심 한 줄: 거듭제곱은 ^가 아니라 **로 쓴다.

4. 리스트 인덱싱·슬라이싱 — 번호로 하나, 구간으로 여럿

리스트는 원소를 순서대로 담은 목록이고, 원소마다 0부터 시작하는 번호(인덱스)가 붙어요. 번호로 하나를 꺼내는 게 인덱싱, 구간을 잘라 새 리스트로 꺼내는 게 슬라이싱이에요. 음수 번호는 뒤에서부터 세요.

개념 설명용 코드 — 번호 붙는 모양을 보여 주는 그림이에요

s = ['시청', '을지로입구', '을지로3가', '을지로4가', '동대문역사문화공원', '신당', '상왕십리', '왕십리']
#      0         1            2           3              4               5        6         7
#     -8        -7           -6          -5             -4              -3       -2        -1

실행: 파이썬 대화형 셸 — 위의 s = [...] 줄을 먼저 입력해요

>>> s[0]      # 출발역
'시청'
>>> s[-1]     # 종점
'왕십리'
>>> s[1:4]
['을지로입구', '을지로3가', '을지로4가']
>>> s[::2]    # 처음부터 끝까지 한 역씩 건너뛰기
['시청', '을지로3가', '동대문역사문화공원', '상왕십리']
>>> s[::-1]   # 반대 방향 열차 = 뒤집기
['왕십리', '상왕십리', '신당', '동대문역사문화공원', '을지로4가', '을지로3가', '을지로입구', '시청']
코드뜻
s[i]i번 원소 하나
s[-1]마지막 원소
s[a:b]a번부터 b번 앞까지
s[a:b:k]a번부터 k칸 간격으로, b번 앞까지
s[::-1]뒤집은 리스트

핵심 한 줄: [시작:끝]은 "시작 이상, 끝 미만"으로 읽으면 헷갈리지 않아요.

5. 추가 도구 — append·extend·insert

append는 원소 1개를, extend는 여러 원소를 풀어서 맨 뒤에 붙이고, insert(i, x)는 i번 자리에 끼워 넣어요.

실행: 파이썬 대화형 셸 — 위에서부터 순서대로 입력해요

>>> f = ['mother', 'father']
>>> f.append('me')                 # 원소 1개를 맨 뒤에
>>> f
['mother', 'father', 'me']
>>> f.extend(['sister', 'dog'])    # 여러 원소를 풀어서 맨 뒤에
>>> f
['mother', 'father', 'me', 'sister', 'dog']
>>> f.insert(1, 'grandma')         # 1번 자리에 끼워 넣기, 뒤는 한 칸씩 밀림
>>> f
['mother', 'grandma', 'father', 'me', 'sister', 'dog']

핵심 한 줄: 여러 원소를 붙일 때 append를 쓰면 리스트 안에 리스트가 생기니 extend를 써요.

6. 삭제 도구 — remove·pop·del

remove(값)은 값으로, pop(위치)은 위치로 지우면서 꺼낸 값을 돌려줘요. del 리스트[위치]는 지우기만 하고 돌려주는 값이 없어요.

실행: 파이썬 대화형 셸 — 위의 추가 코드에 이어서 입력해요

>>> f.remove('dog')     # 값으로 찾아서 지우기
>>> f
['mother', 'grandma', 'father', 'me', 'sister']
>>> x = f.pop()         # 맨 뒤를 꺼내고, 꺼낸 값을 돌려줌
>>> x
'sister'
>>> y = f.pop(1)        # 1번 자리를 꺼냄
>>> y
'grandma'
>>> f
['mother', 'father', 'me']
>>> del f[0]            # 위치로 지우기만, 돌려주는 값 없음
>>> f
['father', 'me']
상황쓸 것
값은 아는데 위치를 모름f.remove('dog')
위치를 알고, 꺼낸 값도 필요x = f.pop(1)
위치를 알고, 지우기만 하면 됨del f[1] (또는 f.pop(1))
여러 개를 구간으로 지움del f[1:3]

핵심 한 줄: 값을 알면 remove, 꺼낸 값이 필요하면 pop, 지우기만 하면 del이에요.

7. 메서드와 키워드 — 괄호가 있나 없나

메서드는 리스트 같은 자료에 딸린 기능이라 점과 괄호를 쓰고, 키워드는 파이썬 언어에 정해진 단어라 괄호 없이 대상을 바로 써요. 자료는 종류마다 쓸 수 있는 메서드가 달라서 f.append()는 리스트만 돼요.

메서드키워드
예f.pop(0), f.append('me')del f[0], import math
정체리스트 같은 자료에 딸린 기능파이썬 언어 자체에 정해진 단어
점 .있음 — "f가 가진 기능"없음
괄호 ()필요 — "지금 실행해라"라는 신호필요 없음 — 단어 뒤에 대상을 바로 씀

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> f = ['mother', 'father']
>>> f.append('me')          # 리스트의 버튼: 됨
>>> 'hello'.upper()         # 문자열의 버튼: 됨
'HELLO'
>>> 'hello'.append('!')     # 문자열에는 append 버튼이 없음
AttributeError: 'str' object has no attribute 'append'

핵심 한 줄: 메서드는 점과 괄호(f.pop()), 키워드는 괄호 없이(del f[0]) 쓴다.

8. input()과 int() — 입력은 글자로 들어와요

input()은 사용자가 친 값을 따옴표 붙은 글자로 돌려줘요. 계산하려면 int()로 정수로 바꿔야 해요.

실행: square.py로 저장 — 아래 "직접 해 보기"에서 python 명령으로 실행해요

num = int(input())
print(num * num)

괄호는 안쪽부터 실행돼요. input()이 '3'(글자)을 돌려주고, int('3')이 정수 3으로 바꾸고, num에 담아요. int를 빼먹으면 이렇게 돼요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> '3' * '3'
TypeError: can't multiply sequence by non-int of type 'str'
>>> '3' * 3
'333'

핵심 한 줄: input()은 글자를 돌려주므로 계산에 쓰려면 int(input())으로 받는다.
