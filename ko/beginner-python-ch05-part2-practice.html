choice로 메뉴 고르기

점심 메뉴 세 가지 중 하나를 뽑아요. 뽑은 메뉴는 매번 달라요.

pick = random.choice(menu)         # pick 에 menu 의 원소 하나를 아무거나 담아 주세요
print(pick in menu)                # pick 이 menu 안에 있는지 화면에 보여 주세요

print(type(menu))                  # menu 의 자료형을 화면에 보여 주세요
print(type(pick))                  # pick 의 자료형을 화면에 보여 주세요

중급 2읽기

re로 이름 거르기

.*p.*n.*은 "p 가 나오고 그 뒤에 n 이 나오는" 이름에 맞아요. 어떤 이름이 걸러질까요?

import re  # re 모듈을 가져와 주세요

names = ['python.exe', 'NEWS.txt', 'pycon.ico', 'LICENSE.txt', 'nap.txt']  # names 에 파일 이름 다섯 개의 리스트를 담아 주세요
p = re.compile('.*p.*n.*')                                                 # p 에 '.*p.*n.*' 패턴 검사기를 담아 주세요
for name in names:                                                         # names 의 원소를 하나씩 name 이라고 부르며 아래를 반복해 주세요
    if p.match(name):                                                      # 만약 name 이 패턴에 맞으면
        print(name)                                                        # name 을 화면에 보여 주세요

이 코드를 실행하면 무엇이 출력될까요?

출력예측

2번째 줄?
힌트 보기

p 가 있어야 하고, 그 뒤에 n 이 나와야 해요. 순서를 하나씩 따져 보세요.

정답·해설 보기 
python.exe
pycon.ico

한 문장으로: 패턴은 p 다음에 n 이 오는 순서를 요구해서, n 이 p 보다 앞에 있는 이름은 걸러져요.

줄일어나는 일
3번째 줄다섯 이름을 차례로 검사해요
6번째 줄python.exe는 p…n 순서, pycon.ico는 p…o…n 순서라 통과해요
6번째 줄NEWS.txt와 LICENSE.txt에는 p 가 없어 탈락. nap.txt는 n 이 p 보다 앞이라 탈락

.는 아무 글자 한 개, *는 앞의 것이 0번 이상이라서, .*p.*n.*은 "앞에 뭐가 와도 좋고, p, 뭐가 와도 좋고, n, 뭐가 와도 좋다"로 읽어요.

핵심 한 줄: .*p.*n.*은 p 뒤에 n 이 오는 이름에 맞아요.

중급 3읽기

비밀번호 글자 후보 만들기

헷갈리는 글자를 빼고 밑줄을 더해 비밀번호 후보를 만들어요.

import string  # string 모듈을 가져와 주세요

chars = [x for x in string.ascii_letters + string.digits if x not in 'lIO0']  # chars 에 영문자와 숫자 중 l, I, O, 0 이 아닌 것을 모아 담아 주세요
print(len(chars))                                                             # chars 의 글자 수를 화면에 보여 주세요
chars.append('_')                                                             # chars 뒤에 '_' 를 붙여 주세요
print(len(chars))                                                             # chars 의 글자 수를 화면에 보여 주세요
print('l' in chars, 'a' in chars, '_' in chars)                               # 'l', 'a', '_' 가 각각 chars 안에 있는지 화면에 보여 주세요

한 문장으로: 영문자 52개와 숫자 10개 62글자에서 네 글자를 빼서 58글자가 되고, 밑줄을 붙여 59글자가 돼요.

7번째 줄l은 뺐으니 False, a는 남았으니 True, _는 더했으니 True

x not in 'lIO0'는 문자열 안에 그 글자가 없는지 물어요. 리스트 컴프리헨션의 if가 조건에 맞는 글자만 남겨요.

핵심 한 줄: 리스트 컴프리헨션의 if로 글자를 걸러 후보를 만들어요.

중급 4읽기

maketrans가 만든 대응표

maketrans와 translate를 아주 작은 표로 확인해요.

tt = str.maketrans('abc', 'xyz')  # tt 에 a→x, b→y, c→z 대응표를 담아 주세요
print(tt)                         # tt 를 화면에 보여 주세요
print('cab'.translate(tt))        # 'cab' 를 표대로 바꿔 화면에 보여 주세요
print('abcd'.translate(tt))       # 'abcd' 를 표대로 바꿔 화면에 보여 주세요
print(len(tt))                    # tt 의 항목 수를 화면에 보여 주세요

한 문장으로: maketrans는 글자 번호끼리 짝지은 딕셔너리를 만들고, translate는 표에 있는 글자만 바꿔요.

줄일어나는 일

두 문자열의 길이가 다르면 maketrans가 오류를 내요. 대응이 "같은 위치끼리"라서 개수가 같아야 해요.

핵심 한 줄: translate는 표에 있는 글자만 바꾸고 나머지는 그대로 둬요.

고급 1읽기

시저 암호표 읽기

3칸 민 시저 암호표를 만들어 여러 글자에 적용해요. 대문자 H는 표의 왼쪽(바꿀 글자)에 없어요.

import string  # string 모듈을 가져와 주세요

lower = string.ascii_lowercase                                   # lower 에 영문 소문자를 담아 주세요
upper = string.ascii_uppercase[3:] + string.ascii_uppercase[:3]  # upper 에 영문 대문자를 3칸 돌린 줄을 담아 주세요
tt = str.maketrans(lower, upper)                                 # tt 에 lower → upper 대응표를 담아 주세요

print(upper[:6])              # upper 의 앞 여섯 글자를 화면에 보여 주세요
print('xyz'.translate(tt))    # 'xyz' 를 표대로 바꿔 화면에 보여 주세요
print('Hello'.translate(tt))  # 'Hello' 를 표대로 바꿔 화면에 보여 주세요
print(len(tt))                # tt 의 항목 수를 화면에 보여 주세요

upper는 D 부터 시작해서 Z 다음에 A 가 와요. 표에 없는 글자는 그대로 두는 규칙을 기억하세요.

정답·해설 보기

한 문장으로: upper가 "D E F … Z A B C"라서 x, y, z 는 A, B, C 가 되고, 표에 없는 대문자 H 는 그대로 남아요.

줄일어나는 일
7번째 줄D 부터 여섯 글자 DEFGHI
8번째 줄x→A, y→B, z→C 로 ABC
9번째 줄H는 소문자 표에 없어 그대로, e→H, l→O, l→O, o→R 로 HHOOR
10번째 줄소문자 26자와 짝지어서 26

첫 글자 H(원래 대문자)와 둘째 글자 H(e 가 바뀐 것)가 같아 보이지만 이유가 달라요. 이런 암호문은 읽기가 어려워서, 평문은 소문자로 쓰는 규칙을 둬요.

핵심 한 줄: 표에 없는 글자는 translate가 그대로 남겨요.

고급 2읽기

튜플은 섞을 수 없어요

shuffle에 튜플을 주면 어떻게 될까요? 오류가 나면 그 줄의 오류를 적고, 다음 줄은 이어서 읽어요.

import random  # random 모듈을 가져와 주세요

menu = '쫄면', '육계장', '비빔밥'  # menu 에 세 메뉴를 묶어 담아 주세요
try:                               # 다음 줄을 시도해 보고
    random.shuffle(menu)           # menu 를 섞어 주세요
except TypeError as e:             # 형식 오류가 나면
    print('TypeError:', e)         # 오류 내용을 화면에 보여 주세요
menu = list(menu)                  # menu 를 리스트로 바꿔 다시 담아 주세요
random.shuffle(menu)               # menu 를 섞어 주세요
print(sorted(menu))                # menu 를 정렬해 화면에 보여 주세요
print(len(menu))                   # menu 의 길이를 화면에 보여 주세요

shuffle은 원소 자리를 그 자리에서 바꿔요. 튜플은 원소를 바꿀 수 있는 자료형일까요?

정답·해설 보기

한 문장으로: 튜플은 원소를 바꿀 수 없어서 shuffle이 오류를 내고, list()로 바꾼 뒤에는 섞여요.

줄일어나는 일
5번째 줄튜플은 원소를 바꿀 수 없어 TypeError. except가 받아 문구를 출력
8번째 줄리스트로 바꾸면 원소를 바꿀 수 있어요
10번째 줄섞인 순서와 상관없이 정렬하면 비빔밥, 육계장, 쫄면 순서(글자 순)

섞인 새 리스트가 필요하면 random.sample(menu, k=len(menu))처럼 튜플에서 바로 뽑을 수도 있어요. 정렬 결과를 출력한 건 섞인 순서가 실행마다 달라서 비교하기 어렵기 때문이에요.

핵심 한 줄: shuffle은 리스트에만 써요. 튜플은 list()로 바꾸거나 sample을 써요.

고급 3읽기

비밀번호 규칙 검사기

영문자·숫자·밑줄이 각각 들어 있는지 알려 주는 함수예요. 세트의 &는 두 세트에 모두 있는 원소만 모아요.

import string  # string 모듈을 가져와 주세요

def check(pw):                                         # pw 를 받는 check 라는 동작을 만들어 주세요
    letters = set(pw) & set(string.ascii_letters)      # letters 에 pw 의 글자 중 영문자인 것을 모아 담아 주세요
    digits = set(pw) & set(string.digits)              # digits 에 pw 의 글자 중 숫자인 것을 모아 담아 주세요
    special = set(pw) & {'_'}                          # special 에 pw 의 글자 중 밑줄인 것을 모아 담아 주세요
    return bool(letters), bool(digits), bool(special)  # 셋이 각각 비어 있지 않은지 묶어서 결과로 돌려주세요

print(check('abc123_'))   # 'abc123_' 를 검사한 결과를 화면에 보여 주세요
print(check('abcdef12'))  # 'abcdef12' 를 검사한 결과를 화면에 보여 주세요
print(check('_____'))     # '_____' 를 검사한 결과를 화면에 보여 주세요

출력예측
1번째 줄?
2번째 줄?
3번째 줄?
힌트 보기

bool(세트)는 세트가 비어 있으면 False, 하나라도 있으면 True예요.

정답·해설 보기 
(True, True, True)
(True, True, False)
(False, False, True)

한 문장으로: &로 얻은 세트가 비어 있는지에 따라 각 종류가 있는지가 정해져요.

줄일어나는 일
9번째 줄영문자 abc, 숫자 123, 밑줄 모두 있어서 (True, True, True)
10번째 줄밑줄이 없어 (True, True, False)
11번째 줄밑줄만 있어 (False, False, True)

return a, b, c처럼 쉼표로 이으면 튜플 하나를 돌려줘요. 이 검사기를 비밀번호 만들기 풀이 끝에 붙이면 "규칙을 지키는지" 자동으로 확인할 수 있어요.

핵심 한 줄: 세트 & 세트가 비었는지로 "그 종류가 있는지"를 알 수 있어요.
