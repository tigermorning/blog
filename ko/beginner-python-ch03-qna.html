함수가 뭐예요? len()도 함수라는데요?

함수는 자주 하는 일을 이름 하나로 묶어 둔 것이에요. 1장에서 리스트 원소 개수를 셀 때 쓴 len()이 바로 함수예요.

>>> len(a_list)                                                   # a_list 의 길이가 얼마예요?
13

  • len()이 없다면 개수를 셀 때마다 반복문을 새로 짜야 해요.

def는 뭐예요?

def는 define(정의하다)의 줄임말이에요. "지금부터 함수를 하나 만들겠다"고 파이썬에 알려 주는 낱말이에요.

개념 설명용 코드 — 각 부분의 이름을 보여 주려는 예시예요

def boy():                    # boy 라는 동작을 만들어 주세요
    print('I am a boy.')      # 'I am a boy.' 를 화면에 보여 주세요
    print('You are a girl.')  # 'You are a girl.' 를 화면에 보여 주세요

  • def는 파이썬이 쓰려고 정해 둔 낱말(예약어)이라 변수 이름으로 쓸 수 없어요. if, for, while도 마찬가지예요.

boy()를 치면 어떻게 두 줄이 나오나요?

함수는 만드는 순간과 실행하는 순간이 따로 있기 때문이에요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

...     print('I am a boy.')      # 'I am a boy.' 를 화면에 보여 주세요
...     print('You are a girl.')  # 'You are a girl.' 를 화면에 보여 주세요
...
>>> boy()                # boy 를 실행해 주세요
I am a boy.
You are a girl.
언제파이썬이 하는 일화면
def로 만들 때"boy라는 이름으로 이 두 줄을 저장해 둔다"만 기억아무것도 안 나옴
boy()로 부를 때저장한 줄을 위에서 아래로 차례대로 실행두 줄 출력
  • 대화형 셸에서는 ... 줄에서 빈 줄로 엔터를 한 번 더 쳐야 정의가 끝나요.
  • boy()를 또 입력하면 같은 두 줄이 또 나와요. 한 번 만들어 두면 계속 쓸 수 있어요.
  • 괄호 없이 boy만 입력하면 <function boy at 0x...>처럼 나와요. "이런 함수가 있다"는 정보일 뿐 실행은 안 돼요. 실행하려면 반드시 ()를 붙여요. 이 증상이 보일 때 ↓

핵심 한 줄: def는 요리법을 적어 두는 일이고, 이름()이 그 요리법대로 요리를 시작하는 일이에요.

def greet(name):          # name 을 받는 greet 라는 동작을 만들어 주세요

a_list를 만들었는데 왜 print a_list가 아니라 print list예요?

print list가 아니라 print_list 한 단어예요. 밑줄(_)로 이어진 함수 이름이라 띄어 읽으면 안 돼요.

실행: 로컬 파이썬 — 아무 환경 OK

def print_list(a):                                            # a 를 받는 print_list 라는 동작을 만들어 주세요
    for i in a:                                               # a 의 원소를 하나씩 i 라고 부르며 아래를 반복해 주세요
        print(i)                                              # i 를 화면에 보여 주세요

a_list = [3, 4, 62, 27, 83, 956, 26, 58, 3, 78, 168, 64, 78]  # 숫자 13개의 리스트를 a_list 에 담아 주세요
print_list(a_list)                                            # print_list 에 a_list 를 넣어 실행해 주세요
  • print_list는 저자가 "리스트를 출력한다"는 뜻으로 지은 이름이에요. show로 지어도 똑같이 동작해요.
  • 파이썬에 원래 있는 print()와는 다른 함수예요.
  • a_list는 이름을 바꾸지 않고 그대로 쓰였어요. 함수 이름 뒤 괄호 안에 인수로 들어간 거예요.

실행 순서를 따라가면 이래요.

  1. print_list(a_list)를 불러요.
  2. 함수 안에서 a = a_list가 돼요 (매개변수가 값을 받는 순간).
  3. for i in a:가 원소를 하나씩 꺼내 print(i)로 출력해요 (2장 후반부의 for 문).

이 절은 매개변수가 있는 함수와 없는 함수를 비교하는 내용인가요?

반은 맞아요. 이 절은 함수를 처음 소개하는 글이고, 두 종류를 나란히 보여 주는 건 뒷부분이에요. 흐름은 네 단계예요.

  1. 함수는 이미 써 봤다 — len()이 함수였다 (함수란)
  2. 매개변수 있는 함수 만들기 — print_list(a) (print_list)
  3. 매개변수 없는 함수 만들기 — boy() (함수 부르기)
  4. 직접 만들어 보기 — 두 수 비교 과제 (두 수 비교)
print_list(a)boy()
매개변수있음 (a)없음
부르는 법print_list(a_list)boy()
결과넣는 값에 따라 달라짐몇 번을 불러도 같음

핵심 한 줄: 매개변수가 있으면 넣는 값에 따라 다르게 동작하는 함수가 되고, 없으면 늘 같은 일을 하는 함수가 돼요.

두 수 비교 과제의 답은요? a와 b를 정의 안 했잖아요?

과제는 a가 크면 'a > b', b가 크면 'a < b', 같으면 'a == b'를 출력하는 함수를 만드는 거예요. 예시 답은 이래요.

실행: 파이썬 대화형 셸 — 정의를 끝낸 뒤 빈 줄 엔터를 한 번 더

>>> def compare(a, b):  # a 와 b 를 받는 compare 라는 동작을 만들어 주세요
...     if a > b:             # 만약 a 가 b 보다 크면
...         print('a > b')    # 'a > b' 를 화면에 보여 주세요
...     elif a < b:           # 아니고, 만약 a 가 b 보다 작으면
...         print('a < b')    # 'a < b' 를 화면에 보여 주세요
...     else:                    # 그 밖의 경우에는
...         print('a == b')      # 'a == b' 를 화면에 보여 주세요
...
>>> compare(5, 3)       # compare 에 5 와 3 을 넣어 실행해 주세요
a > b
>>> compare(2, 7)       # compare 에 2 와 7 을 넣어 실행해 주세요
a < b
>>> compare(4, 4)       # compare 에 4 와 4 를 넣어 실행해 주세요
a == b

a와 b는 따로 정의할 필요가 없어요. 둘은 매개변수라서 부를 때 값이 들어와요.

부르는 줄ab참인 조건
compare(5, 3)53a > b
compare(2, 7)27a < b
compare(4, 4)44else
  • 넣은 순서대로 들어가요. 첫 번째 값은 a, 두 번째 값은 b로 가요.
  • 세 경우 중 하나는 반드시 참이라, 마지막은 else로 충분해요 (2장의 if/elif/else).
  • 교재가 "(x, y)와 같은 형식"이라고 한 것도 같은 뜻이에요. 이름은 x, y든 a, b든 상관없어요.

값을 안 넣고 부르면 파이썬이 빈자리를 알려 줘요.

3.1.1 연습 문제: 자릿수를 구하는 함수 만들기

문제 원문: wikidocs.net/192431 · 양의 정수를 받아 몇 자리 수인지 출력하는 함수 numOfDigits() 만들기

print(len(str(num)))는 어디서부터 읽나요?

저자 풀이 전체예요 (numdigits.py).

실행: 로컬 파이썬 — 아무 환경 OK

def numOfDigits(num):     # num 을 받는 numOfDigits 라는 동작을 만들어 주세요
    print(len(str(num)))  # num 을 글자로 바꾼 것의 길이를 화면에 보여 주세요
  • numOfDigits: 함수 이름. "number of digits(자릿수)"예요.
  • num: 매개변수. 자릿수를 셀 숫자가 여기로 들어와요.

괄호가 세 겹이면 안쪽부터 읽어요. numOfDigits(1234)를 부르면 이렇게 진행돼요.

순서코드결과설명
1num1234숫자
2str(num)'1234'문자열로 바꿈
3len('1234')4글자 수를 셈
4print(4)화면에 4출력

왜 문자열로 바꾸나요? len()은 숫자의 길이를 세지 못해요.

실행: 파이썬 대화형 셸

>>> len(12345)    # 12345 의 길이가 얼마예요?
TypeError: object of type 'int' has no len()
>>> len('12345')  # '12345' 의 길이가 얼마예요?
5

핵심 한 줄: "숫자의 자릿수 = 그 숫자를 글자로 적었을 때 글자 수"라는 아이디어를 str()과 len() 두 함수로 옮긴 풀이예요.

도입부의 _, 8000_000_000, e+28은 뭐예요?

문제 앞에서 IP 주소 개수를 세는 코드에 처음 보는 표기가 세 가지 나와요.

실행: 파이썬 대화형 셸 — _는 셸에서만 동작해요

>>> 256 ** 4                              # 256 의 4제곱이 얼마예요?
4294967296
>>> len(str(_))                           # 바로 앞 결과를 글자로 바꾼 것의 길이가 얼마예요?
10
>>> 256 ** 4 == (2 ** 8) ** 4 == 2 ** 32  # 256 의 4제곱, (2 의 8제곱)의 4제곱, 2 의 32제곱이 모두 같나요?
True
>>> 2 ** 128 / 8000_000_000               # 2 의 128제곱을 8000_000_000 으로 나누면 얼마예요?
4.253529586511731e+28
표기뜻
_ (밑줄 하나)대화형 셸에서 바로 앞 결과를 가리키는 이름. 여기서는 4294967296. .py 파일에서는 이렇게 동작하지 않아요
a == b == c셋이 모두 같은가? 256은 2⁸이라 (2⁸)⁴ = 2³²로 모두 같아서 True
8000_000_000숫자 속 밑줄은 읽기 편하라고 넣는 구분자예요. 파이썬은 무시하고 8000000000으로 읽어요
e+28"× 10²⁸"이라는 뜻. 아주 큰 실수는 이렇게 줄여서 보여 줘요

len(str(_))는 앞 절 자릿수 풀이와 똑같은 모양이에요. 저자가 문제를 내기 전에 답의 아이디어를 미리 보여 준 셈이에요.

이 풀이는 어떤 입력에서 틀리나요?

문제가 "양의 정수"라고 조건을 단 이유가 여기 있어요. 다른 값을 넣으면 에러 없이 이상한 답이 나와요.

입력결과이유
123455정상
01'0'은 한 글자. 0을 한 자리로 본다면 정상
-1204'-120'의 -도 한 글자로 셈
3.144'3.14'의 .도 한 글자로 셈

그리고 이 함수는 결과를 화면에 찍기만 해요. 변수에 담으면 None이 들어가요 (print와 return의 차이에서 자세히).

실행: 파이썬 대화형 셸

>>> r = numOfDigits(7)  # numOfDigits 에 7 을 넣어 돌려받은 값을 r 에 담아 주세요
1
>>> print(r)            # r 을 화면에 보여 주세요
None

핵심 한 줄: 남의 함수를 읽을 때는 "이 함수는 어떤 입력을 가정하고 있나?"와 "결과를 돌려주나, 찍기만 하나?"를 먼저 확인해요.

3.1.2 연습 문제: 구구단

문제 원문: wikidocs.net/67 · 2단부터 9단까지 구구단 출력하기. 교재는 한 번에 만들지 말고 2 * 1 → 2단 → 한 단 함수 → 전체 순으로 쪼개서 가요.

f'...'가 뭐였죠?

f-string이에요. 문자열 안에 변수 값이나 계산 결과를 끼워 넣을 때 써요. 2장의 f-string에서 처음 나왔어요.

실행: 파이썬 대화형 셸

>>> m = 2                        # m 에 2 를 담아 주세요
>>> n = 1                        # n 에 1 을 담아 주세요
>>> print(m, '*', n, '=', m*n)   # m, '*', n, '=', m*n 을 차례로 화면에 보여 주세요
2 * 1 = 2
>>> print(f'{m} * {n} = {m*n}')  # m 과 n 과 m*n 을 글자 사이에 끼워 넣은 문장을 화면에 보여 주세요
2 * 1 = 2
  • 첫 번째 방법은 값 5개를 쉼표로 나열해요. print가 쉼표 사이에 공백을 한 칸씩 넣어 줘요.
  • 두 번째 방법은 따옴표 앞에 f를 붙이고, { } 안을 값으로 바꿔요.
문자열 속 부분바뀐 결과
{m}2
* 글자 그대로
{n}1
= 글자 그대로
{m*n}계산해서 2

{ } 안에는 변수뿐 아니라 m*n 같은 식도 쓸 수 있어요. 결과는 같지만 f-string 쪽이 출력될 모양 그대로 보여서 읽기 쉬워요.

{m*n:2d}에서 :2d는 무슨 뜻이에요?

값을 어떤 모양으로 출력할지 정하는 서식이에요. { } 안에서 콜론(:) 뒤에 써요.

부분뜻
:여기부터 서식 지정
2최소 2칸을 차지
d정수(decimal, 10진수)로 출력

값이 2칸보다 짧으면 왼쪽을 공백으로 채워 오른쪽에 붙여요.

실행: 파이썬 대화형 셸

>>> f'[{4:2d}]'    # 4 를 2칸 폭으로 글자 사이에 끼워 넣은 문장을 만들어 주세요
'[ 4]'
>>> f'[{4:3d}]'    # 4 를 3칸 폭으로 글자 사이에 끼워 넣은 문장을 만들어 주세요
'[  4]'
>>> f'[{123:2d}]'  # 123 을 2칸 폭으로 글자 사이에 끼워 넣은 문장을 만들어 주세요
'[123]'
>>> f'{2.5:2d}'    # 2.5 를 2칸 정수 폭으로 글자 사이에 끼워 넣은 문장을 만들어 주세요
ValueError: Unknown format code 'd' for object of type 'float'
  • 칸 수보다 긴 값은 잘리지 않고 그대로 다 나와요.
  • d는 정수 전용이라 소수(2.5)에 쓰면 에러가 나요.

구구단에서 쓰면 차이가 이렇게 보여요.

{m*n} (서식 없음){m*n:2d}
2 * 4 = 82 * 4 =  8
2 * 5 = 102 * 5 = 10

핵심 한 줄: :2d는 한 자리 결과 앞에 공백을 하나 넣어, 일의 자리를 세로로 맞추는 서식이에요.

multi(m) 함수는 어떻게 읽나요?

저자 풀이 전체예요 (multiplication_table.py).

실행: 로컬 파이썬 — 아무 환경 OK — 파일로 저장해 실행하면 2단~9단이 모두 나와요

def multi(m):                           # m 을 받는 multi 라는 동작을 만들어 주세요
    for n in range(1, 10):              # 1 부터 9 까지 하나씩 n 이라고 부르며 아래를 반복해 주세요
        print(f'{m} * {n} = {m*n:2d}')  # m 과 n 과 m*n 을 글자 사이에 끼워 넣은 문장을 화면에 보여 주세요

if __name__ == '__main__':              # 만약 __name__ 이 '__main__' 이면
    for i in range(2, 10):              # 2 부터 9 까지 하나씩 i 라고 부르며 아래를 반복해 주세요
        multi(i)                        # multi 에 i 를 넣어 실행해 주세요
        print()                         # 빈 줄을 화면에 보여 주세요

함수 부분은 "몇 단을 받아서 그 단 9줄을 출력"하는 일을 해요.

  • multi: multiplication(곱셈)에서 따온 이름이에요.
  • m: 매개변수. 몇 단을 출력할지 이 자리로 들어와요.
  • range(1, 10): 1부터 9까지. 끝 숫자 10은 들어가지 않아요 (2장 후반부의 range()).
  • m은 고정, n만 1 → 9로 바뀌어요.

실행: 파이썬 대화형 셸 — 위 함수를 정의한 뒤

>>> multi(3)  # multi 에 3 을 넣어 실행해 주세요
3 * 1 =  3
3 * 2 =  6
3 * 3 =  9
3 * 4 = 12
3 * 5 = 15
3 * 6 = 18
3 * 7 = 21
3 * 8 = 24
3 * 9 = 27

아래 부분은 그 함수를 반복문 안에서 여러 번 불러요.

이름어디 있나값뜻
i바깥 for2 → 9몇 단인지
m함수 매개변수부를 때의 imulti(i)로 받은 값
n함수 안 for1 → 9곱하는 수
  • print()처럼 괄호를 비우면 빈 줄 하나가 나와요. 단과 단 사이를 띄우는 용도예요.
  • 출력 줄 수는 9줄 × 8단 + 빈 줄 8개 = 80줄이에요.
  • if __name__ == '__main__':은 "이 파일을 직접 실행했을 때만 아래를 실행하라"는 뜻이에요. 다른 파일이 multi만 가져다 쓸 때(5장의 import)는 아래가 실행되지 않아요. 지금은 "실행 시작 지점 표시"로 읽으면 충분해요.

함수 없이 쓰면? 교재가 "직접 해 보라"고 남긴 이중 반복문 버전이에요. 짜는 대신 읽어 보면, 결과가 위와 똑같아요.

실행: 로컬 파이썬 — 아무 환경 OK

for m in range(2, 10):                  # 2 부터 9 까지 하나씩 m 이라고 부르며 아래를 반복해 주세요
    for n in range(1, 10):              # 1 부터 9 까지 하나씩 n 이라고 부르며 아래를 반복해 주세요
        print(f'{m} * {n} = {m*n:2d}')  # m 과 n 과 m*n 을 글자 사이에 끼워 넣은 문장을 화면에 보여 주세요
    print()                             # 빈 줄을 화면에 보여 주세요
  • 바깥 for가 한 번 돌 때 안쪽 for는 9번 돌아요.
  • print()는 안쪽 for와 들여쓰기가 달라서, 한 단이 끝날 때마다 한 번만 실행돼요.
  • 함수 버전의 장점은 multi(7)처럼 원하는 단만 따로 부를 수 있다는 거예요.

3.2 반환(return) 문

원문: wikidocs.net/63

return y와 print(y)는 어떻게 달라요?

둘 다 화면에 35가 보여서 같아 보이지만 하는 일이 달라요.

  • print(y)는 값을 화면에 보여 주기만 해요. 함수를 부른 쪽에는 아무것도 돌려주지 않아요.
  • return y는 값을 함수를 부른 쪽에 돌려줘요. 받은 값은 변수에 담거나 다른 계산에 다시 쓸 수 있어요.

실행: 파이썬 대화형 셸

>>> def f1(x):  # x 를 받는 f1 이라는 동작을 만들어 주세요
...     y = 3 * x + 5    # 3 * x + 5 를 y 에 담아 주세요
...     return y         # y 를 결과로 돌려주세요
...
>>> def f2(x):  # x 를 받는 f2 라는 동작을 만들어 주세요
...     y = 3 * x + 5    # 3 * x + 5 를 y 에 담아 주세요
...     print(y)         # y 를 화면에 보여 주세요
...
>>> c = f1(10)  # f1 에 10 을 넣어 돌려받은 값을 c 에 담아 주세요
>>> print(c)    # c 를 화면에 보여 주세요
35
>>> d = f2(10)  # f2 에 10 을 넣어 돌려받은 값을 d 에 담아 주세요
35
>>> print(d)    # d 를 화면에 보여 주세요
None
c = f1(10)d = f2(10)
함수 안에서35를 계산해 돌려줌35를 계산해 화면에 찍음
화면아무것도 안 나옴35 ← 첫 번째 35의 정체
변수에 들어간 값c = 35d = None ("값 없음")

차이는 그 결과로 계산을 이어 갈 때 확실히 드러나요.

실행: 파이썬 대화형 셸

>>> f1(10) + 1  # f1 에 10 을 넣어 돌려받은 값에 1 을 더하면 얼마예요?
36
>>> f2(10) + 1  # f2 에 10 을 넣어 돌려받은 값에 1 을 더하면 얼마예요?
35
TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'
  • f1은 35를 돌려주니까 35 + 1이 계산돼요.
  • f2는 35를 화면에 찍고 None을 돌려줘요. None + 1은 계산할 수 없어서 에러가 나요. 이 에러를 만났을 때 ↓
계산기에서함수에서
화면에 답을 띄움. 눈으로 보이지만 그 숫자를 가져다 쓸 수는 없음print
답을 종이에 적어 손에 쥐여 줌. 받아서 저장하거나 다른 계산에 씀return

핵심 한 줄: print는 사람에게 보여 주는 것이고, return은 코드에게 넘겨주는 것이에요.

셸에서는 둘 다 35가 보이던데요?

대화형 셸(>>>)은 돌려받은 값을 자동으로 보여 주기 때문이에요.

실행: 파이썬 대화형 셸

>>> f1(10)  # f1 에 10 을 넣으면 뭐가 돌아오나요?
35
>>> f2(10)  # f2 에 10 을 넣어 실행해 주세요
35
셸에서 f1(10).py 파일에서 f1(10)
화면35 (셸이 자동으로 보여 줌)아무것도 안 나옴
보이게 하려면그대로 둠print(f1(10))
  • f2(10)의 35는 함수 안의 print가 찍은 거라 셸이든 파일이든 늘 보여요.
  • 셸에서 결과가 보였다고 그 함수에 return이 있다는 뜻은 아니에요.
  • 반대로 .py로 옮겼더니 결과가 안 보인다면, return만 하고 print로 감싸지 않은 거예요. 이 증상이 보일 때 ↓

3.2.1 연습 문제의 예시 결과가 '일'처럼 따옴표째 보이는 것도 같은 이유예요. 셸이 돌려받은 문자열을 자동으로 보여 줄 때는 따옴표를 붙여요. print였다면 따옴표 없이 일로 나와요.

return 뒤에 1 + 2 == int(ans) 같은 식을 써도 되나요?

돼요. return 뒤에 식이 오면 식을 계산한 결과가 돌아가요. 교재의 덧셈 퀴즈 함수가 그 예예요.

실행: 파이썬 대화형 셸 — 부를 때마다 답을 입력하라고 기다려요

>>> def quiz():          # 받는 값 없이 quiz 라는 동작을 만들어 주세요
...     ans = input('1 + 2 = ')   # '1 + 2 = ' 를 보이고 입력받은 글자를 ans 에 담아 주세요
...     return 1 + 2 == int(ans)  # ans 를 정수로 바꾼 값이 1 + 2 와 같은지를 결과로 돌려주세요
...
>>> quiz()               # quiz 를 실행하면 뭐가 돌아오나요?
1 + 2 = 3
True
>>> quiz()               # quiz 를 실행하면 뭐가 돌아오나요?
1 + 2 = 4
False
  1. input('1 + 2 = ')가 화면에 1 + 2 = 를 띄우고 입력을 문자열로 받아요.
  2. int(ans)가 '3'을 숫자 3으로 바꿔요.
  3. 1 + 2 == 3은 True예요. ==는 "같은가?"를 묻는 연산이라 결과가 True나 False예요 (2장의 비교 연산).
  4. return이 그 True를 돌려줘요.

int()를 빼면? 3 == '3'이 되는데, 숫자와 문자열은 다른 값이라 늘 False예요. 맞는 답을 넣어도 틀렸다고 나와요.

3.2.1 연습 문제: 숫자 읽기 함수(1~10)

문제 원문: wikidocs.net/124002 · 1~10 정수를 받아 한국어 읽기('일', '이', …)를 반환하는 함수 korean_number()

return이 열 개인데 어떻게 동작해요? 11을 넣으면요?

저자 풀이예요 (korean_1_to_10.py). 4~9는 같은 모양이라 줄였어요.

실행: 로컬 파이썬 — 아무 환경 OK — 줄인 부분을 채워 넣으면 그대로 돌아가요

def korean_number(num):  # num 을 받는 korean_number 라는 동작을 만들어 주세요
    if num == 1:         # 만약 num 이 1 이면
        return '일'      # '일' 을 결과로 돌려주세요
    elif num == 2:       # 아니고, 만약 num 이 2 이면
        return '이'      # '이' 를 결과로 돌려주세요
    elif num == 3:       # 아니고, 만약 num 이 3 이면
        return '삼'      # '삼' 을 결과로 돌려주세요
    # ... 4부터 9까지 같은 모양 ...
    elif num == 10:      # 아니고, 만약 num 이 10 이면
        return '십'      # '십' 을 결과로 돌려주세요
  • 위에서부터 차례로 비교하다가 참인 조건을 만나면 그 줄의 return을 실행해요 (2장의 elif 체인).
  • return을 만나는 순간 함수가 끝나요. korean_number(3)이면 1, 2를 거쳐 3에서 '삼'을 돌려주고 끝나요. 아래 elif는 보지도 않아요.
  • 그래서 return이 열 개 있어도, 한 번 부를 때 실행되는 건 딱 하나예요.

11을 넣으면? 어떤 조건에도 안 맞아서 return을 한 번도 못 만나고 함수가 끝나요. 그러면 파이썬은 자동으로 None을 돌려줘요.

실행: 파이썬 대화형 셸

>>> print(korean_number(11))              # korean_number 에 11 을 넣어 돌려받은 값을 화면에 보여 주세요
None
>>> korean_number(1) + korean_number(11)  # korean_number 에 1 을 넣은 값에 11 을 넣은 값을 더하면 뭐가 되나요?
TypeError: can only concatenate str (not "NoneType") to str
  • None을 출력만 할 때는 에러가 안 나요. 조용히 넘어가요.
  • 그 값을 쓰는 순간('일' + None) 에러가 나요. 원인은 11을 넣은 줄인데, 에러는 다른 줄에서 터져요.
  • 문제가 "1 이상 10 이하라고 가정"이라고 쓴 이유예요.

리스트로 한 줄에 줄인 버전은 왜 0에서 이상한 답을 내나요?

같은 일을 리스트로 줄여 쓴 코드를 읽어 볼게요.

실행: 로컬 파이썬 — 아무 환경 OK

def korean_number(num):                                                           # num 을 받는 korean_number 라는 동작을 만들어 주세요
    return ['일', '이', '삼', '사', '오', '육', '칠', '팔', '구', '십'][num - 1]  # 리스트의 num - 1 번째 글자를 결과로 돌려주세요
  • 리스트 번호는 0부터 시작해요 (1장). 그래서 1을 넣으면 [0]번 '일'이 나오도록 num - 1을 해요.
  • 음수 번호 [-1]은 "뒤에서 첫 번째"라는 뜻이에요.
입력if 버전 (return 열 개)리스트 버전
1'일''일' ([0])
10'십''십' ([9])
11NoneIndexError: list index out of range
0None'십' ([-1]) — 에러 없이 틀린 답

핵심 한 줄: 같은 문제를 푼 코드라도 모양이 다르면 잘못된 입력에서 틀리는 방식이 달라요. 에러가 나는 쪽이 조용히 틀리는 쪽보다 찾기 쉬워요.

3.2.2 연습 문제: 함수 정의하기

문제 원문: wikidocs.net/121662 · 문제 1은 숫자는 3배, 문자열은 3번 반복하는 triple(), 문제 2는 태어난 해로 한국 나이를 구하는 korean_age()

triple() 한 줄로 숫자와 문자열을 둘 다 처리하는 이유는?

저자 풀이예요 (define_functions.py).

실행: 로컬 파이썬 — 아무 환경 OK

def triple(x):    # x 를 받는 triple 이라는 동작을 만들어 주세요
    return x * 3  # x * 3 을 결과로 돌려주세요

*가 값의 종류에 따라 다르게 동작하기 때문이에요.

실행: 파이썬 대화형 셸 — 위 함수를 정의한 뒤

>>> triple(2)       # triple 에 2 를 넣으면 뭐가 돌아오나요?
6
>>> triple('x')     # triple 에 'x' 를 넣으면 뭐가 돌아오나요?
'xxx'
>>> triple([1, 2])  # triple 에 [1, 2] 를 넣으면 뭐가 돌아오나요?
[1, 2, 1, 2, 1, 2]
들어온 값* 3이 하는 일
숫자곱셈
문자열3번 이어 붙이기 (1장의 '* ' * 3과 같은 원리)
리스트3번 이어 붙이기

그래서 "숫자용", "문자열용" 함수를 따로 만들 필요가 없어요. 대신 input()으로 받은 '3'을 int() 없이 넣으면 9가 아니라 '333'이 나와요.

korean_age()는 어떻게 읽나요?

저자 풀이예요 (같은 파일).

실행: 로컬 파이썬 — 아무 환경 OK

def korean_age(birth_year):             # birth_year 를 받는 korean_age 라는 동작을 만들어 주세요
    from datetime import datetime       # datetime 도구 상자에서 datetime 을 가져와 주세요
    today = datetime.today()            # datetime.today() 의 값을 today 에 담아 주세요
    return today.year - birth_year + 1  # today.year - birth_year + 1 을 결과로 돌려주세요
줄하는 일
from datetime import datetime날짜를 다루는 도구 datetime을 가져와요 (모듈은 5장)
today = datetime.today()지금 날짜와 시각을 today에 담아요
today.year그중 연도만 꺼내요 (예: 2026)
- birth_year + 1올해 − 태어난 해 + 1
  • + 1은 태어나자마자 1살로 세는 세는 나이라서 붙어요.
  • 2026년에 실행하면 korean_age(2000)은 2026 - 2000 + 1 = 27이에요.
  • 실행하는 해에 따라 결과가 달라져요. 교재 예시는 2021년 기준이라 숫자가 다를 수 있어요.
  • import가 함수 안에 있어서 부를 때마다 실행돼요. 보통은 파일 맨 위에 한 번 써요.
  • 참고로 2023년 6월부터 법과 행정에서 쓰는 나이는 만 나이로 통일됐어요. 이 함수는 계산 연습으로 읽으면 돼요.

3.2.3 연습 문제: 이자(단리) 계산

문제 원문: wikidocs.net/109529 · 원금·이율·기간을 받아 단리 이자와 원리금(원금 + 이자)을 돌려주는 함수 두 개

공식을 함수로 옮기면 인수는 어떻게 들어가나요?

단리는 원금에만 이자가 붙는 방식이라 해마다 이자가 같아요. 공식은 두 개예요.

구하는 것공식
이자원금 × 이율 × 기간
원리금원금 × (1 + 이율 × 기간)

저자 풀이는 공식을 그대로 옮긴 모양이에요 (simpleInterest.py).

실행: 로컬 파이썬 — 아무 환경 OK

def simple_interest(p, r, t):         # p, r, t 를 받는 simple_interest 라는 동작을 만들어 주세요
    return p * r * t                  # p * r * t 를 결과로 돌려주세요

def simple_interest_amount(p, r, t):  # p, r, t 를 받는 simple_interest_amount 라는 동작을 만들어 주세요
    return p * (1 + r * t)            # p * (1 + r * t) 를 결과로 돌려주세요

실행: 파이썬 대화형 셸 — 위 두 함수를 정의한 뒤

>>> simple_interest(10000000, 0.03875, 5)  # simple_interest 에 10000000, 0.03875, 5 를 넣으면 뭐가 돌아오나요?
1937500.0
>>> simple_interest(1100000, 0.05, 5/12)   # simple_interest 에 1100000, 0.05, 5/12 를 넣으면 뭐가 돌아오나요?
22916.666666666668
부르는 줄p (원금)r (이율)t (기간, 년)
첫 번째100000000.03875 (3.875%)5
두 번째11000000.05 (5%)5/12 (5개월)
  • 인수는 순서대로 들어가요. 순서를 바꿔 넣으면 에러 없이 틀린 답이 나와요. 언제 의심하나 ↓
  • 첫 번째는 10000000 × 0.03875 = 387500.0(1년 이자) × 5 = 1937500.0이에요.
  • 결과에 .0이 붙는 건 이율 0.03875가 소수라서예요.
  • 기간이 5개월이면 5/12년으로 넣어요. 함수를 고칠 필요가 없어요.

원리금의 끝자리가 왜 계산할 때마다 달라요?

수학으로는 같은 값인데, 계산 순서를 바꾸면 맨 끝자리가 달라져요.

실행: 파이썬 대화형 셸 — 단리 이자의 두 함수를 정의한 뒤

>>> simple_interest_amount(1100000, 0.05, 5/12)     # simple_interest_amount 에 1100000, 0.05, 5/12 를 넣으면 뭐가 돌아오나요?
1122916.6666666665
>>> 1100000 + simple_interest(1100000, 0.05, 5/12)  # 1100000 에 simple_interest(1100000, 0.05, 5/12) 의 값을 더하면 얼마예요?
1122916.6666666667
  • 컴퓨터의 소수는 아주 작은 오차를 품고 있어요. 2장의 얌체공에서 본 것과 같은 원인이에요.
  • 계산 순서가 다르면 오차가 쌓이는 방식도 달라져서 끝자리가 달라요.
  • 실제 돈 계산에서는 원 단위로 반올림하거나 금액을 정수로 다뤄요.

함수를 다시 쓰는 버전도 읽어 볼게요. 원리금 = 원금 + 이자이니, 이미 만든 함수를 불러 쓸 수 있어요.

실행: 로컬 파이썬 — 아무 환경 OK

def simple_interest_amount(p, r, t):     # p, r, t 를 받는 simple_interest_amount 라는 동작을 만들어 주세요
    return p + simple_interest(p, r, t)  # p 와 simple_interest(p, r, t) 의 합을 결과로 돌려주세요
  • 공식이 바뀌어도 simple_interest 한 곳만 고치면 돼요.
  • simple_interest가 return하기 때문에 가능한 모양이에요. print만 했다면 p + None이 되어 에러가 나요 (print와 return의 차이).

3.2.5 퀴즈

문제 원문: wikidocs.net/292549

퀴즈 두 문제의 정답과 함정은?

퀴즈 1 — 이 코드의 출력은? (보기: 4, 12, 444, None)

실행: 로컬 파이썬 — 아무 환경 OK

def triple(x):      # x 를 받는 triple 이라는 동작을 만들어 주세요
    return x * 3    # x * 3 을 결과로 돌려주세요

result = triple(4)  # triple 에 4 를 넣어 돌려받은 값을 result 에 담아 주세요
print(result)       # result 를 화면에 보여 주세요
  • 정답은 12예요. x = 4 → 4 * 3 = 12 → return → result = 12
  • 444는 triple('4')처럼 문자열을 넣었을 때의 답이에요 (triple()). 4는 따옴표가 없는 숫자예요.
  • None은 return 대신 print를 썼을 때의 답이에요.

퀴즈 2 — x와 y에는 무엇이 들어갈까요?

실행: 로컬 파이썬 — 아무 환경 OK

def print_sum(a, b):   # a 와 b 를 받는 print_sum 이라는 동작을 만들어 주세요
    print(a + b)       # a + b 를 화면에 보여 주세요

def return_sum(a, b):  # a 와 b 를 받는 return_sum 이라는 동작을 만들어 주세요
    return a + b       # a + b 를 결과로 돌려주세요

x = print_sum(3, 5)    # print_sum 에 3 과 5 를 넣어 돌려받은 값을 x 에 담아 주세요
y = return_sum(3, 5)   # return_sum 에 3 과 5 를 넣어 돌려받은 값을 y 에 담아 주세요
  • 정답은 x = None, y = 8이에요.
  • print_sum은 화면에 8을 찍고 아무것도 돌려주지 않아요.
  • return_sum은 화면에 아무것도 안 찍고 8을 돌려줘요.
  • 함정: 이 코드를 실행하면 화면에 8이 한 번 나와요. 그건 print_sum 안의 print가 찍은 거지, y의 값이 나온 게 아니에요.

이럴 때 의심하세요 — 함수를 만들었는데 결과가 이상할 때

함수 문제는 에러가 원인과 다른 줄에서 나거나, 아예 에러 없이 조용히 틀리는 경우가 많아요. 결과가 예상과 다르면 이 표부터 확인해요.

증상이 아직 없어도, AI에게 이런 부탁을 한 직후라면 한 번 확인하고 넘어가요.

  • "이 계산을 함수로 빼 줘" — 새 함수가 결과를 return하는지, print만 하는지
  • "함수 매개변수 순서를 정리해 줘" — 그 함수를 부르는 모든 줄의 인수 순서도 같이 바뀌었는지
이런 증상이 보이면먼저 열어 볼 자리확인 방법
TypeError 메시지에 NoneType이 들어 있거나, 변수를 찍어 보니 None이 나와요 그 값을 만든 함수. 에러가 난 줄은 범인이 아니라 그 값을 쓴 줄이에요 함수에 return이 있는지, 모든 if 갈래가 return을 만나는지 확인하고, print만 하고 있으면 return으로 바꿔요 (print와 return의 차이, return이 열 개)
함수를 만들었는데 실행해도 아무 일이 없거나, <function 이름 at 0x...>가 찍혀요 함수를 부르는 줄. def 안쪽 코드는 범인이 아닌 경우가 많아요 부르는 줄이 아예 있는지, 이름 뒤에 ()가 붙었는지 봐요 (함수 부르기)
TypeError: 이름() missing 2 required positional arguments가 나요 함수를 부르는 줄의 괄호 안 def 줄의 매개변수 개수와 부를 때 넣은 인수 개수가 같은지 세어 봐요 (두 수 비교)
셸에서는 결과가 보였는데, 같은 코드를 .py 파일로 실행하니 아무것도 안 나와요 함수를 부르는 줄 이름(값)만 있고 print(이름(값))으로 감싸지 않았는지 봐요 (셸의 자동 출력)
에러는 없는데 이자·넓이 같은 결과가 터무니없이 크거나 작아요 함수를 부르는 줄의 인수 순서 def 줄의 매개변수 순서와 넣은 값의 순서를 한 칸씩 짝지어 봐요. 손으로 계산한 답 하나와 비교하면 빨라요 (단리 이자)
