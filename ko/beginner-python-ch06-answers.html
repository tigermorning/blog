6.2.1 밴드 이름 짓기 (2)

문제: 색 이름이 한 줄에 하나씩 든 color.txt와 음식 이름이 한 줄에 하나씩 든 food.txt를 읽어서, 색 하나와 음식 하나를 무작위로 이어 밴드 이름을 지어요. 원문 보기 (앞 문제는 5장의 random 모듈로 같은 일을 하되 목록을 코드 안에 적었어요.)

먼저 읽은 모양만 확인 — .py 파일에서 실행

with open('color.txt', encoding='utf-8') as f:  # color.txt 를 UTF-8 읽기용으로 열어 f 라 불러 주세요
    colors = f.readlines()                      # colors 에 f 의 모든 줄을 리스트로 담아 주세요
print(colors)                                   # colors 를 화면에 보여 주세요
['아이보리\n', '미드나이트블루\n', '라이트그레이\n', '플럼\n', '씨쉘\n', '미디엄터콰이즈\n']

파일 안에는 줄마다 끝에 줄 바꿈 글자 \n(메모장에서 엔터를 친 자리)이 저장돼 있고, readlines()는 줄을 그 \n까지 그대로 가져와요. 그래서 그대로 이으면 밴드 이름 가운데가 줄 바꿈으로 끊겨요. 이름을 이을 때 strip()으로 떼요.

※ 앞 장에서는 파일을 읽지 않아서 \n이 보이지 않았어요. input()은 엔터로 들어온 \n을 알아서 떼 주지만, 파일에서 읽은 줄은 떼 주지 않아요.

.py 파일(bandname2.py)로 저장해서 실행

import random                                   # random 모듈을 가져와 주세요

with open('color.txt', encoding='utf-8') as f:  # color.txt 를 UTF-8 읽기용으로 열어 f 라 불러 주세요
    colors = f.readlines()                      # colors 에 f 의 모든 줄을 리스트로 담아 주세요
with open('food.txt', encoding='utf-8') as f:   # food.txt 를 UTF-8 읽기용으로 열어 f 라 불러 주세요
    foods = f.readlines()                       # foods 에 f 의 모든 줄을 리스트로 담아 주세요

food = random.choice(foods).strip()             # food 에 foods 중 하나를 무작위로 골라 줄 끝을 지워 담아 주세요
print(color, food)                              # color 와 food 를 화면에 보여 주세요

6.2.2 비밀 메시지

문제: 1943년 일본의 포로수용소에 있던 미군이 보낸 엽서를 postcard.txt에 저장하고, 단계별로 가공해 숨은 메시지를 찾아요. 엽서는 머리말·본문·꼬리말이 빈 줄 한 줄로 나뉘어 있어요. 원문 보기

풀이 · 실행 결과 · 설명 보기

① 파일 읽기 ② 본문만 추리기 ③ . , : 지우기 ④ 대문자로 ⑤ 각 줄의 앞 두 단어만 이어 붙이기, 다섯 단계예요. 앞 단계의 변수를 이어 쓰니 한 단계씩 코드를 더해 가요.

5. 각 줄의 앞 두 단어만 이어 붙이기

words = []                      # words 에 빈 리스트를 담아 주세요
for line in body.splitlines():  # body 를 줄 단위로 나눈 것을 하나씩 line 이라 부르며 아래를 반복해 주세요
    words += line.split()[:2]   # words 에 line 을 낱말로 나눈 것 중 앞 두 개를 더해 주세요
print(' '.join(words))          # words 의 낱말들을 공백으로 이어 화면에 보여 주세요
AFTER SURRENDER FIFTY PERCENT AMERICANS LOST IN PHILIPPINES IN NIPPON 30% SALARY

아래 그림은 for 가 본문을 한 줄씩 꺼내 각 줄의 앞 두 낱말만 words 에 모으는 모습이에요.

② 단계에서split('\n\n')의 결과 개수가 3이면 머리말·본문·꼬리말로 정확히 나뉜 거예요. 가운데 덩어리(parts[1])가 본문이에요. 빈 줄에 공백이 섞여 있으면 개수가 달라질 수 있으니, 이 값을 먼저 찍어 보는 습관이 도움이 돼요.

⑤ 단계에서는 split()에 아무것도 안 적었어요. 공백이 몇 칸이든 하나로 보고 낱말만 뽑아 주거든요. split(' ')와 비교해 봐요.

line = 'FIFTY PERCENT  BETTER FOOD ETC'  # line 에 'FIFTY PERCENT  BETTER FOOD ETC' (PERCENT 뒤에 공백 두 칸) 를 담아 주세요
print(line.split())                      # line 을 공백 기준으로 낱말만 뽑아 화면에 보여 주세요
print(line.split(' '))                   # line 을 공백 한 칸마다 잘라 화면에 보여 주세요
['FIFTY', 'PERCENT', 'BETTER', 'FOOD', 'ETC']
['FIFTY', 'PERCENT', '', 'BETTER', 'FOOD', 'ETC']

split(' ')는 공백을 한 칸마다 잘라서, 공백이 두 칸 붙어 있으면 그 사이의 빈 글자('')도 낱말처럼 하나 만들어요. 그래서 낱말의 개수와 자리가 어긋날 수 있어요.

이 엽서 본문에서는 공백 두 칸이 모두 앞 두 낱말 뒤쪽에 있어서, split(' ')[:2]와 split()[:2]가 여섯 줄 모두 같았어요. 두 칸 공백이 앞쪽에 있는 줄이면 달라져요. 'AB CD EF' 는 split()[:2]가 ['AB', 'CD']이고 split(' ')[:2]는 ['AB', '']예요.

이 글의 postcard.txt는 문제의 엽서 내용을 설명대로(머리말 · 빈 줄 · 본문 · 빈 줄 · 꼬리말) 저장한 파일이에요. 문제에 정리된 결과(AFTER SURRENDER FIFTY PERCENT AMERICANS LOST IN PHILIPPINES IN NIPPON 30% SALARY)와 같은 글이 나왔어요.

6.2.2 끝말 잇기 (3)

문제: 끝말 잇기를 하는데, 컴퓨터와 사용자가 쓰는 단어를 텍스트 파일에 든 단어로 제한해요. 그 밖의 규칙은 끝말 잇기 (2)와 같아요(두음법칙 포함). 원문 보기 두음법칙을 처리하는 starts()는 5.3.5 끝말 잇기 (2) 해설에서 만든 것을 그대로 가져왔어요. 어떻게 글자를 쪼개는지는 그 글에 있어요.

풀이 · 실행 결과 · 설명 보기

(2)와 달라진 곳은 단어 목록을 코드 안의 큰 세트가 아니라 파일에서 읽는다는 것 하나예요. 파일에는 단어가 한 줄에 하나씩 있어서 read().split()으로 낱말 리스트를 만들고, 세트로 바꿔요.

korean_words.txt를 만들고 .py 파일로 실행 — 플레이어 입력: 차박, 쥐구멍, 게시판

with open('korean_words.txt', encoding='utf-8') as f:           # korean_words.txt 를 UTF-8 읽기용으로 열어 f 라 불러 주세요
    WORDS = set(f.read().split())                               # WORDS 에 f 의 내용을 낱말로 나눠 세트로 담아 주세요

YO = (2, 3, 6, 7, 12, 17, 20)                                   # YO 에 ㅑ ㅒ ㅕ ㅖ ㅛ ㅠ ㅣ 의 모음 번호를 담아 주세요

def starts(ch):                                                 # ch 를 받는 starts 라는 동작을 만들어 주세요
    result = {ch}                                               # result 에 ch 자신이 든 세트를 담아 주세요
    code = ord(ch) - 0xAC00                                     # code 에 ch 의 글자 번호에서 '가' 의 번호를 뺀 값을 담아 주세요
    if not 0 <= code < 11172:                                   # 만약 code 가 한글 글자 범위 밖이면
        return result                                           # result 를 결과로 돌려주세요
    first = code // 588                                         # first 에 초성 번호를 담아 주세요
    vowel = code % 588 // 28                                    # vowel 에 모음 번호를 담아 주세요
    tail = code % 28                                            # tail 에 받침 번호를 담아 주세요
    if first == 5:                                              # 만약 초성이 ㄹ 이면
        new = 11 if vowel in YO else 2                          # new 에 (모음이 YO 에 있으면 ㅇ, 아니면 ㄴ) 의 초성 번호를 담아 주세요
    elif first == 2 and vowel in YO:                            # 아니고 만약 초성이 ㄴ 이고 모음이 YO 에 있으면
        new = 11                                                # new 에 ㅇ 의 초성 번호를 담아 주세요
    else:                                                       # 그 밖에는
        return result                                           # result 를 결과로 돌려주세요
    result.add(chr(0xAC00 + (new * 21 + vowel) * 28 + tail))    # result 에 초성만 new 로 바꾼 글자를 더해 주세요
    return result                                               # result 를 결과로 돌려주세요

last = '기차'                                                     # last 에 '기차' 를 담아 주세요
used = {last}                                                   # used 에 last 가 든 세트를 담아 주세요
print('끝말잇기를 하자. 내가 먼저 말할게.', last)                             # '끝말잇기를 하자. 내가 먼저 말할게.' 와 last 를 화면에 보여 주세요

while True:                                                     # 아래를 끝없이 반복해 주세요
    word = input('> ')                                          # '> ' 를 보여 주고 입력받은 것을 word 에 담아 주세요
    if word == '졌어':                                            # 만약 word 가 '졌어' 와 같으면
        print('내가 이겼다!')                                        # '내가 이겼다!' 를 화면에 보여 주세요
        break                                                   # 반복을 끝내 주세요
    if word[:1] not in starts(last[-1]):                        # 만약 word 의 첫 글자가 last 의 마지막 글자로 이을 수 있는 글자에 없으면
        print('글자가 안 이어져. 내가 이겼다!')                             # '글자가 안 이어져. 내가 이겼다!' 를 화면에 보여 주세요
        break                                                   # 반복을 끝내 주세요
    if word in used:                                            # 만약 word 가 used 에 있으면
        print('아까 했던 말이야. 내가 이겼어!')                             # '아까 했던 말이야. 내가 이겼어!' 를 화면에 보여 주세요
        break                                                   # 반복을 끝내 주세요
    used.add(word)                                              # used 에 word 를 더해 주세요
    ok = starts(word[-1])                                       # ok 에 word 의 마지막 글자로 이을 수 있는 첫 글자들을 담아 주세요
    candidates = sorted(w for w in WORDS - used if w[0] in ok)  # candidates 에 아직 안 쓴 단어 중 첫 글자가 ok 에 있는 것을 정렬해 담아 주세요
    if not candidates:                                          # 만약 candidates 가 비어 있으면
        print('모르겠다. 내가 졌어.')                                   # '모르겠다. 내가 졌어.' 를 화면에 보여 주세요
        break                                                   # 반복을 끝내 주세요
    last = candidates[0]                                        # last 에 candidates 의 첫 단어를 담아 주세요
    used.add(last)                                              # used 에 last 를 더해 주세요
    print(last)                                                 # last 를 화면에 보여 주세요

파일 한 줄이 한 단어라서 split() 하나로 한꺼번에 낱말 리스트가 돼요. 단어를 더 넣고 싶으면 파일에 한 줄 더 적기만 하면 되고, 코드는 고치지 않아요. 이것이 "프로그램과 데이터를 따로 관리한다"는 6.1절의 뜻이에요.

6.2.3 영어 퀴즈

문제: 우리말 문장과 영어 문장이 탭으로 나뉜 ko_en.txt로 영어 퀴즈를 내요. 우리말 문장을 보여 주고, 영어 문장을 입력받아 맞았는지 알려 줘요. 원문 보기

풀이 · 실행 결과 · 설명 보기

파일은 한 줄이 "우리말, 탭, 영어" 모양이에요. 한 줄을 읽어서 탭에서 자르면 두 조각이 나와요.

with open('ko_en.txt', encoding='utf-8') as f:  # ko_en.txt 를 UTF-8 읽기용으로 열어 f 라 불러 주세요
    line = f.readline()                         # line 에 f 의 첫 줄을 담아 주세요
print(repr(line))                               # line 을 보이는 모양 그대로 화면에 보여 주세요
print(line.strip().split('\t'))                 # line 의 줄 끝을 지우고 탭에서 자른 리스트를 화면에 보여 주세요
'그녀는 작가가 아니다.\tShe is not a writer.\n'
['그녀는 작가가 아니다.', 'She is not a writer.']

탭은 글자로 \t라고 써요. strip()으로 줄 끝의 \n을 먼저 떼야 영어 문장 끝에 \n이 안 붙어요.

.py 파일로 실행 — 플레이어 입력: She is not a writer. / They are in the classroom. / I am home.

with open('ko_en.txt', encoding='utf-8') as f:         # ko_en.txt 를 UTF-8 읽기용으로 열어 f 라 불러 주세요
    lines = f.readlines()                              # lines 에 f 의 모든 줄을 리스트로 담아 주세요

for line in lines:                                     # lines 의 줄을 하나씩 line 이라 부르며 아래를 반복해 주세요
    ko, en = line.strip().split('\t')                  # line 의 줄 끝을 지우고 탭에서 잘라, 앞은 ko 에 뒤는 en 에 담아 주세요
    print('Write the following sentence in English.')  # 'Write the following sentence in English.' 를 화면에 보여 주세요
    print(ko)                                          # ko 를 화면에 보여 주세요
    answer = input('your answer: ')                    # 'your answer: ' 를 보여 주고 입력받은 것을 answer 에 담아 주세요
    if answer == en:                                   # 만약 answer 가 en 과 같으면
        print('result: Correct!')                      # 'result: Correct!' 를 화면에 보여 주세요
    else:                                              # 아니면
        print('result: Not correct!')                  # 'result: Not correct!' 를 화면에 보여 주세요
        print('right answer:' + en)                    # 'right answer:' 와 en 을 이어 화면에 보여 주세요
    print('-' * 70)                                    # '-' 를 70번 이은 글자를 화면에 보여 주세요

세 번째 문제는 일부러 틀린 답을 넣어 Not correct!와 정답이 나오게 했어요. 영어 문장은 대소문자와 마침표까지 같아야 맞은 걸로 보니, 더 너그럽게 채점하려면 answer.strip().lower() == en.lower()처럼 바꿀 수 있어요.

6.3 파일을 입맛대로 연습 문제

6.3.1 애국가

문제: korean_national_anthem_1.txt~korean_national_anthem_4.txt에 애국가 1~4절이 한 파일에 한 절씩 들어 있어요. 이 파일들을 읽어 out.txt 한 파일에 "파일 이름, 구분선, 가사" 모양으로 모아 써요. 원문 보기

풀이 · 실행 결과 · 설명 보기

이름이 korean_national_anthem_으로 시작하는 파일을 찾으려면 glob('korean_national_anthem_*.txt')를 써요. glob이 주는 순서는 정해져 있지 않아서 sorted()로 1절부터 순서대로 만들어요. 구분선은 파일 이름 길이만큼 -를 이어 만들어요.

.py 파일로 실행 — 네 파일이 있는 폴더에서

from glob import glob                                          # glob 모듈에서 glob 을 가져와 주세요

with open('out.txt', 'w', encoding='utf-8') as out:            # out.txt 를 UTF-8 쓰기용으로 열어 out 이라 불러 주세요
    for name in sorted(glob('korean_national_anthem_*.txt')):  # 이름이 맞는 파일들을 정렬해 하나씩 name 이라 부르며 아래를 반복해 주세요
        out.write(name + '\n')                                 # out 에 name 과 줄 바꿈을 써 주세요
        out.write('-' * len(name) + '\n')                      # out 에 name 의 글자 수만큼 '-' 를 이은 글자와 줄 바꿈을 써 주세요
        with open(name, encoding='utf-8') as f:                # name 을 UTF-8 읽기용으로 열어 f 라 불러 주세요
            out.write(f.read())                                # out 에 f 의 내용 전부를 써 주세요

print(open('out.txt', encoding='utf-8').read())                # out.txt 의 내용을 읽어 화면에 보여 주세요

아래 그림은 for 가 가사 파일 네 개를 차례로 열어 out.txt 에 이어 쓰는 모습이에요.

with를 겹쳐 써서 쓰는 파일 하나와 읽는 파일 하나를 함께 열었어요. 바깥 with가 끝나면 out.txt가 저절로 닫히고 비로소 내용이 파일에 확실히 적혀서, 마지막 줄에서 다시 열어 읽을 수 있어요. 이 글에서 만든 가사 파일은 마지막 줄 끝에도 \n이 있어서 다음 절의 파일 이름이 새 줄에서 시작해요. 내려받은 파일의 마지막 줄 끝에 \n이 없으면 다음 파일 이름이 가사 끝에 붙어 나오니, 그때는 out.write(f.read()) 뒤에 out.write('\n')을 한 줄 더해요.
