초급

문제 1

다음 값의 자료형을 각각 맞혀 보세요. (5), (5,), (), {}, {5}, set(), {5: 'a'}

정답·해설 보기 (문제 1)

정답 코드

print(type((5)), type((5,)), type(()))                   # (5), (5,), () 의 자료형을 화면에 보여 주세요
print(type({}), type({5}), type(set()), type({5: 'a'}))  # {}, {5}, set(), {5: 'a'} 의 자료형을 화면에 보여 주세요
<class 'int'> <class 'tuple'> <class 'tuple'>
<class 'dict'> <class 'set'> <class 'set'> <class 'dict'>

(5)는 콤마가 없어서 튜플이 아니라 정수예요. 원소 하나짜리 튜플은 (5,)예요. 중괄호는 비어 있으면 딕셔너리, 값만 나열하면 세트, 키: 값이 있으면 딕셔너리예요. 빈 세트는 set()으로 만들어요.

문제 2

임시 변수 없이 x = 3, y = 7의 값을 맞바꿔 출력하세요. 이어서 튜플 t = (1, 2, 3)의 0번 원소를 9로 바꾸면 어떻게 되는지 확인하세요.

정답·해설 보기 (문제 2)

정답 코드

print(x, y)                 # x 와 y 를 화면에 보여 주세요

    print('TypeError:', e)  # 'TypeError:' 와 e 를 화면에 보여 주세요

x, y = y, x는 오른쪽에 (y, x) 튜플을 만들어 왼쪽에 풀어 담아요. 튜플은 불변이라 원소 대입이 TypeError를 일으키고, 튜플은 그대로 남아요.

문제 5

숫자를 몇 개든 받아 합계와 개수를 함께 돌려주는 함수 total을 만드세요. total(4, 8, 15)는 통째로 받아 출력하고, total(1, 2)는 두 변수에 풀어 받아 출력하고, 인자 없는 total()의 결과도 출력하세요.

정답·해설 보기 (문제 5)

정답 코드

def total(*nums):         # 남는 인자를 모두 nums 로 받는 total 이라는 동작을 만들어 주세요
    s = 0                 # s 에 0 을 담아 주세요
    for n in nums:        # nums 의 원소를 하나씩 n 이라고 부르며 아래를 반복해 주세요
        s += n            # s 에 n 을 더해 다시 담아 주세요
    return s, len(nums)   # s 와 nums 의 길이를 결과로 돌려주세요
result = total(4, 8, 15)  # result 에 total 에 4, 8, 15 를 넣은 결과를 담아 주세요
s, count = total(1, 2)    # total 에 1, 2 를 넣은 결과를 s 와 count 에 나눠 담아 주세요
print(result)             # result 를 화면에 보여 주세요
print(s, count)           # s 와 count 를 화면에 보여 주세요
print(total())            # total 에 아무것도 넣지 않은 결과를 화면에 보여 주세요
(27, 3)
3 2
(0, 0)

*nums가 인자를 튜플로 모으고, return s, len(nums)는 튜플 하나를 돌려줘요. 받는 쪽은 result처럼 통째로 받거나 s, count처럼 풀어 받을 수 있어요. 인자가 없으면 nums는 빈 튜플이라 합계 0, 개수 0이에요.

문제 6

문자열 'banana'에서 글자별로 몇 번 나오는지 딕셔너리로 세어 출력하세요. (count() 메서드는 쓰지 않아요.)

정답·해설 보기 (문제 6)

정답 코드

word = 'banana'         # word 에 'banana' 를 담아 주세요
count = {}              # count 에 빈 딕셔너리를 담아 주세요
for ch in word:         # word 의 글자를 하나씩 ch 라고 부르며 아래를 반복해 주세요
    if ch in count:     # 만약 ch 가 count 의 키에 있으면
        count[ch] += 1  # count 의 ch 자리에 1 을 더해 다시 담아 주세요
    else:               # 아니면
        count[ch] = 1   # count 의 ch 자리에 1 을 담아 주세요
print(count)            # count 를 화면에 보여 주세요
{'b': 1, 'a': 3, 'n': 2}

글자를 키로, 나온 횟수를 값으로 해요. 처음 보는 글자(ch in count가 False)는 1로 만들고, 이미 있는 글자는 1을 더해요. 문자열도 반복문으로 한 글자씩 꺼낼 수 있어요.

문제 7

수학반 {'철수', '영희', '민수'}와 미술반 {'영희', '지현', '민수', '서연'}이 있어요. 두 반에 모두 있는 학생, 둘 중 한 반에라도 있는 학생과 그 수, 수학반에만 있는 학생을 구하세요. (출력은 정렬해요)

정답·해설 보기 (문제 7)

정답 코드

math = {'철수', '영희', '민수'}                   # math 에 수학반 학생 세트를 담아 주세요
art = {'영희', '지현', '민수', '서연'}              # art 에 미술반 학생 세트를 담아 주세요
print(sorted(math & art))                   # math 와 art 의 교집합을 정렬해서 화면에 보여 주세요
print(sorted(math | art), len(math | art))  # math 와 art 의 합집합을 정렬한 것과 그 원소 개수를 화면에 보여 주세요
print(sorted(math - art))                   # math 에서 art 를 뺀 차집합을 정렬해서 화면에 보여 주세요
['민수', '영희']
['민수', '서연', '영희', '지현', '철수'] 5
['철수']

"모두"는 교집합 &, "하나라도"는 합집합 |, "~에만"은 차집합 -예요. 합집합에서는 두 반에 모두 있는 학생을 한 번만 세요.

문제 8

점수 딕셔너리 scores = {'철수': 82, '영희': 95, '민수': 78}에서 최고 점수를 받은 사람의 이름과 점수를 max() 없이 구하세요.

정답·해설 보기 (문제 8)

정답 코드

scores = {'철수': 82, '영희': 95, '민수': 78}  # scores 에 이름과 점수가 짝지어진 딕셔너리를 담아 주세요
best_name = None                         # best_name 에 None 을 담아 주세요
best_score = -1                          # best_score 에 -1 을 담아 주세요
for name, score in scores.items():       # scores 의 (키, 값) 쌍을 하나씩 name 과 score 라고 부르며 아래를 반복해 주세요
    if score > best_score:               # 만약 score 가 best_score 보다 크면
        best_name = name                 # best_name 에 name 을 담아 주세요
        best_score = score               # best_score 에 score 를 담아 주세요
print(best_name, best_score)             # best_name 과 best_score 를 화면에 보여 주세요
영희 95

items()가 (키, 값) 튜플을 내주고 for name, score in ...가 그것을 풀어 담아요. 지금까지의 최고 점수보다 크면 이름과 점수를 바꿔요. 시작값 -1은 어떤 점수보다 작아서 첫 반복에서 반드시 바뀌어요.

문제 9

이름 리스트 ['민수', '영희', '민수', '철수', '영희', '지현']에서 중복을 지우되 처음 나온 순서는 유지한 리스트를 만드세요. (set(names)만 쓰면 순서가 보장되지 않아요.)

정답·해설 보기 (문제 9)

정답 코드

names = ['민수', '영희', '민수', '철수', '영희', '지현']  # names 에 이름 여섯 개의 리스트를 담아 주세요
seen = set()                                  # seen 에 빈 세트를 담아 주세요
unique = []                                   # unique 에 빈 리스트를 담아 주세요
for n in names:                               # names 의 원소를 하나씩 n 이라고 부르며 아래를 반복해 주세요
    if n not in seen:                         # 만약 n 이 seen 에 없으면
        seen.add(n)                           # seen 에 n 을 더해 주세요
        unique.append(n)                      # unique 의 맨 뒤에 n 을 붙여 주세요
print(unique)                                 # unique 를 화면에 보여 주세요
['민수', '영희', '철수', '지현']

세트 seen은 "이미 본 이름인지" 확인하는 데만 쓰고, 순서는 리스트 unique가 맡아요. 처음 보는 이름일 때만 두 곳에 모두 넣어요. 세트는 순서가 없고 리스트는 중복을 막지 못하는 약점을 서로 보완한 거예요.

print((0, 0) in grid)                     # (0, 0) 이 grid 의 키에 있나요?

True

문제 11

1부터 20까지의 수 중 2의 배수 세트와 3의 배수 세트를 각각 만든 뒤, 둘 모두에 속하는 수(6의 배수)를 작은 것부터 출력하세요.

정답·해설 보기 (문제 11)

정답 코드

evens = set()                  # evens 에 빈 세트를 담아 주세요
threes = set()                 # threes 에 빈 세트를 담아 주세요
for n in range(1, 21):         # 1 부터 20 까지의 수를 하나씩 n 이라고 부르며 아래를 반복해 주세요
    if n % 2 == 0:             # 만약 n 을 2 로 나눈 나머지가 0 이면
        evens.add(n)           # evens 에 n 을 더해 주세요
    if n % 3 == 0:             # 만약 n 을 3 으로 나눈 나머지가 0 이면
        threes.add(n)          # threes 에 n 을 더해 주세요
print(sorted(evens & threes))  # evens 와 threes 의 교집합을 정렬해서 화면에 보여 주세요
[6, 12, 18]

range(1, 21)은 1부터 20까지예요. %가 나머지라서 n % 2 == 0이 2의 배수예요. 두 if는 서로 독립이라 elif가 아니라 if 두 개로 써요. 교집합 &로 두 조건을 모두 만족하는 수를 얻어요.

문제 12

문자열을 받아 단어별 등장 횟수를 딕셔너리로 돌려주는 함수 word_count(text)를 만들고, 'to be or not to be'로 불러 단어를 사전순으로 출력하세요.

정답·해설 보기 (문제 12)

정답 코드

def word_count(text):                      # text 를 받는 word_count 라는 동작을 만들어 주세요
    counts = {}                            # counts 에 빈 딕셔너리를 담아 주세요
    for w in text.split():                 # text 를 공백으로 자른 단어를 하나씩 w 라고 부르며 아래를 반복해 주세요
        if w in counts:                    # 만약 w 가 counts 의 키에 있으면
            counts[w] += 1                 # counts 의 w 자리에 1 을 더해 다시 담아 주세요
        else:                              # 아니면
            counts[w] = 1                  # counts 의 w 자리에 1 을 담아 주세요
    return counts                          # counts 를 결과로 돌려주세요
result = word_count('to be or not to be')  # result 에 word_count 에 'to be or not to be' 를 넣은 결과를 담아 주세요
for w in sorted(result):                   # result 의 키를 정렬한 것을 하나씩 w 라고 부르며 아래를 반복해 주세요
    print(w, result[w])                    # w 와 result 의 w 자리에 담긴 것을 화면에 보여 주세요
be 2
not 1
or 1
to 2

split()이 단어 리스트를 만들고, 문제 6과 같은 방식으로 세요. 함수가 딕셔너리를 return해요. sorted(딕셔너리)는 키를 정렬한 리스트를 돌려주니 사전순으로 돌 수 있어요.

문제 13

숫자 리스트에서 최솟값과 최댓값을 튜플로 돌려주는 함수 min_max(nums)를 min()·max() 없이 만드세요. [7, 3, 9, 1, 5]는 두 변수에 풀어 받아 출력하고, [4]는 결과를 그대로 출력하세요.

정답·해설 보기 (문제 13)

정답 코드

def min_max(nums):                 # nums 를 받는 min_max 라는 동작을 만들어 주세요
    low = nums[0]                  # low 에 nums 의 첫 원소를 담아 주세요
    high = nums[0]                 # high 에 nums 의 첫 원소를 담아 주세요
    for n in nums:                 # nums 의 원소를 하나씩 n 이라고 부르며 아래를 반복해 주세요
        if n < low:                # 만약 n 이 low 보다 작으면
            low = n                # low 에 n 을 담아 주세요
        if n > high:               # 만약 n 이 high 보다 크면
            high = n               # high 에 n 을 담아 주세요
    return low, high               # low 와 high 를 결과로 돌려주세요
lo, hi = min_max([7, 3, 9, 1, 5])  # min_max 에 [7, 3, 9, 1, 5] 를 넣은 결과를 lo 와 hi 에 나눠 담아 주세요
print(lo, hi)                      # lo 와 hi 를 화면에 보여 주세요
print(min_max([4]))                # min_max 에 [4] 를 넣은 결과를 화면에 보여 주세요
1 9
(4, 4)

첫 원소로 low, high를 시작해 하나씩 비교하며 바꿔요. 원소가 하나뿐이면 최솟값과 최댓값이 같아요. return low, high가 튜플을 돌려주고 부르는 쪽에서 풀어 받아요.

문제 14

전화번호부 프로그램을 만드세요. add는 이름과 번호를 저장하고, find는 이름으로 번호를 찾고 없으면 "없는 이름입니다."를 출력하고, quit는 "등록된 사람 수:"를 출력하고 끝내요. (번호는 예시용 가짜 값이에요.)

정답·해설 보기 (문제 14)

정답 코드

book = {}                               # book 에 빈 딕셔너리를 담아 주세요
while True:                             # 아래를 끝없이 반복해 주세요
    cmd = input('명령(add/find/quit): ')  # '명령(add/find/quit): ' 를 보여 주고 입력받은 것을 cmd 에 담아 주세요
    if cmd == 'quit':                   # 만약 cmd 가 'quit' 와 같으면
        break                           # 반복을 끝내 주세요
    elif cmd == 'add':                  # 아니고 만약 cmd 가 'add' 와 같으면
        name = input('이름: ')            # '이름: ' 을 보여 주고 입력받은 것을 name 에 담아 주세요
        number = input('번호: ')          # '번호: ' 를 보여 주고 입력받은 것을 number 에 담아 주세요
        book[name] = number             # book 의 name 자리에 number 를 담아 주세요
    elif cmd == 'find':                 # 아니고 만약 cmd 가 'find' 와 같으면
        name = input('이름: ')            # '이름: ' 을 보여 주고 입력받은 것을 name 에 담아 주세요
        if name in book:                # 만약 name 이 book 의 키에 있으면
            print(book[name])           # book 의 name 자리에 담긴 것을 화면에 보여 주세요
        else:                           # 아니면
            print('없는 이름입니다.')          # '없는 이름입니다.' 를 화면에 보여 주세요
print('등록된 사람 수:', len(book))           # '등록된 사람 수:' 와 book 의 길이를 화면에 보여 주세요
명령(add/find/quit): add
이름: 철수
번호: 010-1111-2222
명령(add/find/quit): find
이름: 철수
010-1111-2222
명령(add/find/quit): find
이름: 영희
없는 이름입니다.
명령(add/find/quit): quit
등록된 사람 수: 1

이름을 키, 번호를 값으로 하는 딕셔너리가 전화번호부 역할을 해요. while True로 명령을 계속 받다가 quit에서 break해요. 같은 이름으로 add를 다시 하면 번호가 덮어써져요. 위 결과는 add 철수 → find 철수 → find 영희 → quit 순서로 입력했을 때예요.
