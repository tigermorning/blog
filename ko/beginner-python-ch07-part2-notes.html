7.2 변수와 메서드 정리 — 왕초보 Python 7장 객체지향 (2)

2026. 11. 19.

※ 이 글은 위키독스 『왕초보를 위한 Python』 7.2절과 영상은 노마드 코더의 「객체지향 프로그래밍? 문과도 이해쌉가능. 10분컷.」인데, 영어 음성의 자동 자막 전체를 읽고 정리했어요. 화면에 나온 코드는 보지 못해서 예제는 파이썬으로 새로 짜서 직접 돌렸어요. 코드 실행 결과는 실제로 돌려서 넣었어요.

클래스 안에 적은 변수는 모든 인스턴스가 처음에 물려받는 값이고, 메서드 안의 self 는 그 메서드를 부른 인스턴스 자신이에요.

앞 내용은 7.1 클래스와 인스턴스 정리에 있어요.

1. 변수와 메서드를 가진 클래스 (7.2)

말뜻
클래스 변수클래스 안, 메서드 밖에 적은 변수. 만든 인스턴스가 처음에 그대로 가져다 쓴다
메서드클래스 안의 함수. 첫 매개변수는 항상 self
self그 메서드를 부른 인스턴스. 정의할 때는 적고, 부를 때는 쓰지 않는다 (jane.attack())
self.변수 += 값그 인스턴스의 변수만 바꾼다
class Amazon:                       # Amazon 클래스를 정의해 주세요
    strength = 20                   # 클래스 변수 strength 에 20 을 담아 주세요
    dexterity = 25                  # 클래스 변수 dexterity 에 25 를 담아 주세요
    vitality = 20                   # 클래스 변수 vitality 에 20 을 담아 주세요
    energy = 15                     # 클래스 변수 energy 에 15 를 담아 주세요
    def attack(self):               # attack 메서드를 정의해 주세요
        return 'Jab!!!'             # 'Jab!!!' 를 돌려주세요
    def exercise(self):             # exercise 메서드를 정의해 주세요
        self.strength += 2          # 이 인스턴스의 strength 에 2 를 더해 주세요
        self.dexterity += 3         # 이 인스턴스의 dexterity 에 3 을 더해 주세요
        self.vitality += 1          # 이 인스턴스의 vitality 에 1 을 더해 주세요
jane = Amazon()                     # jane 에 Amazon 인스턴스를 만들어 담아 주세요
mary = Amazon()                     # mary 에 Amazon 인스턴스를 만들어 담아 주세요
print(jane.strength, jane.attack()) # jane 의 strength 와 공격 결과를 화면에 보여 주세요
jane.exercise()                     # jane 에게 훈련을 시켜 주세요
print(jane.strength, jane.dexterity, jane.vitality)  # jane 의 힘·기술·체력을 화면에 보여 주세요
20 Jab!!!
22 28 21

※ 위키독스 예제는 디아블로2 게임의 아마존 캐릭터를 클래스로 만든 거예요. 교재는 이 코드를 diablo2.py로 저장하고 import diablo2 한 뒤 diablo2.Amazon()으로 인스턴스를 만들어요.

2. self 가 왜 필요한가

jane과 mary는 같은 exercise 메서드를 써요. 메서드가 “누구의 힘을 올릴지” 알아야 하니, 부른 인스턴스가 자동으로 첫 매개변수 self에 들어와요.

부르는 모양일어나는 일
jane.exercise()self 가 jane 이 된다 → jane 의 strength 가 올라간다
mary.exercise()self 가 mary 가 된다 → mary 의 strength 가 올라간다
Amazon.exercise()부른 인스턴스가 없어서 self 를 채울 수 없다 → 오류
jane = Amazon()                          # jane 에 Amazon 인스턴스를 만들어 담아 주세요
mary = Amazon()                          # mary 에 Amazon 인스턴스를 만들어 담아 주세요
jane.exercise()                          # jane 에게 훈련을 시켜 주세요
print(jane.strength, mary.strength)      # jane 과 mary 의 strength 를 화면에 보여 주세요
print(Amazon.strength)                   # Amazon 클래스의 strength 를 화면에 보여 주세요
print(jane.__dict__)                     # jane 이 따로 가진 변수들을 화면에 보여 주세요
22 20
20
{'strength': 22, 'dexterity': 28, 'vitality': 21}

※ jane.strength += 2는 클래스 변수 20을 읽어 22로 계산한 뒤 jane 자신의 변수로 따로 저장해요. 그래서 mary와 Amazon 클래스의 값은 20 그대로예요. __dict__에는 jane 이 따로 가진 값만 나와서 energy는 보이지 않아요(jane 이 바꾸지 않았으니 클래스 값을 그대로 읽는 중이에요).

Amazon.attack()   # 인스턴스 없이 attack 을 불러 주세요
TypeError: Amazon.attack() missing 1 required positional argument: 'self'

※ 영상은 self(자바스크립트에서는 this)를 “이 플레이어는 xp 라는 속성을 가진다”처럼 읽으면 쉽다고 해요. 그리고 메서드가 있으면 클래스가 데이터만 담는 상자에서 데이터를 읽고 바꾸는 방법까지 정해 둔 틀이 된다고 말해요. 메서드의 예로 인사하기, 공격 받았을 때 체력 줄이기를 들어요.

3. 한눈에 정리

하고 싶은 일쓰는 것
모든 인스턴스가 처음에 같은 값클래스 안에 변수 = 값 (클래스 변수)
인스턴스마다 다른 값__init__ 안에서 self.변수 = 값 (7.1)
메서드 정의def 이름(self, ...): — 첫 매개변수는 self
메서드 부르기인스턴스.이름(...) — self는 쓰지 않는다
내 값 바꾸기self.변수 = 새 값
