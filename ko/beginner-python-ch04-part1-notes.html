자료형·문자열·리스트 정리 — 왕초보 Python 4장 전반부 (1)

2026. 10. 11.

※ 이 글은 위키독스 『왕초보를 위한 Python』 4.1 ~ 4.2.10절(4장 전반부)을 제 나름의 언어로 짧게 정리한 것입니다. 3장 후반부 내용은 3장 후반부 정리에 있어요.

자료형, 문자열, 리스트, 외울 것만 공식처럼.

핵심 정리

개념공식
type(값)자료형 확인
가변 / 불변가변은 list, 불변은 int·str·tuple
x[i], x[a:b]인덱스는 0부터, 슬라이스는 b 앞까지
x[::-1]뒤집기
문자열 메서드원본은 그대로, 새 문자열을 돌려줌
append · sort · insert · del · pop리스트를 직접 바꿈
list() · str() · int() · float()자료형 변환
값 in 리스트완전히 같은 원소가 있나
a[:]리스트 복사본

1. 자료형과 type()

# 숫자: int, float, complex / 시퀀스: str, list, tuple / 그 밖: dict, bool
>>> type(7)
<class 'int'>
>>> type(3.5)
<class 'float'>
>>> type('hi')
<class 'str'>
>>> type([1, 2])
<class 'list'>
>>> type((1, 2))
<class 'tuple'>
>>> type({'a': 1})
<class 'dict'>
>>> type(True)
<class 'bool'>
>>> type(3 + 4j)
<class 'complex'>

# int 끼리 나눠도 / 는 float
>>> 10 / 2
5.0

# 큰 수는 _ 로 자릿수 구분
>>> 100_000_000
100000000

2. 가변 / 불변

# 가변(mutable): list → 안의 원소를 바꿀 수 있다
# 불변: int, str, tuple → 원소를 바꿀 수 없다

핵심 한 줄: 퀴즈 답, 가변 객체는 list.

3. 인덱싱 · 슬라이싱

# x[시작:끝] 은 끝 앞까지
>>> x = 'python'
>>> x[0]
'p'
>>> x[2:4]
'th'
>>> x[:3]
'pyt'
>>> x[3:]
'hon'
>>> x[-1:]
'n'
>>> x[::-1]
'nohtyp'

4. 문자열 불변과 메서드

# 문자열은 불변: 일부만 바꿀 수 없다
>>> x = 'python'
>>> x[0] = 'P'
TypeError: 'str' object does not support item assignment

# 새 문자열을 만들어 다시 붙인다
>>> 'P' + x[1:]
'Python'

>>> s = '  Hello World  '
>>> 'hello'.find('l')
2
>>> 'hello'.find('z')
-1
>>> s.strip()
'Hello World'
>>> s.rstrip()
'  Hello World'
>>> 'a,b,c'.split(',')
['a', 'b', 'c']
>>> 'a b c'.split()
['a', 'b', 'c']
>>> 'cat'.replace('c', 'b')
'bat'
>>> 'ABC'.lower()
'abc'
>>> ', '.join(['사과', '배'])
'사과, 배'

5. 리스트 메서드

>>> L = [3, 1, 2]
>>> L.append(9)
>>> L
[3, 1, 2, 9]
>>> L.sort()
>>> L
[1, 2, 3, 9]
>>> L.insert(0, 7)
>>> L
[7, 1, 2, 3, 9]
>>> del L[1]
>>> L
[7, 2, 3, 9]

# pop() 은 지우고 그 값을 돌려준다
>>> L.pop()
9
>>> L
[7, 2, 3]

# 리스트는 가변이라 대입이 된다
>>> L[0] = 5
>>> L
[5, 2, 3]

# 리스트 안의 리스트
>>> m = [[1, 2], [3, 4]]
>>> m[1][0]
3

6. 변환과 sum

>>> list('abc')
['a', 'b', 'c']
>>> str(123)
'123'
>>> int('123')
123
>>> float('123')
123.0
>>> sum([1, 2, 3])
6
>>> sum(list(range(1, 11)))
55

7. in 과 복사 a[:]

# in 은 원소가 완전히 같을 때만 True (부분 문자열은 False)
>>> books = ['해리포터', '반지의 제왕']
>>> '해리포터' in books
True
>>> '해' in books
False
>>> '반지의 제왕' in books
True

# a[:] 는 복사본: 복사본을 바꿔도 원본은 그대로
>>> a = [1, 2, 3]
>>> b = a[:]
>>> b.remove(2)
>>> b
[1, 3]
>>> a
[1, 2, 3]

# c = a 는 복사가 아니라 같은 리스트: 같이 바뀐다
>>> c = a
>>> c.remove(2)
>>> a
[1, 3]

핵심 한 줄: 순회하면서 그 리스트를 바꾸면 원소를 건너뛰니, L[:] 복사본을 순회하기.
