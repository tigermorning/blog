자료형·문자열·리스트 정리 — 왕초보 Python 4장 전반부 (1)

2026. 10. 11.

※ 이 글은 위키독스 『왕초보를 위한 Python』 4.1 ~ 4.2.10절(4장 전반부)을 제 나름의 언어로 짧게 정리한 것입니다. 3장 후반부 내용은 3장 후반부 정리에 있어요.

자료형, 문자열, 리스트, 외울 것만 공식처럼.

핵심 정리

개념공식
type(값)자료형 확인
가변 / 불변가변은 list, 불변은 int·str·tuple
x[i], x[a:b]인덱스는 0부터, 슬라이스는 b 앞까지
x[::-1]뒤집기
문자열 메서드원본은 그대로, 새 문자열을 돌려줌
append · sort · insert · del · pop리스트를 직접 바꿈
list() · str() · int() · float()자료형 변환
값 in 리스트완전히 같은 원소가 있나
a[:]리스트 복사본

1. 자료형과 type()

# 숫자: int, float, complex / 시퀀스: str, list, tuple / 그 밖: dict, bool
>>> type(7)         # 7은 정수라서 int 예요
<class 'int'>
>>> type(3.5)       # 3.5는 소수라서 float 예요
<class 'float'>
>>> type('hi')      # 따옴표로 감싼 글자는 str 이에요
<class 'str'>
>>> type([1, 2])    # 대괄호로 묶으면 list 예요
<class 'list'>
>>> type((1, 2))    # 소괄호로 묶은 나열은 tuple 이에요
<class 'tuple'>
>>> type({'a': 1})  # 중괄호 안 이름표와 값은 dict 예요
<class 'dict'>
>>> type(True)      # True 는 참거짓 값이라 bool 이에요
<class 'bool'>
>>> type(3 + 4j)    # 4j 가 들어간 수는 complex 예요
<class 'complex'>

# int 끼리 나눠도 / 는 float
>>> 10 / 2          # 정수끼리 / 로 나눠도 결과는 float 예요
5.0

# 큰 수는 _ 로 자릿수 구분
>>> 100_000_000     # _ 는 큰 수를 읽기 쉽게 나눈 표시예요
100000000

2. 가변 / 불변

# 가변(mutable): list → 안의 원소를 바꿀 수 있다
# 불변: int, str, tuple → 원소를 바꿀 수 없다

핵심 한 줄: 퀴즈 답, 가변 객체는 list.

3. 인덱싱 · 슬라이싱

# x[시작:끝] 은 끝 앞까지
>>> x = 'python'  # 변수 x 에 문자열 'python' 을 담아요
>>> x[0]          # 맨 앞 글자 하나를 꺼내요
'p'
>>> x[2:4]        # 2번부터 3번 자리까지 잘라 와요
'th'
>>> x[:3]         # 처음부터 2번 자리까지 잘라 와요
'pyt'
>>> x[3:]         # 3번 자리부터 끝까지 잘라 와요
'hon'
>>> x[-1:]        # 맨 뒤 글자부터 끝까지 잘라 와요
'n'
>>> x[::-1]       # 끝에서 처음으로 거꾸로 읽어요
'nohtyp'

4. 문자열 불변과 메서드

# 문자열은 불변: 일부만 바꿀 수 없다
>>> x = 'python'             # 변수 x 에 문자열 'python' 을 담아요
>>> x[0] = 'P'               # 문자열 일부를 바꾸려 하면 에러가 나요
TypeError: 'str' object does not support item assignment

# 새 문자열을 만들어 다시 붙인다
>>> 'P' + x[1:]              # 'P' 뒤에 x 의 1번부터 끝까지를 붙여요
'Python'

>>> s = '  Hello World  '    # 변수 s 에 앞뒤 공백이 있는 문자열을 담아요
>>> 'hello'.find('l')        # 'l' 이 처음 나온 자리를 알려 줘요
2
>>> 'hello'.find('z')        # 없는 글자는 -1 로 알려 줘요
-1
>>> s.strip()                # 앞뒤 공백을 지워요
'Hello World'
>>> s.rstrip()               # 오른쪽 공백만 지워요
'  Hello World'
>>> 'a,b,c'.split(',')       # 쉼표를 기준으로 잘라 리스트로 만들어요
['a', 'b', 'c']
>>> 'a b c'.split()          # 공백을 기준으로 잘라 리스트로 만들어요
['a', 'b', 'c']
>>> 'cat'.replace('c', 'b')  # 'c' 를 'b' 로 바꾼 새 문자열을 만들어요
'bat'
>>> 'ABC'.lower()            # 모두 소문자로 바꿔요
'abc'
>>> ', '.join(['사과', '배'])   # 리스트 원소를 ', ' 로 이어 한 문자열로 만들어요
'사과, 배'

5. 리스트 메서드

>>> L = [3, 1, 2]         # 변수 L 에 숫자 세 개짜리 리스트를 담아요
>>> L.append(9)           # 리스트 맨 뒤에 9를 덧붙여요
>>> L                     # L 의 현재 내용을 확인해요
[3, 1, 2, 9]
>>> L.sort()              # 작은 수부터 큰 수 순서로 L 을 정렬해요
>>> L                     # L 의 현재 내용을 확인해요
[1, 2, 3, 9]
>>> L.insert(0, 7)        # 0번 자리에 7을 끼워 넣어요
>>> L                     # L 의 현재 내용을 확인해요
[7, 1, 2, 3, 9]
>>> del L[1]              # 1번 자리 원소를 지워요
>>> L                     # L 의 현재 내용을 확인해요
[7, 2, 3, 9]

# pop() 은 지우고 그 값을 돌려준다
>>> L.pop()               # 맨 뒤 원소를 지우고 그 값을 돌려줘요
9
>>> L                     # L 의 현재 내용을 확인해요
[7, 2, 3]

# 리스트는 가변이라 대입이 된다
>>> L[0] = 5              # 0번 자리 값을 5로 바꿔요
>>> L                     # L 의 현재 내용을 확인해요
[5, 2, 3]

# 리스트 안의 리스트
>>> m = [[1, 2], [3, 4]]  # 리스트 안에 리스트를 담아요
>>> m[1][0]               # m 의 1번 리스트에서 0번 원소를 꺼내요
3

6. 변환과 sum

>>> list('abc')              # 문자열을 글자 하나씩 리스트로 만들어요
['a', 'b', 'c']
>>> str(123)                 # 숫자 123을 문자열로 바꿔요
'123'
>>> int('123')               # 문자열 '123'을 정수로 바꿔요
123
>>> float('123')             # 문자열 '123'을 소수로 바꿔요
123.0
>>> sum([1, 2, 3])           # 리스트 안의 수를 모두 더해요
6
>>> sum(list(range(1, 11)))  # 1부터 10까지 수를 리스트로 만들어 더해요
55

7. in 과 복사 a[:]

# in 은 원소가 완전히 같을 때만 True (부분 문자열은 False)
>>> books = ['해리포터', '반지의 제왕']  # 변수 books 에 책 제목 두 개를 담아요
>>> '해리포터' in books             # 원소 중에 '해리포터'가 있는지 물어요
True
>>> '해' in books                # 원소 중에 '해'가 통째로 있는지 물어요
False
>>> '반지의 제왕' in books           # 원소 중에 '반지의 제왕'이 있는지 물어요
True

# a[:] 는 복사본: 복사본을 바꿔도 원본은 그대로
>>> a = [1, 2, 3]               # 변수 a 에 숫자 세 개짜리 리스트를 담아요
>>> b = a[:]                    # a 의 복사본을 만들어 b 에 담아요
>>> b.remove(2)                 # b 에서 값이 2인 원소를 지워요
>>> b                           # b 의 현재 내용을 확인해요
[1, 3]
>>> a                           # a 의 현재 내용을 확인해요
[1, 2, 3]

# c = a 는 복사가 아니라 같은 리스트: 같이 바뀐다
>>> c = a                       # c 가 a 와 같은 리스트를 가리키게 해요
>>> c.remove(2)                 # c 에서 값이 2인 원소를 지워요
>>> a                           # a 의 현재 내용을 확인해요
[1, 3]

핵심 한 줄: 순회하면서 그 리스트를 바꾸면 원소를 건너뛰니, L[:] 복사본을 순회하기.
