자료형·문자열·리스트 정리 — 왕초보 Python 4장 전반부 (1)

2026. 10. 11.

※ 이 글은 위키독스 『왕초보를 위한 Python』 4.1 ~ 4.2.10절(4장 전반부)을 제 나름의 언어로 짧게 정리한 것입니다. 3장 후반부 내용은 3장 후반부 정리에 있어요.

자료형, 문자열, 리스트, 외울 것만 공식처럼.

핵심 정리

개념공식
type(값)자료형 확인
가변 / 불변가변은 list, 불변은 int·str·tuple
x[i], x[a:b]인덱스는 0부터, 슬라이스는 b 앞까지
x[::-1]뒤집기
문자열 메서드원본은 그대로, 새 문자열을 돌려줌
append · sort · insert · del · pop리스트를 직접 바꿈
list() · str() · int() · float()자료형 변환
값 in 리스트완전히 같은 원소가 있나
a[:]리스트 복사본

1. 자료형과 type()

# 숫자: int, float, complex / 시퀀스: str, list, tuple / 그 밖: dict, bool
>>> type(7)         # 7 의 자료형이 뭐예요?
<class 'int'>
>>> type(3.5)       # 3.5 의 자료형이 뭐예요?
<class 'float'>
>>> type('hi')      # 'hi' 의 자료형이 뭐예요?
<class 'str'>
>>> type([1, 2])    # [1, 2] 의 자료형이 뭐예요?
<class 'list'>
>>> type((1, 2))    # (1, 2) 의 자료형이 뭐예요?
<class 'tuple'>
>>> type({'a': 1})  # {'a': 1} 의 자료형이 뭐예요?
<class 'dict'>
>>> type(True)      # True 의 자료형이 뭐예요?
<class 'bool'>
>>> type(3 + 4j)    # 3 + 4j 의 자료형이 뭐예요?
<class 'complex'>

# int 끼리 나눠도 / 는 float
>>> 10 / 2          # 10 을 2 로 나누면?
5.0

# 큰 수는 _ 로 자릿수 구분
>>> 100_000_000     # 100_000_000 에 들어 있는 것이 뭐예요?
100000000

2. 가변 / 불변

# 가변(mutable): list → 안의 원소를 바꿀 수 있다
# 불변: int, str, tuple → 원소를 바꿀 수 없다

핵심 한 줄: 퀴즈 답, 가변 객체는 list.

3. 인덱싱 · 슬라이싱

# x[시작:끝] 은 끝 앞까지
>>> x = 'python'  # x 에 문자열 'python' 을 담아 주세요
>>> x[0]          # x 의 0번 원소는 무엇인가요?
'p'
>>> x[2:4]        # x 의 2번부터 3번까지 잘라 내면?
'th'
>>> x[:3]         # x 의 처음부터 2번까지 잘라 내면?
'pyt'
>>> x[3:]         # x 의 3번부터 끝까지 잘라 내면?
'hon'
>>> x[-1:]        # x 의 뒤에서 1번째부터 끝까지 잘라 내면?
'n'
>>> x[::-1]       # x 를 거꾸로 읽으면 어떻게 되나요?
'nohtyp'

4. 문자열 불변과 메서드

# 문자열은 불변: 일부만 바꿀 수 없다
>>> x = 'python'             # x 에 문자열 'python' 을 담아 주세요
>>> x[0] = 'P'               # x 의 0번 원소를 'P' 로 바꿔 주세요
TypeError: 'str' object does not support item assignment

# 새 문자열을 만들어 다시 붙인다
>>> 'P' + x[1:]              # 'P' 뒤에 x 의 1번부터 끝까지를 붙이면?
'Python'

>>> s = '  Hello World  '    # s 에 앞뒤에 공백이 있는 문자열을 담아 주세요
>>> 'hello'.find('l')        # 'hello' 안에서 'l' 은 몇 번째 자리에 있나요?
2
>>> 'hello'.find('z')        # 'hello' 안에서 'z' 는 몇 번째 자리에 있나요?
-1
>>> s.strip()                # s 의 앞뒤 공백을 지우면?
'Hello World'
>>> s.rstrip()               # s 의 오른쪽 공백을 지우면?
'  Hello World'
>>> 'a,b,c'.split(',')       # 'a,b,c' 를 쉼표 기준으로 자르면?
['a', 'b', 'c']
>>> 'a b c'.split()          # 'a b c' 를 공백 기준으로 자르면?
['a', 'b', 'c']
>>> 'cat'.replace('c', 'b')  # 'cat' 의 'c' 를 'b' 로 바꾸면?
'bat'
>>> 'ABC'.lower()            # 'ABC' 를 소문자로 바꾸면?
'abc'
>>> ', '.join(['사과', '배'])   # ['사과', '배'] 를 ', ' 로 이어 붙이면?
'사과, 배'

5. 리스트 메서드

>>> L = [3, 1, 2]         # L 에 리스트 [3, 1, 2] 를 담아 주세요
>>> L.append(9)           # L 의 맨 뒤에 9 을 붙여 주세요
>>> L                     # L 에 들어 있는 것이 뭐예요?
[3, 1, 2, 9]
>>> L.sort()              # L 을 작은 것부터 순서대로 정렬해 주세요
>>> L                     # L 에 들어 있는 것이 뭐예요?
[1, 2, 3, 9]
>>> L.insert(0, 7)        # L 의 0번 자리에 7 을 끼워 넣어 주세요
>>> L                     # L 에 들어 있는 것이 뭐예요?
[7, 1, 2, 3, 9]
>>> del L[1]              # L 의 1번 원소를 지워 주세요
>>> L                     # L 에 들어 있는 것이 뭐예요?
[7, 2, 3, 9]

# pop() 은 지우고 그 값을 돌려준다
>>> L.pop()               # L 의 맨 뒤 원소를 꺼내면?
9
>>> L                     # L 에 들어 있는 것이 뭐예요?
[7, 2, 3]

# 리스트는 가변이라 대입이 된다
>>> L[0] = 5              # L 의 0번 원소를 5 로 바꿔 주세요
>>> L                     # L 에 들어 있는 것이 뭐예요?
[5, 2, 3]

# 리스트 안의 리스트
>>> m = [[1, 2], [3, 4]]  # m 에 리스트 두 개를 담은 리스트를 담아 주세요
>>> m[1][0]               # m 의 1번 원소의 0번 원소는?
3

6. 변환과 sum

>>> list('abc')              # 'abc' 를 리스트로 만들면?
['a', 'b', 'c']
>>> str(123)                 # 123 을 문자열로 바꾸면?
'123'
>>> int('123')               # '123' 을 정수로 바꾸면?
123
>>> float('123')             # '123' 을 소수로 바꾸면?
123.0
>>> sum([1, 2, 3])           # [1, 2, 3] 의 원소를 모두 더하면?
6
>>> sum(list(range(1, 11)))  # 1 부터 10 까지의 리스트를 모두 더하면?
55

7. in 과 복사 a[:]

# in 은 원소가 완전히 같을 때만 True (부분 문자열은 False)
>>> books = ['해리포터', '반지의 제왕']  # books 에 책 제목 두 개의 리스트를 담아 주세요
>>> '해리포터' in books             # '해리포터' 가 books 안에 있나요?
True
>>> '해' in books                # '해' 가 books 안에 있나요?
False
>>> '반지의 제왕' in books           # '반지의 제왕' 가 books 안에 있나요?
True

# a[:] 는 복사본: 복사본을 바꿔도 원본은 그대로
>>> a = [1, 2, 3]               # a 에 리스트 [1, 2, 3] 을 담아 주세요
>>> b = a[:]                    # a 를 통째로 복사해 b 에 담아 주세요
>>> b.remove(2)                 # b 에서 값 2 를 찾아 지워 주세요
>>> b                           # b 에 들어 있는 것이 뭐예요?
[1, 3]
>>> a                           # a 에 들어 있는 것이 뭐예요?
[1, 2, 3]

# c = a 는 복사가 아니라 같은 리스트: 같이 바뀐다
>>> c = a                       # a 가 가리키는 것을 c 에도 담아 주세요
>>> c.remove(2)                 # c 에서 값 2 를 찾아 지워 주세요
>>> a                           # a 에 들어 있는 것이 뭐예요?
[1, 3]

핵심 한 줄: 순회하면서 그 리스트를 바꾸면 원소를 건너뛰니, L[:] 복사본을 순회하기.
