초급 1읽기

import 두 가지로 제곱근 구하기

모듈을 통째로 가져오는 방법과 필요한 이름만 가져오는 방법을 같이 써 봐요.

import math            # math 모듈을 가져와 주세요
print(math.sqrt(16))   # math 의 sqrt 로 16 의 제곱근을 화면에 보여 주세요
from math import sqrt  # math 에서 sqrt 만 가져와 주세요
print(sqrt(16))        # sqrt 로 16 의 제곱근을 화면에 보여 주세요
print(math.pi)         # math 의 pi 를 화면에 보여 주세요

math.sqrt는 모듈 이름을 붙여서, sqrt는 이름만으로 불러요. pi는 함수가 아니라 값이라 괄호가 없어요.

한 문장으로: 같은 제곱근 함수를 두 가지 방법으로 가져와 부르는 코드예요.

줄쓰는 모양결과
2번째 줄math.sqrt(16) — 모듈 이름을 앞에 붙임4.0 (제곱근은 항상 실수)
4번째 줄sqrt(16) — 이름만 씀4.0
5번째 줄math.pi — 모듈의 변수3.141592653589793

import math는 모듈 전체를 가져와서 math.이름으로 쓰고, from math import sqrt는 이름 하나만 가져와서 sqrt로 써요. 5번째 줄은 첫 줄에서 math를 가져왔기 때문에 쓸 수 있어요.

핵심 한 줄: import 모듈은 모듈.이름, from 모듈 import 이름은 이름으로 써요.

초급 2읽기

가져오지 않은 이름 쓰기

from … import로는 이름 하나만 가져와요. 그러면 모듈 이름은 어떻게 될까요?

from math import sqrt       # math 에서 sqrt 만 가져와 주세요
print(sqrt(9))              # sqrt 로 9 의 제곱근을 화면에 보여 주세요
try:                        # 다음을 시도해 보세요
    print(math.pi)          # math 의 pi 를 화면에 보여 주세요
except NameError as e:      # NameError 가 나면 e 에 담아 주세요
    print('NameError:', e)  # NameError: 와 e 를 화면에 보여 주세요

정답·해설 보기 
3.0
NameError: name 'math' is not defined

한 문장으로: from math import sqrt만 했는데 math.pi를 쓰면 NameError가 나는 것을 확인하는 코드예요.

줄일어나는 일
2번째 줄sqrt는 가져왔으니 3.0이 나와요
4번째 줄math라는 이름은 만들어진 적이 없어서 NameError가 나요
5번째 줄except로 넘어와 NameError: 와 오류 문구를 찍어요

고치려면 import math를 더하거나, math.pi 대신 from math import pi로 pi를 가져와요.

핵심 한 줄: from 모듈 import 이름은 그 이름만 만들고, 모듈 이름은 만들지 않아요.

초급 3읽기

as로 별칭 붙이기

이름 뒤에 as 새이름을 붙이면 다른 이름으로 가져와요.

import math as m               # math 모듈을 m 이라는 이름으로 가져와 주세요
from math import sqrt as root  # sqrt 를 root 라는 이름으로 가져와 주세요
print(m.sqrt(9), root(9))      # m.sqrt(9) 와 root(9) 를 화면에 보여 주세요
print(m.pi)                    # m 의 pi 를 화면에 보여 주세요
try:                           # 다음을 시도해 보세요
    print(math.pi)             # math 의 pi 를 화면에 보여 주세요
except NameError as e:         # NameError 가 나면 e 에 담아 주세요
    print('NameError:', e)     # NameError: 와 e 를 화면에 보여 주세요

중급 1읽기

달력 함수 결과 풀어 읽기

calendar.monthrange는 값 두 개를 튜플로 돌려줘요. 요일 튜플과 이어서 읽어 봐요.

import calendar                                      # calendar 모듈을 가져와 주세요
DAYS = ('월', '화', '수', '목', '금', '토', '일')    # DAYS 에 요일 이름 일곱 개의 튜플을 담아 주세요
first, last = calendar.monthrange(2024, 2)           # first, last 에 2024년 2월의 monthrange 결과를 풀어 담아 주세요
print(first, last)                                   # first 와 last 를 화면에 보여 주세요
print(DAYS[first] + '요일부터', last, '일까지')      # DAYS[first] 요일부터 last 일까지를 화면에 보여 주세요
print(calendar.isleap(2024), calendar.isleap(2100))  # 2024 와 2100 이 윤년인지 화면에 보여 주세요

이 코드를 실행하면 무엇이 출력될까요?

출력예측

monthrange(연, 월)은 (그 달 1일의 요일 번호, 그 달의 마지막 날짜)를 줘요. 요일 번호는 월요일이 0이에요. 2100년은 100으로 나누어떨어지지만 400으로는 아니에요.

한 문장으로: 달력 모듈이 돌려준 튜플을 풀어 담아, 요일 튜플에서 이름을 꺼내는 코드예요.

단계값
calendar.monthrange(2024, 2)(3, 29) — 1일은 3번 요일, 마지막 날짜는 29
first, last = …first = 3, last = 29
DAYS[first]DAYS[3] = '목' (월0·화1·수2·목3)

중급 2읽기

함수 하나와 math 함수 셋

내가 만든 함수와 math의 함수를 함께 읽어요. math에는 hypot, isqrt, gcd가 있어요.

import math                                                 # math 모듈을 가져와 주세요

def hypotenuse(a, b):                                       # a, b 를 받는 함수 hypotenuse 를 정의해 주세요
    return round(math.sqrt(a ** 2 + b ** 2), 2)             # a 제곱과 b 제곱의 합의 제곱근을 소수 둘째 자리까지 반올림해 돌려주세요

print(hypotenuse(3, 4))                                     # hypotenuse(3, 4) 를 화면에 보여 주세요
print(hypotenuse(10, 20))                                   # hypotenuse(10, 20) 을 화면에 보여 주세요
print(math.hypot(5, 12), math.isqrt(30), math.gcd(12, 18))  # hypot(5, 12), isqrt(30), gcd(12, 18) 을 화면에 보여 주세요

이 코드를 실행하면 무엇이 출력될까요? (모르는 함수는 help()로 읽는다고 생각하고 힌트를 보세요)

출력예측

2번째 줄?
3번째 줄?
힌트 보기

hypot(a, b)는 빗변 길이, isqrt(n)은 제곱근의 정수 부분, gcd(a, b)는 최대공약수예요. round(값, 2)는 소수 둘째 자리까지 반올림해요.

22.36
13.0 5 6

한 문장으로: 피타고라스 정리로 빗변을 구하는 함수를 만들고, math에 이미 있는 비슷한 함수들을 불러 보는 코드예요.

줄계산결과
hypotenuse(3, 4)√(9+16) = √25 = 5.0 → 반올림해도 5.05.0
hypotenuse(10, 20)√500 = 22.3606… → 둘째 자리 반올림22.36
math.hypot(5, 12)√(25+144) = √16913.0 (실수)
math.isqrt(30)√30 = 5.47… 의 정수 부분5 (정수)

핵심 한 줄: math.sqrt는 실수, math.isqrt는 정수를 돌려줘요.

중급 3읽기

파일 두 개: import와 직접 실행

같은 폴더에 파일이 두 개 있어요. user.py를 실행했을 때와 tools.py를 직접 실행했을 때를 구분해 읽어요.

tools.py

print('tools의 __name__:', __name__)  # tools의 __name__: 과 __name__ 을 화면에 보여 주세요

def double(x):                        # x 를 받는 함수 double 을 정의해 주세요
    return x * 2                      # x 의 두 배를 돌려주세요

if __name__ == '__main__':            # 만약 __name__ 이 '__main__' 이면
    print('직접 실행:', double(4))    # 직접 실행: 과 double(4) 를 화면에 보여 주세요

user.py

import tools            # tools 모듈을 가져와 주세요
print(tools.double(5))  # tools 의 double 로 5 의 두 배를 화면에 보여 주세요

user.py를 실행하면 무엇이 출력될까요? 그리고 tools.py를 직접 실행하면 무엇이 출력될까요?

출력예측
user.py 실행 1번째 줄?
user.py 실행 2번째 줄?
tools.py 직접 실행 1번째 줄?
tools.py 직접 실행 2번째 줄?
힌트 보기

__name__은 그 파일을 직접 실행하면 '__main__', import 되어 읽히면 모듈 이름이에요. import 도 파일을 위에서부터 실행해요.

정답·해설 보기 
tools의 __name__: tools
10
----------
tools의 __name__: __main__
직접 실행: 8

한 문장으로: 같은 파일이 import 될 때와 직접 실행될 때 __name__이 달라지는 것을 읽는 문제예요. (출력의 ---------- 줄은 구분선이고, 위쪽이 user.py, 아래쪽이 tools.py 직접 실행 결과예요.)

실행tools.py 안의 __name__if 구역출력
python user.pytools건너뜀tools의 __name__: tools → 10
python tools.py__main__실행tools의 __name__: __main__ → 직접 실행: 8

user.py에서 import tools를 하는 순간 tools.py가 위에서부터 실행돼서 첫 줄 print가 나와요. def는 함수를 만들어 둘 뿐이고, if __name__ == '__main__': 안은 직접 실행할 때만 돌아요.

핵심 한 줄: import 해도 파일 맨 위 코드는 실행되고, __main__ 구역만 건너뛰어요.

고급 1읽기

복사된 값과 reload

from … import로 가져온 변수는 모듈 변수와 같을까요? reload 뒤에는 어떻게 될까요? 출력은 모두 여섯 줄이에요.

counter.py

print('counter 로딩')  # counter 로딩 을 화면에 보여 주세요
count = 0              # count 에 0 을 담아 주세요


def up():              # 함수 up 을 정의해 주세요
    global count       # 모듈의 count 를 쓰겠다고 알려 주세요
    count += 1         # count 에 1 을 더해 주세요
    return count       # count 를 돌려주세요

main.py

import counter                 # counter 모듈을 가져와 주세요
from counter import up, count  # counter 에서 up 과 count 를 가져와 주세요
up()                           # up 을 불러 주세요
up()                           # up 을 불러 주세요
print(count)                   # count 를 화면에 보여 주세요
print(counter.count)           # counter 의 count 를 화면에 보여 주세요
import counter                 # counter 모듈을 가져와 주세요
from importlib import reload   # importlib 에서 reload 를 가져와 주세요
reload(counter)                # counter 모듈을 다시 읽어 주세요
print(counter.count)           # counter 의 count 를 화면에 보여 주세요
print(up())                    # up 의 결과를 화면에 보여 주세요

from counter import count는 그 순간의 값을 내 이름에 묶어요. 이후 모듈의 count가 바뀌어도 내 count는 따라가지 않아요. reload는 모듈 코드를 처음부터 다시 실행해요.

한 문장으로: 가져온 변수는 값이 복사되어 따로 놀고, reload는 모듈 변수를 다시 0으로 되돌리는 것을 추적하는 문제예요.

실행되는 줄내 countcounter.count출력

처음 가져온 up은 같은 모듈 공간의 count를 올리므로, reload로 0이 된 값에서 1이 돼요. 그래서 마지막 줄이 1이에요. 변하는 값은 from … import로 가져오지 말고 모듈.이름으로 읽어요.

핵심 한 줄: from 모듈 import 변수는 그 순간의 값을 복사한 것이라, 모듈 안에서 바뀌어도 따라가지 않아요.

park.py

print('park 읽는 중')                             # park 읽는 중 을 화면에 보여 주세요

rides = [                                         # rides 에 다음 리스트를 담아 주세요
    ('와일드 윙', 110, None),
    ('드림보트', 120, None),
    ('플라이벤처', 140, 195),
    ('툼 오브 호러', None, None),
]


def allowedrides(height):                         # height 를 받는 함수 allowedrides 를 정의해 주세요
    result = []                                   # result 에 빈 리스트를 담아 주세요
    for name, cmmin, cmmax in rides:              # rides 에서 name, cmmin, cmmax 를 하나씩 꺼내 주세요
        if cmmin is not None and height < cmmin:  # 만약 cmmin 이 있고 height 가 cmmin 보다 작으면
            continue                              # 다음 차례로 넘어가 주세요
        if cmmax is not None and height > cmmax:  # 만약 cmmax 가 있고 height 가 cmmax 보다 크면
            continue                              # 다음 차례로 넘어가 주세요
        result.append(name)                       # result 뒤에 name 을 붙여 주세요
    return result                                 # result 를 돌려주세요


if __name__ == "__main__":                        # 만약 __name__ 이 "__main__" 이면
    height = int(input())                         # height 에 입력을 정수로 바꿔 담아 주세요
    for name in allowedrides(height):             # allowedrides(height) 에서 name 을 하나씩 꺼내 주세요
        print(name)                               # name 을 화면에 보여 주세요

group.py

import park                                  # park 모듈을 가져와 주세요

heights = list(map(int, input().split()))    # heights 에 입력을 공백으로 쪼개 정수 리스트로 만들어 담아 주세요
common = set(park.allowedrides(heights[0]))  # common 에 첫 사람이 탈 수 있는 기구의 세트를 담아 주세요
for h in heights[1:]:                        # heights 의 둘째부터 h 로 하나씩 꺼내 주세요
    common &= set(park.allowedrides(h))      # common 과 h 가 탈 수 있는 기구 세트의 교집합을 common 에 담아 주세요

print(len(heights), '명')                    # heights 의 개수와 명 을 화면에 보여 주세요
for name in park.allowedrides(heights[0]):   # 첫 사람이 탈 수 있는 기구에서 name 을 하나씩 꺼내 주세요
    if name in common:                       # 만약 name 이 common 안에 있으면
        print(name)                          # name 을 화면에 보여 주세요
