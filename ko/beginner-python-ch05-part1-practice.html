원의 넓이와 둘레 구하기

import로 math 모듈을 가져와서 반지름이 5인 원의 넓이와 둘레를 구해요.

import math                       # math 모듈을 가져와 주세요

radius = 5                        # radius 에 5 를 담아 주세요

print(2 * math.pi * radius)       # 원의 둘레(2 × pi × 반지름)를 화면에 보여 주세요

as로 별칭 붙이기

이름 뒤에 as 새이름을 붙이면 모듈을 짧은 이름으로 가져와요. 시험 점수의 평균과 가운데 값을 구해요.

scores = [72, 85, 90, 78]                # scores 에 점수 네 개의 리스트를 담아 주세요
print(st.mean(scores))                   # st 의 mean 으로 scores 의 평균을 화면에 보여 주세요
print(st.median(scores))                 # st 의 median 으로 scores 의 가운데 값을 화면에 보여 주세요
print(statistics.mean(scores))           # statistics 의 mean 으로 scores 의 평균을 화면에 보여 주세요

초급 4읽기

별표(*)로 가져오면

from 모듈 import *는 모듈의 이름을 전부 가져와요. 파이썬에 처음부터 들어 있는 내장 함수 pow(2, 10)은 정수 1024를 돌려줘요.

중급 1읽기

쪽 수 계산하기

게시판에 글이 몇 개 있을 때 한 쪽에 10개씩 보여 주면 몇 쪽이 필요한지 구하는 함수예요. math의 ceil은 올림이에요.

import math                                # math 모듈을 가져와 주세요

def pages_needed(items, per_page):         # 항목 수와 한 쪽 개수를 받는 함수 pages_needed 를 정의해 주세요
    return math.ceil(items / per_page)     # 나눈 값을 올림해서 돌려주세요

print(pages_needed(95, 10))                # 95 개를 10 개씩 보여 줄 때 필요한 쪽 수를 화면에 보여 주세요
print(pages_needed(100, 10))               # 100 개일 때를 화면에 보여 주세요
print(pages_needed(101, 10))               # 101 개일 때를 화면에 보여 주세요

판별식에 따라 sqrt 고르기

이차방정식의 근을 구하는 함수예요. 판별식이 0 이상이면 실수 제곱근을, 음수면 복소수 제곱근이 필요해서 math와 cmath의 sqrt를 둘 다 가져와요. 이름이 겹치니 as로 구분했어요.

from math import sqrt as real_sqrt         # math 의 sqrt 를 real_sqrt 라는 이름으로 가져와 주세요
from cmath import sqrt as complex_sqrt     # cmath 의 sqrt 를 complex_sqrt 라는 이름으로 가져와 주세요

def roots(a, b, c):                        # a, b, c 를 받는 함수 roots 를 정의해 주세요
    d = b ** 2 - 4 * a * c                 # 판별식 d 를 구해 담아 주세요
    if d >= 0:                             # 만약 d 가 0 이상이면
        s = real_sqrt(d)                   # s 에 실수 제곱근을 담아 주세요
    else:                                  # 아니면
        s = complex_sqrt(d)                # s 에 복소수 제곱근을 담아 주세요
    return (-b + s) / (2 * a), (-b - s) / (2 * a)   # 두 근을 돌려주세요

print(roots(1, -3, 2))                     # roots(1, -3, 2) 를 화면에 보여 주세요
print(roots(1, 2, 5))                      # roots(1, 2, 5) 를 화면에 보여 주세요

같은 이름 sqrt를 둘 다 쓰고 싶을 때는 as로 서로 다른 이름을 붙여 가져오면 부딪히지 않아요. 별표로 가져올 때와 달리 어느 쪽을 부르는지 이름에서 바로 보여요.

def allowedrides(height):                         # height 를 받는 함수 allowedrides 를 정의해 주세요
    result = []                                   # result 에 빈 리스트를 담아 주세요

        if cmmin is not None and height < cmmin:  # 만약 cmmin 이 있고 height 가 cmmin 보다 작으면

            continue                              # 다음 차례로 넘어가 주세요
        result.append(name)                       # result 뒤에 name 을 붙여 주세요
    return result                                 # result 를 돌려주세요

    common &= set(park.allowedrides(h))      # common 과 h 가 탈 수 있는 기구 세트의 교집합을 common 에 담아 주세요

    if name in common:                       # 만약 name 이 common 안에 있으면
