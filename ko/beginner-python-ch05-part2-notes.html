여러 가지 모듈 정리 — 왕초보 Python 5장 모듈 (5.3 ①)

2026. 10. 26.

※ 이 글은 위키독스 『왕초보를 위한 Python』 5.3 ~ 5.3.4절(5.3.2 연습 문제 제외)을 제 나름의 언어로 짧게 정리한 것입니다. 앞 내용은 5.1~5.2 정리에 있어요. 코드 실행 결과는 파이썬 3.14.7로 실제로 돌려서 넣었어요.

파이썬이 들고 있는 모듈은 필요한 기능을 정한 뒤 골라 쓰는 도구 상자이고, random 은 아무거나 뽑고 섞고, string 은 글자 재료를 주고, translate 는 글자를 한꺼번에 바꿔요.

1. 파이썬이 처음부터 들고 있는 모듈 (5.3)

모듈맡은 일대표 도구
sys파이썬 실행기(인터프리터) 다루기sys.exit()(끝내기), sys.ps1(대화형 셸의 프롬프트 모양), sys.path
os운영체제(폴더·파일) 다루기os.getcwd(), os.listdir(), os.chdir(폴더)
re정규 표현식으로 문자열 다루기re.compile(패턴), .match(글자)
glob파일 이름 찾기glob.glob('*')
webbrowser웹 브라우저 띄우기webbrowser.open(주소)

※ 모듈 사용법을 전부 외울 필요는 없어요. 만들려는 프로그램에 어떤 기능이 필요한지 먼저 정하고, 그 기능을 가진 모듈을 골라 설명서(파이썬 라이브러리 레퍼런스)나 dir()·help()를 보며 익히면 돼요.

sys — 실행기 다루기

>>> import sys
>>> sys.ps1                  # 프롬프트 모양은?
'>>> '
>>> sys.ps1 = '^^; '         # 이 모양으로 바꿔
^^; print('hello')
hello
^^; 5 * 3
15
^^; sys.exit()               # 파이썬을 끝낸다

※ sys.ps1은 대화형 셸에서만 있는 값이에요. 위 기록은 python -i로 직접 돌려 확인한 동작을 옮긴 거예요. .py 파일로 실행할 때는 sys.exit()가 그 자리에서 프로그램을 끝내요.

import sys                 # sys 를 가져와 주세요
print('시작')              # '시작' 을 화면에 보여 주세요
sys.exit()                 # 프로그램을 여기서 끝내 주세요
print('여기는 안 돌아요')  # '여기는 안 돌아요' 를 화면에 보여 주세요
시작

os — 폴더와 파일

항목내용
os.getcwd()지금 작업 중인 폴더(current working directory)를 알려 준다
os.listdir()그 폴더 안의 파일·폴더 이름을 리스트로 돌려준다
os.chdir('폴더')작업 폴더를 옮긴다. 위 폴더는 '..'

※ study 폴더 안에 main.py, memo.txt 파일과 docs 폴더가 있는 상태에서 돌렸어요. os.getcwd()는 C:\Users\…처럼 전체 경로를 주는데, 이 글에서는 폴더 이름만 보이게 os.path.basename()으로 줄였어요.

import os                             # os 모듈을 가져와 주세요
print(os.path.basename(os.getcwd()))  # 지금 작업 폴더의 이름을 화면에 보여 주세요
print(sorted(os.listdir()))           # 이 폴더 안의 이름들을 정렬해 화면에 보여 주세요
os.chdir('docs')                      # docs 폴더로 들어가 주세요
print(os.path.basename(os.getcwd()))  # 지금 작업 폴더의 이름을 화면에 보여 주세요
os.chdir('..')                        # 위 폴더로 나가 주세요
print(os.path.basename(os.getcwd()))  # 지금 작업 폴더의 이름을 화면에 보여 주세요
study
['docs', 'main.py', 'memo.txt']
docs
study

re와 glob — 이름 패턴으로 파일 거르기

패턴뜻
.아무 글자 한 개
*바로 앞의 것이 0번 이상
.*p.*n.*p 가 나오고 그 뒤에 n 이 나오는 이름 (앞뒤에 뭐가 붙어도 됨)
import re, glob                      # re 와 glob 을 가져와 주세요
p = re.compile('.*p.*n.*')           # p 에 '.*p.*n.*' 패턴 검사기를 담아 주세요
for name in sorted(glob.glob('*')):  # 이 폴더의 모든 이름을 정렬해 하나씩 name 이라고 부르며 아래를 반복해 주세요
    if p.match(name):                # 만약 name 이 패턴에 맞으면
        print(name)                  # name 을 화면에 보여 주세요
pycon.ico
python.exe
pythonw.exe
w9xpopen.exe

※ glob.glob('*')는 이 폴더의 모든 이름을 리스트로 줘요. 순서가 컴퓨터마다 달라서 sorted()로 정렬해 보였어요. LICENSE.txt와 NEWS.txt에는 p가 없어서 걸러졌어요.

webbrowser — 브라우저 띄우기

import webbrowser               # webbrowser 를 가져와 주세요
url = 'http://www.python.org/'  # url 에 파이썬 공식 사이트 주소를 담아 주세요
webbrowser.open(url)            # 브라우저로 url 을 열어 주세요

※ 실행하면 웹 브라우저가 열려서 여기서는 돌리지 않았어요. 교재에서는 대화형 셸에서 돌렸을 때 True가 보인다고 해요.

2. 난수 만들기 — random (5.3.1)

도구하는 일
random.random()0 이상 1 미만의 실수 하나
random.randrange(a, b)a 이상 b 미만의 정수 하나 (range(a, b)와 같은 범위). 주사위는 randrange(1, 7)
random.shuffle(리스트)리스트를 그 자리에서 섞는다. 돌려주는 값은 없다(None)
random.choice(묶음)리스트·튜플·문자열 같은 묶음에서 원소 하나를 아무거나 뽑는다

※ 값이 실행마다 달라서, 아래는 값 대신 조건이 맞는지를 출력해서 보였어요.

import random  # random 모듈을 가져와 주세요

x = random.random()                 # x 에 0 이상 1 미만의 실수를 담아 주세요
print(0 <= x < 1)                   # x 가 0 이상 1 미만인지 화면에 보여 주세요
d = random.randrange(1, 7)          # d 에 1 이상 7 미만의 정수를 담아 주세요
print(d in range(1, 7))             # d 가 1 부터 6 사이인지 화면에 보여 주세요
abc = ['a', 'b', 'c', 'd', 'e']     # abc 에 다섯 글자 리스트를 담아 주세요
print(random.shuffle(abc))          # abc 를 섞고, shuffle 이 돌려주는 값을 화면에 보여 주세요
print(sorted(abc))                  # 섞인 abc 를 정렬해 화면에 보여 주세요
menu = '쫄면', '육계장', '비빔밥'   # menu 에 세 메뉴를 묶어 담아 주세요
print(random.choice(menu) in menu)  # 뽑은 하나가 menu 안에 있는지 화면에 보여 주세요
True
True
None
['a', 'b', 'c', 'd', 'e']
True

※ 주사위를 많이 던지면 각 눈이 비슷한 횟수로 나와요. 아래는 random.seed(0)으로 출발값을 정해 두고 600번 던진 결과예요. 출발값이 같으면 같은 난수가 나오는데, 파이썬 버전이 다르면 값이 다를 수 있어요. 이 글은 파이썬 3.14.7에서 돌렸어요.

import random                      # random 모듈을 가져와 주세요
random.seed(0)                     # 난수가 똑같이 나오게 출발값을 0 으로 정해 주세요
counts = [0] * 6                   # counts 에 0 이 여섯 개인 리스트를 담아 주세요
for _ in range(600):               # 아래를 600번 반복해 주세요
    dice = random.randrange(1, 7)  # dice 에 1 이상 7 미만의 정수를 담아 주세요
    counts[dice - 1] += 1          # counts 의 dice 번째 눈 칸에 1 을 더해 주세요
print(counts)                      # counts 를 화면에 보여 주세요
print(sum(counts))                 # counts 의 합을 화면에 보여 주세요
[114, 91, 98, 94, 101, 102]
600

3. 글자 재료 — string (5.3.3)

이름들어 있는 글자
string.ascii_lowercase영문 소문자 a ~ z
string.ascii_uppercase영문 대문자 A ~ Z
string.ascii_letters소문자 + 대문자
string.digits숫자 0 ~ 9
import string                                  # string 모듈을 가져와 주세요
alnum = string.ascii_letters + string.digits   # alnum 에 영문자와 숫자를 이어 붙여 담아 주세요
print(len(alnum))                              # alnum 의 글자 수를 화면에 보여 주세요
chars = [x for x in alnum if x not in 'lIO0']  # chars 에 alnum 글자 중 l, I, O, 0 이 아닌 것만 모아 담아 주세요
chars.append('_')                              # chars 뒤에 '_' 를 붙여 주세요
print(len(chars))                              # chars 의 글자 수를 화면에 보여 주세요
62
59

※ 헷갈리는 글자(소문자 l, 대문자 I, 대문자 O, 숫자 0)를 빼고 밑줄을 더한 후보가 59글자예요. 교재는 세트 차집합 set(alnum) - set('lIO0')으로 뺐는데, 세트는 순서가 없어서 이 글에서는 순서가 남는 리스트 컴프리헨션으로 뺐어요.

import random, string                                                                 # random 과 string 을 가져와 주세요
chars = [x for x in string.ascii_letters + string.digits if x not in 'lIO0'] + ['_']  # chars 에 비밀번호에 쓸 글자 59개를 담아 주세요
pw = ''                                                                               # pw 에 빈 글자를 담아 주세요
for i in range(16):                                                                   # 아래를 16번 반복해 주세요
    pw += random.choice(chars)                                                        # pw 뒤에 chars 에서 뽑은 글자 하나를 붙여 주세요
print(len(pw))                                                                        # pw 의 글자 수를 화면에 보여 주세요
print(all(x in chars for x in pw))                                                    # pw 의 모든 글자가 chars 안에 있는지 화면에 보여 주세요
16
True

※ 이렇게만 만들면 밑줄이 안 들어간 비밀번호가 자주 나와요. 영문자·숫자·특수문자를 꼭 넣는 방법은 해설 글에서 풀어요.

4. 시저(카이사르) 암호 (5.3.4)

항목내용
원리알파벳 각 글자를 정해진 칸만큼 밀린 다른 글자로 바꾼다. 아래 줄은 대문자 D 부터 시작하고 Z 다음에 다시 A 가 온다
s[3:] + s[:3]앞 세 글자를 뒤로 보낸 문자열 (알파벳 줄을 3칸 돌리기)
str.maketrans(원래, 바꿀)글자별 대응표(딕셔너리)를 만든다. 두 문자열의 길이가 같아야 한다
글자.translate(표)표대로 글자를 하나씩 바꾼 새 문자열을 돌려준다. 표에 없는 글자는 그대로
import string                                                    # string 모듈을 가져와 주세요
upper = string.ascii_uppercase[3:] + string.ascii_uppercase[:3]  # upper 에 대문자 알파벳을 3칸 돌린 줄을 담아 주세요
print(upper)                                                     # upper 를 화면에 보여 주세요
tt = str.maketrans(string.ascii_lowercase, upper)                # tt 에 소문자 → upper 대응표를 담아 주세요
print('traue nie dem brutus'.translate(tt))                      # 문장을 표대로 바꿔 화면에 보여 주세요
print(str.maketrans('abc', 'DEF'))                               # 작은 대응표가 어떻게 생겼는지 화면에 보여 주세요
DEFGHIJKLMNOPQRSTUVWXYZABC
WUDXH QLH GHP EUXWXV
{97: 68, 98: 69, 99: 70}

※ maketrans가 만든 딕셔너리는 글자를 글자 번호(a = 97, D = 68)로 짝지어 둔 모양이에요. 사용법은 이 정도만 알면 돼요. 메서드(.translate 같은 점으로 부르는 함수)는 7장에서 정식으로 배운다고 해요.
