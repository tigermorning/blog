예제마다 줄이 실행되는 순서를 따라가면서, 어느 순간에 인스턴스가 생기고 어느 값이 누구 것인지 확인해요.

예제핵심
예제 1 Singer (7.1)Singer() 가 인스턴스를 만들고, taeji.sing() 은 self 에 taeji 를 넣어 실행한다

7.1 클래스와 인스턴스 예제

예제 1. 노래하는 Singer

실행 순서 · 결과 · 설명 보기 
class Singer:                  # Singer 라는 클래스를 정의해 주세요
    def sing(self):            # sing 메서드를 정의해 주세요
        return "Lalala~"       # "Lalala~" 를 돌려주세요
taeji = Singer()               # taeji 에 Singer 인스턴스를 만들어 담아 주세요
ricky = Singer()               # ricky 에 Singer 인스턴스를 만들어 담아 주세요
print(taeji.sing())            # taeji 에게 노래를 시킨 결과를 화면에 보여 주세요
print(ricky.sing())            # ricky 에게 노래를 시킨 결과를 화면에 보여 주세요
Lalala~
Lalala~
줄일어나는 일
1~3째 줄Singer 틀만 만들어져요. 아직 인스턴스는 0개예요.
4째 줄Singer() 가 인스턴스를 하나 만들어 taeji 에 담아요. 인스턴스 1개.
5째 줄두 번째 인스턴스를 만들어 ricky 에 담아요. 인스턴스 2개이고 서로 다른 객체예요.
6째 줄taeji.sing() 을 부르면 self 가 taeji 가 되어 "Lalala~" 를 돌려줘요.
7째 줄ricky.sing() 은 self 가 ricky 예요. 같은 메서드를 쓰고 같은 결과가 나와요.

메서드는 틀(Singer)에 한 벌만 있고, 인스턴스는 그걸 빌려 쓰는 모양이에요. 영상의 쿠키 틀에 비유하면 틀은 하나이고 쿠키는 여러 개예요.

예제 2. 값을 받아 만드는 Player

실행 순서 · 결과 · 설명 보기 
class Player:                                  # Player 클래스를 정의해 주세요
    def __init__(self, name, health, skill):   # 만들 때 자동으로 불리는 __init__ 을 정의해 주세요
        self.name = name                       # 이 인스턴스의 name 에 name 을 담아 주세요
        self.health = health                   # 이 인스턴스의 health 에 health 를 담아 주세요
        self.skill = skill                     # 이 인스턴스의 skill 에 skill 을 담아 주세요
        self.xp = 0                            # 이 인스턴스의 xp 에 0 을 담아 주세요
elon = Player("elon", 100, "coding")           # elon 에 Player 인스턴스를 만들어 담아 주세요
mark = Player("mark", 90, "design")            # mark 에 Player 인스턴스를 만들어 담아 주세요
print(elon.name, elon.xp)                      # elon 의 name 과 xp 를 화면에 보여 주세요
print(mark.name, mark.health)                  # mark 의 name 과 health 를 화면에 보여 주세요
elon 0
mark 90
순서일어나는 일
① 빈 인스턴스 만들기Player("elon", 100, "coding") 을 실행하면 속이 빈 인스턴스가 먼저 생겨요.
② __init__ 자동 호출파이썬이 __init__(self=그 인스턴스, name="elon", health=100, skill="coding") 을 대신 불러요. 우리가 __init__ 을 직접 부르지 않아요.
③ 속성 저장self.name, self.health, self.skill 에 받은 값이, self.xp 에는 항상 0 이 저장돼요.
④ 변수에 담기완성된 인스턴스가 elon 에 담겨요. mark 도 같은 순서로 따로 만들어져요.

그래서 elon.xp 와 mark.xp 는 둘 다 0 에서 시작하지만, 서로 다른 인스턴스의 값이에요. 한쪽을 바꿔도 다른 쪽은 그대로예요.

7.2 변수와 메서드 예제

예제 3. 훈련하는 Amazon — 값이 누구 것인가

값 변화 · 결과 · 설명 보기 
class Amazon:                       # Amazon 클래스를 정의해 주세요
    strength = 20                   # 클래스 변수 strength 에 20 을 담아 주세요
    dexterity = 25                  # 클래스 변수 dexterity 에 25 를 담아 주세요
    def exercise(self):             # exercise 메서드를 정의해 주세요
        self.strength += 2          # 이 인스턴스의 strength 에 2 를 더해 주세요
        self.dexterity += 3         # 이 인스턴스의 dexterity 에 3 을 더해 주세요
jane = Amazon()                     # jane 에 Amazon 인스턴스를 만들어 담아 주세요
mary = Amazon()                     # mary 에 Amazon 인스턴스를 만들어 담아 주세요
jane.exercise()                     # jane 에게 훈련을 시켜 주세요
print(jane.strength, mary.strength, Amazon.strength)  # 세 곳의 strength 를 화면에 보여 주세요
jane.exercise()                     # jane 에게 훈련을 한 번 더 시켜 주세요
print(jane.strength, jane.dexterity)                  # jane 의 strength 와 dexterity 를 화면에 보여 주세요
print(jane.__dict__)                # jane 이 따로 가진 변수들을 화면에 보여 주세요
22 20 20
24 31
{'strength': 24, 'dexterity': 31}
시점jane.strengthmary.strengthAmazon.strengthjane 이 따로 가진 변수
처음202020없음
jane.exercise() 한 번222020strength, dexterity
jane.exercise() 두 번242020strength, dexterity

처음에는 jane 이 따로 가진 변수가 없어서 jane.strength 를 읽으면 클래스의 20 이 나와요. self.strength += 2 는 “읽은 값 20 에 2 를 더한 22 를 jane 자신의 변수로 저장”하는 줄이라서, 그때부터 jane 은 자기 값을 가져요. mary 와 클래스 값은 건드리지 않아요.

7.3 상속 예제

예제 4. Person 을 물려받는 Student

찾는 순서 · 결과 · 설명 보기 
class Person:                 # Person 클래스를 정의해 주세요
    eyes = 2                  # 클래스 변수 eyes 에 2 를 담아 주세요
    def talk(self):           # talk 메서드를 정의해 주세요
        print('주절주절...')  # '주절주절...' 을 화면에 보여 주세요
class Student(Person):        # Person 을 상속받는 Student 클래스를 정의해 주세요
    def study(self):          # study 메서드를 정의해 주세요
        print('열공열공...')  # '열공열공...' 을 화면에 보여 주세요
kim = Student()               # kim 에 Student 인스턴스를 만들어 담아 주세요
kim.talk()                    # kim 에게 말을 시켜 주세요
kim.study()                   # kim 에게 공부를 시켜 주세요
print(kim.eyes)               # kim 의 eyes 를 화면에 보여 주세요
print(Student.__mro__)        # 이름을 찾는 순서를 화면에 보여 주세요
주절주절...
열공열공...
2
(<class '__main__.Student'>, <class '__main__.Person'>, <class 'object'>)
부른 것이름을 찾는 순서
kim.talk()kim 인스턴스에 talk 없음 → Student 에 없음 → Person 에서 찾음 → 실행
kim.study()kim 인스턴스에 없음 → Student 에서 바로 찾음 → 실행
kim.eyeskim 에 없음 → Student 에 없음 → Person 의 클래스 변수 2 를 찾음

마지막 줄이 보여 주는 Student, Person, object 가 바로 그 찾는 순서예요(__mro__ 는 “이름을 찾는 순서”를 담은 값이에요). 맨 끝의 object 는 파이썬의 모든 클래스가 물려받는 가장 윗부모예요. 반대로 Person 에서 study 를 찾으면 어디에도 없어요. 찾는 방향은 자식 → 부모 한 방향이에요.

예제 5. 부모의 __init__ 을 부르는 super()

실행 순서 · 결과 · 설명 보기 
class Human:                              # Human 클래스를 정의해 주세요
    def __init__(self, name):             # 만들 때 불리는 __init__ 을 정의해 주세요
        self.name = name                  # 이 인스턴스의 name 에 name 을 담아 주세요
class Baby(Human):                        # Human 을 상속받는 Baby 클래스를 정의해 주세요
    def __init__(self, name):             # Baby 의 __init__ 을 정의해 주세요
        super().__init__(name)            # 부모 Human 의 __init__ 을 name 으로 불러 주세요
        self.cute = True                  # 이 인스턴스의 cute 에 True 를 담아 주세요
b = Baby("아기")                          # b 에 이름이 "아기" 인 Baby 를 만들어 담아 주세요
print(b.name, b.cute)                     # b 의 name 과 cute 를 화면에 보여 주세요
아기 True
순서일어나는 일
① Baby("아기")빈 Baby 인스턴스가 생기고 Baby.__init__(self, "아기") 가 불려요.
② super().__init__(name)부모 Human.__init__(self, "아기") 가 실행돼서 self.name = "아기" 가 저장돼요.
③ self.cute = True다시 Baby 로 돌아와 cute 가 저장돼요.
④ 출력b.name 은 부모가, b.cute 는 자식이 만든 값이에요.

②번 줄이 없으면 부모의 __init__ 이 불리지 않아서 name 이 만들어지지 않아요. 실습 문제 중급 4번에서 이 오류를 직접 만나 봐요.

덮어쓰기와 super().메서드()

class Human:                              # Human 클래스를 정의해 주세요
    def __init__(self, name):             # 만들 때 불리는 __init__ 을 정의해 주세요
        self.name = name                  # 이 인스턴스의 name 에 name 을 담아 주세요
class Teen(Human):                        # Human 을 상속받는 Teen 클래스를 정의해 주세요
    def talk(self):                       # talk 메서드를 정의해 주세요
        return "아 몰라요"                # "아 몰라요" 를 돌려주세요
class Teen2(Teen):                        # Teen 을 상속받는 Teen2 클래스를 정의해 주세요
    def talk(self):                       # talk 메서드를 다시 정의해 주세요
        return super().talk() + "!"       # 부모의 talk 결과에 "!" 를 붙여 돌려주세요
print(Teen2("민수").talk())               # 이름이 "민수" 인 Teen2 의 말을 화면에 보여 주세요
아 몰라요!
순서일어나는 일
Teen2("민수").talk()Teen2 에 talk 가 있으니 그걸 실행해요.
super().talk()부모 Teen.talk 를 불러 "아 몰라요" 를 받아요.
+ "!"받은 글자 뒤에 느낌표를 붙여 돌려줘요.

같은 이름의 메서드를 자식이 다시 적으면 자식 것이 먼저 쓰이고(덮어쓰기), 부모 것도 필요하면 super() 로 불러요.
