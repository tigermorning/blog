함수·매개변수·return 정리 — 왕초보 Python 3장 전반부

2026. 10. 11.

※ 이 글은 위키독스 『왕초보를 위한 Python』 3.1 ~ 3.2.5절을 제 나름의 언어로 짧게 정리한 것입니다. 문제 풀이와 질문 해설은 3장 전반부 해설에, 코드를 읽어 보는 연습은 3장 코드 읽기 실습에 있어요.

def · 매개변수 · return · None · f-string, 공식처럼 외우는 3장 전반부 정리예요.

함수일에 붙인 이름.
def함수를 만든다.

1. def와 호출

>>> def boy():           # boy 라는 함수를 만들기 시작해요
...     print('I am a boy.')      # 'I am a boy.' 를 화면에 출력해요
...     print('You are a girl.')  # 'You are a girl.' 를 화면에 출력해요
...
>>> boy()                # boy 함수를 실행해요
I am a boy.
You are a girl.

핵심 한 줄: def는 만들기만 하고, 이름()이 실행한다.

2. 매개변수와 인수

def greet(name):        # 매개변수 name 을 받는 greet 함수를 만들어요
    print('안녕,', name)  # '안녕,' 과 name 값을 함께 출력해요

greet('철수')             # 인수 '철수' 를 넣어 greet 를 실행해요
greet('영희')             # 인수 '영희' 를 넣어 greet 를 실행해요

핵심 한 줄: 매개변수는 자리, 인수는 그 자리에 들어간 값. 순서대로 들어간다.

3. return과 print

>>> c = f1(10)        # f1 이 돌려준 값을 c 에 담아요
>>> print(c)          # c 에 든 값을 출력해요
35
>>> d = f2(10)        # f2 는 돌려주는 값이 없어 d 는 None 이에요
35
>>> print(d)          # d 에 든 값을 출력해요
None

핵심 한 줄: return은 코드에게 넘기고, print는 사람에게 보인다. return을 만나면 함수는 끝난다.

4. None

>>> print(korean_number(11))        # 11 을 넣은 결과를 출력해요
None

핵심 한 줄: return 없이 끝나면 None. None으로 계산하면 에러.

5. f-string과 :2d

>>> print(f'{m} * {n} = {m*n}')        # f-string 으로 값을 끼워 넣어 출력해요
2 * 1 = 2
>>> f'[{4:2d}]'                        # 4 를 2칸 폭으로 맞춰요
'[ 4]'
>>> f'[{4:3d}]'                        # 4 를 3칸 폭으로 맞춰요
'[  4]'
>>> f'[{123:2d}]'                      # 123 은 2칸보다 길어서 그대로 나와요
'[123]'

핵심 한 줄: { }는 값으로 바뀌고, :Nd는 N칸에 오른쪽 맞춤이다.
