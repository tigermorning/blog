함수·매개변수·return 정리 — 왕초보 Python 3장 전반부

2026. 10. 11.

※ 이 글은 위키독스 『왕초보를 위한 Python』 3.1 ~ 3.2.5절을 제 나름의 언어로 짧게 정리한 것입니다. 문제 풀이와 질문 해설은 3장 전반부 해설에, 코드를 읽어 보는 연습은 3장 코드 읽기 실습에 있어요.

1. def와 호출 — 만드는 일과 실행하는 일은 따로

def는 "지금부터 함수를 하나 만들겠다"는 신호예요. 만들 때는 이름과 할 일을 저장해 둘 뿐이라 화면에 아무것도 안 나와요. 괄호를 붙여 이름()으로 부를 때 비로소 저장한 줄이 위에서 아래로 실행돼요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> def boy():
...     print('I am a boy.')
...     print('You are a girl.')
...
>>> boy()
I am a boy.
You are a girl.

핵심 한 줄: def는 요리법을 적어 두는 일이고, 이름()이 그 요리법대로 요리를 시작하는 일이다.

2. 매개변수와 인수 — 자리와 그 자리에 넣는 값

매개변수는 함수를 만들 때 괄호 안에 적는 빈 자리의 이름이고, 인수는 함수를 부를 때 그 자리에 넣는 실제 값이에요. 인수는 적은 순서대로 매개변수에 들어가요. 첫 번째 값은 첫 번째 매개변수로, 두 번째 값은 두 번째 매개변수로 가요.

실행: 로컬 파이썬 — 아무 환경 OK — 파일로 저장해 실행하거나 셸에 한 줄씩 입력해요

def greet(name):          # name = 매개변수
    print('안녕,', name)

greet('철수')              # '철수' = 인수
greet('영희')

실행: 파이썬 대화형 셸 — 정의를 끝낸 뒤 빈 줄 엔터를 한 번 더

>>> def compare(a, b):
...     if a > b:
...         print('a > b')
...     elif a < b:
...         print('a < b')
...     else:
...         print('a == b')
...
>>> compare(5, 3)
a > b
>>> compare(2, 7)
a < b
>>> compare(4, 4)
a == b

a와 b는 따로 정의하지 않아도 돼요. 부를 때 값이 들어오니까요.

핵심 한 줄: 매개변수는 "값이 들어올 자리", 인수는 "그 자리에 실제로 들어간 값"이다.

3. return과 print — 코드에게 주느냐, 사람에게 보여 주느냐

return y는 값을 함수를 부른 쪽에 돌려줘요. 받은 값은 변수에 담거나 다른 계산에 다시 쓸 수 있어요. print(y)는 값을 화면에 보여 주기만 하고 부른 쪽에는 아무것도 돌려주지 않아요. 화면에는 둘 다 35가 보이지만 변수에 들어가는 값이 달라요.

실행: 파이썬 대화형 셸

>>> def f1(x):
...     y = 3 * x + 5
...     return y
...
>>> def f2(x):
...     y = 3 * x + 5
...     print(y)
...
>>> c = f1(10)
>>> print(c)
35
>>> d = f2(10)
35
>>> print(d)
None

return을 만나는 순간 함수는 거기서 끝나요. 그 아래 줄은 실행하지 않아요. 또 셸(>>>)은 돌려받은 값을 자동으로 보여 주지만 .py 파일은 그러지 않아서, 파일에서 보려면 print(f1(10))처럼 감싸야 해요.

핵심 한 줄: print는 사람에게 보여 주는 것이고, return은 코드에게 넘겨주는 것이다.

4. None — return이 없을 때 돌아오는 값

return을 한 번도 만나지 못하고 함수가 끝나면 파이썬이 자동으로 None을 돌려줘요. 아래 함수에 1~10이 아닌 값을 넣으면 어떤 조건에도 안 맞아서 None이 나와요. None은 출력만 할 때는 조용히 넘어가지만, 그 값을 계산에 쓰는 순간 에러가 나요.

실행: 로컬 파이썬 — 아무 환경 OK — 줄인 부분을 채워 넣으면 그대로 돌아가요

def korean_number(num):
    if num == 1:
        return '일'
    elif num == 2:
        return '이'
    elif num == 3:
        return '삼'
    # ... 4부터 9까지 같은 모양 ...
    elif num == 10:
        return '십'

실행: 파이썬 대화형 셸

>>> print(korean_number(11))
None

퀴즈로 확인해 볼까요? 아래 코드를 실행하면 x에는 None, y에는 8이 들어가요. 화면에 나오는 8 하나는 print_sum 안의 print가 찍은 거예요.

실행: 로컬 파이썬 — 아무 환경 OK

def print_sum(a, b):
    print(a + b)

def return_sum(a, b):
    return a + b

x = print_sum(3, 5)
y = return_sum(3, 5)

핵심 한 줄: 값을 돌려주지 않는 함수의 결과는 None이고, None을 계산에 쓰면 에러가 난다.

5. f-string과 :2d — 문자열에 값을 끼우고 칸을 맞추기

문자열 앞에 f를 붙이면 { } 안이 값이나 계산 결과로 바뀌어요. { } 안에서 콜론 뒤에 2d를 쓰면 정수를 최소 2칸에 맞춰 출력해요. 값이 2칸보다 짧으면 왼쪽을 공백으로 채워 오른쪽에 붙이고, 더 길면 잘리지 않고 그대로 나와요.

실행: 파이썬 대화형 셸

>>> m = 2
>>> n = 1
>>> print(m, '*', n, '=', m*n)
2 * 1 = 2
>>> print(f'{m} * {n} = {m*n}')
2 * 1 = 2
>>> f'[{4:2d}]'
'[ 4]'
>>> f'[{4:3d}]'
'[  4]'
>>> f'[{123:2d}]'
'[123]'

핵심 한 줄: f-string은 출력될 모양 그대로 적을 수 있고, :2d는 일의 자리를 세로로 맞추는 서식이다.
