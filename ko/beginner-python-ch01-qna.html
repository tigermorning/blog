1.1.1 퀴즈: 사칙 연산

문제 원문: wikidocs.net/170810

Q1. 수식 8÷2(2+2)를 코드로 옮긴 답이 왜 /가 아니라 //인가요?

이 식에서는 /를 써도 계산 결과는 같아요. 달라지는 건 결과의 자료형뿐이에요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> 8 / 2 * (2 + 2)
16.0
>>> 8 // 2 * (2 + 2)
16
연산자하는 일예
/나눗셈. 결과가 항상 소수점 있는 수(float)로 나와요8 / 2 → 4.0
//나눈 뒤 소수점 아래를 버려요(floor division). 정수끼리면 정수(int)로 나와요8 // 2 → 4
  • //를 쓴 이유(추정): 답이 정수 16이라 16.0 대신 16으로 깔끔하게 보여 주려던 것 같아요.
  • 계산 순서는 같아요. /, //, *는 우선순위가 같아서 왼쪽부터 계산해요. 그래서 (8÷2)×4 = 16이에요.

주의 — 항상 바꿔 쓸 수 있는 건 아니에요. 8이 2로 나누어떨어져서 우연히 같았을 뿐이에요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> 7 / 2 * 4
14.0      # 수학적으로 맞는 값
>>> 7 // 2 * 4
12        # 3.5에서 소수점을 버려 3, 3 × 4 = 12
  • 일반 수학식을 옮길 때는 /가 맞아요.
  • //는 몫만 필요하거나, 결과가 정수라는 게 확실할 때 써요.

1.1.2 연습 문제: 직선 거리 계산

문제 원문: wikidocs.net/215049

Q2. import math의 import는 무슨 뜻인가요?

import는 다른 파일(모듈)에 들어 있는 기능을 가져와서 쓸 수 있게 하는 명령이에요.

공구함 비유파이썬에서는
기본 도구만 든 공구함아무것도 가져오지 않은 파이썬
수학 도구만 모은 별도 상자math 모듈
상자를 꺼내 책상에 올려놓기import math
상자에서 도구 하나 꺼내 쓰기math.sqrt(2)

핵심 한 줄: 모듈은 가져온 뒤에야 모듈이름.기능이름으로 쓸 수 있어요.

가져오지 않고 쓰면 에러가 나요. 파이썬이 math가 뭔지 모르기 때문이에요.

실행: 파이썬 대화형 셸 — 새로 연 셸에서 import 없이 실행해야 보여요

>>> math.sqrt(2)
NameError: name 'math' is not defined. Did you forget to import 'math'?

math.sqrt(2)는 이렇게 읽어요.

  • math — 모듈 이름(수학 상자)
  • . — "~ 안에 있는"
  • sqrt — 함수 이름(square root, 제곱근)
  • 합치면 "math 안에 있는 sqrt 함수에 2를 넣어라"

왜 처음부터 다 켜 두지 않을까요? 모듈이 수백 개라 전부 불러오면 느리고 메모리를 낭비해요. 그래서 필요한 것만 골라 가져와요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> from math import sqrt    # sqrt 하나만 가져오기
>>> sqrt(2)                  # math. 없이 바로 사용
1.4142135623730951
>>> import math as m         # 별명 붙여 가져오기
>>> m.sqrt(2)
1.4142135623730951
>>> math.pi, math.floor(3.7), math.ceil(3.2)   # math의 다른 기능: 원주율, 내림, 올림
(3.141592653589793, 3, 4)

마지막 줄은 import math를 먼저 한 셸에서 실행해야 해요.

Q3. 문제 풀이 — 두 가게 사이의 직선 거리 구하기

문제 요약: 바둑판처럼 길이 직각으로 난 동네에서, A에서 B까지 550m, B에서 C까지 600m를 걸어요. 두 길이 직각으로 만날 때, A와 C 사이의 직선 거리를 math.sqrt()로 구하는 문제예요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> import math
>>> math.sqrt(550 ** 2 + 600 ** 2)
813.9410298049853

답은 약 814m예요.

풀이 순서

  1. 두 길과 직선 거리가 직각삼각형을 이뤄요. 두 길은 직각을 끼는 변(a, b), 직선 거리는 빗변(c)이에요.
  2. 피타고라스 정리: c² = a² + b²
  3. 그래서 c = √(a² + b²)
  4. 코드로 옮기기
    • 550 ** 2 — 550을 2번 곱하기 → 302500
    • + 600 ** 2 — 600을 2번 곱한 값을 더하기 → 662500
    • math.sqrt(...) — 제곱근 → 약 813.94

**는 거듭제곱 기호예요. "제곱"만 하는 기호가 아니라, 뒤에 붙은 숫자만큼 곱해요.

코드수학으로 쓰면뜻결과
3 ** 23²3을 2번 곱하기(제곱)9
3 ** 33³3을 3번 곱하기(세제곱)27
2 ** 102¹⁰2를 10번 곱하기1024
  • ** 앞의 수는 곱할 수, 뒤의 수는 곱하는 횟수예요.
  • ** 2만 따로 쓰면 SyntaxError가 나요. 앞에 곱할 수가 꼭 있어야 해요.
  • -3 ** 2는 -9예요. **가 빼기 부호보다 먼저 계산되니, 음수를 거듭제곱하려면 (-3) ** 2처럼 괄호로 감싸요.

다른 방법

실행: 파이썬 대화형 셸 — import math를 먼저 한 셸에서

>>> math.sqrt(550 * 550 + 600 * 600)   # ** 대신 같은 수를 직접 두 번 곱하기
813.9410298049853
>>> math.hypot(550, 600)               # 빗변 길이를 바로 구하는 함수 (Q4)
813.9410298049853
나쁜 선택좋은 선택
다른 언어나 계산기 습관대로 거듭제곱을 550 ^ 2로 쓴다 → 파이썬에서 ^는 거듭제곱이 아니라 비트 연산(XOR)이라, 에러 없이 548이라는 엉뚱한 값이 나와요. 거듭제곱은 550 ** 2로 쓴다 → 302500이 나오고, 직선 거리도 814m로 맞게 나와요.

Q4. hypot은 무슨 뜻인가요?

hypot은 hypotenuse(빗변)를 줄인 이름이에요. 직각을 끼는 두 변의 길이를 넣으면 빗변 길이, 즉 √(a² + b²)를 돌려줘요.

실행: 파이썬 대화형 셸 — import math를 먼저 한 셸에서

>>> math.hypot(3, 4)
5.0
>>> math.sqrt(3 ** 2 + 4 ** 2)   # 같은 계산
5.0
>>> math.hypot(1, 2, 2)          # 값 3개도 가능 (Python 3.8부터): √(1² + 2² + 2²)
3.0
  • sqrt 대신 쓰면 좋은 점: 코드가 짧고, "빗변을 구한다"는 뜻이 이름에 드러나요.
  • 정확도: 아주 크거나 아주 작은 수를 넣어도 더 정확하게 계산해요.
  • 값 3개 이상: 3차원 공간에서 두 점 사이 직선 거리를 구할 때 써요.

Q5. 인덱싱과 슬라이싱을 비유로 설명하면? — 음수 번호와 간격까지

리스트는 원소를 순서대로 담은 목록이고, 원소마다 0부터 시작하는 번호(인덱스)가 붙어요. 번호로 원소 하나를 꺼내는 게 인덱싱, 구간을 잘라 새 리스트로 꺼내는 게 슬라이싱이에요.

지하철 비유리스트에서는
노선리스트
역원소
출발역에서 몇 정거장 떨어졌나 (출발역은 0정거장)인덱스
종점에서 거꾸로 몇 번째 역인가음수 인덱스
구간 승차권슬라이싱 [시작:끝]
몇 역씩 건너뛰며 서는 급행열차간격 [시작:끝:간격]

핵심 한 줄: 인덱스는 "출발역에서 몇 정거장 떨어졌나"라서 첫 역이 0이에요.

개념 설명용 코드 — 번호 붙는 모양을 보여 주는 그림이에요

s = ['시청', '을지로입구', '을지로3가', '을지로4가', '동대문역사문화공원', '신당', '상왕십리', '왕십리']
#      0         1            2           3              4               5        6         7
#     -8        -7           -6          -5             -4              -3       -2        -1

1) 인덱싱 — 역 하나 고르기

실행: 파이썬 대화형 셸 — 위의 s = [...] 줄을 먼저 입력해요

>>> s[0]      # 출발역
'시청'
>>> s[3]      # 3정거장 뒤
'을지로4가'
>>> s[8]      # 없는 역
IndexError: list index out of range

2) 음수 인덱싱 — 종점부터 거꾸로

실행: 파이썬 대화형 셸 — 위의 s = [...] 줄을 먼저 입력해요

>>> s[-1]     # 종점
'왕십리'
>>> s[-2]     # 종점 바로 앞
'상왕십리'
  • -1은 "뒤에서 첫 번째"예요.
  • 리스트 길이를 몰라도 마지막 원소를 꺼낼 수 있어서 자주 써요.
  • s[-1]은 s[len(s) - 1]과 같아요.

3) 슬라이싱 [시작:끝] — 구간 승차권

실행: 파이썬 대화형 셸 — 위의 s = [...] 줄을 먼저 입력해요

>>> s[1:4]
['을지로입구', '을지로3가', '을지로4가']
>>> s[:3]     # 시작 생략 = 처음부터
['시청', '을지로입구', '을지로3가']
>>> s[5:]     # 끝 생략 = 끝까지
['신당', '상왕십리', '왕십리']
>>> s[-3:]    # 뒤에서 3개
['신당', '상왕십리', '왕십리']
  • 끝 번호의 역은 들어가지 않아요. 끝 번호는 "이 역 앞에서 내린다"는 뜻이에요(이유는 Q8).
  • s[1:4]는 1, 2, 3번이라 4 - 1 = 3개예요.

4) 간격 [시작:끝:간격] — 급행열차

실행: 파이썬 대화형 셸 — 위의 s = [...] 줄을 먼저 입력해요

>>> s[1:5:2]
['을지로입구', '을지로4가']
>>> s[::2]    # 처음부터 끝까지 한 역씩 건너뛰기
['시청', '을지로3가', '동대문역사문화공원', '상왕십리']
>>> s[::-1]   # 반대 방향 열차 = 뒤집기
['왕십리', '상왕십리', '신당', '동대문역사문화공원', '을지로4가', '을지로3가', '을지로입구', '시청']
  • s[1:5:2]는 1번에서 출발해 2정거장씩 가요.
  • 1번에 서고, 3번에 서요.
  • 다음 5번은 끝 번호라 들어가지 않아서 멈춰요.
코드뜻
s[i]i번 원소 하나
s[-1]마지막 원소
s[a:b]a번부터 b번 앞까지
s[a:b:k]a번부터 k칸 간격으로, b번 앞까지
s[::-1]뒤집은 리스트

Q6. 예시에 나온 s는 무슨 뜻인가요?

s는 파이썬에 정해진 기호가 아니라, 리스트에 붙인 변수 이름이에요. 지하철역 목록이라 stations(역들)의 첫 글자를 땄어요.

  • s = [...]는 "오른쪽 리스트에 s라는 이름표를 붙인다"는 뜻이에요.
  • 그다음 s[0]은 "s라는 리스트의 0번 원소"예요.
  • 교재가 가족 목록에 family라는 이름을 붙인 것과 같아요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> stations = ['시청', '을지로입구', '을지로3가']
>>> stations[0]
'시청'
>>> subway = ['시청', '을지로입구', '을지로3가']
>>> subway[-1]
'을지로3가'

변수 이름 규칙

  • 영문자, 숫자, _만 쓸 수 있어요.
  • 숫자로 시작하면 안 돼요(1st는 안 됨).
  • list, len처럼 파이썬이 이미 쓰는 이름은 피해요. 원래 기능이 가려져요.
  • 한 글자보다 stations, family처럼 내용이 드러나는 이름이 나중에 읽기 쉬워요.

Q7. s[::-1]의 ::는 뭔가요? s[-1]과 다른가요?

완전히 달라요. ::는 기호 하나가 아니라, 콜론 두 개 사이의 칸이 비어 있는 것이에요.

개념 설명용 코드 — 칸 배치를 보여 주는 그림이에요

s[ 시작 : 끝 : 간격 ]
s[     :    : -1  ]   # 시작 생략, 끝 생략, 간격 -1
  • 시작 생략 — 처음부터(간격이 음수면 맨 뒤부터)
  • 끝 생략 — 끝까지(간격이 음수면 맨 앞까지)
  • 간격 -1 — 한 칸씩 거꾸로
  • 합치면 "맨 뒤부터 맨 앞까지 한 칸씩 거꾸로" = 뒤집기

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> s = ['시청', '을지로입구', '을지로3가', '을지로4가']
>>> s[-1]
'을지로4가'
>>> s[::-1]
['을지로4가', '을지로3가', '을지로입구', '시청']
>>> s[:-1]
['시청', '을지로입구', '을지로3가']
s[-1]s[::-1]s[:-1]
종류인덱싱슬라이싱슬라이싱
콜론 개수0개2개1개
-1의 뜻뒤에서 첫 번째 위치거꾸로 가는 간격마지막 원소 앞에서 멈추는 끝
결과원소 1개뒤집은 새 리스트마지막만 뺀 새 리스트
  • 구분법: 대괄호 안에 콜론이 있으면 슬라이싱이고 결과는 리스트예요.
  • 슬라이싱은 새 리스트를 만들 뿐, 원래 s는 바뀌지 않아요.

Q8. s[1:5:2]에서 끝 번호는 왜 포함되지 않나요?

파이썬이 "시작은 포함, 끝은 제외"로 정한 규칙이에요. 이렇게 하면 편한 점이 많아서 대부분의 프로그래밍 언어가 같은 방식을 써요.

이해하는 요령: 번호가 원소 자체가 아니라 원소 사이의 칸막이를 가리킨다고 생각해요.

개념 설명용 코드 — 칸막이 번호를 보여 주는 그림이에요

| 시청 | 을지로입구 | 을지로3가 | 을지로4가 | 동대문 | 신당 |
0      1           2          3          4        5      6
  • s[1:5]는 "1번 칸막이부터 5번 칸막이까지 잘라라"예요.
  • 그 사이에 있는 원소는 을지로입구, 을지로3가, 을지로4가, 동대문이에요.
  • 5번 칸막이 오른쪽의 신당은 자연스럽게 빠져요.

끝을 빼면 좋은 점

좋은 점예
개수 계산이 쉬워요. 끝을 포함하는 규칙이면 매번 끝 - 시작 + 1을 해야 해요s[1:5] → 5 - 1 = 4개
같은 숫자를 경계로 자르면 겹치지 않고 딱 맞게 나뉘어요s[:3] + s[3:] == s → True
나중에 배울 range()와 규칙이 같아요list(range(1, 5)) → [1, 2, 3, 4]

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> s = ['시청', '을지로입구', '을지로3가', '을지로4가', '동대문', '신당']
>>> s[1:5:2]    # 1, 3 → 다음 5는 끝 번호라 제외
['을지로입구', '을지로4가']
>>> s[1:6:2]    # 5번까지 넣고 싶으면 끝을 하나 크게
['을지로입구', '을지로4가', '신당']

핵심 한 줄: [시작:끝]은 "시작 이상, 끝 미만"으로 읽으면 헷갈리지 않아요.

Q9. 추가 append·extend·insert와 삭제 remove·pop·del은 어떻게 다른가요?

리스트 하나를 계속 이어서 바꿔 가며 볼게요.

추가

실행: 파이썬 대화형 셸 — 위에서부터 순서대로 입력해요

>>> f = ['mother', 'father']
>>> f.append('me')                 # 원소 1개를 맨 뒤에
>>> f
['mother', 'father', 'me']
>>> f.extend(['sister', 'dog'])    # 여러 원소를 풀어서 맨 뒤에
>>> f
['mother', 'father', 'me', 'sister', 'dog']
>>> f.insert(1, 'grandma')         # 1번 자리에 끼워 넣기, 뒤는 한 칸씩 밀림
>>> f
['mother', 'grandma', 'father', 'me', 'sister', 'dog']
나쁜 선택좋은 선택
원소 여러 개를 붙이려고 f.append(['a', 'b'])를 쓴다 → 리스트가 통째로 원소 1개가 되어 [..., ['a', 'b']]처럼 리스트 안에 리스트가 생겨요. f.extend(['a', 'b'])를 쓴다 → 'a', 'b'가 각각 원소로 붙어요.

삭제 (위에서 이어서)

실행: 파이썬 대화형 셸 — 위의 추가 코드에 이어서 입력해요

>>> f.remove('dog')     # 값으로 찾아서 지우기
>>> f
['mother', 'grandma', 'father', 'me', 'sister']
>>> x = f.pop()         # 맨 뒤를 꺼내고, 꺼낸 값을 돌려줌
>>> x
'sister'
>>> y = f.pop(1)        # 1번 자리를 꺼냄
>>> y
'grandma'
>>> f
['mother', 'father', 'me']
>>> del f[0]            # 위치로 지우기만, 돌려주는 값 없음
>>> f
['father', 'me']
>>> del f[0:1]          # 슬라이스로 구간 지우기
>>> f
['me']
  • remove(값): 같은 값이 여러 개면 첫 번째만 지워요(['a', 'b', 'a'] → ['b', 'a']). 값이 없으면 ValueError가 나요.
  • pop(위치): 꺼낸 값을 돌려줘서 변수에 받아 쓸 수 있어요. 위치를 생략하면 맨 뒤를 꺼내요.
  • del 리스트[위치]: 메서드가 아니라 파이썬 문법이라 괄호 없이 써요(Q11).

언제 무엇을 쓰나

상황쓸 것
원소 1개를 뒤에 추가append
다른 리스트의 원소들을 뒤에 추가extend
특정 위치에 끼워 넣기insert
값은 아는데 위치는 모를 때 삭제remove
지운 값을 다시 써야 할 때pop
위치로 지우기만, 또는 구간 삭제del

속도 차이

  • 빠름 — append, pop(): 맨 뒤만 건드려서 리스트가 길어도 속도가 같아요.
  • 느림 — insert(0, x), pop(0), del f[0]: 앞쪽을 바꾸면 뒤의 원소를 전부 한 칸씩 옮겨야 해요.
  • 느림 — remove(값): 값을 찾으려고 처음부터 하나씩 확인해요.
  • 팁: 앞쪽에서 넣고 빼는 일이 잦으면 collections.deque의 appendleft(), popleft()가 빨라요.

Q10. x = f.pop(), y = f.pop(1)에서 x와 y는 뭔가요?

x, y도 Q6의 s처럼 임의로 붙인 변수 이름이에요. pop()이 꺼낸 값을 담아 두는 그릇이에요.

x = f.pop()이 실행되는 순서

  1. 오른쪽 f.pop()이 먼저 실행돼요. f의 맨 뒤 'sister'를 빼내요.
  2. pop()이 빼낸 'sister'를 돌려줘요.
  3. 돌려받은 값을 x에 담아요.
  • =는 "같다"가 아니라 "오른쪽 결과를 왼쪽 이름에 담아라"예요.
  • 담아 두면 print(x), y + ' 안녕'처럼 나중에 쓸 수 있어요.
  • f.pop()만 쓰면 원소는 똑같이 빠지지만, 꺼낸 값은 다시 쓸 수 없어요(대화형 셸은 화면에 한 번 보여 주기만 해요).
  • x = del f[0]은 SyntaxError가 나요. del은 돌려주는 값이 없어요.
  • 실제 코드에서는 last = f.pop()처럼 내용이 드러나는 이름이 좋아요.

Q11. del은 "메서드가 아니라 파이썬 문법이라 괄호가 없다"는 게 무슨 말인가요?

파이썬 명령에는 쓰는 모양이 다른 두 종류가 있어요.

메서드키워드
예f.pop(0), f.append('me')del f[0], import math
정체리스트 같은 자료에 딸린 기능파이썬 언어 자체에 정해진 단어
점 .있음 — "f가 가진 기능"없음
괄호 ()필요 — "지금 실행해라"라는 신호필요 없음 — 단어 뒤에 대상을 바로 씀
돌려주는 값있기도 함(pop)없음
  • 메서드는 괄호를 빠뜨리면 실행되지 않아요. f.pop은 기능을 가리키기만 하고, f.pop()이어야 실행돼요.
  • del은 앞에서 본 import와 같은 종류라서 "지워라: f의 0번"처럼 읽어요.
  • 앞으로 배울 if, for, while도 키워드라서 괄호 없이 써요.
  • del(f[0])도 동작은 해요. 다만 이때 괄호는 실행 신호가 아니라 (1 + 2)처럼 묶는 괄호라서, 보통 del f[0]으로 써요.

Q12. "리스트에만 있는 기능"이라는 말 자체가 이해가 안 돼요

핵심은 파이썬 자료에는 종류가 있고, 종류마다 할 줄 아는 일이 다르다는 거예요.

개념 설명용 코드 — 자료 종류를 보여 주는 예시예요

5                      # 숫자

['mother', 'father']   # 리스트 (대괄호로 묶은 목록)
집 안 기계 비유파이썬에서는
전화기, TV 같은 기계 종류리스트, 문자열 같은 자료 종류

버튼 누르기자료.메서드()

AttributeError: 'list' object has no attribute 'upper'

  • "리스트에만 있는 기능"은 이 뜻이에요. append는 리스트에는 달려 있고 문자열에는 없어요.
  • len은 어느 한 자료에 딸린 버튼이 아니라서 f.len()이 아니라 len(f)로 써요.

Q13. 메서드와 키워드는 언제 각각 쓰나요?

둘 다 파이썬이에요. 그리고 대부분은 내가 고르는 게 아니에요. 하려는 일마다 쓸 도구가 정해져 있고, 그 도구가 메서드일 수도, 키워드일 수도, 함수일 수도 있어요.

Q14. int도 input도 모르겠어요 — 풀이 예시 한 줄씩

이 두 줄이 하는 일을 말로 적으면 네 단계예요.

  1. 사용자에게 숫자를 입력받는다 — input
  2. 입력받은 글자를 계산할 수 있는 숫자로 바꾼다 — int
  3. 60으로 나눠 몫(시간)과 나머지(분)를 구한다 — //, %
  4. 결과를 화면에 보여 준다 — print

1단계: input() — 키보드로 입력받기

  • 프로그램이 여기서 멈추고, 사용자가 무언가 치고 Enter를 누를 때까지 기다려요.
  • 사용자가 친 내용을 그대로 돌려줘요.

실행: 파이썬 대화형 셸 — 첫 줄을 친 뒤 135를 입력하고 Enter

>>> answer = input()
135
>>> answer
'135'
  • 결과가 135가 아니라 '135'예요. 따옴표가 붙어 있어요.
  • input()은 무엇을 치든 항상 글자(문자열)로 돌려줘요.
  • 괄호 안에 input('분을 입력하세요: ')처럼 문구를 넣으면, 기다리기 전에 그 문구를 먼저 보여 줘요. 비워 두면 아무것도 안 뜬 채 기다려서 멈춘 것처럼 보여요.

2단계: 글자로는 왜 계산이 안 되나

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

  • 사람 눈에는 같아 보여도, 파이썬에게 '135'는 "1", "3", "5"라는 글자 세 개일 뿐이에요.
모양종류파이썬 이름
'135'글자(문자열)str
135정수int

3단계: int() — 글자를 정수로 바꾸기

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> int('135')
135
>>> int('135') // 60
2
>>> int('abc')          # 숫자로 바꿀 수 없는 글자
ValueError: invalid literal for int() with base 10: 'abc'
  • int는 integer(정수)의 줄임말이에요.
  • 괄호 안의 값을 정수로 바꿔 돌려줘요. 따옴표가 사라진 135는 계산할 수 있어요.

4단계: int(input()) — 괄호는 안쪽부터

  1. input() — 사용자가 135를 치면 '135'
  2. int('135') — 135
  3. total = 135 — total이라는 이름표에 담기(Q10의 =와 같아요)

두 줄로 나눠 써도 뜻이 같아요.

개념 설명용 코드 — 위 한 줄을 풀어 쓴 모양이에요

text = input()      # '135' (글자)
total = int(text)   # 135   (숫자)

5단계: //와 % — 시간과 분 구하기

"135분은 몇 시간 몇 분?"은 "60분 묶음이 몇 개이고, 몇 분이 남나?"와 같은 질문이에요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> 135 // 60     # 몫 = 60이 몇 번 들어가나
2
>>> 135 % 60      # 나머지 = 60씩 빼고 남은 것
15
  • //는 몫이라 2시간, %는 나머지라 15분이에요(//는 Q1).
  • 확인: 60 × 2 + 15 = 135

6단계: print() — 쉼표로 여러 개 출력하기

  • 쉼표로 나눈 값이 차례로 출력되고, 사이에 공백이 하나씩 자동으로 들어가요.
  • total // 60 → 2, '시간' → 시간, total % 60 → 15, '분' → 분
  • 합치면 2 시간 15 분이에요.
  • 따옴표가 있는 '시간'은 글자 그대로, 따옴표가 없는 total // 60은 계산 결과가 나와요.

직접 실행해 보기

  1. 메모장이나 VS Code에서 아래 두 줄을 쓰고 minutes.py로 저장해요.

실행: minutes.py로 저장 — 다음 명령이 이 파일을 읽어요

total = int(input('분을 입력하세요: '))
print(total // 60, '시간', total % 60, '분')
  1. 그 파일이 있는 폴더에서 터미널을 열고 실행해요.

실행: 로컬 터미널

python minutes.py
  1. 분을 입력하세요:가 뜨면 135를 치고 Enter를 눌러요.
  2. 2 시간 15 분이 나오면 성공이에요. 60, 59, 200도 넣어 봐요.

Q15. input은 텍스트로 바꾸는 명령이고, int는 숫자로 바꾸는 명령인가요?

반은 맞고 반은 조금 달라요.

  • int() — 맞아요. 괄호 안의 값을 정수로 바꾸는 명령이에요.
  • input() — 조금 달라요. 원래 일은 키보드 입력을 받아 오는 것이고, 받아 온 결과가 항상 텍스트로 나올 뿐이에요. 이미 있는 값을 텍스트로 바꿔 주지는 못해요.
식당 주문 비유파이썬에서는
손님이 말한 주문을 종이에 받아 적는 직원 — 종이에 적었으니 늘 글자input() — 입력을 받아 오고, 결과는 늘 텍스트
종이에 적힌 "135"를 계산기에 숫자로 옮겨 치는 직원int() — 텍스트를 정수로 바꾸기

핵심 한 줄: input()은 받아 오는 명령, int()는 바꾸는 명령이에요.

텍스트로 바꾸는 명령은 따로 있어요. str은 string(문자열)의 줄임말이에요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> str(135)
'135'
명령하는 일예
input()키보드 입력 받기 (결과는 텍스트)135 입력 → '135'
int()정수로 바꾸기int('135') → 135
str()텍스트로 바꾸기str(135) → '135'
float()소수점 있는 수로 바꾸기 (Q16)float('3.7') → 3.7

int()는 정수 전용이라 소수점을 다루지 못해요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> int(3.7)       # 소수점 숫자를 넣으면 소수점 아래를 버림
3
>>> int('3.7')     # 소수점이 있는 글자는 바꾸지 못함
ValueError: invalid literal for int() with base 10: '3.7'

Q16. float는 뭔가요?

float는 소수점이 있는 숫자를 뜻하는 자료 종류 이름이에요. floating point(떠다니는 소수점)의 줄임말인데, 처음에는 "float = 소수점 있는 수"로 기억하면 충분해요.

종류파이썬 이름예
정수 (소수점 없음)int3, 135, -7
실수 (소수점 있음)float3.7, 0.5, 3.0
  • 3과 3.0은 값은 같지만 종류가 달라요.
  • 소수점이 붙어 있으면 .0이어도 float예요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> type(3)          # type()은 값의 종류를 알려 줘요
<class 'int'>
>>> type(3.0)
<class 'float'>
>>> float('3.7')     # 글자를 실수로
3.7
>>> float(3)         # 정수를 실수로
3.0
>>> float('abc')     # 숫자가 아닌 글자는 바꾸지 못함
ValueError: could not convert string to float: 'abc'

괄호를 빼면 안 돼요. float, int, str은 모두 괄호 안에 바꿀 값을 넣어야 실행돼요.

나쁜 선택좋은 선택
float 3처럼 띄어 쓴다 → SyntaxError: invalid syntax가 나요. 파이썬은 이걸 명령으로 읽지 못해요. float(3)처럼 괄호로 감싼다 → 3.0이 나와요.
  • 괄호 없이 float만 치면 에러는 안 나지만 <class 'float'>라는 이름만 보여 주고 아무것도 바꾸지 않아요(Q11의 f.pop과 같은 경우).
  • 괄호 없이 쓰는 건 del, import 같은 키워드뿐이에요.

이미 만난 float: Q1의 8 / 2 * (2 + 2)가 16.0이었던 이유예요.

  • / 나눗셈은 나누어떨어져도 결과가 항상 float예요.
  • 정수와 실수를 섞어 계산해도 결과는 float예요(3 + 0.5 → 3.5, 2 * 1.0 → 2.0).
  • 사용자가 1.5처럼 소수점을 입력할 수 있으면 float(input())으로 받아요.

float는 아주 조금 틀릴 때가 있어요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> 0.1 + 0.2
0.30000000000000004
>>> round(0.1 + 0.2, 2)    # 소수 둘째 자리까지 반올림
0.3
  • 컴퓨터가 소수를 0과 1로 저장하면서 생기는 아주 작은 오차예요.
  • 파이썬만의 버그가 아니라 대부분의 언어에서 똑같이 생겨요.
  • 화면에 보여 줄 때는 round()로 반올림해요.

이럴 때 의심하세요 — 1장 문법으로 짠 코드의 결과가 이상할 때

에러 없이 틀린 값이 나오거나, 에러가 엉뚱한 줄을 가리키는 경우를 모았어요. 결과가 예상과 다르면 이 표부터 확인해요.

이런 증상이 보이면먼저 열어 볼 자리확인 방법
나눗셈 결과가 계산기 값보다 조금 작은 정수로 나와요 (14가 나와야 하는데 12) 식 안의 // //를 /로 바꿔 다시 실행해요. 값이 맞게 나오면 소수점이 버려졌던 거예요 (Q1)
거듭제곱을 했는데 원래 수와 비슷한 엉뚱한 값이 나와요 (550 ^ 2 → 548) 식 안의 ^ 거듭제곱은 **예요. 550 ** 2가 302500인지 확인해요 (Q3)
슬라이싱 결과에서 마지막 원소 하나가 늘 빠져요 대괄호 안의 끝 번호 len(결과)가 끝 - 시작과 같은지 봐요. 끝 원소까지 넣으려면 끝 번호를 1 크게 써요 (Q8)
리스트 출력에 대괄호가 겹쳐 [..., ['a', 'b']]처럼 보이고, len()이 예상보다 작아요 원소를 붙인 줄의 append 여러 원소를 붙이려던 거라면 extend로 바꿔요 (Q9)
입력받은 숫자로 계산하는 줄에서 TypeError: unsupported operand type(s)로 시작하는 에러가 나고, 끝에 'str' and 'int'가 보여요 값을 받는 줄의 input(). 에러가 난 계산 줄은 범인이 아니에요 input()이 int(...)로 감싸져 있는지 봐요. 소수점도 받아야 하면 float(...)로 감싸요 (Q14)
돈이나 점수를 더했는데 0.30000000000000004처럼 끝자리가 지저분한 값이 찍혀요 소수점 있는 수(float)끼리 계산한 줄 계산이 틀린 게 아니라 float의 작은 오차예요. 보여 줄 때 round(값, 2)로 반올림해요 (Q16)
