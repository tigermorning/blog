7.1 클래스와 인스턴스 정리 — 왕초보 Python 7장 객체지향 (1)

2026. 11. 19.

※ 이 글은 위키독스 『왕초보를 위한 Python』 7.1절과 영상은 노마드 코더의 「객체지향 프로그래밍? 문과도 이해쌉가능. 10분컷.」인데, 영어 음성의 자동 자막 전체를 읽고 정리했어요. 화면에 나온 코드는 보지 못해서 예제는 파이썬으로 새로 짜서 직접 돌렸어요. 코드 실행 결과는 실제로 돌려서 넣었어요.

클래스(class)는 같은 모양의 객체를 만드는 틀이고, 그 틀로 만든 하나하나가 인스턴스예요.

1. 틀과 결과물 (7.1)

말뜻
클래스(class)같은 종류의 객체가 갖는 공통점을 적어 둔 틀. “부류”. 예: 스케이터, 사과
인스턴스(instance)·객체(object)틀로 만든, 실제로 하나 콕 집을 수 있는 것. 예: 김연아, 어제 먹은 사과 두 번째 것
메서드(method)클래스 안에 정의한 함수
만들기인스턴스 = 클래스()
쓰기인스턴스.메서드()

클래스 만들고 인스턴스 만들기

class Singer:                  # Singer 라는 클래스를 정의해 주세요
    def sing(self):            # sing 메서드를 정의해 주세요 (self 는 7.2 에서 정리해요)
        return "Lalala~"       # "Lalala~" 를 돌려주세요
taeji = Singer()               # taeji 에 Singer 인스턴스를 만들어 담아 주세요
ricky = Singer()               # ricky 에 Singer 인스턴스를 만들어 담아 주세요
print(taeji.sing())            # taeji 에게 노래를 시킨 결과를 화면에 보여 주세요
print(ricky.sing())            # ricky 에게 노래를 시킨 결과를 화면에 보여 주세요
print(type(taeji))             # taeji 의 자료형을 화면에 보여 주세요
print(isinstance(taeji, Singer))  # taeji 는 Singer 인스턴스인가요?
print(taeji is ricky)          # taeji 와 ricky 는 같은 객체인가요?
Lalala~
Lalala~
<class '__main__.Singer'>
True
False

※ 같은 클래스에서 만든 taeji와 ricky는 같은 메서드를 쓰지만 서로 다른 객체예요(is가 False). __main__은 이 코드를 파일로 직접 실행했다는 표시이고, 다른 파일에서 import하면 그 파일 이름으로 바뀌어요.

2. 왜 클래스를 쓰나 — 영상 요약

영상은 게임 플레이어를 예로 들어요. 플레이어를 하나씩 손으로 적으면 세 가지 문제가 생겨요.

문제왜 생기나
틀이 없어서 빠뜨림어떤 플레이어에는 skill 을 안 적고 넘어가도 아무도 알려 주지 않는다
오타helth처럼 속성 이름을 잘못 적어도 찾기 어렵다
고칠 곳이 많음경험치(xp)를 모든 플레이어에게 추가하려면 하나씩 찾아가 고쳐야 한다

해결은 “이름·체력·기술 값만 넣으면 플레이어 하나를 내주는 공장”을 한 곳에 만드는 거예요. 그 공장이 클래스예요. 영상은 클래스를 쿠키 틀, 인스턴스를 그 틀로 찍은 쿠키에 비유해요. 나중에 틀 한 곳만 고치면 이후에 찍는 쿠키가 모두 달라져요.

값을 받아서 만들기 — __init__

말뜻
__init__인스턴스를 만들 때 파이썬이 자동으로 한 번 불러 주는 특별한 메서드. 처음 속성 값을 정한다
self.이름 = 값이 인스턴스가 가질 속성(변수)을 저장한다
클래스(값1, 값2)값들이 __init__의 self 다음 매개변수로 들어간다
class Player:                                  # Player 클래스를 정의해 주세요
    def __init__(self, name, health, skill):   # 만들 때 자동으로 불리는 __init__ 을 정의해 주세요
        self.name = name                       # 이 인스턴스의 name 에 name 을 담아 주세요
        self.health = health                   # 이 인스턴스의 health 에 health 를 담아 주세요
        self.skill = skill                     # 이 인스턴스의 skill 에 skill 을 담아 주세요
        self.xp = 0                            # 이 인스턴스의 xp 에 0 을 담아 주세요
    def say_hello(self):                       # say_hello 메서드를 정의해 주세요
        return "안녕, 나는 " + self.name       # "안녕, 나는 " 과 이름을 이어서 돌려주세요
elon = Player("elon", 100, "coding")           # elon 에 Player 인스턴스를 만들어 담아 주세요
mark = Player("mark", 90, "design")            # mark 에 Player 인스턴스를 만들어 담아 주세요
print(elon.name, elon.xp)                      # elon 의 name 과 xp 를 화면에 보여 주세요
print(mark.say_hello())                        # mark 에게 인사를 시킨 결과를 화면에 보여 주세요
elon 0
안녕, 나는 mark

※ 영상의 자바스크립트 constructor가 파이썬의 __init__에 해당해요. 함수처럼 생겼지만 클래스 안에 있어서 메서드라고 불러요. xp 처럼 값을 받지 않고 항상 0으로 시작하게 정하는 것도 __init__ 안에서 해요.
