여러 개념이 겹치는 실전형 코드

while True, 중첩 if, elif 순서, 부동소수점, 튜플 언패킹이 한 코드 안에 섞여 나옵니다. 결과를 보고 "왜"를 끝까지 설명하는 것이 목표입니다.

상급 1읽기

비밀번호 3번의 기회

password = '1234'
tries = 0
success = False
while tries < 3:
    guess = input()
    if guess == password:
        success = True
        break
    tries += 1
if success:
    print('성공')
else:
    print('실패')
  • 입력이 순서대로 0000, 1111, 2222일 때 출력을 예측하기
  • 입력이 0000, 1234, 9999일 때(둘째 시도에 성공) 출력과, tries가 최종적으로 몇인지 예측하기

성공
시나리오guessguess == password ?동작
전부 실패0000거짓tries → 1

  • 정답을 맞히면 break가 즉시 반복을 끝내기 때문에 tries는 그 시점에서 멈추고, 남은 입력(9999)은 아예 받지 않음
  • 3번 다 틀리면 break 없이 tries == 3이 되어 while 조건 자체가 거짓이 되며 자연스럽게 끝남

        break

처음 보는 초기화 문법

2장에서 직접 배우지 않은 문법이 한 줄 섞여 있습니다. 남의 코드를 읽을 때 매일 겪는 상황을 연습합니다.

i, total = 0, 0
nums = [3, 6, 9]
while i < len(nums):
    total = total + nums[i]
    i = i + 1
print(i, total)
  • 실행하지 말고 출력을 예측하기
  • i, total = 0, 0이 무슨 뜻인지 추측하기
  • 2장 해설 Q17의 min, max = map(int, ...)과 이 문법이 왜 닮았는지 설명하기
해설 보기 
3 18
  • i, total = 0, 0은 오른쪽 0, 0이라는 값 2개를 왼쪽 이름 2개에 순서대로 나눠 담는 것 → i = 0, total = 0과 완전히 같은 뜻
  • 줄 두 개를 한 줄로 줄인 것뿐, 새로운 계산이 생기는 게 아님
  • 2장 해설 Q17의 min, max = map(int, input().split())도 "왼쪽 이름 여러 개 = 오른쪽 값 여러 개"라는 같은 언패킹 문법 — 다만 그쪽은 오른쪽 값을 input()에서 만들고, 여기는 그냥 숫자를 직접 나열했다는 점만 다름
  • total = total + nums[i]를 세 번(3, 6, 9) 거치며 total은 3 → 9 → 18로, i는 0 → 1 → 2 → 3으로 바뀌고 마지막에 3 18이 출력됨
