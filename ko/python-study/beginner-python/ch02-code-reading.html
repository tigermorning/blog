  • 그래서 실제로는 있지도 않은 0도가 최고 기온으로 출력됨 — 에러 없이 조용히 틀림

        max_temp = temps[i]
    i += 1
print(max_temp)
  • 시작값을 "있을 법한 아무 값(0)"이 아니라 temps[0](실제 데이터의 첫 값)으로 잡음 → i도 이미 비교한 0번을 건너뛰고 1부터 시작
