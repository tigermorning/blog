함수가 언제 실행되고 무엇을 돌려주나

정의와 호출, 매개변수에 값이 들어가는 순서, print와 return의 차이를 짧은 코드로 확인합니다.

  • def는 "hello라는 이름으로 이 줄을 저장해 둔다"만 함. 실행은 안 함
  • 실제 실행 순서: print('시작') → hello() 안으로 들어가 print('안녕') → 돌아와서 print('끝') → 또 hello()

return과 조건·반복이 섞일 때

return이 함수를 끝내는 시점, 조건에 없는 값이 들어왔을 때, 반복문 안의 함수 호출을 따라갑니다.

중급 1읽기

성적 등급

def grade(score):
    if score >= 90:
        return 'A'
    if score >= 80:
        return 'B'
    return 'C'
    print('여기는 실행될까?')

print(grade(95), grade(85), grade(80), grade(50))
  • 출력을 예측하기
  • '여기는 실행될까?'가 출력되는 경우가 있는지 말하기
  • elif를 안 썼는데도 95가 'B'가 되지 않는 이유 설명하기
해설 보기 
A B B C
  • return을 만나면 함수는 즉시 끝남
  • 95: 첫 if가 참 → 'A' 반환하고 끝. 두 번째 if는 검사조차 안 함
  • 80: >=라서 80도 포함 → 'B'
  • 50: 두 조건 모두 거짓 → 마지막 return 'C'
  • print('여기는 실행될까?')는 바로 위 return 'C' 때문에 절대 실행 안 됨 (죽은 코드)

실제 코드에서 · return 바로 아래 같은 들여쓰기에 코드가 있으면 거의 항상 실수. 지우거나 위로 옮겨야 함

def to_clock(total):
    minutes = total // 60
    seconds = total % 60
    return f'{minutes:2d}:{seconds:2d}'

print(to_clock(3599))
print(to_clock(3600))
print(to_clock(59))

  • 실제 타이머 화면으로 보면 어색한 줄을 모두 찾고 이유 말하기

  • 125 // 60 = 2, 125 % 60 = 5 (1장의 몫과 나머지)

def multi(m):
    for n in range(1, 4):
        print(f'{m} * {n} = {m*n:2d}')

for i in range(2, 4):
    multi(i)
    print('---')

  • 두 range를 3.1.2 구구단처럼 range(1, 10)과 range(2, 10)으로 바꾸면 출력이 몇 줄이 될지 계산하기

첫 번째 배수 찾기

def find_first(nums, k):
    for x in nums:
        if x % k == 0:
            return x
    return -1

print(find_first([5, 7, 9, 12], 3))
print(find_first([5, 7, 11], 3))
print(find_first([10, 20], 5))
print(find_first([], 5))

  • 첫 줄이 12가 아닌 이유 설명하기
