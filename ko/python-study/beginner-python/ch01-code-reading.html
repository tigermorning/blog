질문과 해설 - input · int · str · float

Q1. int(input())이 뭔지 모르겠어요

풀이 예시 두 줄이 하는 일은 네 단계.

  1. 사용자가 키보드로 친 내용을 받아 오기(결과는 글자) — input
  2. 받아 온 글자를 계산할 수 있는 숫자로 바꾸기 — int
  3. 60으로 나눠 몫(시간)과 나머지(분) 구하기 — //, %
  4. 결과를 화면에 보여 주기 — print

1단계 · input() — 사용자가 친 내용을 받아 오기

>>> answer = input()
135                  ← 키보드로 치고 Enter
>>> answer
'135'
  • 프로그램이 멈추고, 사용자가 치고 Enter를 누를 때까지 기다림
  • 3을 치는 건 사용자가 하는 일(입력하기), 친 내용을 프로그램 안으로 가져오는 건 input()이 하는 일(받아 오기)
  • input()이 없으면 키보드로 3을 쳐도 프로그램은 그 값을 쓸 수 없음
  • 결과는 135가 아니라 '135' → 무엇을 치든 항상 글자(문자열)
  • input('분을 입력하세요: ')처럼 괄호에 문구를 넣으면 기다리기 전에 먼저 보여 줌
  • 괄호를 비우면 아무것도 안 뜬 채 기다려서 멈춘 것처럼 보임

질문 · 3을 굳이 텍스트로 바꿨다가 다시 정수로 바꾸는 이유는? 파이썬이 3을 이해 못 하나?

  • 파이썬은 3을 잘 이해함
  • 텍스트로 바꾸는 단계는 없음 → 키보드로 들어오는 건 처음부터 텍스트, 우리가 하는 일은 텍스트를 정수로 바꾸는 한 번뿐
3이 들어온 곳파이썬이 받는 것종류
코드에 직접 num = 3숫자 3정수
실행 중 키보드로 3 입력글자 "3"텍스트
  • 코드에 쓴 3은 숫자로 알아봄 → num = 3에는 int() 불필요
  • 키보드는 글자를 치는 장치 → 3 키를 누르면 "3"이라는 글자, a 키를 누르면 "a"라는 글자가 들어옴
  • 실제 흐름: 키보드 "3"(처음부터 글자) → input()이 그대로 받아 옴 '3' → int()로 한 번 바꿈 3

그럼 input()이 알아서 숫자로 바꿔 주면 안 되나?

input()은 사용자가 무엇을 칠지 모름. 같은 input()으로 이런 값도 받음.

사용자가 친 것숫자로 바꾸면 안 되는 이유
홍길동이름이라 애초에 숫자가 아님
010전화번호 앞자리인데 정수로 바꾸면 10이 되어 0이 사라짐
3.5정수로 바꾸면 오류 → float가 필요 (Q3)
3개숫자와 글자가 섞여 있음
 
>>> int('010')
10
  • 그래서 input()은 받은 그대로(텍스트) 넘겨 주고, 어떻게 읽을지는 코드를 쓰는 사람이 정함
  • 정수로 쓸 거면 int(input())
  • 소수점 수로 쓸 거면 float(input())
  • 이름처럼 글자 그대로 쓸 거면 input()
  • 비유: 손님이 주문서에 "3"이라고 적어 냄 → 직원(input())은 3인분인지, 3번 테이블인지, 메뉴 3번인지 모르니 글자 그대로 가져옴 → 주방장(코드를 쓴 사람)이 "수량이니 숫자로 읽자"고 정함(int())

핵심 한 줄 · 텍스트로 바꾸는 단계는 없음. 키보드 입력은 원래 텍스트이고, 숫자로 쓸지는 우리가 int()로 정함

2단계 · 글자로는 왜 계산이 안 되나

>>> '135' // 60
TypeError: unsupported operand type(s) for //: 'str' and 'int'
  • 뜻: 글자(str)와 숫자(int)로는 // 계산 불가
  • 파이썬에게 '135'는 "1", "3", "5"라는 글자 세 개일 뿐
모양종류파이썬 이름

3단계 · int() — 글자를 정수로 바꾸기

>>> int('135')

>>> int('135') // 60
2
>>> int('abc')          # 숫자로 바꿀 수 없는 글자

  • int = integer(정수)의 줄임말
  • 괄호 안의 값을 정수로 바꿔 돌려줌 → 따옴표가 사라져 계산 가능

4단계 · int(input()) — 괄호는 안쪽부터

  1. input() → 사용자가 135를 치면 '135'
  2. int('135') → 135
  3. total = 135 → total이라는 이름표에 담기
text = input()      # '135' (글자)
total = int(text)   # 135   (숫자) — 위 한 줄과 같은 뜻

5단계 · //와 % — 시간과 분 구하기

>>> 135 // 60     # 몫 = 60이 몇 번 들어가나
2
>>> 135 % 60      # 나머지 = 60씩 빼고 남은 것
15
  • "135분은 몇 시간 몇 분?" = "60분 묶음이 몇 개이고 몇 분이 남나?"
  • 확인: 60 × 2 + 15 = 135

6단계 · print() — 쉼표로 여러 개 출력

  • 쉼표로 나눈 값이 차례로 나오고, 사이에 공백이 하나씩 들어감
  • total // 60 → 2, '시간' → 시간, total % 60 → 15, '분' → 분
  • 따옴표 있는 '시간'은 글자 그대로, 따옴표 없는 total // 60은 계산 결과

Q2. input은 텍스트로, int는 숫자로 바꾸는 명령인가요?

  • int() — 맞음. 괄호 안의 값을 정수로 바꾸는 명령
  • input() — 조금 다름. 원래 일은 키보드 입력을 받아 오는 것이고, 결과가 늘 텍스트일 뿐
  • input()은 이미 있는 값을 텍스트로 바꿔 주지 못함
  • 비유: input()은 손님 주문을 종이에 받아 적는 직원(종이라 늘 글자), int()는 그 글자를 계산기에 숫자로 옮겨 치는 직원

텍스트로 바꾸는 명령은 따로 있음 → str (string, 문자열)

>>> str(135)
'135'
명령하는 일예
input()키보드 입력 받기 (결과는 텍스트)135 입력 → '135'
int()정수로 바꾸기int('135') → 135
str()텍스트로 바꾸기str(135) → '135'
float()소수점 있는 수로 바꾸기 (Q3)float('3.7') → 3.7

int()는 정수 전용이라 소수점을 다루지 못함

>>> int(3.7)       # 소수점 숫자는 소수점 아래를 버림
3
>>> int('3.7')     # 소수점이 있는 글자는 바꾸지 못함
ValueError: invalid literal for int() with base 10: '3.7'

Q3. float는 뭔가요?

  • float = 소수점이 있는 숫자의 자료 종류 이름
  • floating point(떠다니는 소수점)의 줄임말 → "float = 소수점 있는 수"로 기억하면 충분
  • 3과 3.0은 값은 같지만 종류가 다름 (int / float)
종류파이썬 이름예
정수 (소수점 없음)int3, 135, -7
실수 (소수점 있음)float3.7, 0.5, 3.0
 
>>> type(3)          # type()은 값의 종류를 알려 줌
<class 'int'>
>>> type(3.0)
<class 'float'>
>>> float('3.7')     # 글자를 실수로
3.7
>>> float(3)         # 정수를 실수로
3.0
>>> float('abc')
ValueError: could not convert string to float: 'abc'

괄호를 빼면 안 됨

>>> float 3
SyntaxError: invalid syntax
>>> float
<class 'float'>
  • float 3처럼 띄어 쓰면 파이썬이 명령으로 읽지 못해 에러
  • float만 치면 에러는 없지만 이름만 보여 주고 아무것도 안 바꿈
  • float, int, str은 항상 float(3)처럼 괄호 안에 값을 넣기
  • 괄호 없이 쓰는 건 del, import 같은 키워드뿐

이미 만난 float

  • / 나눗셈은 나누어떨어져도 항상 float → 6 / 2가 3.0인 이유 (기본 1)
  • 정수와 실수를 섞어 계산해도 float → 3 + 0.5는 3.5, 2 * 1.0은 2.0
  • 소수점까지 입력받으려면 float(input())

처음 보는 문법 읽어 내기

1장에서 배우지 않은 문법이 섞인 코드입니다. 남의 코드를 읽을 때 매일 겪는 상황을 연습합니다.

minutes, seconds = divmod(3725, 60)
hours, minutes = divmod(minutes, 60)
print(hours, minutes, seconds)
  • 실행하지 말고 출력을 예측하기
  • a, b = ... 문법이 무슨 뜻인지 추측하기
  • 추측의 근거를 divmod(3725, 60)의 결과 모양으로 설명하기
  • 중급 7에서 내가 짠 코드와 비교해 어느 쪽이 읽기 쉬운지 이야기하기
해설 보기 
1 2 5

  • 왼쪽 이름표도 2개 → 순서대로 하나씩 붙음: minutes = 62, seconds = 5
  • 둘째 줄: divmod(62, 60) → (1, 2) → hours = 1, minutes = 2
  • 이 문법은 "언패킹(unpacking)"이라고 부름 → 4장 튜플에서 배움
  • h[0], m[1]보다 hours, seconds가 무엇인지 바로 보임
