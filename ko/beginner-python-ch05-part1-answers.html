2026. 10. 21.

※ 이 글은 위키독스 『왕초보를 위한 Python』 5.2.1 ~ 5.2.4절의 연습 문제를 제 나름의 언어로 풀어 설명한 것입니다. 문제 원문은 각 절의 링크에서 먼저 읽어 보세요. 코드는 이 글에서 새로 작성한 풀이이고, 실행 결과는 파이썬 3.12.10으로 실제로 돌려서 넣었어요.

모듈 가져오기 연습 문제는 "dir()와 help()로 모듈 안을 뒤져 알맞은 함수를 찾아 쓰기"를 익히는 문제예요.

5.2 모듈 가져오기 연습 문제

5.2.1 모듈 사용법 알아내기

문제: calendar 모듈을 가져오고, dir()와 help()로 윤년을 판별하는 함수를 찾아 2077년이 윤년인지 확인해요. 원문 보기

파이썬 셸이나 .py 파일에서 실행

import calendar                                   # calendar 모듈을 가져와 주세요
print([x for x in dir(calendar) if 'leap' in x])  # calendar 안의 이름 중 이름에 'leap' 이 든 것만 모아 화면에 보여 주세요
help(calendar.isleap)                             # calendar.isleap 의 사용법을 보여 주세요
print(calendar.isleap(2077))                      # 2077 은 윤년이에요? 를 화면에 보여 주세요
['isleap', 'leapdays']
Help on function isleap in module calendar:

isleap(year)
    Return True for leap years, False for non-leap years.

False

빈칸 네 개의 답은 import, ['isleap', 'leapdays'], calendar.isleap, calendar.isleap(2077)이에요. 모듈 안에 무엇이 있는지는 dir(모듈)이 이름 목록으로 알려 주고, [x for x in dir(calendar) if 'leap' in x]는 그 목록에서 이름에 leap이 든 것만 거르는 리스트 컴프리헨션이에요. 찾은 함수의 사용법은 help()로 읽어요. isleap(year)는 연도를 넣으면 윤년일 때 True를 돌려주는 함수예요. 2077은 4로 나누어떨어지지 않아 False가 나와요. dir 결과에 __name__처럼 밑줄로 시작하는 이름이 많은데, 모듈이 내부에서 쓰는 이름이라 처음에는 밑줄 없는 이름만 보면 돼요.

5.2.2 직각삼각형의 빗변 길이 구하기

문제: 직각을 낀 두 변 a, b로 빗변 c = √(a² + b²)를 구해요. 먼저 3, 4일 때를 셸에서 구하고, 이어서 함수 hypotenuse()를 만들어요. 원문 보기

문제 1 — 파이썬 셸에서 실행

import math                        # math 모듈을 가져와 주세요
print(math.sqrt(3 ** 2 + 4 ** 2))  # 3 의 제곱과 4 의 제곱을 더한 값의 제곱근을 화면에 보여 주세요
5.0

문제 2 — .py 파일에서 실행

import math                                      # math 모듈을 가져와 주세요

def hypotenuse(a, b):                            # a 와 b 를 받는 hypotenuse 라는 동작을 만들어 주세요
    return round(math.sqrt(a ** 2 + b ** 2), 2)  # a 의 제곱과 b 의 제곱을 더한 값의 제곱근을 소수 둘째 자리까지 반올림해 결과로 돌려주세요

print(hypotenuse(3, 4))                          # hypotenuse(3, 4) 를 화면에 보여 주세요
print(hypotenuse(10, 20))                        # hypotenuse(10, 20) 을 화면에 보여 주세요
5.0
22.36

제곱은 **, 제곱근은 math.sqrt, 셋째 자리에서 반올림은 round(값, 2)예요. round는 모듈을 가져오지 않아도 쓰는 내장 함수예요. hypotenuse(10, 20)은 √500 = 22.3606…이라 셋째 자리에서 반올림해 22.36이 돼요. return은 값을 돌려줄 뿐 화면에 보이지는 않아서, 보려면 print가 따로 필요해요.

보충 1더 짧은 길 — math.hypot

같은 계산을 한 번에 해 주는 math.hypot(a, b)가 이미 들어 있어요. 직접 만들기 전에 dir(math)로 먼저 찾아보는 습관이 5.2.1의 목적이에요.

입력: 10 20

import math                        # math 모듈을 가져와 주세요
a, b = map(int, input().split())   # 입력한 한 줄을 공백으로 잘라 각각 정수로 바꿔 a 와 b 에 담아 주세요
print(round(math.hypot(a, b), 2))  # a 와 b 로 구한 빗변 길이를 소수 둘째 자리까지 반올림해 화면에 보여 주세요
10 20
22.36

문제 2 — .py 파일에서 실행 (두 줄이 적힌 글상자 창이 떠요)

import tkinter as tk                   # tkinter 를 tk 라는 이름으로 가져와 주세요

s = "Life is short\nUse Python"        # s 에 두 줄짜리 글자를 담아 주세요

root = tk.Tk()                         # root 에 바탕 창을 담아 주세요
t = tk.Text(root, height=2, width=13)  # t 에 높이 2, 너비 13 인 글상자를 담아 주세요
t.insert(tk.END, s)                    # 글상자 t 의 맨 끝에 s 를 넣어 주세요
t.pack()                               # 글상자 t 를 창에 놓아 주세요
tk.mainloop()                          # 창을 띄워 두고 기다려 주세요

실행하면 창이 떠서 이 글에서는 창 대신 글상자 안의 글자를 읽어 확인했어요. 위 코드의 tk.mainloop() 자리에 t.get('1.0', 'end-1c')를 출력하는 코드를 넣고, 창은 띄우지 않았어요.

5.2.4 놀이 공원 (2)

문제: 놀이 공원 (1)에서 만든 해석 함수를 모듈로 가져와, 키를 입력하면 탈 수 있는 놀이 기구를 출력해요. 원문 보기

빈칸의 import ...에 들어갈 이름은 놀이 공원 (1)을 어떤 파일 이름으로 저장했느냐에 따라 달라서, 여기서는 해석 함수를 ch04/ride_parser.py에 저장했다고 가정했어요. 파일은 둘이에요.

ch04/ride_parser.py — 놀이 공원 (1)에서 만든 함수를 저장

def read(text):                                          # text 를 받는 read 라는 동작을 만들어 주세요
    ridename, limit = text.split(':')                    # text 를 콜론으로 잘라 ridename 과 limit 에 나눠 담아 주세요
    ridename = ridename.strip()                          # ridename 양쪽의 공백을 지워 다시 담아 주세요
    limit = limit.strip()                                # limit 양쪽의 공백을 지워 다시 담아 주세요
    cmmin = None                                         # cmmin 에 '없음' 을 담아 주세요
    cmmax = None                                         # cmmax 에 '없음' 을 담아 주세요
    if '~' in limit:                                     # 만약 limit 안에 '~' 가 있으면
        low, high = limit.split('~')                     # limit 를 '~' 로 잘라 low 와 high 에 나눠 담아 주세요
        cmmin = int(low.replace('cm', ''))               # low 에서 'cm' 를 지우고 정수로 바꿔 cmmin 에 담아 주세요
        cmmax = int(high.replace('cm', ''))              # high 에서 'cm' 를 지우고 정수로 바꿔 cmmax 에 담아 주세요
    elif '이상' in limit:                                # 아니고 limit 안에 '이상' 이 있으면
        cmmin = int(limit.split()[0].replace('cm', ''))  # limit 의 첫 낱말에서 'cm' 를 지우고 정수로 바꿔 cmmin 에 담아 주세요
    return ridename, cmmin, cmmax                        # ridename, cmmin, cmmax 를 결과로 돌려주세요

ch05/park.py — 저장해 두기

import sys                                           # sys 모듈을 가져와 주세요

sys.path.append("../ch04")                           # 모듈 찾는 길 목록에 "../ch04" 를 더해 주세요
import ride_parser                                   # ride_parser 모듈을 가져와 주세요

rides = [                                            # rides 에 놀이 기구 글자들을 담은 리스트를 담아 주세요
    '와일드 윙: 110cm 이상',
    '드림보트: 120cm 이상',
    '자이안트 루프: 120cm 이상',
    '툼 오브 호러: -',
    '플라이벤처: 140cm~195cm',
    '회전목마: 100cm 이상',
    '매직 붕붕카: 110cm~140cm',
]


def allowedrides(height):                            # height 를 받는 allowedrides 라는 동작을 만들어 주세요
    assert type(height) == int                       # height 가 정수가 맞는지 확인하고 아니면 멈춰 주세요

    result = []                                      # result 에 빈 리스트를 담아 주세요
    for text in rides:                               # rides 의 원소를 하나씩 text 라고 부르며 아래를 반복해 주세요
        name, cmmin, cmmax = ride_parser.read(text)  # text 를 풀어 헤친 결과를 name, cmmin, cmmax 에 나눠 담아 주세요
        if cmmin is not None and height < cmmin:     # 만약 cmmin 이 있고 height 가 cmmin 보다 작으면
            continue                                 # 이번 차례는 넘어가 주세요
        if cmmax is not None and height > cmmax:     # 만약 cmmax 가 있고 height 가 cmmax 보다 크면
            continue                                 # 이번 차례는 넘어가 주세요
        result.append(name)                          # result 뒤에 name 을 붙여 주세요
    return result                                    # result 를 결과로 돌려주세요


if __name__ == "__main__":                           # 만약 이 파일을 직접 실행했다면
    height = int(input())                            # 입력한 한 줄을 정수로 바꿔 height 에 담아 주세요
    for name in allowedrides(height):                # allowedrides(height) 의 원소를 하나씩 name 이라고 부르며 아래를 반복해 주세요
        print(name)                                  # name 을 화면에 보여 주세요

sys.path는 파이썬이 모듈을 찾는 폴더 목록이고, sys.path.append("../ch04")가 ch04 폴더를 그 목록에 더해서 다음 줄의 import ride_parser가 ch04/ride_parser.py를 찾아요. 내가 만든 .py 파일도 같은 방식으로 가져와요. 이때 ../ch04는 파일이 있는 폴더가 아니라 프로그램을 실행하는 위치를 기준으로 해서, ch05 폴더에서 실행해야 해요. 한 기구의 이름과 제한은 ride_parser.read()가 (이름, 하한, 상한) 튜플로 돌려주고, 제한이 없으면 None이라 is not None으로 확인해요. 키가 하한보다 작거나 상한보다 크면 continue로 그 기구를 건너뛰고, 두 검사를 통과한 기구만 result에 모아요. assert는 키가 정수가 아니면 바로 멈추는 검사예요.

보충 1입력 코드를 if __name__ == "__main__": 안에 두는 이유

모듈은 가져오는 순간 위에서부터 실행돼요. input()이 맨 위에 있으면 import park만 해도 입력을 기다리겠죠. __name__은 파일을 직접 실행하면 '__main__'이고 다른 파일이 가져오면 모듈 이름이라서, 이 if 안의 코드는 직접 실행할 때만 돌아요. 그래서 한 파일을 프로그램으로도, 모듈로도 쓸 수 있어요.
