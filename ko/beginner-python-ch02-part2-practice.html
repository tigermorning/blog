1장 리스트·변수와 2장 후반부 and/or·for·for-else가 섞인 완성된 코드 3개를 보고, 코드를 짜지 않고 실행 결과만 예측해보는 읽기 문제예요.

핵심 정리

개념한 줄 정리
A and B둘 다 참이어야 참이고, 왼쪽이 거짓이면 오른쪽은 보지 않는다.
x in 리스트리스트 안에 x가 있으면 참이다.
for x in 리스트:원소를 하나씩 꺼내 x에 담고 몸통을 되풀이한다.
range(len(cart))인덱스 0부터 개수-1까지 만든다(개수는 빠짐).
for-elseelse는 break 없이 끝까지 돌았을 때만 실행된다.

문제 1 — 정회원 확인

카페 정회원 명단과 적립 포인트를 보고 VIP 여부를 판정하는 코드예요.

members = ['서준', '하은', '도윤']
name = input()
points = int(input())

if name in members and points >= 1000:
    print('VIP 회원입니다')
else:
    print('VIP 회원이 아닙니다')

다음 네 가지 입력에서 각각 무엇이 출력될지 예측해보세요.

namepoints출력?

수아1200?

문제 2 — 장바구니 총액, 이번엔 for로

while이 아니라 for + range(len())로 리스트 합계를 구하는 코드예요.

cart = [12000, 8500, 3000]
total = 0
for i in range(len(cart)):
    total += cart[i]
print('총액:', total)

이 코드를 실행하면 무엇이 출력될까요? i가 어떤 값들로 바뀌는지, 그때마다 cart[i]가 뭔지도 함께 짚어보세요.

힌트 보기

range(len(cart))는 cart의 인덱스인 0, 1, 2를 순서대로 만들어요. i가 0 → 1 → 2로 바뀌면서 cart[i]도 cart[0] → cart[1] → cart[2]로 바뀐다는 뜻이에요.

문제 3 — 명단에서 이름 찾기, 이번엔 for-else로

while + found 변수 대신 for-else로 이름을 찾는 코드예요.

members = ['지민', '서준', '하은']
name = input()
for m in members:
    if m == name:
        print('있음')
        break
else:
    print('없음')

name = '하은'일 때와 name = '수아'일 때, 각각 무엇이 출력될까요?

힌트 보기

for로 명단을 하나씩 확인하다 일치하면 break로 즉시 멈춰요. else는 if가 아니라 for에 딸린 것이라서, break를 한 번도 안 타고 끝까지 돌았을 때만 실행돼요.

추가 질문 (버그 찾기): 아래는 위 코드에서 break 한 줄만 뺀 거예요. name = '하은'일 때 결과가 위 코드와 어떻게 달라질까요? 실행하지 말고 먼저 예측해보세요.

for m in members:
    if m == name:
        print('있음')
        # break 없음
else:
    print('없음')
힌트 보기

break가 없으면 '있음'을 찍은 뒤에도 for는 멈추지 않고 남은 원소를 마저 확인해요. 그리고 break를 한 번도 안 탔으니 반복이 끝난 뒤 else도 실행돼요.
