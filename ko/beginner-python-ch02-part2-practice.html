1장에서 배운 리스트·변수와 2장 후반부에서 배운 and/or·for·for-else를 한 문제씩 섞어서 풀어보는 실습 3문제예요.

이런 게 궁금했다면
  • and/or를 배웠는데, 실제로 어떤 문제에 쓰는 건지 감이 잘 안 와요.
  • while로 짜던 걸 for로 다시 짜면 뭐가 달라지는지 직접 해보고 싶어요.
  • for-else를 배웠는데 while+flag 변수랑 뭐가 더 나은지 손으로 비교해 보고 싶어요.
읽고 나면 할 수 있는 것
  • 리스트 소속 확인(in)과 and를 엮어서 "둘 다 만족해야" 조건을 짤 수 있어요.
  • while로 짜던 누적 계산을 for + range(len())로 옮겨 쓸 수 있어요.
  • 플래그 변수 없이 for-else로 "찾았는지 아닌지" 판정을 짤 수 있어요.
모르면 이런 일이 생겨요
  • and/or, for-else를 눈으로만 읽고 넘어가면, 막상 코드를 짤 때 어디에 써야 할지 안 떠올라요.
  • while 방식만 계속 쓰면, 다른 사람이 짠 for/for-else 코드를 만났을 때 낯설어서 읽는 데 오래 걸려요.
어디에 쓰나
  • AI에게 코드를 맡기기 전에, 내가 먼저 짜 보고 싶을 때. 세 문제 모두 AI 없이 직접 짜 볼 수 있는 분량이에요.
  • 같은 문제를 while로도, for로도 짤 수 있다는 걸 손으로 확인하고 싶을 때.

세 문제 모두 지난 글에서 정리한 문법만으로 풀 수 있어요. 1번은 지난 글의 "정문 출입" 비유, 3번은 "우편함" 비유를 그대로 코드로 옮긴 문제예요. 직접 짜 본 뒤에 문제 해설과 맞춰 보세요.

문제 1 — 정회원 확인

카페 정회원 명단과 적립 포인트가 있어요. 명단에 있고(and) 포인트가 1000 이상이어야 VIP 회원으로 인정해요.

  • 정회원 명단: members = ['서준', '하은', '도윤']
  • 이름과 포인트를 각각 input()으로 한 줄씩 입력받기 (포인트는 int()로 변환)
  • 조건을 만족하면 VIP 회원입니다, 아니면 VIP 회원이 아닙니다 출력하기
  • 조건: and와 in을 한 문장에 같이 쓰기
입력: 하은
      1200
출력: VIP 회원입니다

입력: 수아
      1200
출력: VIP 회원이 아닙니다
힌트 보기

if 이름 in 리스트 and 포인트 >= 1000: 처럼 in으로 만든 참/거짓값과 >=로 만든 참/거짓값을 and로 바로 이어 쓸 수 있어요. 괄호는 없어도 돼요.

문제 2 — 장바구니 총액, 이번엔 for로

while로 리스트 합계를 구하던 걸, 이번엔 for + range(len())로 다시 짜 보세요.

  • 장바구니: cart = [12000, 8500, 3000]
  • for i in range(len(cart)): 로 인덱스 i를 순서대로 돌면서 cart[i]를 누적 더하기
  • 조건: while이 아니라 for와 range()를 쓰기
출력: 총액: 23500
힌트 보기

range(len(cart))는 cart의 인덱스인 0, 1, 2를 순서대로 만들어 줘요. total = 0을 미리 만들어 두고, 반복마다 total += cart[i]로 더하세요.

문제 3 — 명단에서 이름 찾기, 이번엔 for-else로

while + found 변수로 짜던 이름 찾기를, 이번엔 for-else로 다시 짜서 플래그 변수 없이 풀어보세요.

  • 명단: members = ['지민', '서준', '하은']
  • 이름을 input()으로 입력받기
  • 명단에 있으면 있음, 끝까지 없으면 없음 출력하기
  • 조건: found 같은 참/거짓 변수를 만들지 않고, for ... else와 break만으로 풀기
입력: 하은
출력: 있음

입력: 수아
출력: 없음
힌트 보기

for로 명단을 돌다가 이름이 일치하면 그 자리에서 있음을 출력하고 break 하세요. for에 딸린 else: 블록에는 없음 출력을 넣으면, break로 멈추지 않고 끝까지 돈 경우에만 그 줄이 실행돼요.
