1. and / or — 조건 두 개를 한 문장으로

and와 or는 참(True)/거짓(False)값 두 개를 하나로 합치는 연산자예요. if 문 조건 자리뿐 아니라 그냥 값으로도 쓸 수 있어요.

일상 비유 — 회사 정문 출입 심사

회사 정문에 안내 데스크가 있다고 해볼게요. 정직원은 "사원증이 있고(and) 얼굴도 사진과 맞으면" 통과, 방문객은 "사원증이 있거나(or) 방문 예약이 되어 있으면" 통과예요.

비유 속 요소원래 개념
사원증이 있다조건 A가 참
방문 예약이 있다조건 B가 참
둘 다 있어야 통과A and B
하나만 있어도 통과A or B
안내 데스크가 사원증부터 확인하고, 이미 통과가 정해지면 방문 예약은 아예 확인 안 함and/or는 왼쪽 항부터 평가하고, 결과가 이미 정해지면 오른쪽 항은 평가하지 않음(단락 평가1)

핵심 한 줄: and는 "둘 다 참이어야" 참이고, or는 "하나라도 참이면" 참이며, 파이썬은 왼쪽부터 확인하다 답이 이미 정해지면 오른쪽은 아예 보지 않는다.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> s = 'banana'
>>> if 'a' in s and 'b' in s:
...     print('a도 있고 b도 있어요')
...
a도 있고 b도 있어요
>>> a, b = 3, 0
>>> (a * b) > 0 and (a / b) > 0   # 왼쪽이 False라서 오른쪽 나눗셈은 계산 안 함
False

마지막 줄이 핵심이에요. a * b는 0이라 (a * b) > 0은 이미 거짓이고, and는 왼쪽이 거짓이면 결과가 거짓으로 확정되니 오른쪽의 a / b(0으로 나누기라서 원래 에러가 나는 계산)는 아예 실행하지 않아요.

2. for 문 — 리스트를 한 번에 하나씩

for 변수 in 리스트:는 리스트의 원소를 앞에서부터 하나씩 꺼내 변수에 담고, 몸통을 그만큼 반복해요. while처럼 "몇 번 돌지"를 직접 세지 않아도 리스트 길이만큼 자동으로 돌아요.

실행: 파이썬 대화형 셸

>>> family = ['mother', 'father', 'sister']
>>> for x in family:
...     print(x, len(x))
...
mother 6
father 6
sister 6

3. range() — 숫자를 필요할 때 하나씩

range(2, 7)은 2 이상 7 미만인 정수를 순서대로 만들어 줘요. for 문에 직접 쓸 수 있어서, 리스트 없이도 "1부터 5까지" 같은 반복에 자주 써요.

>>> list(range(2, 7))
[2, 3, 4, 5, 6]
>>> for i in range(4, 8):
...     print(i)
...
4
5
6
7

파이썬 3의 range()는 [2, 3, 4, 5, 6] 같은 리스트를 미리 만들어 두는 게 아니라, 시작값·끝값·간격만 기억해 뒀다가 필요할 때마다 숫자를 하나씩 계산해요. 이런 방식을 지연 평가2라고 불러요 — range(100만)을 만들어도 메모리에 100만 개짜리 리스트가 생기지 않는다는 뜻이에요. 진짜 리스트가 필요하면 list(range(...))로 바꾸면 돼요.

4. for-else / while-else — "끝까지 다 돌았다"는 신호

for와 while 뒤에도 else를 붙일 수 있어요. 이 else는 반복문이 break 없이 끝까지 다 돌았을 때만 실행돼요. break로 중간에 빠져나오면 else는 건너뛰어요.

일상 비유 — 우편함에서 소포 찾기

여러 칸짜리 우편함에서 내 소포를 찾는다고 해볼게요. 왼쪽 칸부터 순서대로 하나씩 열어보다가, 소포를 찾으면 그 자리에서 멈추고 더 이상 안 열어봐요. 끝 칸까지 다 열어봤는데도 못 찾았을 때만, 마지막에 "찾으시는 소포가 없습니다" 안내방송이 나와요.

비유 속 요소원래 개념
칸을 순서대로 하나씩 열어본다for 변수 in 리스트: 로 리스트 원소를 하나씩 꺼냄
소포를 찾으면 더 안 열어보고 멈춤break
끝까지 다 열어봤지만 못 찾음break 없이 반복문이 끝까지 돎
다 연 뒤에만 나오는 안내방송else 블록 — break로 중간에 멈추면 이 안내는 안 나옴

핵심 한 줄: else는 "끝까지 다 돌았다"는 신호일 때만 실행되고, break로 중간에 멈추면 실행되지 않는다.

같은 "우편함에서 소포 찾기"를 코드로 옮긴다면 이렇게 갈려요.

나쁜 선택좋은 선택
found = False 플래그 변수를 만들고, 찾으면 found = True로 바꾼 뒤 반복이 끝나고 나서 if found:로 따로 검사 → found = True로 바꾸는 줄을 깜빡하면 찾았는데도 "없음"이 나오는 조용한 버그가 생김 for ... else:를 씀 → break를 못 타고 끝까지 돈 경우를 파이썬이 알아서 판단해 줘서, 플래그 변수 자체가 필요 없음

읽는 법: 가운데 박스(몸통 반복)에서 두 갈래로 갈립니다. 왼쪽 화살표(break 없이 끝까지)를 타면 else가 실행되고, 오른쪽 화살표(break로 중간 종료)를 타면 else를 건너뛰고 바로 끝나요.

이럴 때 의심하세요 — for-else가 생각한 대로 안 돌 때

else가 이미 for/while 몸통과 같은 들여쓰기인 줄 알고 무심코 빼먹거나, break 유무를 안 따지고 "반복 끝나면 무조건 실행"이라고 착각하면 결과가 조용히 틀려요.

이런 증상이 보이면먼저 열어 볼 자리확인 방법
분명 리스트에 있는 값을 찾았는데도 else의 "없습니다" 메시지가 같이 나와요 for-else 블록의 들여쓰기와 break 위치 else:가 for/if가 아니라 for와 같은 들여쓰기에 있는지, 찾았을 때 break를 실제로 실행하는지 확인해요 (위 4번 비교표)
