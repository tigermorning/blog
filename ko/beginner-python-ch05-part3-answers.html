문제 해설 — 두음법칙 끝말 잇기·datetime으로 내일 날짜 구하기 (2)

2026. 10. 26.

※ 이 글은 위키독스 『왕초보를 위한 Python』 5.3.5·5.3.7 연습 문제와 5.3.9 본문 예제를 제 나름의 언어로 풀어 설명한 것입니다. 문제 원문은 각 절의 링크에서 먼저 읽어 보세요. 코드는 이 글에서 새로 작성한 풀이이고, 실행 결과는 파이썬 3.14.7로 실제로 돌려서 넣었어요.

예전에 손으로 만들던 날짜 계산은 datetime 이 대신해 주고, 두음법칙은 한글 글자를 쪼개서 풀어요.

5.3 여러 가지 모듈 연습 문제 (이어서)

5.3.5 끝말 잇기 (2)

문제: 끝말 잇기 (1)과 같은 규칙에 두음법칙을 더해요. 앞 글자가 량으로 끝나면 양으로 시작하는 말도 이을 수 있어요. 원문 보기 (앞 문제는 4.5.3 끝말 잇기 (1) 해설에 있어요.)

두음법칙은 한 글자를 초성·모음·받침으로 쪼개서 다룰 수 있어야 해요. 한글 글자는 유니코드에서 가(0xAC00)부터 "초성 19 × 모음 21 × 받침 28"가지가 순서대로 놓여 있어서, 글자 번호에서 0xAC00을 뺀 값을 588과 28로 나눠 꺼낼 수 있어요. 규칙은 두 가지예요.

첫소리다음 모음바뀜예
ㄹㅑ ㅒ ㅕ ㅖ ㅛ ㅠ ㅣㅇ량→양, 려→여, 료→요, 류→유, 리→이
ㄹ그 밖의 모음(ㅏ ㅐ ㅗ ㅜ ㅡ …)ㄴ라→나, 래→내, 로→노, 루→누, 르→느
ㄴㅑ ㅒ ㅕ ㅖ ㅛ ㅠ ㅣㅇ녀→여, 뇨→요, 뉴→유, 니→이

먼저 함수 하나만 따로 — .py 파일에서 실행

YO = (2, 3, 6, 7, 12, 17, 20)  # YO 에 ㅑ ㅒ ㅕ ㅖ ㅛ ㅠ ㅣ 의 모음 번호를 담아 주세요

def starts(ch):                                               # ch 를 받는 starts 라는 동작을 만들어 주세요
    result = {ch}                                             # result 에 ch 자신이 든 세트를 담아 주세요
    code = ord(ch) - 0xAC00                                   # code 에 ch 의 글자 번호에서 '가' 의 번호를 뺀 값을 담아 주세요
    if not 0 <= code < 11172:                                 # 만약 code 가 한글 글자 범위 밖이면
        return result                                         # result 를 결과로 돌려주세요
    first = code // 588                                       # first 에 초성 번호를 담아 주세요
    vowel = code % 588 // 28                                  # vowel 에 모음 번호를 담아 주세요
    tail = code % 28                                          # tail 에 받침 번호를 담아 주세요
    if first == 5:                                            # 만약 초성이 ㄹ 이면
        new = 11 if vowel in YO else 2                        # new 에 (모음이 YO 에 있으면 ㅇ, 아니면 ㄴ) 의 초성 번호를 담아 주세요
    elif first == 2 and vowel in YO:                          # 아니고 만약 초성이 ㄴ 이고 모음이 YO 에 있으면
        new = 11                                              # new 에 ㅇ 의 초성 번호를 담아 주세요
    else:                                                     # 그 밖에는
        return result                                         # result 를 결과로 돌려주세요
    result.add(chr(0xAC00 + (new * 21 + vowel) * 28 + tail))  # result 에 초성만 new 로 바꾼 글자를 더해 주세요
    return result                                             # result 를 결과로 돌려주세요

for ch in '량녀라례리류차':        # 글자들을 하나씩 ch 라고 부르며 아래를 반복해 주세요
    print(ch, sorted(starts(ch)))  # ch 와 ch 로 이을 수 있는 첫 글자들을 정렬해 화면에 보여 주세요

녀 ['녀', '여']

초성 번호 5는 ㄹ, 2는 ㄴ, 11은 ㅇ이고, 모음 번호 2·3·6·7·12·17·20이 ㅑ·ㅒ·ㅕ·ㅖ·ㅛ·ㅠ·ㅣ예요. 차처럼 바뀔 일이 없는 글자는 자기 자신만 나와요. 세트는 순서가 없어서 sorted()로 정렬해 보였어요.

    if word[:1] not in starts(last[-1]):                        # 만약 word 의 첫 글자가 last 의 마지막 글자로 이을 수 있는 글자에 없으면
        print('글자가 안 이어져. 내가 이겼다!')                 # '글자가 안 이어져. 내가 이겼다!' 를 화면에 보여 주세요

        print('아까 했던 말이야. 내가 이겼어!')                 # '아까 했던 말이야. 내가 이겼어!' 를 화면에 보여 주세요
        break                                                   # 반복을 끝내 주세요
    used.add(word)                                              # used 에 word 를 더해 주세요
    ok = starts(word[-1])                                       # ok 에 word 의 마지막 글자로 이을 수 있는 첫 글자들을 담아 주세요
    candidates = sorted(w for w in WORDS - used if w[0] in ok)  # candidates 에 아직 안 쓴 단어 중 첫 글자가 ok 에 있는 것을 정렬해 담아 주세요

    used.add(last)                                              # used 에 last 를 더해 주세요
    print(last)                                                 # last 를 화면에 보여 주세요

5.3.7 내일의 날짜 구하기 (2)

문제: 내일의 날짜 구하기 (1)을 datetime 모듈로 다시 풀어요. 힌트로 strftime(), strptime(), timedelta가 주어져요. 원문 보기 (앞 문제는 4.3.2 해설이에요.)

입력: 2018 10 2

from datetime import datetime, timedelta  # datetime 모듈에서 datetime 과 timedelta 를 가져와 주세요

date = datetime.strptime(input(), '%Y %m %d')  # 입력한 한 줄을 '연 월 일' 모양으로 읽어 날짜로 만들어 date 에 담아 주세요
print(date.strftime('%m/%d/%Y'))               # date 를 '월/일/연' 글자로 바꿔 화면에 보여 주세요
tomorrow = date + timedelta(days=1)            # tomorrow 에 date 의 하루 뒤를 담아 주세요
print(tomorrow.strftime('%m/%d/%Y'))           # tomorrow 를 '월/일/연' 글자로 바꿔 화면에 보여 주세요

(1)에서 직접 만들던 DAYS 튜플과 next_day() 함수가 모두 사라지고 네 줄이 됐어요. strptime(글자, '%Y %m %d')가 "연 월 일" 입력을 날짜로 읽고, timedelta(days=1)을 더하면 달이 바뀌는 것도 알아서 처리되고, strftime('%m/%d/%Y')가 mm/dd/yyyy 모양으로 찍어요. 달·일이 한 자리여도 %m·%d가 두 자리로 채워서(10/02/2018) (1)에서 쓰던 :02d 서식이 필요 없어요.

(1)은 "윤년은 무시해요"라는 조건이 있었어요. datetime은 윤년까지 맞게 계산하고, 없는 날짜는 오류로 알려 줘요.

2100년은 100의 배수지만 400의 배수가 아니라서 윤년이 아니에요. 2월 28일의 다음 날이 3월 1일로 나와요. 마지막 입력은 2월 30일이 없는 날이라 strptime이 ValueError를 내고 프로그램이 멈춰요. 입력이 틀렸을 때 안내 문구를 보여 주려면 try/except ValueError로 감싸면 돼요.

5.3.9 [심화] ast — 다른 식에도 대 보기

문제: 교재 5.3.9는 연습 문제 없이 8 // 2 * (2 + 2) 하나만 해부해 보여 줘요. 같은 방법으로 다른 식 두 개를 해부해서 괄호가 트리 모양을 어떻게 바꾸는지 이 글에서 이어 봤어요(교재의 연습 문제가 아니에요). 원문 보기

.py 파일에서 실행

import ast  # ast 모듈을 가져와 주세요

for expr in ('1 + 2 * 3', '(1 + 2) * 3'):                   # 식 두 개를 하나씩 expr 라고 부르며 아래를 반복해 주세요
    tree = ast.parse(expr, mode='eval')                     # tree 에 expr 를 트리로 만들어 담아 주세요
    print(expr, '=', eval(compile(tree, '<ast>', 'eval')))  # expr 와 계산한 값을 화면에 보여 주세요
    print(ast.dump(tree.body, indent=2))                    # tree 의 body(실제 식) 를 들여쓰기해서 화면에 보여 주세요
1 + 2 * 3 = 7
BinOp(
  left=Constant(value=1),
  op=Add(),
  right=BinOp(
    left=Constant(value=2),
    op=Mult(),
    right=Constant(value=3)))
(1 + 2) * 3 = 9
BinOp(
  left=BinOp(
    left=Constant(value=1),
    op=Add(),
    right=Constant(value=2)),
  op=Mult(),
  right=Constant(value=3))

첫 식은 맨 바깥이 덧셈(Add)이고, 그 오른쪽에 곱셈(Mult) 묶음이 안쪽으로 들어가 있어요. 안쪽부터 계산하니 2 * 3이 먼저고 결과는 7이에요. 괄호를 친 두 번째 식은 1 + 2 묶음이 안쪽으로 들어가고 맨 바깥이 곱셈이라 결과가 9예요. 트리 어디에도 괄호 모양은 남지 않아요. 괄호는 "이것을 먼저 묶는다"는 뜻을 전하려고 쓰는 것이고, 그 뜻은 트리의 깊이로 표현돼요. tree.body를 쓰면 맨 위의 Expression 껍데기를 건너뛰고 실제 식부터 볼 수 있어요.
