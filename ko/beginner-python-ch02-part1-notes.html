while·if-elif-else 정리 — 왕초보 Python 2장 전반부

2026. 10. 11.

※ 이 글은 위키독스 『왕초보를 위한 Python』 2.1 ~ 2.2.6절을 제 나름의 언어로 짧게 정리한 것입니다. 2.2.7 ~ 2.5절은 2장 후반부 정리에 있고, 문제 풀이와 질문 해설은 2장 전반부 해설에 있어요.

while 반복문, if-elif-else 조건문, break, pass, 중첩 if, 파이썬 2장 전반부에 나오는 문법이 각각 무슨 뜻인지만 딱 정리한 글이에요.

핵심 정리

개념한 줄 정리
while 조건:조건이 참인 동안 들여쓴 블록을 되풀이한다.

1. while 반복 — 조건이 참인 동안 되풀이

while 조건: 아래에 들여쓴 코드는 조건이 참인 동안 계속 실행돼요. 매번 반복하기 전에 조건부터 다시 검사해요. if는 참이면 딱 한 번 실행하고 끝나지만, while은 참인 동안 계속 되돌아가서 실행해요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> num = 1
>>> while num <= 3:
...     print(num)
...     num = num + 1
...
1
2
3

핵심 한 줄: while은 매번 조건부터 검사하고, 참인 동안만 들여쓴 블록을 되풀이한다.

2. 무한 루프와 break — 끝나지 않는 반복과 빠져나오는 문

while은 조건만 보고 반복 여부를 정해요. 조건에 쓰인 값이 반복 중에 한 번도 안 바뀌면 조건은 영원히 똑같은 결과를 내서 반복이 끝나지 않아요. 그래서 while 몸통 안에는 조건에 쓰인 값을 바꾸는 줄이 최소 하나 있어야 해요.

개념 설명용 코드 — 절대 실행하지 마세요. num이 계속 1이라 조건이 늘 참이에요

num = 1
while num <= 3:
    print(num)
    # num = num + 1 을 빠뜨림

반대로 while True:는 일부러 무한히 도는 반복문이에요. 이걸 멈추려면 몸통 안에서 break로 직접 빠져나와요. break를 만나면 그 자리에서 즉시 반복문을 빠져나가요.

# filename: ten.py
max = 10

while True:
    num = int(input())
    if num > max:
        print(num, 'is too big!')
        break

핵심 한 줄: 조건에 쓰인 값이 안 바뀌면 무한 루프가 되고, while True:는 break로만 끝난다.

3. if / elif / else 순서 — 처음 참인 하나만

if는 "조건이 참이면 이 블록을, 아니면 건너뛰어라"예요. else는 참이 아닐 때 대신 실행할 것을, elif는 조건을 여러 개 늘어놓을 때 써요. 파이썬은 위에서부터 순서대로 검사하다가 처음으로 참인 조건 하나를 찾으면 그 블록만 실행하고, 나머지 elif는 전부 건너뛰어요.

실행: 파이썬 대화형 셸

>>> c = 15 * 5
>>> d = 15 + 15 + 15 + 15 + 15
>>> if c > d:
...     print('c is greater than d')
... elif c == d:
...     print('c is equal to d')
... else:
...     print('I don\'t know')
...
c is equal to d

그래서 순서가 결과를 바꿔요. 조건이 <=(이하)면 작은 경계부터, >=(이상)면 큰 경계부터 검사해야 해요.

나쁜 선택좋은 선택
큰 경계(1996)부터 검사한다 → 1930년생도 y <= 1996이 먼저 참이 되어 'a millennial'로 잘못 나와요. 작은 경계(1924)부터 검사한다 → 1930년생은 'the Silent Generation'으로 정확히 나와요.

핵심 한 줄: elif 체인은 처음 참인 조건 하나만 실행하니까, 부등호 방향에 맞춰 순서를 정해야 한다.

4. pass — 아무 일도 안 하는 자리 표시

pass는 "여기서는 아무 일도 하지 않는다"는 뜻의 키워드예요. 파이썬은 if, elif, while 같은 블록 뒤에 반드시 실행할 코드가 하나 이상 있어야 해서, 비워 두면 에러가 나요.

실행: 파이썬 대화형 셸 — pass 없이 블록을 비워 두면 나는 에러

>>> num = 5
>>> if num >= 1000:
...     result = 'big'
... elif num >= 0:
...
  File "<stdin>", line 4
IndentationError: expected an indented block after 'elif' statement on line 3

핵심 한 줄: 블록에 할 일이 없을 때 pass로 자리만 채우면 에러가 나지 않는다.

5. 중첩 if — 조건 안의 조건

if 블록 안에 또 다른 if를 넣는 거예요. 윤년 규칙처럼 "4의 배수인가 → (맞다면) 그중 100의 배수인가 → (맞다면) 그중 400의 배수인가" 식으로 조건이 겹겹이 있을 때 코드도 그 층을 그대로 따라가요. 바깥 if가 거짓이면 안쪽 if들은 검사조차 하지 않고 바로 else로 가요.

year = int(input())

if year % 4 == 0:
    if year % 100 == 0:
        if year % 400 == 0:
            is_leap_year = True
        else:
            is_leap_year = False
    else:
        is_leap_year = True
else:
    is_leap_year = False

실행: 파이썬 대화형 셸 — 규칙의 네 갈래를 각각 대표하는 연도

2000 -> 2000 is a leap year       # 4, 100, 400 모두로 나누어떨어짐
1900 -> 1900 is not a leap year   # 4, 100으로 나누어떨어지지만 400은 아님
2024 -> 2024 is a leap year       # 4로 나누어떨어지고 100으로는 안 나누어떨어짐
2023 -> 2023 is not a leap year   # 4로도 안 나누어떨어짐

핵심 한 줄: 조건이 층층이 있으면 if 안에 if를 넣어서 규칙의 층을 그대로 따라간다.
