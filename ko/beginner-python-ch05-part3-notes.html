날짜와 시간·ast 정리 — 왕초보 Python 5장 모듈 (5.3 ②)

2026. 10. 26.

※ 이 글은 위키독스 『왕초보를 위한 Python』 5.3.6절(날짜와 시간 다루기)과 5.3.9절([심화] ast)을 제 나름의 언어로 짧게 정리한 것입니다. 앞 내용은 5.3 ~ 5.3.4 정리에 있어요. 코드 실행 결과는 파이썬 3.14.7로 실제로 돌려서 넣었어요.

날짜는 datetime 으로 만들고, 빼면 기간(timedelta)이 되고, strftime·strptime 으로 글자와 오가요.

1. 날짜와 시간 — datetime (5.3.6)

하고 싶은 일쓰는 것
날짜·시간 만들기datetime(연, 월, 일, 시, 분, 초) — 시·분·초는 생략하면 0
지금 시각datetime.now()
두 시각의 차이datetime 두 개를 빼면 timedelta(기간)가 나온다
날짜 → 글자날짜.strftime('형식')
글자 → 날짜datetime.strptime('글자', '형식')
날짜에 기간 더하고 빼기날짜 + timedelta(days=7), 날짜 - timedelta(hours=36)

※ datetime 모듈 안에 같은 이름의 datetime이 있어서 보통 from datetime import datetime, timedelta로 가져와요.

만들기와 차이 계산

from datetime import datetime                        # datetime 모듈에서 datetime 을 가져와 주세요
d1 = datetime(2024, 2, 27, 12, 30)                   # d1 에 2024년 2월 27일 12시 30분을 담아 주세요
d2 = datetime(2024, 2, 27)                           # d2 에 2024년 2월 27일(시각은 0시)을 담아 주세요
print(d1)                                            # d1 을 화면에 보여 주세요
print(d2)                                            # d2 를 화면에 보여 주세요
print(datetime(2024, 3, 5) - d2)                     # 2024년 3월 5일에서 d2 를 뺀 기간을 화면에 보여 주세요
print(datetime(2023, 3, 5) - datetime(2023, 2, 27))  # 2023년 3월 5일에서 2023년 2월 27일을 뺀 기간을 화면에 보여 주세요
2024-02-27 12:30:00
2024-02-27 00:00:00
7 days, 0:00:00
6 days, 0:00:00

※ 교재 예제는 datetime(2024, 2, 27)과 datetime(2024, 3, 5)의 차이 옆에 6 days, 0:00:00이라고 적어 두었는데, 직접 돌리면 7 days가 나와요. 2024년은 윤년이라 2월이 29일까지 있어서 하루가 더 끼기 때문이고, 윤년이 아닌 2023년은 6 days 예요.

글자로 바꾸기와 읽어 오기

형식 글자뜻예 (2024-02-27 00:53:38)
%Y네 자리 연도2024
%m두 자리 월02
%d두 자리 일27
%H %M %S24시간제 시·분·초00 53 38
%B월 이름(영어)February
from datetime import datetime                            # datetime 모듈에서 datetime 을 가져와 주세요
d = datetime(2024, 2, 27, 0, 53, 38)                     # d 에 2024년 2월 27일 0시 53분 38초를 담아 주세요
print(d.strftime('%Y-%m-%d %H:%M:%S'))                   # d 를 '연-월-일 시:분:초' 글자로 바꿔 화면에 보여 주세요
print(d.strftime('%B %d, %Y'))                           # d 를 '월이름 일, 연' 글자로 바꿔 화면에 보여 주세요
e = datetime.strptime('27 February, 2024', '%d %B, %Y')  # e 에 '27 February, 2024' 글자를 날짜로 읽어 담아 주세요
print(e)                                                 # e 를 화면에 보여 주세요
print(type(e))                                           # e 의 자료형을 화면에 보여 주세요
2024-02-27 00:53:38
February 27, 2024
2024-02-27 00:00:00
<class 'datetime.datetime'>

※ strftime은 날짜를 글자로, strptime은 글자를 날짜로 바꾸는 서로 반대 방향이에요. 두 함수 모두 같은 형식 글자를 쓰니, 읽을 글자의 모양에 맞춰 형식을 적어요. %B는 컴퓨터의 언어 설정에 따라 이름이 달라질 수 있어서, 이 글은 영어 이름이 나오는 환경에서 돌렸어요.

※ 현재 시각은 실행할 때마다 달라서 값 대신 모양만 확인했어요.

from datetime import datetime                       # datetime 모듈에서 datetime 을 가져와 주세요
now = datetime.now().strftime('%Y-%m-%d %H:%M:%S')  # now 에 지금 시각을 '연-월-일 시:분:초' 글자로 담아 주세요
print(len(now))                                     # now 의 글자 수를 화면에 보여 주세요
19

기간 더하고 빼기 — timedelta

from datetime import datetime, timedelta  # datetime 모듈에서 datetime 과 timedelta 를 가져와 주세요
d = datetime(2024, 2, 27, 12, 0)          # d 에 2024년 2월 27일 12시를 담아 주세요
print(d + timedelta(days=7))              # d 에 7일을 더해 화면에 보여 주세요
print(d - timedelta(hours=36))            # d 에서 36시간을 빼 화면에 보여 주세요
print(d + timedelta(days=1, hours=3))     # d 에 1일 3시간을 더해 화면에 보여 주세요
2024-03-05 12:00:00
2024-02-26 00:00:00
2024-02-28 15:00:00

※ timedelta의 이름 붙인 값은 days, hours, minutes, seconds 등이에요. 월과 연은 길이가 달라서 timedelta에 없어요. 달력이 알아서 맞춰 주니 윤년도 따로 계산하지 않아도 돼요.

시간대(time zone)

교재는 서울 시각을 얻으려고 pytz를 써요. pytz는 파이썬에 들어 있지 않아 따로 설치해야 하는 외부 모듈이에요(이 컴퓨터에서는 import pytz가 ModuleNotFoundError로 실패했어요). 파이썬에 처음부터 들어 있는 zoneinfo로도 시간대를 붙일 수 있어요.

from datetime import datetime                                    # datetime 모듈에서 datetime 을 가져와 주세요
from zoneinfo import ZoneInfo                                    # zoneinfo 모듈에서 ZoneInfo 를 가져와 주세요
d = datetime(2024, 2, 27, 12, 0, tzinfo=ZoneInfo('Asia/Seoul'))  # d 에 서울 시간대의 2024년 2월 27일 12시를 담아 주세요
print(d)                                                         # d 를 화면에 보여 주세요
2024-02-27 12:00:00+09:00

※ 끝의 +09:00은 세계 표준시보다 9시간 빠르다는 뜻이에요.

2. [심화] 파이썬이 식을 읽는 모양 — ast (5.3.9)

※ 교재의 목차에는 5.3.7 다음이 바로 5.3.9이고 5.3.8은 보이지 않았어요. 이 글은 목차에 있는 절을 따라 정리했어요.

항목내용
ast추상 구문 트리(Abstract Syntax Tree). 파이썬이 코드를 어떻게 나누어 이해하는지 들여다보는 모듈
ast.parse(식, mode='eval')식 하나를 트리로 만든다. 맨 위에는 Expression이 오고, 실제 식은 .body에 들어 있다
ast.dump(트리, indent=2)트리를 들여쓰기해서 글자로 보여 준다
BinOp이항 연산. left(왼쪽), op(연산자), right(오른쪽)로 이뤄진다
Constant숫자·글자 같은 값 그 자체 (value=8)
import ast                                         # ast 모듈을 가져와 주세요
tree = ast.parse('8 // 2 * (2 + 2)', mode='eval')  # tree 에 식 '8 // 2 * (2 + 2)' 를 트리로 만들어 담아 주세요
print(ast.dump(tree, indent=2))                    # tree 를 들여쓰기해서 화면에 보여 주세요
print(eval(compile(tree, '<ast>', 'eval')))        # tree 를 계산한 값을 화면에 보여 주세요
Expression(
  body=BinOp(
    left=BinOp(
      left=Constant(value=8),
      op=FloorDiv(),
      right=Constant(value=2)),
    op=Mult(),
    right=BinOp(
      left=Constant(value=2),
      op=Add(),
      right=Constant(value=2))))
16

※ 맨 바깥 BinOp가 곱셈(Mult)이고, 왼쪽에 8 // 2, 오른쪽에 2 + 2가 매달려 있어요. 안쪽에 있는 것부터 계산돼서 (8 // 2) × (2 + 2) = 4 × 4 = 16이에요. 트리 그대로 계산하는 마지막 줄은 compile()과 eval() 두 함수를 이어 쓴 것인데, 지금은 "트리도 계산할 수 있다" 정도만 알면 돼요. 교재도 이 내용을 몰라도 파이썬을 쓰는 데 지장이 없다고 해요.
