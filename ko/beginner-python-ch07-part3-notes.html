※ 이 글은 위키독스 『왕초보를 위한 Python』 7.3절과 영상은 노마드 코더의 「객체지향 프로그래밍? 문과도 이해쌉가능. 10분컷.」인데, 영어 음성의 자동 자막 전체를 읽고 정리했어요. 화면에 나온 코드는 보지 못해서 예제는 파이썬으로 새로 짜서 직접 돌렸어요. 코드 실행 결과는 실제로 돌려서 넣었어요.

상속(inheritance)은 자식 클래스가 부모 클래스의 변수와 메서드를 그대로 물려받고, 자기만의 것을 더하는 것이에요.

앞 내용은 7.2 변수와 메서드 정리에 있어요.

1. 물려받기 (7.3)

말뜻
부모 클래스물려주는 클래스. 위키독스는 상위 클래스, 영상은 father class 라고 불러요
자식 클래스물려받는 클래스. 만들 때 class 자식(부모):
is a 읽기자식 → 부모 화살표를 따라 읽는다. “Student is a Person”(학생은 사람이다)
class Person:                 # Person 클래스를 정의해 주세요
    eyes = 2                  # 클래스 변수 eyes 에 2 를 담아 주세요
    def eat(self):            # eat 메서드를 정의해 주세요
        print('얌냠...')      # '얌냠...' 을 화면에 보여 주세요
    def sleep(self):          # sleep 메서드를 정의해 주세요
        print('쿨쿨...')      # '쿨쿨...' 을 화면에 보여 주세요
    def talk(self):           # talk 메서드를 정의해 주세요
        print('주절주절...')  # '주절주절...' 을 화면에 보여 주세요
class Student(Person):        # Person 을 상속받는 Student 클래스를 정의해 주세요
    def study(self):          # study 메서드를 정의해 주세요
        print('열공열공...')  # '열공열공...' 을 화면에 보여 주세요
kim = Student()               # kim 에 Student 인스턴스를 만들어 담아 주세요
kim.talk()                    # kim 에게 말을 시켜 주세요
kim.study()                   # kim 에게 공부를 시켜 주세요
print(kim.eyes)               # kim 의 eyes 를 화면에 보여 주세요
print(isinstance(kim, Person))        # kim 은 Person 인스턴스이기도 한가요?
print(issubclass(Student, Person))    # Student 는 Person 의 자식 클래스인가요?
print(hasattr(Person(), 'study'))     # Person 인스턴스에 study 가 있나요?

※ Student에는 study만 적었는데 talk와 eyes도 써져요. 반대로 부모 Person에는 study가 없어요. 물려주는 방향은 부모 → 자식 한 방향이에요.

왜 복사해 붙이지 않고 상속하나

방법나중에 고칠 때
복사해 붙임나중에 “옷 색깔” 같은 것을 넣으려면 사람 클래스와 학생 클래스를 각각 고쳐야 한다
상속부모 한 곳만 고치면 자식에게도 반영된다

영상의 예도 같아요. 사람 시뮬레이션에 아기, 십대 클래스가 있으면 둘 다 이름·팔·다리를 갖는 “사람”이에요. 이 공통 부분을 사람 클래스에 한 번만 적고, 아기와 십대는 사람을 extend(확장)해서 자기만의 것(아기는 울기, 십대는 투덜대기)만 더해요. 영상은 이것으로 코드 중복을 줄이고 코드를 다시 쓸 수 있는 조각으로 나눈다고 말해요.

2. 부모의 __init__ 부르기 — super()

부모에 __init__이 있는데 자식이 자기 __init__을 다시 적으면, 부모의 __init__은 자동으로 불리지 않아요. 부모의 속성도 만들고 싶으면 자식의 __init__ 안에서 super().__init__(...)으로 부모 것을 불러 줘요. 영상은 이 줄이 빠지면 “사람의 이름을 정하는 부분이 실행되지 않아서” 코드가 동작하지 않는다고 설명해요(자바스크립트는 super()).

class Human:                              # Human 클래스를 정의해 주세요
    def __init__(self, name):             # 만들 때 불리는 __init__ 을 정의해 주세요
        self.name = name                  # 이 인스턴스의 name 에 name 을 담아 주세요
class Baby(Human):                        # Human 을 상속받는 Baby 클래스를 정의해 주세요
    def __init__(self, name):             # Baby 의 __init__ 을 정의해 주세요
        super().__init__(name)            # 부모 Human 의 __init__ 을 name 으로 불러 주세요
        self.cute = True                  # 이 인스턴스의 cute 에 True 를 담아 주세요
    def cry(self):                        # cry 메서드를 정의해 주세요
        return self.name + " 응애"        # 이름과 " 응애" 를 이어서 돌려주세요
b = Baby("아기")                          # b 에 이름이 "아기" 인 Baby 를 만들어 담아 주세요
print(b.name, b.cute, b.cry())            # b 의 name, cute, 울음 결과를 화면에 보여 주세요
아기 True 아기 응애

메서드 덮어쓰기와 super()

자식이 부모와 같은 이름의 메서드를 적으면 자식 것이 우선해요(덮어쓰기). 부모 것도 같이 쓰고 싶으면 super().메서드()로 불러요.

class Teen(Human):                          # Human 을 상속받는 Teen 클래스를 정의해 주세요
    def talk(self):                         # talk 메서드를 정의해 주세요
        return "아 몰라요"                  # "아 몰라요" 를 돌려주세요
class Teen2(Teen):                          # Teen 을 상속받는 Teen2 클래스를 정의해 주세요
    def talk(self):                         # talk 메서드를 다시 정의해 주세요
        return super().talk() + "!"         # 부모의 talk 결과에 "!" 를 붙여 돌려주세요
print(Teen2("민수").talk())                 # 이름이 "민수" 인 Teen2 의 말을 화면에 보여 주세요
아 몰라요!

※ 이 예제의 Human은 위 __init__ 예제의 것을 그대로 써요. 덮어쓰기는 위키독스 7.3에는 없고, 영상의 “자식은 부모 것 + 자기 것” 설명을 이어서 이 글이 덧붙인 내용이에요.
