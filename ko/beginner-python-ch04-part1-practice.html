실습 문제 5개 — 문자열·리스트 코드 읽고 결과 예측하기 (3)

2026. 10. 11.

※ 이 글은 위키독스 『왕초보를 위한 Python』 4장 4.1~4.2 내용을 바탕으로 제가 직접 만든 문제입니다. 교재의 공식 연습 문제가 아니에요. 완성된 코드를 보여드리니 직접 짤 필요 없이, 코드를 읽고 실행 결과가 뭘지 먼저 예측해보세요. 정답과 이유는 앞 글(문제 해설)의 실습 문제 해설에 있어요.

슬라이싱, 문자열은 불변, 리스트 메서드, in과 복사, 순회 중 remove가 나오는 완성된 코드 5개를 보고, 코드를 짜지 않고 실행 결과만 예측해보는 읽기 문제예요.

핵심 정리

개념한 줄 정리
슬라이싱x[2:4]는 2번 이상 4번 미만, x[::-1]은 뒤집기, x[-3:]은 끝 세 개다.
문자열은 불변x[0] = 'n'은 TypeError이고, 새 문자열을 만들어 다시 붙인다('n' + x[1:]).
split · strip · replace쪼개기, 양끝 공백 지우기, 바꾸기. 모두 새 문자열을 돌려주고 원본은 그대로다.
리스트 메서드append 끝에 추가, insert(0, v) 앞에 추가, pop() 끝을 빼서 돌려줌, del l[i] 삭제.
in리스트에서는 완전히 같은 원소만 찾고, 문자열에서는 부분 문자열도 찾는다.
a[:]리스트의 복사본이라 고쳐도 원본 a는 그대로다(b = a는 복사가 아니다).
순회 중 remove돌고 있는 리스트를 고치면 원소를 건너뛰니, L[:] 복사본을 돈다.

다섯 문제 모두 지난 글에서 정리한 문법만으로 읽을 수 있어요. 난이도는 1번에서 5번으로 갈수록 조금씩 올라가요. 코드를 눈으로 따라가며 예측한 뒤, 문제 해설과 맞춰 보세요.

문제 1 — 슬라이싱

문자열과 리스트를 잘라 보는 코드예요.

word = 'python'              # word 에 문자열 'python' 을 담아 주세요
nums = [10, 20, 30, 40, 50]  # nums 에 리스트 [10, 20, 30, 40, 50] 을 담아 주세요
print(word[::-1])            # word 를 거꾸로 읽은 것을 화면에 보여 주세요
print(word[1:4])             # word 의 1번부터 3번까지 잘라 낸 것을 화면에 보여 주세요
print(nums[-3:])             # nums 의 뒤에서 3번째부터 끝까지 잘라 낸 것을 화면에 보여 주세요
print(nums[::-1])            # nums 를 거꾸로 읽은 것을 화면에 보여 주세요
print(word[:2] + word[-2:])  # word 의 앞 두 글자와 뒤 두 글자를 붙여 화면에 보여 주세요

이 코드를 실행하면 다섯 줄이 출력돼요. 각 줄은 무엇일까요?

출력 줄예측
첫 번째 줄?
두 번째 줄?
세 번째 줄?
네 번째 줄?
다섯 번째 줄?
힌트 보기

word의 글자마다 0번부터 번호를 붙여 보세요. [시작:끝]에서 끝 번호의 칸은 포함하지 않아요. 음수 번호는 뒤에서부터 세고, 맨 뒤 칸이 -1이에요.

문제 2 — 문자열은 불변, split과 strip

문자열을 새로 만들고, 쪼개고, 공백을 지우는 코드예요.

x = 'banana'                      # x 에 문자열 'banana' 를 담아 주세요
y = 'n' + x[1:]                   # 'n' 뒤에 x 의 1번부터 끝까지를 붙여 y 에 담아 주세요
print(x)                          # x 를 화면에 보여 주세요
print(y)                          # y 를 화면에 보여 주세요
line = '  apple, kiwi , melon  '  # line 에 문자열 '  apple, kiwi , melon  ' 을 담아 주세요
parts = line.strip().split(',')   # line 의 앞뒤 공백을 지우고 쉼표로 잘라 parts 에 담아 주세요
print(parts)                      # parts 를 화면에 보여 주세요
print(parts[1].strip())           # parts 의 1번 원소의 앞뒤 공백을 지워 화면에 보여 주세요
print(len(parts))                 # parts 의 원소 개수를 화면에 보여 주세요

이 코드를 실행하면 다섯 줄이 출력돼요. 각 줄은 무엇일까요? 특히 x가 두 번째 줄에서 바뀌었는지 생각해 보세요.

출력 줄예측
첫 번째 줄?
두 번째 줄?
세 번째 줄?
네 번째 줄?
다섯 번째 줄?
힌트 보기

x[1:]이 무엇인지부터 구하세요. 문자열 메서드와 +는 새 문자열을 만들 뿐 x를 고치지 않아요. strip()은 양끝 공백만 지우고, split(',')는 쉼표 자리에서 자를 뿐 쉼표 옆 공백은 그대로 두는 점을 주의하세요.

문제 3 — 리스트 메서드 연쇄

리스트에 값을 더하고 빼는 줄이 여러 개 이어지는 코드예요.

a = [3, 1]      # a 에 리스트 [3, 1] 을 담아 주세요
a.append(5)     # a 의 맨 뒤에 5 를 붙여 주세요
a.insert(0, 9)  # a 의 0번 자리에 9 을 끼워 넣어 주세요
x = a.pop()     # a 의 맨 뒤 원소를 꺼내 x 에 담아 주세요
del a[1]        # a 의 1번 원소를 지워 주세요
a.append(x)     # a 의 맨 뒤에 x 를 붙여 주세요
print(a)        # a 를 화면에 보여 주세요
print(x)        # x 를 화면에 보여 주세요
print(len(a))   # a 의 원소 개수를 화면에 보여 주세요

이 코드를 실행하면 세 줄이 출력돼요. 각 줄은 무엇일까요? 줄마다 a가 어떻게 바뀌는지 적어 보세요.

출력 줄예측
첫 번째 줄 (a)?
두 번째 줄 (x)?
세 번째 줄 (len(a))?
힌트 보기

줄마다 a를 한 칸씩 다시 적어 가며 따라가요. append는 끝에, insert(0, 값)은 맨 앞에 넣어요. pop()은 끝 원소를 지우면서 그 값을 돌려줘서 x에 담겨요. del a[1]은 그 시점의 1번 칸을 지워요.

문제 4 — in과 복사 a[:]

복사한 리스트와 이름만 붙인 리스트가 나오는 코드예요.

a = [1, 2, 3]    # a 에 리스트 [1, 2, 3] 을 담아 주세요
b = a[:]         # a 를 통째로 복사해 b 에 담아 주세요
b.append(4)      # b 의 맨 뒤에 4 를 붙여 주세요
c = a            # a 가 가리키는 것을 c 에도 담아 주세요
c.append(5)      # c 의 맨 뒤에 5 를 붙여 주세요
print(a)         # a 를 화면에 보여 주세요
print(b)         # b 를 화면에 보여 주세요
print(2 in a)    # 2 가 a 안에 있는지 화면에 보여 주세요
print('2' in a)  # '2' 가 a 안에 있는지 화면에 보여 주세요
print(4 in a)    # 4 가 a 안에 있는지 화면에 보여 주세요

이 코드를 실행하면 다섯 줄이 출력돼요. 각 줄은 무엇일까요? a가 바뀌는 줄이 어디인지 먼저 찾아보세요.

출력 줄예측
첫 번째 줄 (a)?
두 번째 줄 (b)?
세 번째 줄?
네 번째 줄?
다섯 번째 줄?
힌트 보기

b = a[:]는 새 리스트(복사본)이고 c = a는 같은 리스트에 이름만 하나 더 붙인 거예요. 누구의 append가 a에 보이는지 따져 보세요. in은 자료형까지 완전히 같은 원소를 찾아요.

문제 5 — 순회 중 remove와 복사본 순회

같은 일을 하는 두 코드 중 하나만 복사본을 도는 코드예요.

L = [1, 2, 2, 3]     # L 에 리스트 [1, 2, 2, 3] 을 담아 주세요
for x in L:          # L 의 원소를 하나씩 x 라고 부르며 아래를 반복해 주세요
    if x == 2:       # 만약 x 가 2 와 같으면
        L.remove(x)  # L 에서 값 x 를 찾아 지워 주세요
print(L)             # L 을 화면에 보여 주세요

M = [1, 2, 2, 3]     # M 에 리스트 [1, 2, 2, 3] 을 담아 주세요
for x in M[:]:       # M 의 복사본 원소를 하나씩 x 라고 부르며 아래를 반복해 주세요
    if x == 2:       # 만약 x 가 2 와 같으면
        M.remove(x)  # M 에서 값 x 를 찾아 지워 주세요
print(M)             # M 을 화면에 보여 주세요

이 코드를 실행하면 두 줄이 출력돼요. 각 줄은 무엇일까요? 두 줄이 같을지 다를지부터 예측해 보세요.

출력 줄예측
첫 번째 줄 (L)?
두 번째 줄 (M)?
힌트 보기

for 문은 "지금 몇 번째 칸을 보고 있는지"만 기억해요. 첫 코드에서 2를 지우면 뒤 원소들이 한 칸씩 앞으로 당겨지는데, 반복은 그다음 번호로 가요. 그러면 당겨진 원소를 한 번 건너뛰지 않을까요? 두 번째 코드는 도는 대상이 M이 아니라 M[:]이라는 점이 달라요.
