초급 1읽기

type()과 자료형

값마다 정해진 자료형을 type()으로 알아보는 코드예요.

print(type(7))       # 7 의 자료형을 화면에 보여 주세요
print(type(3.5))     # 3.5 의 자료형을 화면에 보여 주세요
print(type('hi'))    # 'hi' 의 자료형을 화면에 보여 주세요
print(type([1, 2]))  # [1, 2] 의 자료형을 화면에 보여 주세요
print(type(True))    # True 의 자료형을 화면에 보여 주세요
print(type(10 / 2))  # 10 을 2 로 나눈 값의 자료형을 화면에 보여 주세요
print(100_000)       # 100_000 을 화면에 보여 주세요

이 코드를 실행하면 일곱 줄이 출력돼요. 각 줄은 무엇일까요?

네 번째 줄?
다섯 번째 줄?

type()은 값의 종류를 알려 주는 함수예요. 따옴표로 감싸면 str, True와 False는 bool이에요. 여섯 번째 줄은 10 / 2의 값이 정수일지 소수일지부터 생각해 보세요.

  • <class 'int'>는 "자료형은 int(정수)"라는 뜻이에요. 앞의 class와 바깥의 < >는 파이썬이 자료형을 보여 줄 때 늘 붙이는 모양이에요.
  • 10 / 2는 딱 나누어떨어져도 결과가 5.0(float)이라서 float이에요. /는 늘 소수가 있는 수를 내요. 몫만 정수로 얻는 건 //예요.
  • 100_000의 밑줄은 자릿수를 읽기 쉽게 나눈 표시일 뿐이라 값은 100000이에요.

핵심 한 줄: type()은 값의 종류를 알려 주고, /는 늘 float을 내요.

초급 2읽기

가변과 불변

리스트와 문자열의 원소를 같은 방법으로 바꿔 보는 코드예요.

a = [1, 2, 3]  # a 에 리스트 [1, 2, 3] 을 담아 주세요
a[0] = 9       # a 의 0번 원소를 9 로 바꿔 주세요
print(a)       # a 를 화면에 보여 주세요
s = 'abc'      # s 에 문자열 'abc' 를 담아 주세요
s[0] = 'z'     # s 의 0번 원소를 'z' 로 바꿔 주세요
print(s)       # s 를 화면에 보여 주세요

이 코드를 실행하면 어디까지 출력되고, 어떤 에러가 날까요? (실제 화면에는 에러가 난 줄 번호가 더 나오지만, 핵심은 마지막 줄이에요.)

원소를 바꿀 수 있는 자료(가변)와 바꿀 수 없는 자료(불변)를 떠올려 보세요. 리스트는 가변이에요. 에러가 나면 파이썬은 그 줄에서 멈춰요.

정답·해설 보기 
[9, 2, 3]
TypeError: 'str' object does not support item assignment
  • 리스트는 가변이라 a[0] = 9가 되어 [9, 2, 3]이 출력돼요.
  • 문자열은 불변이라 s[0] = 'z'에서 TypeError가 나요. 에러가 난 줄에서 프로그램이 멈추니 마지막 print(s)는 실행되지 않아요.
  • 불변인 자료는 int, str, tuple이고, 가변인 자료는 list예요.
  • 문자열을 바꾸고 싶으면 일부를 고치는 대신 새 문자열을 만들어요: 'z' + s[1:]은 'zbc'예요.

핵심 한 줄: list는 원소를 바꿀 수 있고, str은 바꿀 수 없어요.

인덱싱과 슬라이싱

문자열을 번호로 꺼내고 잘라 보는 코드예요.

h = 'Hello world!'  # h 에 문자열 'Hello world!' 를 담아 주세요
print(h[0])         # h 의 0번 글자를 화면에 보여 주세요
print(h[-1])        # h 의 맨 뒤 글자를 화면에 보여 주세요
print(h[-1:])       # h 의 뒤에서 1번째부터 끝까지 잘라 낸 것을 화면에 보여 주세요
print(h[:5])        # h 의 처음부터 4번까지 잘라 낸 것을 화면에 보여 주세요
print(h[6:])        # h 의 6번부터 끝까지 잘라 낸 것을 화면에 보여 주세요
print(h[-6:])       # h 의 뒤에서 6번째부터 끝까지 잘라 낸 것을 화면에 보여 주세요
print(h[::-1])      # h 를 거꾸로 읽은 것을 화면에 보여 주세요

초급 4읽기

문자열 메서드

문자열을 다듬고 쪼개고 이어 붙이는 코드예요.

s = '  Hello World  '           # s 에 앞뒤로 공백 두 칸씩 있는 문자열을 담아 주세요
print(len(s.strip()))           # s 의 앞뒤 공백을 지운 것의 글자 수를 화면에 보여 주세요
print(len(s.rstrip()))          # s 의 오른쪽 공백을 지운 것의 글자 수를 화면에 보여 주세요
print('a,b,c'.split(','))       # 'a,b,c' 를 쉼표로 자른 것을 화면에 보여 주세요
print('a b  c'.split())         # 'a b  c' 를 공백으로 자른 것을 화면에 보여 주세요
print('cat'.replace('c', 'b'))  # 'cat' 의 'c' 를 'b' 로 바꾼 것을 화면에 보여 주세요
print('hello'.find('z'))        # 'hello' 안에서 'z' 의 자리를 화면에 보여 주세요
print(', '.join(['사과', '배']))   # ['사과', '배'] 를 ', ' 로 이어 붙인 것을 화면에 보여 주세요
print(len(s))                   # s 의 글자 수를 화면에 보여 주세요

이 코드를 실행하면 여덟 줄이 출력돼요. 각 줄은 무엇일까요? 마지막 줄에서 s가 바뀌었는지도 생각해 보세요.

  • 전체 길이는 2 + 11 + 2 = 15예요. strip()은 양쪽을 지워 11, rstrip()은 오른쪽만 지워 13이에요.

초급 5읽기

리스트 메서드

리스트에 더하고, 정렬하고, 지우는 코드예요.

L = [3, 1, 2]   # L 에 리스트 [3, 1, 2] 를 담아 주세요
L.append(9)     # L 의 맨 뒤에 9 를 붙여 주세요
print(L)        # L 을 화면에 보여 주세요
L.sort()        # L 을 작은 것부터 순서대로 정렬해 주세요
print(L)        # L 을 화면에 보여 주세요
L.insert(0, 7)  # L 의 0번 자리에 7 을 끼워 넣어 주세요
del L[1]        # L 의 1번 원소를 지워 주세요
print(L)        # L 을 화면에 보여 주세요
print(L.pop())  # L 의 맨 뒤 원소를 꺼내 그 값을 화면에 보여 주세요
print(L)        # L 을 화면에 보여 주세요

이 코드를 실행하면 다섯 줄이 출력돼요. 각 줄은 무엇일까요? 줄마다 L이 어떻게 바뀌는지 적으면서 따라가 보세요.

변환과 sum

자료를 다른 자료형으로 바꾸고 합계를 내는 코드예요.

print(list('abc'))              # 'abc' 를 리스트로 만든 것을 화면에 보여 주세요
print(str(123) + '4')           # 123 을 문자열로 바꾼 것에 '4' 를 붙여 화면에 보여 주세요
print(int('123') + 4)           # '123' 을 정수로 바꾼 것에 4 를 더해 화면에 보여 주세요
print(float('123'))             # '123' 을 소수로 바꾼 것을 화면에 보여 주세요
print(sum([1, 2, 3]))           # [1, 2, 3] 의 원소를 모두 더해 화면에 보여 주세요
print(sum(list(range(1, 11))))  # 1 부터 10 까지를 리스트로 만들어 모두 더해 화면에 보여 주세요

  • str(123) + '4'는 문자열 '123'과 '4'를 이어 붙여 1234이고, int('123') + 4는 숫자 더하기라 127이에요. 같은 +라도 자료형에 따라 달라요.

중급 1읽기

단어의 가운데 글자

문자열은 일부를 바꿀 수 없으니, 잘라서 새 문자열을 만드는 코드예요.

word = 'apple'                           # word 에 문자열 'apple' 을 담아 주세요
mid = len(word) // 2                     # word 의 글자 수를 2 로 나눈 몫을 mid 에 담아 주세요
new = word[:mid] + 'X' + word[mid + 1:]  # word 의 mid 앞까지, 'X', word 의 mid 다음부터 끝까지를 붙여 new 에 담아 주세요
print(mid)                               # mid 를 화면에 보여 주세요
print(new)                               # new 를 화면에 보여 주세요
print(word)                              # word 를 화면에 보여 주세요

중급 5읽기

글자를 자르는 함수

앞 두 글자와 뒤 두 글자를 붙이던 일을 함수로 만든 코드예요.

def edges(s, n):           # s, n 을 받는 edges 라는 동작을 만들어 주세요
    return s[:n] + s[-n:]  # s 의 앞 n 글자와 뒤 n 글자를 붙여 결과로 돌려주세요

print(edges('python', 2))  # edges 에 'python' 과 2 를 넣은 결과를 화면에 보여 주세요
print(edges('abcdef', 3))  # edges 에 'abcdef' 와 3 을 넣은 결과를 화면에 보여 주세요
print(edges('ab', 1))      # edges 에 'ab' 와 1 을 넣은 결과를 화면에 보여 주세요
print(edges('hello', 0))   # edges 에 'hello' 와 0 을 넣은 결과를 화면에 보여 주세요

함수에 넘긴 값의 행방

함수에 리스트, 숫자, 문자열을 넘겼을 때 바깥 값이 바뀌는지 보는 코드예요.

def grow(items, n):  # items, n 을 받는 grow 라는 동작을 만들어 주세요
    items.append(n)  # items 의 맨 뒤에 n 을 붙여 주세요
    n = n + 1        # n 에 n 보다 1 큰 값을 담아 주세요
    return n         # n 을 결과로 돌려주세요

def reset(s):        # s 를 받는 reset 이라는 동작을 만들어 주세요
    s = 'X' + s[1:]  # s 에 'X' 와 s 의 1번부터 끝까지를 붙인 것을 담아 주세요
    return s         # s 를 결과로 돌려주세요

nums = [1]           # nums 에 리스트 [1] 을 담아 주세요
k = 5                # k 에 5 를 담아 주세요
r = grow(nums, k)    # grow 에 nums 와 k 를 넣은 결과를 r 에 담아 주세요
print(nums)          # nums 를 화면에 보여 주세요
print(k)             # k 를 화면에 보여 주세요
print(r)             # r 을 화면에 보여 주세요
word = 'abc'         # word 에 문자열 'abc' 를 담아 주세요
reset(word)          # reset 에 word 를 넣어 실행해 주세요
print(word)          # word 를 화면에 보여 주세요

리스트는 가변이라 함수가 받은 items와 바깥 nums는 같은 리스트예요. 숫자와 문자열은 불변이라 함수 안에서 n = ..., s = ...를 하면 그 함수 안의 새 이름이 생길 뿐이에요. 마지막 줄은 reset이 돌려준 값을 어디에도 담지 않았다는 점도 보세요.

  • items.append(n)은 받은 리스트 자체를 바꿔서 바깥 nums가 [1, 5]가 돼요.
  • n = n + 1은 숫자(불변)라 함수 안의 n만 6이 되고, 바깥 k는 그대로 5예요. 바뀐 값은 return n으로 r에 담겨 6이에요.
  • reset은 문자열(불변)이라 안에서 새 문자열을 만들 뿐이고, 그 결과를 return으로 돌려줬지만 reset(word)의 결과를 어디에도 담지 않아서 word는 abc 그대로예요.

핵심 한 줄: 가변 자료(리스트)는 함수 안에서 바꾸면 밖도 바뀌고, 불변 자료(숫자·문자열)는 안 바뀌어요.

    return total       # total 을 결과로 돌려주세요

bump()                 # bump 를 실행해 주세요

print(shadow())        # shadow 의 결과를 화면에 보여 주세요

리스트가 거치는 세 단계

문자열을 숫자 리스트로 바꾸고 걸러내고 다시 문자열로 돌리는 코드예요.

nums = list(map(int, '643'))                     # '643' 의 글자마다 int 를 적용한 결과를 리스트로 만들어 nums 에 담아 주세요

print(list(map(lambda x: x * 2, nums)))          # nums 의 원소마다 두 배로 만들어 리스트로 화면에 보여 주세요
print(list(map(str, nums)))                      # nums 의 원소마다 str 을 적용해 리스트로 화면에 보여 주세요
print(''.join(map(str, nums[::-1])))             # nums 를 거꾸로 읽어 글자로 바꾼 것을 빈 글자로 이어 붙여 화면에 보여 주세요

  • sum은 6 + 4 + 3 = 13이에요.

고급 6읽기

수를 걸러 내는 함수

2부터 n까지에서 소수만 남기는 코드와, 조건 하나를 뺀 변형 코드를 비교해요.

def primes(n):                         # n 을 받는 primes 라는 동작을 만들어 주세요
    L = list(range(2, n + 1))          # 2 부터 n 까지의 수를 리스트로 만들어 L 에 담아 주세요
    for p in L[:]:                     # L 의 복사본 원소를 하나씩 p 라고 부르며 아래를 반복해 주세요
        for x in L[:]:                 # L 의 복사본 원소를 하나씩 x 라고 부르며 아래를 반복해 주세요
            if x != p and x % p == 0:  # 만약 x 가 p 와 다르고 x 를 p 로 나눈 나머지가 0 이면
                L.remove(x)            # L 에서 값 x 를 찾아 지워 주세요
    return L                           # L 을 결과로 돌려주세요

def primes_b(n):                       # n 을 받는 primes_b 라는 동작을 만들어 주세요
    L = list(range(2, n + 1))          # 2 부터 n 까지의 수를 리스트로 만들어 L 에 담아 주세요
    for p in L[:]:                     # L 의 복사본 원소를 하나씩 p 라고 부르며 아래를 반복해 주세요
        for x in L[:]:                 # L 의 복사본 원소를 하나씩 x 라고 부르며 아래를 반복해 주세요
            if x % p == 0:             # 만약 x 를 p 로 나눈 나머지가 0 이면
                L.remove(x)            # L 에서 값 x 를 찾아 지워 주세요
    return L                           # L 을 결과로 돌려주세요

print(primes(10))                      # primes 에 10 을 넣은 결과를 화면에 보여 주세요
print(primes(20))                      # primes 에 20 을 넣은 결과를 화면에 보여 주세요
print(primes_b(10))                    # primes_b 에 10 을 넣은 결과를 화면에 보여 주세요

primes는 p의 배수를 L에서 지워 나가요. 그런데 어떤 수든 자기 자신으로 나누면 나머지가 0이에요. x != p는 이 자기 자신을 지우지 않으려는 조건이에요. 이 조건이 없으면 p = 2일 때 2는 어떻게 될까요?

정답·해설 보기 
[2, 3, 5, 7]
[2, 3, 5, 7, 11, 13, 17, 19]
[]
  • primes는 p = 2일 때 4, 6, 8, 10을, p = 3일 때 9를 지워서 [2, 3, 5, 7]이에요. 20까지는 [2, 3, 5, 7, 11, 13, 17, 19]이에요.
  • primes_b는 x != p and를 뺐어서 p 자신도 지워요. p = 2일 때 2, 4, 6, 8, 10이 모두 지워지고, 같은 식으로 3, 5, 7도 지워져서 결과가 [](빈 리스트)가 돼요.
  • 그래서 x != p가 "자기 자신은 남긴다"는 역할을 해요. 두 for 모두 복사본(L[:])을 돌아서 remove해도 건너뛰기가 생기지 않아요.

핵심 한 줄: x != p는 소수 자신을 남기는 조건이고, 지울 때는 복사본을 돌아요.

문장 속 단어 정리하기

문장을 단어로 쪼개고, 중복을 빼고, 정렬해서 다시 합치는 종합 코드예요.

text = '  the cat the dog  '  # text 에 앞뒤로 공백이 있는 문자열을 담아 주세요
words = text.strip().split()  # text 의 앞뒤 공백을 지우고 공백으로 잘라 words 에 담아 주세요
print(words)                  # words 를 화면에 보여 주세요
uniq = []                     # uniq 에 빈 리스트를 담아 주세요
for w in words:               # words 의 원소를 하나씩 w 라고 부르며 아래를 반복해 주세요
    if w not in uniq:         # 만약 w 가 uniq 안에 없으면
        uniq.append(w)        # uniq 의 맨 뒤에 w 를 붙여 주세요
print(uniq)                   # uniq 를 화면에 보여 주세요
uniq.sort()                   # uniq 를 순서대로 정렬해 주세요
print(uniq)                   # uniq 를 화면에 보여 주세요
print(' '.join(uniq[::-1]))   # uniq 를 거꾸로 읽어 공백으로 이어 붙인 것을 화면에 보여 주세요
print(len(words), len(uniq))  # words 의 원소 개수와 uniq 의 원소 개수를 화면에 보여 주세요
