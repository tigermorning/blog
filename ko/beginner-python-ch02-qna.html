2.1 while을 사용하는 반복문

문제 원문: wikidocs.net/56

while은 조건이 참인 동안 반복해요

while은 조건이 참인 동안 그 아래 들여쓴 코드를 반복해서 실행해요. 매번 반복하기 전에 조건부터 다시 검사해요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> num = 1            # num 에 1 을 담아 주세요
>>> while num <= 3:    # num 이 3 이하인 동안 아래를 반복해 주세요
...     print(num)     # num 을 화면에 보여 주세요
...     num = num + 1  # num 에 1 을 더한 값을 다시 담아 주세요
...
1
2
3

이 코드가 실행되는 순서를 표로 그리면 이래요.

몇 번째 검사이때 numnum <= 3 ?동작
11참1 출력, num을 2로
22참2 출력, num을 3으로
33참3 출력, num을 4로
44거짓반복 끝, 다음 줄로
  • while 조건: 뒤에는 콜론(:)이 꼭 있어야 해요. if도 마찬가지예요.
  • 몸통은 공백 4칸(또는 Tab 1번)으로 들여써요. 들여쓴 줄들이 "조건이 참인 동안 반복할 부분"이에요.
  • num = num + 1은 "num에 1을 더한 새 값을 다시 num에 넣어라"는 뜻이에요. num += 1로 줄여 써도 똑같이 동작해요.
  • 조건이 처음부터 거짓이면(예: num = 10으로 시작) 몸통은 한 번도 실행되지 않아요.

while과 if는 뭐가 다른가요? 둘 다 조건을 검사한다는 점은 같아요. if는 조건이 참이면 딱 한 번 실행하고 끝나지만, while은 조건이 참인 동안 계속 되돌아가서 다시 실행해요.

카운터 갱신을 빠뜨리면 무한 루프가 돼요

while은 조건만 보고 반복 여부를 정해요. 조건에 쓰인 값이 반복 중에 한 번도 안 바뀌면, 조건은 영원히 똑같은 결과를 내서 반복이 끝나지 않아요.

개념 설명용 코드 — 절대 실행하지 마세요. num이 계속 1이라 조건이 늘 참이에요

num = 1          # num 에 1 을 담아 주세요
while num <= 3:  # num 이 3 이하인 동안 아래를 반복해 주세요
    print(num)   # num 을 화면에 보여 주세요
    # num = num + 1 을 빠뜨림
  • 매번 검사할 때 num은 항상 1 → 1 <= 3은 항상 참 → 1을 영원히 찍음
  • 이런 코드를 실수로 실행했다면 터미널에서 Ctrl + C를 눌러 강제로 멈춰요

무한 루프를 피하는 원칙: while 몸통 안에는 조건에 쓰인 값을 바꾸는 줄이 최소 하나 있어야 하고, 그 값이 언젠가는 조건을 거짓으로 만들 수 있어야 해요. 카운터를 늘리다가 빼먹거나(num = num + 1 자리를 지워도, 들여쓰기를 잘못해서 while 밖으로 나가도) 같은 실수로 자주 생겨요.

실행: 파이썬 대화형 셸 — 들여쓰기가 잘못돼서 num이 while 밖에서만 바뀌는 예

num = 1          # num 에 1 을 담아 주세요
while num <= 3:  # num 이 3 이하인 동안 아래를 반복해 주세요
    print(num)   # num 을 화면에 보여 주세요
num = num + 1    # num 에 1 을 더한 값을 다시 담아 주세요
  • 마지막 줄이 while과 같은 위치까지 나와 있으면 몸통이 아니라 while이 끝난 뒤에 딱 한 번 실행되는 코드예요
  • 그러면 몸통 안에는 print(num)만 남아서 num이 영원히 1 → 무한 루프

2.1.1 연습 문제: 입력받은 숫자만큼 반복하기(while)

문제 원문: wikidocs.net/101633

반복 횟수를 세는 i와 출력할 값 num은 다른 변수예요

공식 풀이는 이래요.

num = int(input())  # 입력받은 글자를 정수로 바꿔 num 에 담아 주세요

i = 0               # i 에 0 을 담아 주세요
while i < num:      # i 가 num 보다 작은 동안 아래를 반복해 주세요
    print('', num)  # '' 와 num 을 화면에 보여 주세요
    i += 1          # i 에 1 을 더해 다시 담아 주세요

i와 num은 하는 일이 완전히 달라요.

변수역할반복 중 값이 바뀌나
num화면에 찍을 값 (입력받은 그 수 자체)안 바뀜
i몇 번 돌았는지 세는 카운터매번 1씩 늘어남

입력이 3일 때 흐름을 표로 그리면 이래요.

검사ii < num(3) ?출력다음 i
10참 31
21참 32
32참 33
43거짓(끝)-
  • num을 i < num 자리에도 쓰고 print(num) 자리에도 쓰지만, 세는 것과 찍는 것은 목적이 다른 일이라서 이름도 역할도 분리해요.
  • 만약 i 없이 num 하나로 세면서 동시에 출력하면, 출력할 값 자체가 줄어들어 버려서(예: 3, 2, 1) 원하는 결과가 안 나와요.
  • i, j, count는 "세는 용도의 변수"에 흔히 쓰는 이름이에요.

print('', num)의 빈 문자열은 공백을 만들어요

문제의 요구 사항이 "출력 앞에 공백을 한 칸 주어서 입력과 출력이 구분되게" 하는 것이었죠. print()에 쉼표로 여러 값을 넣으면 사이에 공백이 하나씩 자동으로 들어간다는 점(1장 기본 6)을 이용한 거예요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> print('', 3)  # '' 와 3 을 화면에 보여 주세요
 3
>>> print(3)      # 3 을 화면에 보여 주세요
3
  • print('', 3)은 빈 문자열 ''과 3을 쉼표로 나열한 것 → 그 사이에 공백 1칸이 끼어서 ' 3'처럼 보임
  • 빈 문자열 자체는 아무 글자도 없어서 화면에 아무것도 안 남기고, 오직 "공백을 만들기 위한 자리"로만 쓰임
  • print(' ', 3)처럼 써도 결과는 같아요. 다만 ' '은 공백 1칸을 담은 문자열이고 ''은 빈 문자열이라, 둘 다 그 자체로는 화면에 아무것도 안 보여준다는 점은 똑같아요.

비교: 앞에 붙이는 게 목적이면 문자열을 직접 이어 붙여 print(' ' + str(num))이라고 써도 같은 결과가 나와요. 다만 str(num)으로 숫자를 문자열로 바꿔야 +로 이어 붙일 수 있어요(1장 기본 4의 '3' + '4'처럼요).

2.1.2 연습 문제: 제곱표(while)

문제 원문: wikidocs.net/86465

카운터를 1부터 시작하고 <= num을 쓰는 이유

공식 풀이는 이래요.

num = int(input())   # 입력받은 글자를 정수로 바꿔 num 에 담아 주세요
i = 1                # i 에 1 을 담아 주세요
while i <= num:      # i 가 num 이하인 동안 아래를 반복해 주세요
    print(i, i * i)  # i 와 i * i 를 화면에 보여 주세요
    i = i + 1        # i 에 1 을 더한 값을 다시 담아 주세요

입력이 3일 때 1 1, 2 4, 3 9가 나와야 하죠. "1부터 num까지, num도 포함"이 목표라서 i = 1로 시작하고 조건도 <=(이하)를 써요.

ii <= 3 ?출력
1참1 1
2참2 4
3참3 9
4거짓(끝)

2.1.1의 리스트 인덱스(1장 기본 5)는 0부터 세지만, 이 문제의 "1부터 num까지의 수"는 사람이 세는 방식 그대로 1부터 세요. 0부터 세는 건 리스트 번호의 규칙이지, while의 규칙이 아니에요. 무엇을 세느냐에 따라 시작 값과 부등호를 맞추면 돼요.

나쁜 선택좋은 선택
1부터 num까지 다 돌리려고 i = 1로 시작하고 조건을 i < num으로 쓴다 → num 줄이 통째로 빠져요(입력 3이면 1, 2만 나옴). <=를 쓴다 → num까지 포함돼서 3줄이 정확히 나와요.

2.1.3 연습 문제: 얌체공

문제 원문: wikidocs.net/85687

곱셈을 반복하면 소수점 오차가 쌓이고, round()는 그걸 없애지 않아요

공식 풀이는 이래요.

height = 100                    # height 에 100 을 담아 주세요
bounce = 3 / 5                  # bounce 에 3 / 5 를 담아 주세요

i = 1                           # i 에 1 을 담아 주세요
while i <= 10:                  # i 가 10 이하인 동안 아래를 반복해 주세요
    height = height * bounce    # height 에 bounce 를 곱한 값을 다시 담아 주세요
    print(i, round(height, 4))  # i 와 height 를 소수 넷째 자리로 반올림한 값을 화면에 보여 주세요
    i = i + 1                   # i 에 1 을 더한 값을 다시 담아 주세요

round() 없이 그냥 찍으면 벌써 세 번째 줄부터 지저분한 값이 나와요.

실행: 파이썬 대화형 셸 — round() 없이 그대로 찍은 결과

>>> height = 100 * (3/5)     # height 에 100 * (3/5) 를 담아 주세요
>>> height                   # height 의 값은 얼마예요?
60.0
>>> height = height * (3/5)  # height 에 (3/5) 를 곱한 값을 다시 담아 주세요
>>> height                   # height 의 값은 얼마예요?
36.0
>>> height = height * (3/5)  # height 에 (3/5) 를 곱한 값을 다시 담아 주세요
>>> height                   # height 의 값은 얼마예요?
21.599999999999998
  • 컴퓨터는 소수를 2진수로 저장하는데, 0.6(3/5) 같은 수는 2진수로 딱 떨어지지 않아서 아주 작은 오차가 생겨요(1장 기본 6 질문과 해설의 float 오차와 같은 현상).
  • 이 오차를 가진 값을 다시 곱하는 계산에 또 쓰기 때문에, 반복할수록 오차가 조금씩 쌓여요(누적 오차).
  • round(height, 4)는 "이 값을 소수점 넷째 자리까지 반올림한 새로운 값을 화면에 보여 달라"는 뜻이에요. height 변수 자체를 깎아 내는 게 아니라 print()에 넘길 때만 반올림해요.

그래서 round()가 오차를 "없애는" 건 아니에요. 다음 계산에도 반올림 전의 height(오차 포함)가 그대로 쓰여요. round()는 "화면에 보여 줄 자릿수를 정리하는 것"이지 "저장된 값을 고치는 것"이 아니에요.

iround(height, 4) 출력

count = 3              # count 에 3 을 담아 주세요

됩니다. while은 "조건이 참인 동안 반복"할 뿐, 값이 커지든 작아지든 상관하지 않아요. 흐름을 표로 그려요.

countcount > 0 ?출력다음 count
3참32
2참21
1참10
0거짓(끝)-

정답은 "3 2 1이 각각 다른 줄에 출력"이에요. print()는 인자 하나만 넘기면 그 값을 찍고 줄바꿈까지 자동으로 해 주기 때문에, 세 번 호출하면 세 줄이 나와요. "한 줄에 출력"이 되려면 print(count, end=' ')처럼 줄바꿈 방식을 따로 바꿔야 하는데, 이건 2장 범위 밖이에요.

2.2 조건문(if-elif-else)

문제 원문: wikidocs.net/57

if/elif/else는 조건에 따라 블록을 골라요

if는 "조건이 참이면 이 블록을, 아니면 건너뛰어라"예요. else를 붙이면 "참이 아닐 때 대신 실행할 것"을 정할 수 있고, elif를 끼워 넣으면 조건을 여러 개 검사할 수 있어요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> a = 1234 * 4    # a 에 1234 * 4 를 담아 주세요
>>> b = 13456 / 2   # b 에 13456 / 2 를 담아 주세요

while True:는 break로 끝내요

True는 그 자체로 "항상 참"이에요. 그래서 while True:는 조건 검사 없이 무조건 도는 반복문이 돼요. 이걸 멈추려면 몸통 안에서 break로 직접 빠져나와야 해요.

    gen = 'a Gen X'                          # gen 에 'a Gen X' 를 담아 주세요

2.2.3 연습 문제: 단위 기호

큰 값부터 쓰는 elif 순서와 단위 기호

백만·10억 단위까지 확장한 공식 풀이는 이래요.

num = int(input())                                  # 입력받은 글자를 정수로 바꿔 num 에 담아 주세요

    result = str(num // 1000000000000) + 'T'        # result 에 num // 1000000000000 을 글자로 바꾸고 'T' 를 붙여 담아 주세요

    result = str(num // 1000000000) + 'G'           # result 에 num // 1000000000 을 글자로 바꾸고 'G' 를 붙여 담아 주세요
elif num >= 1000000:                                # 아니고, 만약 num 이 1000000 이상이면
    result = str(num // 1000000) + 'M'              # result 에 num // 1000000 을 글자로 바꾸고 'M' 을 붙여 담아 주세요
elif num >= 1000:                                   # 아니고, 만약 num 이 1000 이상이면
    result = str(num // 1000) + 'k'                 # result 에 num // 1000 을 글자로 바꾸고 'k' 를 붙여 담아 주세요
elif num >= 0:                                      # 아니고, 만약 num 이 0 이상이면
    pass                                            # 아무것도 하지 않고 넘어가 주세요

print(result)                                       # result 를 화면에 보여 주세요

result = str(num)이 왜 맨 위에 있을까요? 이건 "혹시 아래 elif 중 아무것도 안 걸리면 쓸 기본값"이에요. num이 1000 미만이면 어떤 elif도 참이 안 돼서 result는 이 첫 줄 값(원래 숫자를 글자로 바꾼 것) 그대로 출력돼요. input()은 애초에 글자를 돌려주지만(1장 해설), 여기 num은 이미 int()로 숫자가 된 뒤라서, 다시 글자로 합쳐 쓰려면 str()로 바꿔 둬야 해요.

E, P, T, G, M, k는 무슨 뜻인가요? 큰 수를 줄여 쓰는 단위 접두사(SI 접두어)예요. USB 용량 GB(기가바이트), 인터넷 속도 Mbps(메가)에 이미 쓰이는 그 접두사예요.

기호이름배수
k킬로(kilo)1,000 (10³)
M메가(mega)100만 (10⁶)
G기가(giga)10억 (10⁹)
T테라(tera)1조 (10¹²)
P페타(peta)1000조 (10¹⁵)
E엑사(exa)100경 (10¹⁸)

2.2.2와 반대로 보이지만 원칙은 똑같아요. elif 체인은 위에서부터 검사해 처음 참인 조건 하나만 쓴다는 규칙은 그대로고, 다만 이번엔 조건이 >=(이상)예요. >=는 "그 값과 그보다 큰 모든 값"을 잡기 때문에, 큰 경계부터 먼저 걸러내지 않으면 정말 큰 수도 제일 작은 조건(>= 1000)에 걸려 버려요.

지수(3, 6, 9, 12, 15, 18)가 3씩 늘어나는 걸 눈으로 바로 확인할 수 있어서, 0 개수를 세다 하나 빠뜨리는 실수를 줄여 줘요. 두 방식 모두 500, 1500, 2500000, 5000000000 같은 값에 똑같은 결과(500, 1k, 2M, 5G)를 내는 걸 직접 실행해 확인했어요.

핵심 한 줄(2.2.2와 이어서): elif 체인의 올바른 순서는 부등호 방향으로 정해져요 — <=는 작은 값부터, >=는 큰 값부터. 이 버그가 의심될 때 확인하는 법 ↓

pass는 아무 일도 안 하는 자리 표시예요

pass는 "여기서는 아무 일도 하지 않는다"는 뜻의 키워드예요. elif num >= 0: 조건이 참일 때(0 이상 1000 미만) 딱히 더 할 일이 없어요. 맨 위에서 이미 result = str(num)으로 기본값을 넣어 뒀기 때문이에요.

그런데 파이썬은 if, elif, while 같은 블록 뒤에 반드시 실행할 코드가 하나 이상 있어야 해요. 아무것도 안 쓰면 에러가 나요.

  • 나중에 이 자리에 코드를 채울 계획이라는 표시로도 자주 써요.
  • pass 자체는 실행돼도 프로그램 상태를 전혀 바꾸지 않아요.

조건을 elif 0 <= num < 1000:처럼 범위로 다 쓰면 더 정확하지 않나요? 결과는 똑같아요. elif에 도착했다는 것 자체가 이미 "위의 if·elif들이 전부 거짓이었다"는 뜻이라서, 여기서는 num < 1000이 이미 보장돼 있어요. 그래서 num >= 0만 써도 0 <= num < 1000과 같은 뜻이 돼요. 아래 걸로 직접 실행해 두 방식이 모든 경우에 같은 값을 내는 걸 확인했어요.

-5   -> -5    (두 방식 동일)
0    -> 0     (두 방식 동일)
999  -> 999   (두 방식 동일)
1000 -> 1k    (두 방식 동일)

elif 체인에서 이미 걸러진 조건을 다시 쓰는 건 틀린 게 아니라 중복이에요. 앞에서 본 "elif는 위에서부터 검사해 하나 걸리면 나머지는 안 본다"는 규칙을 거꾸로 이용하면, 뒤쪽 elif일수록 조건을 짧게 쓸 수 있어요.

2.2.5 연습 문제: 윤년 판별하기

문제 원문: wikidocs.net/88691

중첩 if는 층이 있는 규칙을 그대로 따라가요

공식 풀이는 이래요.

is_leap_year = None                      # is_leap_year 에 None 을 담아 주세요

year = int(input())                      # 입력받은 글자를 정수로 바꿔 year 에 담아 주세요

if year % 4 == 0:                        # 만약 year 를 4 로 나눈 나머지가 0 이면
    if year % 100 == 0:                  # 만약 year 를 100 으로 나눈 나머지가 0 이면
        if year % 400 == 0:              # 만약 year 를 400 으로 나눈 나머지가 0 이면
            is_leap_year = True          # is_leap_year 에 True 를 담아 주세요
        else:                            # 그 밖의 경우에는
            is_leap_year = False         # is_leap_year 에 False 를 담아 주세요
    else:                                # 그 밖의 경우에는
        is_leap_year = True              # is_leap_year 에 True 를 담아 주세요
else:                                    # 그 밖의 경우에는
    is_leap_year = False                 # is_leap_year 에 False 를 담아 주세요

if is_leap_year:                         # 만약 is_leap_year 가 참이면
    print(f'{year} is a leap year')      # f'{year} is a leap year' 를 화면에 보여 주세요
else:                                    # 그 밖의 경우에는
    print(f'{year} is not a leap year')  # f'{year} is not a leap year' 를 화면에 보여 주세요

중첩 if는 if 블록 안에 또 다른 if를 넣는 거예요. "4로 나누어떨어지는 것들 중에서, 다시 100으로 나누어떨어지는 것들 중에서, 다시 400으로 나누어떨어지는지"처럼 조건이 조건 안에 겹겹이 들어있을 때 자연스럽게 나오는 모양이에요. 규칙 자체가 "4의 배수인가 → (맞다면) 그중 100의 배수인가 → (맞다면) 그중 400의 배수인가"로 층이 있어서, 코드도 층을 그대로 따라가요.

직접 실행해서 네 가지 경우를 다 확인했어요.

실행: 파이썬 대화형 셸 — 규칙의 네 갈래를 각각 대표하는 연도

2000 -> 2000 is a leap year
1900 -> 1900 is not a leap year
2024 -> 2024 is a leap year
2023 -> 2023 is not a leap year
  • 바깥 if year % 4 == 0:이 거짓이면 안쪽 if들은 아예 검사조차 하지 않고 바로 else(평년)로 가요.
  • is_leap_year 변수에 결과(True/False)만 담아 두고, 메시지 출력은 맨 아래에서 한 번만 하도록 나눠 놨어요. "판단"과 "출력"을 분리한 셈이에요.
  • 같은 로직을 and로 한 줄에 풀어 쓰는 법은 바로 다음 절 2.2.7(and/or 연산자)에서 다뤄요.

f와 { }는 f-string이에요

f는 문자열 앞에 붙이는 표시(접두사)예요. 이 표시가 있으면 문자열 안의 { }에 넣은 변수가 그 값으로 바뀌어 들어가요. 이런 문자열을 f-string이라고 불러요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> year = 2024                      # year 에 2024 를 담아 주세요
>>> print(f'{year} is a leap year')  # f'{year} is a leap year' 를 화면에 보여 주세요
2024 is a leap year
>>> print('{year} is a leap year')   # '{year} is a leap year' 를 화면에 보여 주세요
{year} is a leap year
  • f가 붙은 줄은 {year} 자리에 year의 값 2024를 넣어요.
  • f가 없는 줄은 {year}를 글자 그대로 찍어요. 따옴표로 감싼 문자열 바로 앞에 f가 붙어야만 f-string이에요. f 혼자 쓰면 그냥 f라는 이름의 변수로 읽혀요.

str()과 뭐가 다른가요? str()은 숫자 하나를 문자열로 바꿔 주는 변환 함수고, f-string은 그 변환과 다른 글자와 이어 붙이는 것까지 한 번에 해 줘요.

str()f-string
하는 일숫자 → 문자열 변환만변환 + 다른 글자와 조립까지
year = 2024일 때str(year) → '2024'f'{year}년' → '2024년'

f-string 없이 str()만으로 같은 결과를 만들려면 +로 직접 이어 붙여야 해요.

>>> print(str(year) + ' is a leap year')  # year 를 글자로 바꿔 ' is a leap year' 와 이어 화면에 보여 주세요
2024 is a leap year

즉 f'{year} is a leap year'는 str(year) + ' is a leap year'를 줄여 쓴 것과 같아요. { } 안에 값을 넣으면 파이썬이 str()과 비슷한 변환을 자동으로 해 주기 때문에, str()과 +를 직접 안 써도 돼요.

괄호 세 종류를 한 번에 정리하면 이래요. 지금까지 나온 소괄호 (), 대괄호 []와 헷갈리기 쉬워요.

괄호이 교재에서 쓰인 곳예
소괄호 ()함수 호출, 식 순서 묶기int(input()), (a + b) * c
대괄호 []리스트, 인덱싱·슬라이싱L[0] (아래 split 해설)
중괄호 { }f-string 안에서 값 넣는 자리f'{year}년'

참고로 중괄호는 딕셔너리(이름표와 값을 짝지어 담는 자료형, 예: {'name': '김철수'})를 만들 때도 쓰는데, 딕셔너리는 이 교재 2장 범위 밖이라 여기서는 f-string 용법만 기억해 두면 충분해요.

핵심 한 줄: f는 따옴표 문자열 앞에 붙어야 뜻이 있고, 그 안 { }에 변수를 넣으면 값으로 바뀌어요. str()이 "숫자를 글자로 바꾸는 도구"라면, f-string은 "바꾸면서 동시에 다른 글자와 합치는 지름길"이에요.

2.2.6 연습 문제: 화학 실험실

문제 원문: wikidocs.net/99692

split()으로 나눈 값을 두 변수에 나눠 담기

공식 풀이의 앞부분이에요.

L = input().split()  # 입력받은 글을 공백으로 쪼개 L 에 담아 주세요
min = int(L[0])      # L[0] 을 정수로 바꿔 min 에 담아 주세요
max = int(L[1])      # L[1] 을 정수로 바꿔 max 에 담아 주세요
# min, max = map(int, input().split())

split()은 문자열을 공백 기준으로 잘라 리스트로 돌려줘요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> '10 20'.split()  # '10 20' 을 공백으로 쪼개면 뭐가 되나요?
['10', '20']

이 풀이는 리스트를 만든 뒤 L[0], L[1]로 인덱싱해서(1장 해설) 각각 정수로 바꿔요. 주석으로 남겨 둔 둘째 줄은 다른 방법이에요.

>>> min, max = map(int, '10 20'.split())  # '10 20' 을 쪼개 정수로 바꿔 min 과 max 에 담아 주세요
>>> min                                   # min 의 값은 얼마예요?
10
>>> max                                   # max 의 값은 얼마예요?
20
  • map(int, 리스트)는 리스트의 원소 하나하나에 int()를 적용해 줘요. ['10', '20'] → 10, 20
  • min, max = ...처럼 왼쪽에 이름을 여러 개 쓰면, 오른쪽 값의 개수와 순서를 맞춰 한 번에 나눠 담아요. 1장 상급 8에서 본 divmod() 언패킹과 같은 문법이에요.
  • 원소 개수가 정확히 정해져 있을 때(여기서는 항상 2개)만 이렇게 바로 나눠 담을 수 있어요. 개수가 몇 개일지 모르면 for 문으로 하나씩 꺼내야 해요.

변수 이름 주의: 여기서 쓴 min, max도 sum처럼 파이썬 내장 함수 이름이에요. 자세한 이유는 sum 변수 이름 해설을 참고하세요.

min <= temp <= max처럼 부등호를 연달아 써도 돼요

됩니다. 파이썬은 이런 연쇄 비교(chained comparison)를 지원해요. min <= temp <= max는 "temp가 min 이상이면서 동시에 max 이하"라는 뜻이에요.

실행: 파이썬 대화형 셸 — 터미널에서 python을 입력하면 열려요

>>> 10 <= 15 <= 20  # 15 가 10 이상 20 이하인가요?
True
>>> 10 <= 25 <= 20  # 25 가 10 이상 20 이하인가요?
False

수학에서 10 ≤ 15 ≤ 20이라고 쓰는 것과 똑같은 모양이에요. 풀어 쓰면 (min <= temp) and (temp <= max)와 같은 뜻인데, and는 2.2.7에서 배우니 지금은 "부등호 두 개를 나란히 쓰면 범위를 한 번에 검사할 수 있다"는 것만 기억해도 충분해요.

-999 같은 신호 값으로 반복을 끝내는 이유

공식 풀이 전체예요.

L = input().split()                 # 입력받은 글을 공백으로 쪼개 L 에 담아 주세요
min = int(L[0])                     # L[0] 을 정수로 바꿔 min 에 담아 주세요
max = int(L[1])                     # L[1] 을 정수로 바꿔 max 에 담아 주세요

temp = int(input())                 # 입력받은 글자를 정수로 바꿔 temp 에 담아 주세요

while temp != -999:                 # temp 가 -999 가 아닌 동안 아래를 반복해 주세요
    if min <= temp <= max:          # 만약 temp 가 min 이상 max 이하이면
        print('Nothing to report')  # 'Nothing to report' 를 화면에 보여 주세요
        temp = int(input())         # 입력받은 글자를 정수로 바꿔 temp 에 담아 주세요
    else:                           # 그 밖의 경우에는
        print('Alert!')             # 'Alert!' 를 화면에 보여 주세요
        break                       # 반복을 멈추고 빠져나와 주세요

-999는 온도로는 절대 나올 리 없는 값을 "그만 보내겠다"는 신호로 약속한 거예요. 이런 값을 센티널 값(sentinel value)이라고 불러요. 2.2.4의 "음수면 그만"과 비슷한 발상인데, 여기서는 정상적인 온도가 음수일 수도 있어서(영하 온도) 아예 있을 수 없는 -999를 약속 값으로 정한 거예요.

예 1(최소 10, 최대 20 / 온도 15, 10, 20, 0, 15, -999)을 표로 따라가요.

temptemp != -999 ?10 <= temp <= 20 ?출력
15참참Nothing to report
10참참Nothing to report
20참참Nothing to report
0참거짓Alert! (break로 종료)
  • while의 조건(temp != -999)은 "정상 종료 신호가 왔는가"만 검사해요.
  • 범위를 벗어난 경우(Alert!)는 while 조건과 별개로 break가 직접 끊어요. 그래서 장치가 -999를 보내기 전이라도 위험하면 즉시 멈출 수 있어요.
  • 온도를 계속 읽는 줄(temp = int(input()))이 if 블록 안에만 있다는 점도 중요해요 — 정상일 때만 다음 값을 읽고, 위험하면 더 안 읽고 바로 끝나요.

이럴 때 의심하세요 — 2장 문법으로 짠 코드의 결과가 이상할 때

아래 문제들은 에러 없이 조용히 틀리거나, 아예 멈추지 않는 경우가 많아요. 결과가 예상과 다르면 이 표부터 확인해요.

이런 증상이 보이면먼저 열어 볼 자리확인 방법
프로그램이 안 끝나고 화면에 같은 내용이 계속 찍히거나, 아무 반응 없이 멈춘 것처럼 보여요 while 몸통 안에서 조건에 쓰인 변수를 바꾸는 줄 그 변수가 반복마다 실제로 값이 바뀌는지, 들여쓰기가 while 몸통 안에 제대로 들어가 있는지 봐요 (무한 루프 해설)
등급·단위 같은 결과가 조용히 틀리게 나와요 (큰 수인데 작은 단위로, 젊은 나이인데 늙은 세대로) elif 체인의 조건 순서 조건이 <=면 작은 값부터, >=면 큰 값부터 쓰여 있는지 확인해요 (작은 값부터 쓰는 이유, 큰 값부터 쓰는 경우)
sum(), min(), max() 같은 함수를 불렀는데 TypeError: 'int' object is not callable이 나요 같은 이름을 변수로 먼저 만든 적이 있는지 그 위에서 sum = ..., min = ... 같은 대입이 있었는지 찾아 total, lo 같은 이름으로 바꿔요 (내장 함수 이름 해설)
