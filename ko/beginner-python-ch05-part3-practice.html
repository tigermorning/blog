5.3.6 기본기 — datetime 하나씩

datetime 만들기, 날짜 차이, strftime, strptime, timedelta 를 한 문제에 한 가지씩 확인해요.

초급 1읽기

날짜 만들기

datetime(연, 월, 일, 시, 분)으로 날짜·시각을 만들어요. 시·분·초를 생략하면 어떻게 보일까요?

from datetime import datetime  # datetime 모듈에서 datetime 을 가져와 주세요

d1 = datetime(2024, 2, 27, 12, 30)  # d1 에 2024년 2월 27일 12시 30분을 담아 주세요
d2 = datetime(2024, 2, 27)          # d2 에 2024년 2월 27일을 담아 주세요
print(d1)                           # d1 을 화면에 보여 주세요
print(d2)                           # d2 를 화면에 보여 주세요
print(type(d1))                     # d1 의 자료형을 화면에 보여 주세요

생략한 시·분·초는 0으로 채워져요. 출력 모양은 "연-월-일 시:분:초"예요.

정답·해설 보기

한 문장으로: datetime 객체를 출력하면 시·분·초까지 항상 "연-월-일 시:분:초" 모양으로 나와요.

줄일어나는 일
5번째 줄12시 30분, 초는 생략해 00
6번째 줄시각을 생략하면 자정(00:00:00)
7번째 줄자료형 이름은 모듈 이름까지 붙은 datetime.datetime

from datetime import datetime은 "datetime 모듈에서 datetime 이라는 이름을 가져와요"라는 뜻이에요. 앞의 것은 모듈, 뒤의 것은 그 안의 자료형이라 이름이 같아 헷갈려요.

핵심 한 줄: datetime(연, 월, 일, …)으로 만들고 안 쓴 시·분·초는 0이에요.

초급 2읽기

날짜 차이와 윤년

같은 "2월 27일 ~ 3월 5일"인데 해가 달라요. 두 차이는 같을까요?

from datetime import datetime  # datetime 모듈에서 datetime 을 가져와 주세요

a = datetime(2024, 2, 27)  # a 에 2024년 2월 27일을 담아 주세요
b = datetime(2024, 3, 5)   # b 에 2024년 3월 5일을 담아 주세요
print(b - a)               # b 에서 a 를 뺀 기간을 화면에 보여 주세요
c = datetime(2023, 2, 27)  # c 에 2023년 2월 27일을 담아 주세요
d = datetime(2023, 3, 5)   # d 에 2023년 3월 5일을 담아 주세요
print(d - c)               # d 에서 c 를 뺀 기간을 화면에 보여 주세요
print(type(b - a))         # b - a 의 자료형을 화면에 보여 주세요

2024년과 2023년 중 2월이 29일까지 있는 해는 어느 쪽일까요?

정답·해설 보기 
7 days, 0:00:00
6 days, 0:00:00
<class 'datetime.timedelta'>

한 문장으로: datetime 두 개를 빼면 기간(timedelta)이 나오고, 윤년의 2월 29일이 자동으로 센 값에 들어가요.

줄일어나는 일
5번째 줄윤년인 2024년은 2월 27일 → 29일(2일), 3월 1일 → 5일(5일)로 7 days
8번째 줄2023년은 2월이 28일까지라 6 days
9번째 줄기간 자료형 timedelta

기간은 "7 days, 0:00:00"처럼 "일수, 시:분:초" 모양으로 나와요. 교재 5.3.6의 같은 예제 주석에는 6 days 로 적혀 있지만, 실제로 돌리면 2024년은 7 days 예요.

핵심 한 줄: datetime 두 개를 빼면 timedelta가 되고 윤년이 반영돼요.

초급 3읽기

날짜를 글자로 — strftime

형식 글자를 바꿔 같은 날짜를 여러 모양으로 찍어요.

from datetime import datetime  # datetime 모듈에서 datetime 을 가져와 주세요

d = datetime(2024, 2, 27, 0, 53, 38)    # d 에 2024년 2월 27일 0시 53분 38초를 담아 주세요
print(d.strftime('%Y-%m-%d %H:%M:%S'))  # d 를 '연-월-일 시:분:초' 글자로 바꿔 화면에 보여 주세요
print(d.strftime('%B %d, %Y'))          # d 를 '월이름 일, 연' 글자로 바꿔 화면에 보여 주세요
print(d.strftime('%m/%d/%Y'))           # d 를 '월/일/연' 글자로 바꿔 화면에 보여 주세요
print(d.strftime('%d.%m'))              # d 를 '일.월' 글자로 바꿔 화면에 보여 주세요

%Y 연도, %m 월, %d 일, %H 시, %M 분, %S 초, %B 월 이름이에요. 형식 글자 사이의 -, :, /는 그대로 찍혀요.

정답·해설 보기 
2024-02-27 00:53:38
February 27, 2024
02/27/2024
27.02

한 문장으로: strftime은 형식 글자만 날짜 값으로 바꾸고 나머지 글자는 그대로 두어서, 형식을 바꾸면 같은 날짜가 다른 모양이 돼요.

줄일어나는 일
4번째 줄2024-02-27 00:53:38
5번째 줄월 이름 February, 일 27, 연도 2024
6번째 줄월이 먼저 오는 미국식 날짜
7번째 줄일이 먼저 오고 점으로 이은 모양

%m과 %d는 한 자리 수를 두 자리로 채워요(2월 → 02). %B의 월 이름은 컴퓨터의 언어 설정에 따라 영어가 아닐 수 있어요.

핵심 한 줄: strftime('형식')은 형식 글자만 값으로 바꾸고 나머지는 그대로 둬요.

초급 4읽기

글자를 날짜로 — strptime

strptime은 글자를 읽어서 날짜로 만들어요. 읽을 글자의 모양과 형식이 맞아야 해요.

from datetime import datetime  # datetime 모듈에서 datetime 을 가져와 주세요

text = '27 February, 2024'                # text 에 '27 February, 2024' 를 담아 주세요
d = datetime.strptime(text, '%d %B, %Y')  # d 에 text 를 '일 월이름, 연' 모양으로 읽어 날짜로 만들어 담아 주세요
print(d)                                  # d 를 화면에 보여 주세요
print(type(text), type(d))                # text 와 d 의 자료형을 화면에 보여 주세요
print(d.strftime('%Y/%m/%d'))             # d 를 '연/월/일' 글자로 바꿔 화면에 보여 주세요

text는 글자(str), d는 날짜 값이에요. 출력할 때 시·분·초는 어떻게 보일까요?

정답·해설 보기

한 문장으로: strptime이 글자를 날짜로 읽어서, 읽은 뒤에는 글자가 아니라 날짜 값이에요. 시각이 없던 글자라 자정으로 채워져요.

줄일어나는 일
5번째 줄시각이 없던 글자라 00:00:00
6번째 줄원래 글자는 str, 읽은 결과는 datetime.datetime
7번째 줄날짜를 다시 글자로 바꾼 모양

글자와 형식이 어긋나면 ValueError가 나요. 예를 들어 위 글자를 '%Y-%m-%d' 형식으로 읽으면 오류예요.

핵심 한 줄: strptime(글자, 형식)은 글자를 날짜로 읽어요.

초급 5읽기

timedelta로 더하고 빼기

시각에 일·시간·분을 더하고 빼요. 날짜가 바뀌는 곳을 눈여겨보세요.

from datetime import datetime, timedelta  # datetime 모듈에서 datetime 과 timedelta 를 가져와 주세요

d = datetime(2024, 2, 27, 12, 0)  # d 에 2024년 2월 27일 12시를 담아 주세요
print(d + timedelta(days=7))      # d 에 7일을 더해 화면에 보여 주세요
print(d - timedelta(days=1))      # d 에서 1일을 빼 화면에 보여 주세요
print(d - timedelta(hours=36))    # d 에서 36시간을 빼 화면에 보여 주세요
print(d + timedelta(minutes=90))  # d 에 90분을 더해 화면에 보여 주세요

36시간은 1일 12시간이에요. 2024년 2월은 29일까지 있어요.

정답·해설 보기 
2024-03-05 12:00:00
2024-02-26 12:00:00

2024-02-27 13:30:00

한 문장으로: timedelta를 더하고 빼면 날짜와 시각이 함께 움직이고, 달이 바뀌는 것도 알아서 계산돼요.

줄일어나는 일
4번째 줄2월 27일 + 7일. 29일까지 2일, 3월 5일(2024-03-05 12:00:00)
5번째 줄하루 전은 2월 26일 12시
6번째 줄하루 12시간 전이라 2월 26일 0시
7번째 줄1시간 30분 뒤라 13시 30분

timedelta는 days, hours, minutes, seconds를 같이 쓸 수 있어요(timedelta(days=1, hours=3)).

핵심 한 줄: 날짜 ± timedelta(…)로 기간을 더하고 빼요.

초급 이어 쓰기 — 한 걸음 더

중급 1읽기

윤년 경계의 다음 날

2월 28일의 다음 날을 세 해에 대해 구해요. 세 번째 해는 100의 배수라서 함정이에요.

from datetime import datetime, timedelta  # datetime 모듈에서 datetime 과 timedelta 를 가져와 주세요

for y in (2024, 2023, 2100):                    # 연도들을 하나씩 y 라고 부르며 아래를 반복해 주세요
    d = datetime(y, 2, 28) + timedelta(days=1)  # d 에 y 년 2월 28일의 하루 뒤를 담아 주세요
    print(d.strftime('%m/%d/%Y'))               # d 를 '월/일/연' 글자로 바꿔 화면에 보여 주세요

윤년은 4의 배수이고, 100의 배수는 윤년이 아니에요. 단 400의 배수는 윤년이에요.

정답·해설 보기

한 문장으로: datetime이 윤년 규칙(4의 배수, 단 100의 배수는 제외, 400의 배수는 다시 포함)을 알아서 적용해요.

줄일어나는 일
3번째 줄연도 세 개를 차례로 돌아요
4번째 줄2024는 윤년이라 2월 29일, 2023은 평년이라 3월 1일, 2100은 400의 배수가 아니라 평년이라 3월 1일

직접 만든 달력 계산은 "4의 배수는 윤년"까지만 구현하고 100의 배수를 놓치기 쉬워요. 날짜 계산은 직접 짜기보다 datetime을 믿는 편이 안전해요.

핵심 한 줄: 윤년 규칙은 datetime이 알아서 적용해요.

중급 2읽기

남은 날과 걸린 시간

두 시각을 빼서 기간을 구하고, 그 기간을 다시 더해서 원래 시각으로 돌아가요.

from datetime import datetime  # datetime 모듈에서 datetime 을 가져와 주세요

today = datetime(2024, 10, 26)  # today 에 2024년 10월 26일을 담아 주세요
xmas = datetime(2024, 12, 25)   # xmas 에 2024년 12월 25일을 담아 주세요
left = xmas - today             # left 에 xmas 에서 today 를 뺀 기간을 담아 주세요
print(left)                     # left 를 화면에 보여 주세요
print(today + left)             # today 에 left 를 더해 화면에 보여 주세요

start = datetime(2024, 3, 1, 9, 30)  # start 에 2024년 3월 1일 9시 30분을 담아 주세요
end = datetime(2024, 3, 1, 18, 0)    # end 에 2024년 3월 1일 18시를 담아 주세요
print(end - start)                   # end 에서 start 를 뺀 기간을 화면에 보여 주세요

이 코드를 실행하면 무엇이 출력될까요?

출력예측
1번째 줄?
2번째 줄?

힌트 보기

10월 26일 → 11월 26일이 31일, 11월 26일 → 12월 25일이 29일이에요. 같은 날 안의 시각 차이는 "일" 없이 시:분:초로만 나와요.

정답·해설 보기 
60 days, 0:00:00
2024-12-25 00:00:00
8:30:00

한 문장으로: timedelta는 "더하면 원래 값으로 돌아가는 기간"이라서, 빼서 얻은 기간을 시작점에 더하면 끝점이 돼요.

줄일어나는 일
6번째 줄31일 + 29일 = 60일
7번째 줄시작에 기간을 더하니 끝 날짜 12월 25일
11번째 줄9시 30분에서 18시까지 8시간 30분. 일 부분이 0이면 days는 생략돼요

기간이 1일 미만이면 8:30:00처럼 시:분:초만 나오고, 1일 이상이면 60 days, 0:00:00처럼 일수가 앞에 붙어요.

핵심 한 줄: 빼서 얻은 timedelta를 시작점에 더하면 끝점이 돼요.

중급 3읽기

두음법칙으로 이을 수 있나

끝 글자에 두음법칙을 적용한 글자도 허용하는 판정 함수예요. 각 줄은 앞 말에 뒷말을 이을 수 있는지 물어요.

RULE = {'량': '양', '리': '이', '녀': '여'}  # RULE 에 두음법칙으로 바뀌는 글자 짝을 담은 딕셔너리를 담아 주세요

def can_follow(last, word):                             # last 와 word 를 받는 can_follow 라는 동작을 만들어 주세요
    allowed = {last[-1], RULE.get(last[-1], last[-1])}  # allowed 에 last 의 끝 글자와 그 글자가 바뀐 글자를 세트로 담아 주세요
    return word[0] in allowed                           # word 의 첫 글자가 allowed 에 있는지를 결과로 돌려주세요

print(can_follow('차량', '양심'))  # '차량' 뒤에 '양심' 을 이을 수 있는지 화면에 보여 주세요

고급 3읽기

한글 글자 쪼개기

한글 한 글자를 초성·모음·받침 번호로 쪼개 두음법칙으로 바뀔 글자를 구해요. 초성 번호 5는 ㄹ, 2는 ㄴ, 11은 ㅇ이고, YO의 번호는 ㅑ·ㅒ·ㅕ·ㅖ·ㅛ·ㅠ·ㅣ의 모음이에요.

YO = (2, 3, 6, 7, 12, 17, 20)  # YO 에 ㅑ ㅒ ㅕ ㅖ ㅛ ㅠ ㅣ 의 모음 번호를 담아 주세요

def starts(ch):                                               # ch 를 받는 starts 라는 동작을 만들어 주세요
    result = {ch}                                             # result 에 ch 자신이 든 세트를 담아 주세요
    code = ord(ch) - 0xAC00                                   # code 에 ch 의 글자 번호에서 '가' 의 번호를 뺀 값을 담아 주세요
    first = code // 588                                       # first 에 초성 번호를 담아 주세요
    vowel = code % 588 // 28                                  # vowel 에 모음 번호를 담아 주세요
    tail = code % 28                                          # tail 에 받침 번호를 담아 주세요
    if first == 5:                                            # 만약 초성이 ㄹ 이면
        new = 11 if vowel in YO else 2                        # new 에 (모음이 YO 에 있으면 ㅇ, 아니면 ㄴ) 의 초성 번호를 담아 주세요
    elif first == 2 and vowel in YO:                          # 아니고 만약 초성이 ㄴ 이고 모음이 YO 에 있으면
        new = 11                                              # new 에 ㅇ 의 초성 번호를 담아 주세요
    else:                                                     # 그 밖에는
        return result                                         # result 를 결과로 돌려주세요
    result.add(chr(0xAC00 + (new * 21 + vowel) * 28 + tail))  # result 에 초성만 new 로 바꾼 글자를 더해 주세요
    return result                                             # result 를 결과로 돌려주세요

for ch in '량녀라차':              # 글자들을 하나씩 ch 라고 부르며 아래를 반복해 주세요
    print(ch, sorted(starts(ch)))  # ch 와 ch 로 이을 수 있는 첫 글자들을 정렬해 화면에 보여 주세요

9번째 줄량은 ㄹ + ㅑ(YO 에 있음)라 ㅇ 으로 바뀌어 양, 라는 ㄹ + ㅏ(YO 에 없음)라 ㄴ 으로 바뀌어 나
