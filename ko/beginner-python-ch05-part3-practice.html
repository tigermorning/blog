import로 가져온 datetime은 모듈이에요. 그 안의 datetime은 날짜 값을 만드는 틀(클래스)이고, 틀로 만든 d는 날짜 값이에요.

정답·해설 보기 
<class 'module'>
2025-07-04 00:00:00
<class 'type'>
<class 'datetime.datetime'>

한 문장으로: import 모듈로 가져오면 앞의 datetime은 모듈이고, 그 안의 datetime은 날짜 값을 만드는 틀이며, 틀로 만든 값이 d예요. 같은 글자가 세 단계에 겹쳐 나오는 것이 이 문제의 함정이에요.

먼저 알아 둘 기본

  • 모듈(module)은 관련된 기능을 파일 하나로 모아 둔 "도구 상자"예요. datetime 모듈에는 날짜와 시간을 다루는 도구가 모여 있어요.
  • import 모듈이름은 그 상자를 통째로 가져와요. 상자 안의 도구는 점(.)으로 꺼내요. 점 앞은 상자, 점 뒤는 상자 안의 도구예요.
  • type(값)은 값이 어떤 종류인지 알려 줘요. 정수는 int, 글자는 str, 모듈은 module이라고 나와요.
  • datetime 모듈 안에는 같은 이름 datetime인 도구가 있어요. 날짜 값을 만들어 내는 틀(클래스)이에요. 붕어빵 틀이 붕어빵을 찍어 내듯, 틀에 연·월·일을 넣으면 날짜 값이 하나 나와요.
  • print(값)에 날짜 값을 넣으면 "연-월-일 시:분:초" 모양으로 나와요. 시·분·초를 안 적으면 0으로 채워져요.

3번째 줄print(type(datetime))지금 이름 datetime은 모듈을 가리켜요. 모듈의 자료형은 module이라서 <class 'module'>이 나와요.
4번째 줄d = datetime.datetime(2025, 7, 4)점 앞 datetime은 모듈, 점 뒤 datetime은 그 안의 틀이에요. 틀에 2025, 7, 4를 넣어 날짜 값을 만들고 d에 담아요. 시·분·초를 안 적었으니 0시 0분 0초예요.

왜 이런 결과가 나올까요

결과를 순서대로 놓으면 module → type → datetime.datetime이에요. 모듈 ⊃ 틀 ⊃ 값, 즉 "도구 상자 안에 틀이 있고, 틀로 값을 만든다"는 세 단계예요.

같은 글자 datetime이 서로 다른 것을 가리켜요.

쓴 모양가리키는 것자료형
datetime모듈(도구 상자)module
datetime.datetime모듈 안의 틀type
d틀로 만든 날짜 값datetime.datetime

헷갈리기 쉬운 곳

  • datetime(2025, 7, 4)처럼 점 없이 쓰면 모듈 자체를 함수처럼 부르는 셈이라 TypeError가 나요(메시지: 'module' object is not callable). 날짜 값을 만들려면 datetime.datetime(…)이에요.
  • datetime.now()처럼 쓰면 AttributeError가 나요(메시지: module 'datetime' has no attribute 'now'). now()는 모듈이 아니라 틀 datetime.datetime이 가진 기능이라 datetime.datetime.now()라고 써야 해요.
  • type(datetime.datetime)이 type으로 나오는 건 이상한 게 아니에요. "틀의 종류는 type"이라는 규칙이니, 지금은 그렇게 나온다고만 알아 두세요.

정답·해설 보기

한 문장으로: from datetime import datetime을 하면 datetime이라는 이름이 모듈에서 날짜 틀로 바뀌어서, 같은 이름으로 모듈 안의 다른 도구를 더는 꺼낼 수 없어요.

먼저 알아 둘 기본

  • 이름은 값에 붙이는 꼬리표예요. x = 1을 한 뒤 x = 2를 하면 꼬리표 x는 2에 붙고 1과의 연결은 끊겨요. import도 "이름을 만들어 연결하는" 일이라 같은 규칙이 적용돼요.
  • import datetime: 이름 datetime이 모듈에 붙어요. 안의 도구는 datetime.datetime, datetime.timedelta처럼 점으로 꺼내요.
  • from datetime import datetime: 모듈 안의 틀 datetime만 꺼내 와서 이름 datetime이 틀에 붙어요. 바로 datetime(2025, 7, 4)처럼 써요.
  • 가져오는 방식쓰는 모양이름 datetime이 가리키는 것
    import datetimedatetime.datetime(…)모듈
    from datetime import datetimedatetime(…)날짜 틀

5번째 줄print(type(datetime))이제 datetime은 틀이라 틀의 자료형 <class 'type'>이 나와요. 두 번째 줄과 결과가 달라진 것이 이름이 바뀐 증거예요.

왜 이런 결과가 나올까요

같은 이름에 다시 연결하면 앞의 것이 가려진다는 것이 핵심이에요. 4번째 줄 뒤에는 datetime.timedelta가 더는 모듈 안의 timedelta를 뜻하지 않아요. datetime이 이제 틀을 가리키니, 틀 안에서 timedelta를 찾게 되기 때문이에요.

한 파일에서는 import datetime과 from datetime import datetime 중 한 가지 방식만 쓰는 것이 안전해요. 두 방식을 섞으면 이름이 겹쳐서 읽기도 어렵고 오류도 나요.

헷갈리기 쉬운 곳

  • 4번째 줄 뒤에 datetime.timedelta를 쓰면 AttributeError가 나요(메시지: type object 'datetime.datetime' has no attribute 'timedelta'). 틀 안에는 timedelta가 없기 때문이에요.
  • 이름을 덮어쓰는 일은 datetime에만 있는 게 아니에요. 나중에 가져온(또는 나중에 대입한) 이름이 앞의 같은 이름을 가려요.
  • 오류가 나지 않고 조용히 다른 것을 가리키는 경우가 더 위험해요. 이름이 겹칠 수 있을 때는 아래처럼 별명을 붙이면 안전해요.

초급 3읽기

timedelta 안의 값 꺼내기

timedelta는 기간을 담는 값이에요. 기간 안에서 일수, 초 같은 부분을 따로 꺼낼 수 있어요.

from datetime import timedelta              # datetime 모듈에서 timedelta 를 가져와 주세요

t = timedelta(days=1, hours=2, minutes=30)  # t 에 1일 2시간 30분의 기간을 담아 주세요
print(t)                                    # t 를 화면에 보여 주세요
print(t.days)                               # t 의 days 를 화면에 보여 주세요
print(t.seconds)                            # t 의 seconds 를 화면에 보여 주세요
print(t.total_seconds())                    # t 전체를 초로 바꾼 값을 화면에 보여 주세요

한 문장으로: timedelta는 일과 나머지 초로 나뉘어 보관돼서 days와 seconds로 따로 꺼낼 수 있고, 전체 초는 total_seconds()로 구해요.

먼저 알아 둘 기본

  • 날짜(시점)와 기간(길이)은 달라요. "7월 4일"은 시점이고 "3일", "2시간 30분"은 길이예요. timedelta는 길이를 담는 값이에요.
  • timedelta(days=1, hours=2)처럼 이름을 붙여 값을 줘요. 적지 않은 것은 0이고, 적는 순서는 상관없어요. 쓸 수 있는 이름은 days, hours, minutes, seconds 등이에요.
  • 안에서는 기간을 일(days)과 그날을 뺀 나머지 초(seconds)로 나눠 보관해요. 그래서 days와 seconds를 따로 꺼낼 수 있어요.
  • print(기간)은 1 day, 2:30:00처럼 "일수, 시:분:초" 모양으로 나와요. 일수가 1이면 day(단수), 2 이상이면 days, 0이면 일수 부분이 아예 빠져요.
  • t.days처럼 값 뒤에 점과 이름을 붙이면 값 안의 정보를 꺼내요. 괄호가 없으면 정보를, t.total_seconds()처럼 괄호가 있으면 계산을 시키는 기능이에요.

코드를 한 줄씩 따라가기

줄코드일어나는 일
3번째 줄t = timedelta(days=1, hours=2, minutes=30)1일 2시간 30분의 기간을 만들어요. 안에서는 days=1, seconds=2×3600 + 30×60 = 9000으로 나뉘어 보관돼요.
4번째 줄print(t)일수가 1이라 1 day, 나머지 2시간 30분은 2:30:00이라서 1 day, 2:30:00이에요.
5번째 줄print(t.days)일 부분만 꺼내서 1이에요.
6번째 줄print(t.seconds)일을 뺀 나머지 2시간 30분을 초로 센 값 9000이에요. 하루(86400초)는 들어 있지 않아요.
7번째 줄print(t.total_seconds())기간 전체를 초로 센 값이에요. 86400 + 9000 = 95400이고, 소수점이 붙은 95400.0으로 나와요.

왜 이런 결과가 나올까요

t.seconds가 전체 초가 아니라 "일을 뺀 나머지의 초"라서 9000이 나와요. 전체 초를 원하면 total_seconds()를 써야 해요.

total_seconds()가 95400.0처럼 소수로 나오는 건 초 아래 단위(마이크로초)까지 담을 수 있게 소수로 돌려주기 때문이에요. 이 문제에서는 소수점 아래가 0이에요.

헷갈리기 쉬운 곳

  • t.total_seconds처럼 괄호를 빼면 계산 결과가 아니라 "기능 그 자체"가 나와서 의도한 값이 아니에요. 기능은 괄호로 불러야 실행돼요.
  • timedelta(months=1)은 오류예요(메시지: unexpected keyword argument 'months'). 달과 해는 길이가 제각각이라 timedelta에 없고, 일·시간·분·초로 나타내야 해요.
  • t.days가 "전체 일수"라고 생각하기 쉬운데, 시간이 섞여 있으면 일 부분(정수)만 나와요. 예: 1일 23시간이면 days는 1이에요.

한 문장으로: strftime은 형식 글자(% + 글자)만 날짜 값으로 바꾸고 나머지는 그대로 두어서, 형식을 어떻게 적느냐에 따라 같은 날짜가 전혀 다르게 보여요.

먼저 알아 둘 기본

  • strftime은 날짜 값을 글자(문자열)로 바꾸는 기능이에요. 이름의 f는 format(모양을 만든다)이라고 외우면 쉬워요.
  • 형식 글자는 %와 한 글자로 이뤄져요. 자주 쓰는 것: %Y 네 자리 연도, %y 두 자리 연도, %m 월, %d 일, %H 24시간제 시, %M 분, %S 초.
  • %m, %d, %H, %M, %S는 한 자리 수도 두 자리로 채워요(7월 → 07, 8분 → 08).
  • %가 붙지 않은 글자(/, :, -, 영어 단어 등)는 적은 그대로 찍혀요.
  • 결과는 날짜 값이 아니라 글자예요. 그래서 이 값으로 날짜 계산은 할 수 없고, 보여 주는 용도로 써요.

  • 월 이름(%B)은 컴퓨터의 언어 설정에 따라 영어가 아닐 수 있어요.

글자 ↔ 날짜 — strftime과 strptime

strftime은 날짜를 글자로, strptime은 글자를 날짜로 바꿔요. 서로 반대 방향이에요. 한 바퀴 돌려 보고 결과가 어떻게 달라지는지 확인해요.

s = d.strftime('%Y-%m-%d')            # s 에 d 를 '연-월-일' 글자로 바꿔 담아 주세요
print(s)                              # s 를 화면에 보여 주세요
print(type(s))                        # s 의 자료형을 화면에 보여 주세요
e = datetime.strptime(s, '%Y-%m-%d')  # e 에 s 를 '연-월-일' 모양으로 읽어 날짜로 만들어 담아 주세요
print(e)                              # e 를 화면에 보여 주세요
print(type(e))                        # e 의 자료형을 화면에 보여 주세요
print(d == e)                         # d 와 e 가 같은 날짜인지 화면에 보여 주세요

먼저 알아 둘 기본

  • 글자(문자열, str)와 날짜 값(datetime)은 전혀 다른 종류예요. 글자는 "보여 주는 모양", 날짜 값은 "계산할 수 있는 값"이에요.
  • strftime의 f는 format(모양을 만든다) — 날짜 값 → 글자. strptime의 p는 parse(읽어서 해석한다) — 글자 → 날짜 값. 이렇게 외우면 헷갈리지 않아요.
  • 부르는 모양도 달라요. strftime은 이미 있는 날짜 값에게 시키니 d.strftime(형식)이고, strptime은 글자로 새 날짜 값을 만들어 내는 일이라 틀에게 시켜서 datetime.strptime(글자, 형식)이에요.
  • 두 함수는 같은 형식 글자를 써요. strptime의 형식은 "읽을 글자의 모양과 똑같이" 적어야 해요.
  • 날짜 값을 print하면 시·분·초까지 항상 나와요. 시각을 안 적은 값은 자정(00:00:00)으로 채워져요.

datetime 값은 바뀌지 않는다

날짜를 계산한 뒤에 원래 날짜는 어떻게 될까요? 계산 결과를 어디에 담는지에 주목하세요.

print(d)                                   # d 를 화면에 보여 주세요
print(e)                                   # e 를 화면에 보여 주세요

print(d.replace(hour=20))                  # d 의 시만 20 으로 바꾼 날짜를 화면에 보여 주세요

먼저 알아 둘 기본

  • 표현식은 계산해서 값을 만드는 식이에요. d + timedelta(hours=5)는 "d의 5시간 뒤"라는 새 값을 만들어 내요. 그 값을 e =처럼 이름에 담아야 이후에 쓸 수 있어요.
  • datetime 값은 불변(immutable)이에요. 한 번 만들어지면 그 값 자체는 바뀌지 않아요. 계산을 하면 항상 "새 값"이 나와요. 숫자와 글자도 똑같아요(아래 "고쳐서 돌려 보기" 참고).
  • print(a, b)처럼 값을 쉼표로 여러 개 주면 한 줄에 공백으로 띄워 출력해요.
  • >는 "더 나중인가"를 묻는 비교예요. 날짜 값은 이른 쪽이 작고 늦은 쪽이 커요. ==는 같은지를 물어서 True/False를 돌려줘요.
  • 계산 순서: e - d == timedelta(hours=5)는 먼저 e - d(기간)를 구하고 그다음 ==로 비교해요.
  • d.replace(hour=20)은 "시만 20으로 바꾼 새 날짜"를 돌려줘요. 원래 d는 그대로예요.

같은 글자, 다른 형식

strptime은 글자를 정해 준 형식대로 읽기만 해요. 같은 글자 '03/04/05'를 형식 세 가지로 읽어 봐요.

from datetime import datetime                     # datetime 모듈에서 datetime 을 가져와 주세요

text = '03/04/05'                                 # text 에 '03/04/05' 를 담아 주세요
for fmt in ('%y/%m/%d', '%d/%m/%y', '%m/%d/%y'):  # 형식 세 개를 하나씩 fmt 라고 부르며 아래를 반복해 주세요
    d = datetime.strptime(text, fmt)              # d 에 text 를 fmt 모양으로 읽어 날짜로 만들어 담아 주세요
    print(d.year, d.month, d.day)                 # d 의 연, 월, 일을 화면에 보여 주세요

%y는 두 자리 연도(03이면 2003)예요. 형식에서 %y·%m·%d가 놓인 순서대로 글자의 앞·가운데·뒤 두 자리를 읽어요.

한 문장으로: strptime은 글자가 무슨 뜻인지 짐작하지 않고 형식에 적힌 순서대로 읽기만 해서, 같은 글자도 형식에 따라 다른 날짜가 돼요.

먼저 알아 둘 기본

  • strptime(글자, 형식)은 글자 한 칸 한 칸을 형식 글자와 순서대로 짝지어 읽어요. 형식의 첫 글자가 %y이면 글자의 첫 두 자리가 연도예요.
  • %y는 두 자리 연도예요. 03은 2003년, 05는 2005년으로 읽혀요(이 문제의 값은 모두 2000년대로 읽혀요).
  • for 이름 in (A, B, C):는 괄호 안의 값을 하나씩 이름으로 불러 가며 아래 들여 쓴 줄을 반복해요. 여기서는 형식 세 개를 하나씩 fmt라고 불러요.
  • 날짜 값에서 d.year, d.month, d.day를 쓰면 연, 월, 일을 정수로 꺼낼 수 있어요. 앞의 0은 사라져서 04가 4로 나와요.
  • 글자가 형식과 모양이 어긋나면 ValueError가 나요.

  • 글자의 구분 기호가 형식과 다르면 오류예요. 예: '2025.07.04'를 '%Y-%m-%d'로 읽으면 ValueError(메시지: time data '2025.07.04' does not match format '%Y-%m-%d').
  • %y(두 자리)와 %Y(네 자리)를 바꿔 쓰면 안 돼요. 2025를 %y로 읽으려 하면 오류예요.

ast 트리 처음 열어 보기

ast.parse(식, mode='eval')로 만든 트리의 맨 위는 Expression이고, 실제 식은 .body에 들어 있어요. 값 두 개와 연산자 하나로 된 식은 BinOp(이항 연산)라고 불러요.

import ast                                          # ast 모듈을 가져와 주세요

tree = ast.parse('3 + 4', mode='eval')              # tree 에 식 '3 + 4' 를 트리로 만들어 담아 주세요
print(type(tree))                                   # tree 의 자료형을 화면에 보여 주세요
print(type(tree.body))                              # tree 의 body(실제 식) 의 자료형을 화면에 보여 주세요
print(tree.body.left.value, tree.body.right.value)  # tree.body 의 왼쪽 값과 오른쪽 값을 화면에 보여 주세요
print(ast.dump(tree.body.op))                       # tree.body 의 연산자를 화면에 보여 주세요

먼저 알아 둘 기본

  • 파싱(parse)은 글자로 쓴 식을 "어느 부분이 값이고 어느 부분이 연산자인지" 구조로 나누는 일이에요. 파이썬은 코드를 실행하기 전에 이 일을 먼저 해요.
  • 트리(tree)는 나무처럼 가지가 뻗는 구조고, 가지의 한 칸 한 칸을 노드라고 불러요. ast 모듈은 이 구조를 우리가 들여다볼 수 있게 보여 줘요.
  • mode='eval'은 "식 하나"를 읽겠다는 뜻이에요. 이렇게 만든 트리의 맨 위 노드는 항상 Expression이고, 진짜 식은 그 안의 .body에 들어 있어요.
  • BinOp는 이항 연산(binary operation) 노드예요. 연산자의 양쪽에 값이 하나씩 있어서 left(왼쪽), op(연산자), right(오른쪽) 세 칸을 가져요.
  • Constant는 숫자·글자 같은 값 그 자체예요. 값은 .value로 꺼내요. 덧셈 연산자는 Add(), 뺄셈은 Sub(), 곱셈은 Mult()라고 나와요.

두음법칙으로 이을 수 있나

끝 글자에 두음법칙을 적용한 글자도 허용하는 판정 함수예요. 각 줄은 앞 말에 뒷말을 이을 수 있는지 물어요.

RULE = {'량': '양', '리': '이', '녀': '여'}  # RULE 에 두음법칙으로 바뀌는 글자 짝을 담은 딕셔너리를 담아 주세요

def can_follow(last, word):                             # last 와 word 를 받는 can_follow 라는 동작을 만들어 주세요
    allowed = {last[-1], RULE.get(last[-1], last[-1])}  # allowed 에 last 의 끝 글자와 그 글자가 바뀐 글자를 세트로 담아 주세요
    return word[0] in allowed                           # word 의 첫 글자가 allowed 에 있는지를 결과로 돌려주세요

print(can_follow('차량', '양심'))  # '차량' 뒤에 '양심' 을 이을 수 있는지 화면에 보여 주세요
print(can_follow('차량', '량심'))  # '차량' 뒤에 '량심' 을 이을 수 있는지 화면에 보여 주세요
print(can_follow('차량', '심술'))  # '차량' 뒤에 '심술' 을 이을 수 있는지 화면에 보여 주세요
print(can_follow('기차', '리본'))  # '기차' 뒤에 '리본' 을 이을 수 있는지 화면에 보여 주세요
print(can_follow('다리', '이빨'))  # '다리' 뒤에 '이빨' 을 이을 수 있는지 화면에 보여 주세요

먼저 알아 둘 기본

  • 두음법칙은 단어 첫머리에서 소리가 바뀌는 규칙이에요. 끝말잇기에서 "차량" 다음에 "량심"뿐 아니라 "양심"도 이을 수 있는 이유예요(량 → 양, 리 → 이, 녀 → 여).
  • 딕셔너리 {키: 값}는 짝을 담는 자료예요. RULE['량']은 '양'이에요. RULE.get(키, 기본값)은 키가 있으면 짝의 값을, 없으면 기본값을 돌려줘요. 없는 키를 RULE[…]로 꺼내면 오류지만 get은 오류가 안 나요.
  • 세트 {a, b}는 중복 없이 모아 두는 자료예요. 같은 값을 두 번 넣어도 하나만 남아요({'차', '차'} → {'차'}).
  • 글자 꺼내기: 글자[0]은 첫 글자, 글자[-1]은 마지막 글자예요. 그래서 '차량'[-1]은 '량', '양심'[0]은 '양'이에요.
  • in은 "안에 들어 있는가"를 물어서 True/False를 돌려줘요.
  • 함수: def 이름(받는 값): 아래 들여 쓴 줄이 함수의 몸이고, return 값은 "이 값을 결과로 돌려준다"는 뜻이에요.

고급 1읽기

괄호와 우선순위가 트리에 보이는 모습

type(x).__name__은 x가 어떤 종류의 노드인지 이름(글자)으로 알려 줘요. 맨 나중에 계산되는 연산이 트리의 맨 위에 와요.

import ast                                                # ast 모듈을 가져와 주세요

tree = ast.parse('(1 + 2) * 3 - 4', mode='eval')          # tree 에 식 '(1 + 2) * 3 - 4' 를 트리로 만들어 담아 주세요
top = tree.body                                           # top 에 tree 의 body(실제 식) 를 담아 주세요
print(type(top.op).__name__)                              # top 의 연산자 종류 이름을 화면에 보여 주세요
print(type(top.left).__name__, type(top.right).__name__)  # top 의 왼쪽 가지와 오른쪽 가지의 종류 이름을 화면에 보여 주세요
print(type(top.left.op).__name__)                         # top 의 왼쪽 가지의 연산자 종류 이름을 화면에 보여 주세요
print(eval(compile(tree, '<ast>', 'eval')))               # tree 를 계산한 값을 화면에 보여 주세요

먼저 알아 둘 기본

  • 계산 순서(우선순위)는 괄호 → 곱셈·나눗셈 → 덧셈·뺄셈이에요. 같은 순위끼리는 왼쪽에서 오른쪽으로 계산해요.
  • 트리를 읽는 규칙: 가장 나중에 계산되는 연산이 맨 위(뿌리)에 와요. 먼저 계산되는 연산일수록 아래(안쪽)에 있어요. 맨 위 연산의 왼쪽과 오른쪽이 각각 가지가 돼요.
  • type(x)는 x의 자료형, type(x).__name__은 그 자료형의 이름 글자예요. 예: BinOp, Constant, Sub.
  • 연산자 노드의 이름: 덧셈 Add, 뺄셈 Sub, 곱셈 Mult. 노드를 글자로 보면 Sub()처럼 괄호가 붙고, __name__으로 보면 Sub처럼 이름만 나와요.
  • eval(compile(tree, '<ast>', 'eval'))은 "트리를 실제로 계산하는" 줄이에요. 지금은 "트리도 계산할 수 있다" 정도만 알면 돼요.

고급 2읽기

같은 순간, 다른 시간대

zoneinfo는 파이썬에 처음부터 들어 있는 시간대 모듈이에요(교재가 쓰는 pytz는 따로 설치해야 해요). astimezone(시간대)는 같은 순간을 다른 시간대의 시계 모양으로 바꿔 줘요.

from datetime import datetime                                       # datetime 모듈에서 datetime 을 가져와 주세요
from zoneinfo import ZoneInfo                                       # zoneinfo 모듈에서 ZoneInfo 를 가져와 주세요

seoul = datetime(2025, 7, 4, 12, 0, tzinfo=ZoneInfo('Asia/Seoul'))  # seoul 에 서울 시간대의 2025년 7월 4일 12시를 담아 주세요
utc = seoul.astimezone(ZoneInfo('UTC'))                             # utc 에 seoul 과 같은 순간을 세계 표준시(UTC) 모양으로 바꿔 담아 주세요
print(seoul)                                                        # seoul 을 화면에 보여 주세요
print(utc)                                                          # utc 를 화면에 보여 주세요
print(seoul.utcoffset())                                            # seoul 이 세계 표준시와 얼마나 차이 나는지 화면에 보여 주세요
print(seoul == utc)                                                 # seoul 과 utc 가 같은 순간인지 화면에 보여 주세요
print(seoul.hour, utc.hour)                                         # seoul 과 utc 의 시를 화면에 보여 주세요

먼저 알아 둘 기본

  • 시간대(time zone)는 지역마다 시계가 가리키는 시각이 다른 것을 나타내는 약속이에요. 지구 전체가 같은 순간이어도 서울이 정오일 때 UTC 시계는 새벽 3시예요.
  • UTC(세계 표준시)는 기준이 되는 시계예요. 각 지역은 UTC와의 차이(오프셋)로 나타내요. 서울은 UTC보다 9시간 빨라서 +09:00이에요.
  • 시간대가 없는 날짜(naive)는 어느 지역의 시각인지 모르는 값이고, 시간대가 붙은 날짜(aware)는 "어느 순간"인지 정확히 알려져 있어요. tzinfo=ZoneInfo('Asia/Seoul')로 시간대를 붙여요.
  • ZoneInfo('지역/도시')는 지역 이름으로 시간대를 만들어 줘요. 서울은 Asia/Seoul, 세계 표준시는 UTC예요.
  • astimezone(시간대)는 같은 순간을 다른 시간대의 시계 모양으로 바꿔서 새 값을 돌려줘요. utcoffset()은 그 값이 UTC와 얼마나 차이 나는지를 기간(timedelta)으로 알려 줘요.

한글 글자 쪼개기

한글 한 글자를 초성·모음·받침 번호로 쪼개 두음법칙으로 바뀔 글자를 구해요. 초성 번호 5는 ㄹ, 2는 ㄴ, 11은 ㅇ이고, YO의 번호는 ㅑ·ㅒ·ㅕ·ㅖ·ㅛ·ㅠ·ㅣ의 모음이에요.

YO = (2, 3, 6, 7, 12, 17, 20)  # YO 에 ㅑ ㅒ ㅕ ㅖ ㅛ ㅠ ㅣ 의 모음 번호를 담아 주세요

def starts(ch):                                               # ch 를 받는 starts 라는 동작을 만들어 주세요
    result = {ch}                                             # result 에 ch 자신이 든 세트를 담아 주세요
    code = ord(ch) - 0xAC00                                   # code 에 ch 의 글자 번호에서 '가' 의 번호를 뺀 값을 담아 주세요
    first = code // 588                                       # first 에 초성 번호를 담아 주세요
    vowel = code % 588 // 28                                  # vowel 에 모음 번호를 담아 주세요
    tail = code % 28                                          # tail 에 받침 번호를 담아 주세요
    if first == 5:                                            # 만약 초성이 ㄹ 이면
        new = 11 if vowel in YO else 2                        # new 에 (모음이 YO 에 있으면 ㅇ, 아니면 ㄴ) 의 초성 번호를 담아 주세요
    elif first == 2 and vowel in YO:                          # 아니고 만약 초성이 ㄴ 이고 모음이 YO 에 있으면
        new = 11                                              # new 에 ㅇ 의 초성 번호를 담아 주세요
    else:                                                     # 그 밖에는
        return result                                         # result 를 결과로 돌려주세요
    result.add(chr(0xAC00 + (new * 21 + vowel) * 28 + tail))  # result 에 초성만 new 로 바꾼 글자를 더해 주세요
    return result                                             # result 를 결과로 돌려주세요

for ch in '량녀라차':              # 글자들을 하나씩 ch 라고 부르며 아래를 반복해 주세요
    print(ch, sorted(starts(ch)))  # ch 와 ch 로 이을 수 있는 첫 글자들을 정렬해 화면에 보여 주세요

먼저 알아 둘 기본

  • 한글 글자는 번호로 정리돼 있어요. 컴퓨터는 모든 글자에 번호를 붙여 두는데, 한글 완성형 글자(가~힣)는 가(번호 0xAC00)부터 초성 → 모음 → 받침 순서로 빈틈없이 놓여 있어요.
  • ord(글자)는 글자의 번호를, chr(번호)는 번호의 글자를 돌려줘요. 서로 반대 방향이에요. 0xAC00은 16진수 표기이고 십진수로 44032예요.
  • 초성은 19가지, 모음은 21가지, 받침은 28가지(받침 없음 포함)예요. 한 초성 아래 모음 21 × 받침 28 = 588글자가 있어서, 번호를 588로 나눈 몫이 초성 번호가 돼요.
  • 쪼개는 식(code = ord(ch) - 0xAC00): 초성 번호 = code // 588, 모음 번호 = code % 588 // 28, 받침 번호 = code % 28. //는 나눈 몫, %는 나눈 나머지예요.
  • 초성 번호: ㄱ0 ㄲ1 ㄴ2 ㄷ3 ㄸ4 ㄹ5 ㅁ6 ㅂ7 ㅃ8 ㅅ9 ㅆ10 ㅇ11 ㅈ12 ㅉ13 ㅊ14 ㅋ15 ㅌ16 ㅍ17 ㅎ18. 모음 번호: ㅏ0 ㅐ1 ㅑ2 ㅒ3 ㅓ4 ㅔ5 ㅕ6 ㅖ7 ㅗ8 ㅘ9 ㅙ10 ㅚ11 ㅛ12 ㅜ13 ㅝ14 ㅞ15 ㅟ16 ㅠ17 ㅡ18 ㅢ19 ㅣ20.
  • YO는 이중모음(ㅑ ㅒ ㅕ ㅖ ㅛ ㅠ ㅣ)의 번호 묶음이에요. 두음법칙에서 ㄹ은 이 모음 앞에서 ㅇ으로, 그 밖의 모음 앞에서 ㄴ으로 바뀌어요.
  • sorted()는 작은 번호의 글자부터 늘어놓아요. 번호가 작은 글자는 가나다 순으로 앞에 있는 글자예요.

량은 받침 ㅇ이 있어서 받침 번호가 21이에요. 초성만 ㅇ으로 바꾸고 받침은 그대로 두니 양이 돼요. 받침이 있는 글자도 같은 식으로 처리돼요.

sorted는 번호가 작은 글자가 앞이에요. 나가 라보다 번호가 작아서 ['나', '라'], 량이 양보다 작아서 ['량', '양']예요.

헷갈리기 쉬운 곳

  • starts(ch)가 돌려주는 건 "이을 수 있는 첫 글자 세트"이지 한 글자가 아니에요. 그래서 출력에 대괄호 리스트가 나와요(sorted가 세트를 리스트로 바꿔요).
  • elif로 갈 때 초성이 ㄴ(2)이어도 모음이 YO에 없으면(예: 나) 바뀌지 않고 else로 가요. elif의 조건은 "ㄴ이고 이중모음"이에요.
  • 이 코드는 한글 완성형 글자(가~힣)에만 맞아요. 영어나 자음만 있는 글자(ㄱ)를 넣으면 엉뚱한 번호가 나와요.
  • //(몫)와 %(나머지)를 섞어 쓴 식이 낯설어요. code % 588 // 28은 "나머지를 먼저 구하고(%), 그 결과를 28로 나눈 몫(//)"이에요(같은 순위라 왼쪽부터).
