전체는 7단계로 쌓여요

문 ①로 들어오면 1단계부터, 문 ②는 1단계 안쪽에서, 문 ③은 3단계에서 시작해요. 어느 문으로 들어와도 결국 같은 계단을 타요.

  1. 웹과 컴퓨터가 어떻게 돌아가는가 깃으로 내 코드를 남기고, 페이지를 만들고, 그 뒤의 서버와 데이터베이스까지. 사전 지식 필요 없음.
  2. AI 도구 써보기 에이전트가 뭔지 먼저 짚고, 이론 전에 손으로 써 봐요.
  3. AI는 어떻게 작동하는가 2단계에서 쓴 도구의 안쪽. 학습·트랜스포머·내 노트북에서 돌리기.
  4. AI가 다루는 여러 분야 같은 원리가 글자 밖으로. 이미지·음성·3D·과학. 여기가 제일 재밌어요.
  5. 지시·컨텍스트·도구 설계 2단계 프롬프트 개념을 설계로. 만들기 직전 준비 단계.
  6. 내 도구를 직접 만들기 근거를 보여주는 챗봇 하나, 내 업무를 맡길 MCP 서버 하나를 끝까지.
  7. 에이전트를 굴리는 판 가장 무거워요. 여러 에이전트와 하네스. 1~6단계 없이 오면 안 읽혀요.
