7.1 ~ 7.2 기본기 — 클래스·인스턴스·self

클래스로 인스턴스를 만들고, 값이 인스턴스마다 따로 저장되는 모습과 self 의 자리를 한 문제에 한 가지씩 확인해요.

초급 1읽기

틀은 하나, 인스턴스는 여러 개

클래스로 인스턴스를 두 개 만든 뒤 여러 가지를 물어봐요.

class Dog:                       # Dog 클래스를 정의해 주세요
    def bark(self):              # bark 메서드를 정의해 주세요
        return "멍멍"            # "멍멍" 을 돌려주세요
a = Dog()                        # a 에 Dog 인스턴스를 만들어 담아 주세요
b = Dog()                        # b 에 Dog 인스턴스를 만들어 담아 주세요
print(a.bark())                  # a 에게 짖게 한 결과를 화면에 보여 주세요
print(a is b)                    # a 와 b 는 같은 객체인가요?
print(isinstance(b, Dog))        # b 는 Dog 인스턴스인가요?

왜 이런 결과가 나올까요

Dog() 를 두 번 불러서 서로 다른 인스턴스 두 개가 생겼어요. 그래서 a is b 는 False 이고, 둘 다 Dog 틀에서 나왔으니 isinstance(b, Dog) 는 True 예요.

헷갈리기 쉬운 곳

  • 같은 틀에서 만들었다고 같은 객체는 아니에요. 틀(클래스)은 하나이고 결과물(인스턴스)은 여러 개예요.

핵심 한 줄: 클래스는 틀, 인스턴스는 그 틀로 만든 서로 다른 결과물이에요.

초급 2읽기

인스턴스마다 자기 값

__init__ 으로 값을 받아 만든 두 인스턴스 가운데 하나만 바꿔요.

class Box:                       # Box 클래스를 정의해 주세요
    def __init__(self, size):    # 만들 때 불리는 __init__ 을 정의해 주세요

x = Box(3)                       # x 에 size 가 3 인 Box 를 만들어 담아 주세요
y = Box(7)                       # y 에 size 가 7 인 Box 를 만들어 담아 주세요
x.size = x.size + 1              # x 의 size 에 x 의 size 더하기 1 을 담아 주세요
print(x.size, y.size)            # x 와 y 의 size 를 화면에 보여 주세요

초급 3오류 찾기

self 를 빠뜨리면

고양이 클래스에서 meow() 를 불렀더니 오류가 나요. 어떤 오류가 나는지, 어떻게 고치는지 답해 보세요.

class Cat:                       # Cat 클래스를 정의해 주세요
    def meow():                  # meow 메서드를 정의해 주세요
        return "야옹"            # "야옹" 을 돌려주세요
tom = Cat()                      # tom 에 Cat 인스턴스를 만들어 담아 주세요
print(tom.meow())                # tom 에게 울게 한 결과를 화면에 보여 주세요

오류 이름과 고칠 방법을 적어 보세요.

항목예측
오류 이름?
고친 코드?
힌트 보기

tom.meow() 를 부르면 부른 인스턴스 tom 이 첫 번째 값으로 자동으로 들어가요. 그 값을 받을 매개변수가 있어야 해요.

정답·해설 보기 
TypeError: Cat.meow() takes 0 positional arguments but 1 was given

고친 코드와 결과예요.

class Cat:                       # Cat 클래스를 정의해 주세요
    def meow(self):                  # meow 메서드를 정의해 주세요 (self 를 받도록 고쳤어요)
        return "야옹"            # "야옹" 을 돌려주세요
tom = Cat()                      # tom 에 Cat 인스턴스를 만들어 담아 주세요
print(tom.meow())                # tom 에게 울게 한 결과를 화면에 보여 주세요
야옹

왜 이런 결과가 나올까요

tom.meow() 는 tom 을 첫 번째 값으로 넘기는데, meow() 에는 받을 자리가 없어서 TypeError 가 나요. def meow(self): 로 고치면 돼요.

헷갈리기 쉬운 곳

  • 호출할 때는 self 를 쓰지 않으니, 값을 안 넘겼는데 “1개를 줬다”는 말이 이상하게 느껴져요. 넘기는 건 파이썬이 몰래 해 주는 일이에요.

핵심 한 줄: 메서드는 첫 매개변수로 self 를 꼭 받아요.

초급 4읽기

메서드로 값 바꾸기

두 인스턴스에 같은 메서드를 불러요.

class Player:                    # Player 클래스를 정의해 주세요
    def __init__(self, name):    # 만들 때 불리는 __init__ 을 정의해 주세요
        self.name = name         # 이 인스턴스의 name 에 name 을 담아 주세요
        self.xp = 0              # 이 인스턴스의 xp 에 0 을 담아 주세요
    def gain(self, n):           # gain 메서드를 정의해 주세요
        self.xp += n             # 이 인스턴스의 xp 에 n 을 더해 주세요
p = Player("elon")               # p 에 이름이 "elon" 인 Player 를 만들어 담아 주세요
p.gain(5)                        # p 에게 경험치 5 를 주세요
p.gain(3)                        # p 에게 경험치 3 을 주세요
q = Player("mark")               # q 에 이름이 "mark" 인 Player 를 만들어 담아 주세요
print(p.name, p.xp)              # p 의 name 과 xp 를 화면에 보여 주세요
print(q.name, q.xp)              # q 의 name 과 xp 를 화면에 보여 주세요

이 코드를 실행하면 무엇이 출력될까요?

출력예측
1번째 줄?
2번째 줄?
힌트 보기

gain 을 부른 건 p 뿐이에요. q 의 xp 는 만들 때 0 으로 정해졌어요.

정답·해설 보기 
elon 8
mark 0

왜 이런 결과가 나올까요

p.gain(5) 와 p.gain(3) 에서 self 는 p 라서 p.xp 가 0 → 5 → 8 이 돼요. q 는 한 번도 건드리지 않아 0 이에요.

헷갈리기 쉬운 곳

  • gain(5) 처럼 부를 때 적는 값은 하나인데 정의에는 self, n 두 개가 있어요. self 는 파이썬이 채워 줘요.

핵심 한 줄: 메서드 안의 self.xp 는 그 메서드를 부른 인스턴스의 값이에요.

중급 1읽기

클래스 변수와 내 변수

클래스에 적어 둔 값을 인스턴스가 바꾸면 무엇이 달라질까요?

class Hero:                      # Hero 클래스를 정의해 주세요
    power = 10                   # 클래스 변수 power 에 10 을 담아 주세요
    def train(self):             # train 메서드를 정의해 주세요
        self.power += 5          # 이 인스턴스의 power 에 5 를 더해 주세요
a = Hero()                       # a 에 Hero 인스턴스를 만들어 담아 주세요
b = Hero()                       # b 에 Hero 인스턴스를 만들어 담아 주세요
a.train()                        # a 에게 훈련을 시켜 주세요
a.train()                        # a 에게 훈련을 한 번 더 시켜 주세요
print(a.power, b.power, Hero.power)  # a, b, 클래스의 power 를 화면에 보여 주세요
Hero.power = 50                  # 클래스 변수 power 에 50 을 담아 주세요
print(a.power, b.power)          # a 와 b 의 power 를 화면에 보여 주세요

이 코드를 실행하면 무엇이 출력될까요?

출력예측
1번째 줄?
2번째 줄?
힌트 보기

self.power += 5 는 클래스의 값을 읽어 계산한 뒤 그 인스턴스에 새로 저장해요. 저장한 뒤부터 그 인스턴스는 자기 값을 읽어요.

정답·해설 보기 
20 10 10
20 50

왜 이런 결과가 나올까요

a.train() 을 두 번 하면 a 가 자기 power 를 갖게 돼서 20 이 돼요. b 와 클래스는 10 그대로예요. 그 뒤 클래스 값을 50 으로 바꾸면 자기 값이 없는 b 는 50 을 읽고, 자기 값이 있는 a 는 20 이에요.

헷갈리기 쉬운 곳

  • “클래스 값을 바꾸면 모든 인스턴스가 바뀐다”는 말은 자기 값이 없는 인스턴스만 맞아요.

핵심 한 줄: self.변수 = ... 를 하는 순간 그 인스턴스는 클래스 값 대신 자기 값을 써요.

중급 2읽기

리스트를 클래스에 적으면

클래스 변수로 빈 리스트를 두고, 두 인스턴스가 각각 물건을 넣어요.

class Bag:                       # Bag 클래스를 정의해 주세요
    items = []                   # 클래스 변수 items 에 빈 리스트를 담아 주세요
    def add(self, x):            # add 메서드를 정의해 주세요
        self.items.append(x)     # 이 인스턴스가 보는 items 에 x 를 덧붙여 주세요
a = Bag()                        # a 에 Bag 인스턴스를 만들어 담아 주세요
b = Bag()                        # b 에 Bag 인스턴스를 만들어 담아 주세요
a.add("사과")                    # a 에 "사과" 를 넣어 주세요
b.add("배")                      # b 에 "배" 를 넣어 주세요
print(a.items)                   # a 의 items 를 화면에 보여 주세요
print(b.items)                   # b 의 items 를 화면에 보여 주세요
print(a.items is b.items)        # a 와 b 의 items 는 같은 리스트인가요?

이 코드를 실행하면 무엇이 출력될까요?

출력예측
1번째 줄?
2번째 줄?
3번째 줄?
힌트 보기

이 코드에는 self.items = ... 처럼 새로 저장하는 줄이 없어요. 있는 리스트에 append 만 해요.

정답·해설 보기 
['사과', '배']
['사과', '배']
True

왜 이런 결과가 나올까요

self.items 는 따로 저장한 적이 없어서 둘 다 클래스에 하나뿐인 리스트를 가리켜요. 거기에 사과와 배를 모두 넣었으니 두 인스턴스가 같은 내용을 보고, is 도 True 예요.

헷갈리기 쉬운 곳

  • 앞 문제의 self.power += 5 는 새로 저장하는 줄이라 값이 갈라졌지만, 이 문제의 append 는 있는 리스트를 고치는 줄이라 갈라지지 않아요.
  • 인스턴스마다 따로 리스트를 가지게 하려면 __init__ 안에서 self.items = [] 로 저장해요.

핵심 한 줄: 인스턴스마다 다른 리스트가 필요하면 __init__ 에서 만들어요.

중급 3읽기

자식이 물려받는 것과 더한 것

부모 클래스와 자식 클래스 사이에서 누가 무엇을 갖는지 읽어 보세요.

class Animal:                    # Animal 클래스를 정의해 주세요
    legs = 4                     # 클래스 변수 legs 에 4 를 담아 주세요
    def eat(self):               # eat 메서드를 정의해 주세요
        return "냠냠"            # "냠냠" 을 돌려주세요
class Bird(Animal):              # Animal 을 상속받는 Bird 클래스를 정의해 주세요
    legs = 2                     # 클래스 변수 legs 에 2 를 담아 주세요
    def fly(self):               # fly 메서드를 정의해 주세요
        return "푸드덕"          # "푸드덕" 을 돌려주세요
b = Bird()                       # b 에 Bird 인스턴스를 만들어 담아 주세요
print(b.legs, Animal.legs)       # b 의 legs 와 Animal 의 legs 를 화면에 보여 주세요
print(b.eat())                   # b 에게 먹게 한 결과를 화면에 보여 주세요

읽고 추리하고 짜 보기 — super 와 덮어쓰기

super() 가 쌓는 결과를 따라가고, 상속과 덮어쓰기로 직접 클래스를 짜 봐요.

고급 1읽기

세 겹 super()

super() 가 부모 것을 부르면서 글자가 쌓이는 모습을 따라가 보세요.

class A:                         # A 클래스를 정의해 주세요
    def hello(self):             # hello 메서드를 정의해 주세요
        return "A"               # "A" 를 돌려주세요
class B(A):                      # A 를 상속받는 B 클래스를 정의해 주세요
    def hello(self):             # hello 메서드를 다시 정의해 주세요
        return super().hello() + "B"  # 부모의 hello 결과에 "B" 를 붙여 돌려주세요
class C(B):                      # B 를 상속받는 C 클래스를 정의해 주세요
    def hello(self):             # hello 메서드를 다시 정의해 주세요
        return super().hello() + "C"  # 부모의 hello 결과에 "C" 를 붙여 돌려주세요
class D(B):                      # B 를 상속받는 D 클래스를 정의해 주세요
    pass                         # 아무것도 더하지 않아요
print(C().hello())               # C 인스턴스의 hello 결과를 화면에 보여 주세요
print(D().hello())               # D 인스턴스의 hello 결과를 화면에 보여 주세요
print(A().hello())               # A 인스턴스의 hello 결과를 화면에 보여 주세요

이 코드를 실행하면 무엇이 출력될까요?

출력예측

2번째 줄?
3번째 줄?

C().hello() 는 C → B → A 로 올라갔다가 값이 돌아오며 글자가 붙어요. D 에는 hello 가 없어요.

정답·해설 보기 
ABC
AB
A

왜 이런 결과가 나올까요

C().hello() 는 C 가 부모 B 것을 부르고, B 는 다시 A 것을 불러요. A 가 "A" 를 주면 B 가 "AB", C 가 "ABC" 로 돌려줘요. D 는 hello 가 없어 부모 B 것을 그대로 써서 "AB", A 는 "A" 예요.

헷갈리기 쉬운 곳

  • super() 는 “지금 클래스의 부모”를 뜻해요. 인스턴스가 어느 클래스냐에 따라 올라가는 길이가 달라져요.

핵심 한 줄: super().메서드() 는 부모 메서드의 결과를 받아 와서 거기에 덧붙일 때 써요.

고급 2코드 쓰기

학생도 사람 — Person 과 Student 만들기

아래 조건에 맞게 두 클래스를 직접 써 보세요.

  • Person(name) — name 을 저장하고, intro() 가 "저는 kim입니다" 같은 글자를 돌려줘요.
  • Student(name, school) — Person 을 상속받아요. school 도 저장하고, intro() 는 부모의 소개 뒤에 ", 한빛고 학생이에요" 를 붙여 돌려줘요.
  • 마지막 줄은 print(Student("kim", "한빛고").intro()) 예요.

코드를 쓴 뒤 실행하면 어떤 줄이 출력되어야 할까요?

class Person:
    pass

class Student:
    pass
힌트 보기

Student.__init__ 안에서 부모의 __init__ 을 부르는 것, intro 안에서 부모의 intro 를 부르는 것, 두 곳에 super() 가 필요해요.

정답·해설 보기 
class Person:                              # Person 클래스를 정의해 주세요
    def __init__(self, name):              # 만들 때 불리는 __init__ 을 정의해 주세요
        self.name = name                   # 이 인스턴스의 name 에 name 을 담아 주세요
    def intro(self):                       # intro 메서드를 정의해 주세요
        return "저는 " + self.name + "입니다"  # "저는 이름입니다" 를 돌려주세요
class Student(Person):                     # Person 을 상속받는 Student 클래스를 정의해 주세요
    def __init__(self, name, school):      # Student 의 __init__ 을 정의해 주세요
        super().__init__(name)             # 부모 Person 의 __init__ 을 name 으로 불러 주세요
        self.school = school               # 이 인스턴스의 school 에 school 을 담아 주세요
    def intro(self):                       # intro 메서드를 다시 정의해 주세요
        return super().intro() + ", " + self.school + " 학생이에요"  # 부모의 소개 뒤에 학교를 붙여 돌려주세요
print(Student("kim", "한빛고").intro())    # kim 의 소개를 화면에 보여 주세요
저는 kim입니다, 한빛고 학생이에요

왜 이런 결과가 나올까요

위 코드가 한 가지 정답이에요. Student.__init__ 은 super().__init__(name) 으로 이름 저장을 부모에게 맡기고 자기 몫인 school 만 저장해요. intro 는 부모의 intro() 결과에 학교를 덧붙여요.

헷갈리기 쉬운 곳

  • 두 super() 중 하나를 빼도 오류 없이 돌아갈 수 있어요. intro 의 super() 를 빼고 소개를 새로 적으면 결과는 같아도 부모를 고칠 때 자식이 따라 바뀌지 않아요.

핵심 한 줄: 부모가 하는 일은 super() 로 맡기고, 자식은 자기 몫만 적어요.

고급 3코드 쓰기

체력이 줄어드는 Player 와 방어하는 Warrior

영상에서 “공격받았을 때 일어나는 일을 메서드로 정한다”고 한 것을 직접 만들어 봐요.

  • Player(name, health) — take_hit(damage) 는 체력을 damage 만큼 줄이되 0 밑으로는 내려가지 않게 하고, 줄어든 체력을 돌려줘요.
  • Warrior — Player 를 상속받고, take_hit 는 받은 damage 의 절반(// 로 몫만)만 부모의 take_hit 에 넘겨요. __init__ 은 따로 적지 않아요.
  • 마지막 줄은 p = Player("elon", 100) 에 take_hit(30), take_hit(90), w = Warrior("mark", 100) 에 take_hit(30) 을 하고 각각 출력하는 거예요.

코드를 쓴 뒤 실행하면 어떤 줄들이 출력되어야 할까요?

class Player:
    pass

class Warrior:
    pass
힌트 보기

max(0, 값) 은 0 과 값 중 큰 쪽을 돌려줘서 음수가 되지 않게 해요. Warrior 는 __init__ 이 없으니 부모 것이 그대로 쓰여요.

정답·해설 보기 
class Player:                              # Player 클래스를 정의해 주세요
    def __init__(self, name, health):      # 만들 때 불리는 __init__ 을 정의해 주세요
        self.name = name                   # 이 인스턴스의 name 에 name 을 담아 주세요
        self.health = health               # 이 인스턴스의 health 에 health 를 담아 주세요
    def take_hit(self, damage):            # take_hit 메서드를 정의해 주세요
        self.health = max(0, self.health - damage)  # health 를 damage 만큼 줄이되 0 밑으로는 안 내려가게 해 주세요
        return self.health                 # 줄어든 health 를 돌려주세요
class Warrior(Player):                     # Player 를 상속받는 Warrior 클래스를 정의해 주세요
    def take_hit(self, damage):            # take_hit 메서드를 다시 정의해 주세요
        return super().take_hit(damage // 2)  # damage 의 절반을 부모의 take_hit 에 넘겨 결과를 돌려주세요
p = Player("elon", 100)                    # p 에 체력이 100 인 Player 를 만들어 담아 주세요
print(p.take_hit(30))                      # p 가 30 의 피해를 입은 뒤 체력을 화면에 보여 주세요
print(p.take_hit(90))                      # p 가 90 의 피해를 입은 뒤 체력을 화면에 보여 주세요
w = Warrior("mark", 100)                   # w 에 체력이 100 인 Warrior 를 만들어 담아 주세요
print(w.take_hit(30))                      # w 가 30 의 피해를 입은 뒤 체력을 화면에 보여 주세요
70
0
85

왜 이런 결과가 나올까요

Player 는 100 → 70 → max(0, 70 - 90) 이라 0 이에요. Warrior 는 30 의 절반인 15 만 부모에게 넘겨서 100 - 15 = 85 가 돼요.

헷갈리기 쉬운 곳

  • Warrior 에 __init__ 을 안 적었으니 Warrior("mark", 100) 도 Player 의 __init__ 으로 만들어져요.

핵심 한 줄: 자식은 필요한 메서드만 덮어쓰고, 나머지는 부모 것을 써요.
