지역·전역변수, lambda, map, reduce, filter, 외울 것만 공식처럼.

핵심 정리

개념공식
함수 안 x = ...지역변수를 새로 만듦, 같은 이름 전역변수는 그대로
지역변수함수가 끝나면 사라짐
전역변수함수 안에서 읽기는 됨
global 이름함수 안에서 전역변수 값을 바꾸고 싶을 때
lambda x: 식이름 없는 한 줄 함수
map(함수, 이터러블)전부에 함수 적용 (list()로 감싸 보기)
reduce(함수, 시퀀스)원소를 누적해 하나로 (functools)
filter(함수, 이터러블)결과가 참인 것만 남김

1. 지역변수 / 전역변수

# 함수 안에서 x = ... 는 지역변수를 새로 만든다
>>> x = 10                 # 바깥에서 변수 x 에 10 을 담아요
>>> def f():               # f 라는 함수를 만들기 시작해요
...     x = 99             # 함수 안에서 지역변수 x 를 새로 만들어요
...     print('안쪽', x)   # 안쪽 x 의 값을 화면에 보여 줘요
...
>>> f()                    # 함수 f 를 실행해요
안쪽 99
>>> print('바깥', x)       # 바깥 x 의 값을 화면에 보여 줘요
바깥 10

# 지역변수는 함수가 끝나면 사라진다
>>> def g():               # g 라는 함수를 만들기 시작해요
...     y = 5              # 함수 안에서 지역변수 y 를 만들어요
...
>>> g()                    # 함수 g 를 실행해요
>>> print(y)               # 함수 밖에서 y 를 보여 달라고 해요
NameError: name 'y' is not defined

# 전역변수는 함수 안에서 읽을 수 있다
>>> n = 3                  # 전역변수 n 에 3 을 담아요
>>> def read():            # read 라는 함수를 만들기 시작해요
...     print(n + 1)       # 전역변수 n 에 1 을 더해 보여 줘요
...
>>> read()                 # 함수 read 를 실행해요
4

# 함수 안에서 전역변수를 바꾸려면 global
>>> count = 0              # 전역변수 count 에 0 을 담아요
>>> def up():              # up 이라는 함수를 만들기 시작해요
...     global count       # 전역변수 count 를 쓰겠다고 알려요
...     count = count + 1  # 전역변수 count 를 1 늘려요
...
>>> up()                   # 함수 up 을 실행해요
>>> up()                   # 한 번 더 실행해요
>>> print(count)           # count 의 값을 화면에 보여 줘요
2

핵심 한 줄: 전역변수는 복잡해질수록 골칫거리, 되도록 쓰지 않기.

2. lambda

# lambda 매개변수: 표현식
>>> (lambda x, y: x + y)(10, 20)  # 이름 없는 함수를 만들어 바로 실행해요
30
>>> square = lambda x: x * x      # 제곱하는 lambda 에 square 이름을 붙여요
>>> square(7)                     # square 에 7 을 넣어 실행해요
49

3. map()

# 파이썬 3: map 객체를 돌려주므로 list()로 감싼다
>>> list(map(lambda x: x * 2, [1, 2, 3, 4]))  # 각 값에 2 를 곱해 리스트로 만들어요
[2, 4, 6, 8]
>>> map(lambda x: x * 2, [1, 2, 3, 4])        # list() 없이 map 만 부르면 map 객체가 나와요
<map object at 0x000001DDAB69F5E0>

4. reduce()

# from functools import reduce 가 먼저 필요
>>> from functools import reduce                 # functools 에서 reduce 를 가져와요
>>> reduce(lambda a, b: a + b, [1, 2, 3, 4, 5])  # 값들을 차례로 더해 하나로 합쳐요
15
>>> reduce(lambda a, b: a * b, [1, 2, 3, 4])     # 값들을 차례로 곱해 하나로 합쳐요
24

5. filter()

# 결과가 참인 것만 남긴다 (x % 2 는 홀수일 때 1 → 참)
>>> list(filter(lambda x: x % 2, [1, 2, 3, 4, 5, 6, 7]))  # 조건이 참인 홀수만 골라 리스트로 만들어요
[1, 3, 5, 7]
