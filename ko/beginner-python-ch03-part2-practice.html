실습 문제 5개 — 지역·전역변수와 lambda·map·filter·reduce 코드 읽고 결과 예측하기 (3)

2026. 10. 11.

※ 이 글은 위키독스 『왕초보를 위한 Python』 3장 3.3~3.4 내용을 바탕으로 제가 직접 만든 문제입니다. 교재의 공식 연습 문제가 아니에요. 완성된 코드를 보여드리니 직접 짤 필요 없이, 코드를 읽고 실행 결과가 뭘지 먼저 예측해보세요. 자세한 정답과 이유는 앞 글(문제 해설)에 따로 있어요.

지역·전역변수, global, lambda, map·filter·reduce가 나오는 완성된 코드 5개를 보고, 코드를 짜지 않고 실행 결과만 예측해보는 읽기 문제예요.

핵심 정리

개념한 줄 정리
지역변수함수 안에서 x = ...로 만든 변수는 그 함수 안에서만 살고, 같은 이름의 전역 x는 그대로다.
global 이름함수 안에서 전역변수 값을 바꾸려면 먼저 이렇게 선언해야 한다.
lambda 매개변수: 식이름 없는 한 줄짜리 함수이고, 식의 결과가 곧 return 값이다.
map(함수, 리스트)모든 원소에 함수를 적용한다(결과는 list()로 감싸야 보인다).
filter(함수, 리스트)함수 결과가 참인 원소만 남긴다.
reduce(함수, 리스트)앞에서부터 두 개씩 합쳐 하나로 만든다(from functools import reduce 필요).

다섯 문제 모두 지난 글에서 정리한 문법만으로 읽을 수 있어요. 1·2번은 지역·전역변수, 3번은 lambda, 4·5번은 map·filter·reduce 문제예요. 코드를 눈으로 따라가며 결과를 예측한 뒤, 문제 해설에서 본 풀이와 맞춰 보세요.

문제 1 — 이름이 같은 지역변수와 전역변수

함수 밖과 함수 안에 똑같이 x가 있는 코드예요.

x = 10

def change():
    x = 99
    print('함수 안:', x)

change()
print('함수 밖:', x)

이 코드를 실행하면 두 줄이 차례로 출력돼요. 각각 무엇일까요?

출력 줄예측
첫 번째 줄(함수 안)?
두 번째 줄(함수 밖)?
힌트 보기

함수 안에서 x = 99라고 쓰면 전역 x를 고치는 게 아니라 이름만 같은 새 변수를 함수 안에 하나 더 만들어요. 함수 안 print가 어느 x를 보는지, 함수가 끝난 뒤 밖의 x는 어떻게 됐는지 따로 생각해보세요.

문제 2 — global로 전역 값 누적하기

함수를 부를 때마다 전역변수 count에 값을 더하는 코드예요.

count = 0

def add(n):
    global count
    count = count + n
    print('더한 뒤:', count)

add(3)
add(4)
print('최종:', count)

이 코드를 실행하면 세 줄이 출력돼요. 각 줄은 무엇일까요? add(3)과 add(4)를 부른 뒤 count가 어떻게 변하는지도 함께 짚어보세요.

힌트 보기

global count 덕분에 함수 안의 count는 새 변수가 아니라 바깥의 그 count 하나예요. 그래서 add(3)이 바꾼 값이 함수가 끝난 뒤에도 남아 있고, 이어지는 add(4)는 그 값에서 시작해요.

문제 3 — lambda를 바로 부르기, 변수에 담아 부르기

같은 lambda를 두 가지 방식으로 쓰는 코드예요.

square = lambda x: x * x
print((lambda a, b: a + b)(3, 4))
print(square(5))
print(square(square(2)))

이 코드를 실행하면 세 줄이 출력돼요. 각 줄은 무엇일까요?

힌트 보기

lambda a, b: a + b 뒤에 바로 (3, 4)를 붙이면 만들자마자 호출하는 거예요. square(square(2))는 안쪽 괄호부터 계산해서, 그 결과를 다시 square에 넣어요.

문제 4 — map과 filter로 리스트 만들기

같은 리스트에 map과 filter를 각각 적용하고, filter 결과에 map을 한 번 더 쓰는 코드예요.

nums = [1, 2, 3, 4, 5, 6]
doubled = list(map(lambda x: x * 2, nums))
evens = list(filter(lambda x: x % 2 == 0, nums))
print(doubled)
print(evens)
print(list(map(lambda x: x + 1, evens)))

이 코드를 실행하면 세 줄이 출력돼요. 각 줄은 무엇일까요?

힌트 보기

map은 원소를 전부 바꾸고 개수는 그대로예요. filter는 조건이 참인 원소만 남기고 값은 바꾸지 않아요. 마지막 줄은 evens에 남은 원소들에 다시 map을 적용한 거라, nums가 아니라 evens에서 출발해야 해요.

문제 5 — reduce로 합치기 (숫자와 문자)

reduce로 숫자는 더하기·곱하기, 문자열은 뒤집기를 하는 코드예요.

from functools import reduce

nums = [1, 2, 3, 4]
print(reduce(lambda a, b: a + b, nums))
print(reduce(lambda a, b: a * b, nums))
print(reduce(lambda a, b: b + a, 'abc'))

이 코드를 실행하면 세 줄이 출력돼요. 각 줄은 무엇일까요? 세 번째 줄은 a와 b에 반복마다 어떤 값이 들어가는지 표로 적어 보세요.

힌트 보기

reduce는 먼저 앞의 두 원소를 a, b로 받아 계산하고, 그 결과를 다음 반복의 a에 넣어요. 그다음 원소가 b로 들어오고요. 세 번째 줄은 b + a의 순서가 거꾸로라는 점이 핵심이에요. 문자열 'abc'는 'a', 'b', 'c' 세 원소로 취급돼요.
