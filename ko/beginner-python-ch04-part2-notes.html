1. 튜플(tuple)

항목내용
튜플리스트와 비슷하지만 원소를 직접 바꿀 수 없다 (불변)
만들기('a', 'b', 'c') — 괄호는 써도 되고 안 써도 된다
빈 튜플() — 괄호를 꼭 쓴다
원소 하나5, — 뒤에 콤마를 꼭 붙인다. (5)는 튜플이 아니라 그냥 5
변환list(튜플) ↔ tuple(리스트)
 
t = ('a', 'b', 'c')                # t 에 'a', 'b', 'c' 가 든 튜플을 담아 주세요

not_tuple = (5)                    # not_tuple 에 (5) 를 담아 주세요
print(t, u, empty)                 # t, u, empty 를 화면에 보여 주세요
print(one, type(one))              # one 과 one 의 자료형을 화면에 보여 주세요

값 맞바꾸기와 *rest

※ 매개변수는 함수를 만들 때 def 괄호 안에 적는 "받을 값의 자리 이름"(def add(x, y)의 x, y)이고, 인자는 함수를 부를 때 그 자리에 넘기는 실제 값(add(3, 5)의 3, 5)이에요. def magu_print(x, y, *rest)에서는 x, y, *rest가 모두 매개변수이고, *rest는 앞 두 자리를 채우고 남은 인자를 전부 튜플로 받는 자리예요. 위키독스는 둘을 섞어 "인자(매개변수)"처럼 쓰기도 해서, 처음에는 같은 말로 읽어도 큰 문제는 없어요.
항목내용
c, d = d, c오른쪽 튜플 (d, c)를 만들어 왼쪽 c, d에 풀어 담는다. 한 줄로 맞바꾼다
*rest함수를 정의할 때 매개변수※ 앞에 *를 붙이면 남는 인자를 전부 튜플로 받는다
 
a = 10       # a 에 10 을 담아 주세요
b = 20       # b 에 20 을 담아 주세요
a, b = b, a  # a 와 b 에 담긴 값을 서로 바꿔 주세요
print(a, b)  # a 와 b 를 화면에 보여 주세요
20 10
def magu_print(x, y, *rest):         # x, y 와 나머지 인자를 받는 magu_print 라는 동작을 만들어 주세요
    print(x, y, rest)                # x, y, rest 를 화면에 보여 주세요

magu_print(1, 2, 3, 5, 6, 7, 9, 10)  # magu_print 에 1, 2, 3, 5, 6, 7, 9, 10 을 넣어 주세요
magu_print(1, 2)                     # magu_print 에 1, 2 만 넣어 주세요

튜플은 바꿀 수 없으니 잘라 붙인다

※ 리스트와 비교 — 리스트 nums = [1, 2, 3]은 nums[1] = 5로 그 자리에서 바로 바뀌어 [1, 5, 3]이 된다(가변). 튜플은 이게 안 되니(불변) 잘라 붙여 새 튜플을 만들어야 한다. 정리하면 리스트는 직접 고치고, 튜플은 새로 만든다.
항목내용
p[1] = 5튜플의 원소를 직접 바꾸면 TypeError※
새로 만들기p[:1] + (5,) + p[2:] — 가운데 2 를 뺀 앞뒤 조각 사이에 5 를 끼워 이어 붙인 새 튜플
p[:1], 5, p[2:]이어 붙이는 게 아니라 세 값을 묶은 튜플이 된다
보충 1슬라이싱: 대괄호 안에 콜론(:)으로 일부분을 잘라낸다

p[시작:끝] 처럼 콜론이 들어간 대괄호를 슬라이싱이라고 부른다. 시작 번호부터 끝 번호 바로 앞까지 잘라내고, 시작을 비우면 처음부터, 끝을 비우면 끝까지다. 번호는 0부터 센다.

코드 (p = (1, 2, 3))하는 일결과
p[0]0번 원소 하나를 꺼냄 (콜론이 없으니 슬라이싱이 아님)1
p[:1]처음부터 0번까지 잘라냄(1,)
p[1:]1번부터 끝까지 잘라냄(2, 3)
p[2:]2번부터 끝까지 잘라냄(3,)

슬라이싱 결과는 자르는 대상과 같은 종류다. 튜플을 자르면 튜플 조각이 나오고(원소가 하나뿐이어도 (1,) 처럼 튜플), 리스트를 자르면 리스트, 문자열을 자르면 문자열이 나온다. 잘라도 p 는 그대로이고, 잘라낸 결과는 따로 받아 쓴다.

p = (1, 2, 3)   # p 에 (1, 2, 3) 을 담아 주세요
q = p[:2]       # q 에 p 의 앞 두 개를 잘라 담아 주세요
print(q)        # q 를 화면에 보여 주세요
print(p)        # p 를 화면에 보여 주세요
(1, 2)
(1, 2, 3)
보충 2+ 와 , 는 하는 일이 다르다
기호하는 일a = (1, 2), b = (3,) 일 때
a + b두 튜플의 내용물을 꺼내 한 튜플로 합침(1, 2, 3) — 원소 3개
a, b쉼표 앞뒤의 것을 각각 원소 하나로 담음((1, 2), (3,)) — 원소 2개

상자 [1, 2] 와 [3] 이 있다면, + 는 두 상자 속 물건을 한 상자에 쏟아 붓는 것이고 , 는 두 상자를 더 큰 상자에 그대로 넣는 것이다. 그래서 아래 q 는 (1,) + (5,) + (3,) 이 합쳐져 숫자 3개짜리가 되고, r 은 (1,), 5, (3,) 이 그대로 담겨 안에 튜플이 든 튜플이 된다.

(5,) 의 쉼표를 빼고 (5) 로 쓰면 튜플이 아니라 그냥 숫자 5 라서, (1,) + 5 처럼 튜플에 숫자를 더하는 꼴이 되어 오류가 난다.

p = (1, 2, 3)               # p 에 (1, 2, 3) 튜플을 담아 주세요
q = p[:1] + (5,) + p[2:]   # q 에 p 의 앞 1개, (5,), p 의 2번부터 끝까지를 이어 붙인 튜플을 담아 주세요
r = p[:1], 5, p[2:]         # r 에 p[:1], 5, p[2:] 세 값을 묶은 튜플을 담아 주세요
print(q)                    # q 를 화면에 보여 주세요
print(r)                    # r 을 화면에 보여 주세요
try:                        # 아래를 시도해 주세요
    p[1] = 5                # p 의 1번 자리에 5 를 담아 주세요
except TypeError as e:      # TypeError 가 나면 그 오류를 e 라고 부르며
    print('TypeError:', e)  # 'TypeError:' 와 e 를 화면에 보여 주세요
(1, 5, 3)
((1,), 5, (3,))
TypeError: 'tuple' object does not support item assignment
p = (1, 2, 3)  # p 에 (1, 2, 3) 튜플을 담아 주세요
q = list(p)    # q 에 p 로 만든 리스트를 담아 주세요
q.append(4)    # q 의 맨 뒤에 4 를 붙여 주세요
r = tuple(q)   # r 에 q 로 만든 튜플을 담아 주세요
print(q, r)    # q 와 r 을 화면에 보여 주세요
[1, 2, 3, 4] (1, 2, 3, 4)

2. 딕셔너리(dict)

항목내용
딕셔너리키(key)와 값(value)이 짝을 이룬 자료형. 숫자 인덱스 대신 키로 값을 찾는다
만들기{} 또는 {키: 값, 키: 값}
조회dic[키]
추가·수정dic[키] = 값 — 없는 키면 추가, 있는 키면 덮어쓴다
삭제del dic[키]
키 확인키 in dic — 값이 아니라 키가 있는지 본다
모아 보기dic.keys() 키, dic.values() 값, dic.items() (키, 값) 쌍
없는 키 조회KeyError
 
dic = {}                                                   # dic 에 빈 딕셔너리를 담아 주세요
dic['dictionary'] = 'a book of words'                      # dic 의 'dictionary' 자리에 'a book of words' 를 담아 주세요
dic['python'] = 'a kind of snake'                          # dic 의 'python' 자리에 'a kind of snake' 를 담아 주세요
print(dic['dictionary'])                                   # dic 의 'dictionary' 자리에 담긴 것을 화면에 보여 주세요
smalldic = {'dictionary': 'reference', 'python': 'snake'}  # smalldic 에 두 쌍이 든 딕셔너리를 담아 주세요
print(smalldic['python'])                                  # smalldic 의 'python' 자리에 담긴 것을 화면에 보여 주세요
del smalldic['dictionary']                                 # smalldic 의 'dictionary' 쌍을 지워 주세요

※ 위 코드에서 in 을 쓴 세 줄(코드 끝에 붉은 ※)의 결과가 True, False, False 인 이유: in 은 "있나?"만 묻고 True / False 로 답한다. 값을 꺼내는 것이 아니다. 'dad' in family 는 True, 값 'Choi' 를 꺼내려면 family['dad'] 를 쓴다. 'Kim' in family 는 'Kim' 이 키가 아니라 값이라서 False 이고, 값에 있는지 보려면 'Kim' in family.values() 로 쓴다.

d = {'a': 1, 'a': 2}                    # d 에 키 'a' 를 두 번 쓴 딕셔너리를 담아 주세요

    print(family['sister'])             # family 의 'sister' 자리에 담긴 것을 화면에 보여 주세요
except KeyError as e:                   # KeyError 가 나면 그 오류를 e 라고 부르며
    print('KeyError:', e)               # 'KeyError:' 와 e 를 화면에 보여 주세요

3. 세트(set)

항목내용
세트중복이 없고 순서가 없는 모음
만들기{'apple', 'banana'} — 중괄호 안에 값만 나열
빈 세트set() — {}는 빈 딕셔너리
추가s.add(값) — 이미 있으면 그대로
교집합 · 합집합 · 차집합a & b · a | b · a - b
리스트의 중복 없애기set(리스트)
 
fruits = {'apple', 'banana', 'orange'}        # fruits 에 'apple', 'banana', 'orange' 세트를 담아 주세요

companies = {'apple', 'microsoft', 'google'}  # companies 에 'apple', 'microsoft', 'google' 세트를 담아 주세요

print(sorted(fruits & companies))             # fruits 와 companies 의 교집합을 정렬해서 화면에 보여 주세요

print(sorted(fruits - companies))             # fruits 에서 companies 를 뺀 차집합을 정렬해서 화면에 보여 주세요
